# 科學批判性思維

## 概述

批判性思維是評估科學嚴謹性的系統化流程。運用GRADE與Cochrane ROB框架檢驗研究方法、實驗設計、統計有效性、偏誤、干擾因素及證據品質。此技能適用於對科學主張進行批判性分析。

## 使用時機

本技能適用於：
- 評估研究方法與實驗設計
- 檢驗統計有效性與證據品質
- 識別研究中的偏誤與干擾因素
- 審查科學主張與結論
- 執行系統性文獻回顧或統合分析
- 應用GRADE或Cochrane偏誤風險評估
- 提供研究論文的批判性分析

## 核心能力

### 1. 方法論批判

評估研究方法的嚴謹性、有效性與潛在缺陷。

**適用情境：**
- 審查研究論文
- 評估實驗設計
- 檢驗研究方案
- 規劃新研究

**評估框架：**

1. **研究設計評估**
   - 設計是否符合研究問題？
   - 設計能否支持因果主張？
   - 對照組是否適當且充分？
   - 考量實驗性、準實驗性或觀察性設計的合理性

2. **有效性分析**
   - **內部效度：** 因果推論是否可信？
     - 檢驗隨機化品質
     - 評估干擾因素控制
     - 檢視選擇偏誤
     - 審查流失/退出模式
   - **外部效度：** 結果是否具普遍性？
     - 評估樣本代表性
     - 考量環境生態效度
     - 檢驗條件是否符合目標應用場景
   - **建構效度：** 測量是否捕捉目標構念？
     - 審查測量驗證過程
     - 檢核操作型定義
     - 評估測量屬直接或代理指標
   - **統計結論效度：** 統計推論是否嚴謹？
     - 驗證統計檢定力/樣本量充足性
     - 檢核假設合規性
     - 評估檢驗方法適當性

3. **控制與盲法**
   - 隨機化是否正確實施（序列生成、分配隱蔽）？
   - 盲法是否可行且執行（受試者、執行者、評估者）？
   - 對照條件是否適當（安慰劑、活性對照、無治療）？
   - 執行偏誤或檢測偏誤是否影響結果？

4. **測量品質**
   - 工具是否經驗證且可靠？
   - 測量是否盡可能客觀，或主觀測量有明確限制說明？
   - 結果評估是否標準化？
   - 是否採用多重測量交叉驗證？

**參考：** 詳見`references/scientific_method.md`原則文件與`references/experimental_design.md`設計檢核表。

### 2. 偏誤偵測

識別並評估可能扭曲研究結果的潛在偏誤來源。

**適用情境：**
- 審查已發表研究
- 設計新研究
- 解讀矛盾證據
- 評估研究品質

**系統性偏誤審查：**

1. **認知偏誤（研究者）**
   - **確認偏誤：** 是否僅強調支持性發現？
   - **HARKing：** 假設是否預先聲明或結果後形成？
   - **發表偏誤：** 文獻是否缺失陰性結果？
   - **揀選偏誤：** 證據是否選擇性報告？
   - 檢驗預註冊與分析計畫透明度

2. **選擇偏誤**
   - **抽樣偏誤：** 樣本是否代表目標群體？
   - **志願者偏誤：** 參與者是否系統性自選？
   - **流失偏誤：** 組間退出率是否有差異？
   - **倖存者偏誤：** 樣本是否僅含「倖存者」？
   - 檢視受試者流程圖與基線特徵比較

3. **測量偏誤**
   - **觀察者偏誤：** 預期是否影響觀察結果？
   - **回憶偏誤：** 回溯性報告是否系統性失準？
   - **社會期許偏誤：** 回應是否傾向可接受答案？
   - **工具偏誤：** 測量工具是否系統性誤差？
   - 評估盲法、驗證與測量客觀性

4. **分析偏誤**
   - **P值操縱：** 是否重複分析直至顯著？
   - **結果替換：** 是否用顯著結果替代未顯著指標？
   - **選擇性報告：** 是否報告所有預定分析？
   - **亞組挖掘：** 是否未校正即進行亞組分析？
   - 比對研究註冊與發表結果

5. **干擾因素**
   - 哪些變量可能同時影響暴露與結果？
   - 干擾因素是否測量並控制（統計或設計層面）？
   - 未測量干擾因素能否解釋結果？
   - 是否存在合理替代解釋？

**參考：** 詳見`references/common_biases.md`偏誤分類與偵測緩解策略。

### 3. 統計分析評估

批判性檢驗統計方法、解讀與報告。

**適用情境：**
- 審查量化研究
- 評估數據驅動主張
- 檢驗臨床試驗結果
- 審查統合分析

**統計審核查表：**

1. **樣本量與檢定力**
   - 是否執行事前檢定力分析？
   - 樣本是否足以檢測有意義效應？
   - 研究是否檢定力不足（常見問題）？
   - 小樣本顯著結果是否暗示效應量膨脹？

2. **統計檢驗**
   - 檢驗方法是否符合資料類型與分布？
   - 是否檢驗並滿足假設條件？
   - 參數檢驗是否合理？或應採用無母數檢驗？
   - 分析是否匹配研究設計（如配對vs獨立）？

3. **多重比較**
   - 是否檢驗多重假設？
   - 是否應用校正（Bonferroni、FDR等）？
   - 主要結果是否與次要/探索性結果區分？
   - 結果是否可能為多重檢驗假陽性？

4. **P值解讀**
   - P值是否正確解讀（虛無假設成立時數據出現機率）？
   - 是否將未顯著誤解為「無效應」？
   - 是否混淆統計顯著性與實務重要性？
   - 是否報告精確P值，或僅標註「p < .05」？
   - P值是否異常聚集於.05臨界值下方？

5. **效應量與信賴區間**
   - 是否同時報告效應量與顯著性？
   - 是否提供信賴區間顯示精確度？
   - 效應量是否具實務意義？
   - 標準化效應量是否結合領域背景解讀？

6. **缺失數據**
   - 缺失數據比例？
   - 是否考量缺失機制（MCAR、MAR、MNAR）？
   - 如何處理缺失數據（刪除、插補、最大概似法）？
   - 缺失數據是否導致偏誤？

7. **迴歸與建模**
   - 模型是否過度擬合（預測因子過多、未交叉驗證）？
   - 是否超出資料範圍預測（外推）？
   - 是否處理多重共線性問題？
   - 是否檢驗模型假設？

8. **常見陷阱**
   - 相關性視為因果關係
   - 忽略均值回歸現象
   - 忽略基礎率
   - 德州神槍手謬誤（在雜訊中尋找模式）
   - 辛普森悖論（亞組干擾）

**參考：** 詳見`references/statistical_pitfalls.md`常見陷阱與正確實踐。

### 4. 證據品質評估

系統性評估證據強度與品質。

**適用情境：**
- 權衡決策證據
- 執行文獻回顧
- 比較矛盾發現
- 判定結論可信度

**證據評估框架：**

1. **研究設計階層**
   - 系統性文獻回顧/統合分析（干預效應最高等級）
   - 隨機對照試驗
   - 世代研究
   - 病例對照研究
   - 橫斷面研究
   - 病例系列/報告
   - 專家意見（最低等級）

   **注意：** 高階設計未必品質更佳。設計良好的觀察性研究可能優於執行不佳的RCT。

2. **同類設計品質差異**
   - 偏誤風險評估（採用適當工具：Cochrane ROB、Newcastle-Ottawa等）
   - 方法學嚴謹度
   - 透明度與報告完整性
   - 利益衝突

3. **GRADE考量（如適用）**
   - 從設計類型起始（RCT=高品質，觀察性=低品質）
   - **降級因素：**
     - 偏誤風險
     - 研究間不一致性
     - 間接性（錯誤群體/干預/結果）
     - 不精確性（寬信賴區間、小樣本）
     - 發表偏誤
   - **升級因素：**
     - 大效應量
     - 劑量反應關係
     - 干擾因素可能減弱（非增強）效應

4. **證據收斂性**
   - **強化證據：**
     - 多重獨立重複驗證
     - 不同研究團隊與環境
     - 多元方法導向相同結論
     - 機制性與實證證據一致
   - **弱化證據：**
     - 單一研究或團隊
     - 文獻存在矛盾發現
     - 明顯發表偏誤
     - 無重複驗證嘗試

5. **情境因素**
   - 生物/理論合理性
   - 與既有知識一致性
   - 時序性（因先於果）
   - 關係特異性
   - 關聯強度

**參考：** 詳見`references/evidence_hierarchy.md`證據階層、GRADE系統與品質評估工具。

### 5. 邏輯謬誤識別

偵測並指認科學論證中的邏輯錯誤。

**適用情境：**
- 評估科學主張
- 審查討論/結論章節
- 檢視科普傳播內容
- 識別缺陷推理

**科學常見謬誤：**

1. **因果謬誤**
   - **後此謬誤：** 「B發生於A後，故A導致B」
   - **相關即因果：** 混淆關聯與因果
   - **倒置因果：** 錯認因果方向
   - **單因謬誤：** 將複雜結果歸因單一因素

2. **概括謬誤**
   - **草率概括：** 小樣本推廣結論
   - **軼事謬誤：** 以個人經歷為證
   - **揀選證據：** 僅選支持性證據
   - **生態謬誤：** 將群體模式套用個體

3. **權威與來源謬誤**
   - **訴諸權威：** 「專家所言即真理」（無證據支持）
   - **人身攻擊：** 攻擊對象而非論點
   - **起源謬誤：** 依來源而非價值判斷
   - **訴諸自然：** 「天然=安全/有益」

4. **統計謬誤**
   - **忽略基礎率：** 漠視先驗機率
   - **德州神槍手：** 在隨機數據中尋找模式
   - **多重比較：** 未校正多重檢驗
   - **檢察官謬誤：** 混淆P(E|H)與P(H|E)

5. **結構謬誤**
   - **假兩難：** 忽略其他選項的「非A即B」
   - **移動門柱：** 達標後更改證據標準
   - **循環論證：** 預設結論為前提
   - **稻草人：** 曲解論點加以攻擊

6. **科學特定謬誤**
   - **伽利略牌：** 「他們曾嘲笑伽利略，故我的邊緣理論正確」
   - **訴諸無知：** 「未被證偽即為真」
   - **烏托邦謬誤：** 拒絕不完美方案
   - **不可證偽性：** 提出無法檢驗的主張

**謬誤識別要點：**
- 指認具體謬誤類型
- 解釋推理缺陷所在
- 說明有效推論所需證據
- 注意：謬誤推理不證明結論錯誤，僅表明該論證無效

**參考：** 詳見`references/logical_fallacies.md`謬誤案例庫與偵測策略。

### 6. 研究設計指引

提供規劃嚴謹研究的建設性指導。

**適用情境：**
- 協助設計新實驗
- 規劃研究專案
- 審查研究提案
- 優化研究方案

**設計流程：**

1. **研究問題精煉**
   - 確保問題具體、可解答、可證偽
   - 驗證是否解決文獻缺口或矛盾
   - 確認可行性（資源、倫理、時程）
   - 操作型定義變量

2. **設計選擇**
   - 匹配問題與設計（因果→實驗性；關聯→觀察性）
   - 考量可行性與倫理限制
   - 選擇受試者間、受試者內或混合設計
   - 測試多因子時規劃因子設計

3. **偏誤最小化策略**
   - 盡可能實施隨機化
   - 規劃各層級盲法（受試者、執行者、評估者）
   - 識別並控制干擾因素（隨機化、匹配、分層、統計調整）
   - 標準化所有流程
   - 規劃減少受試者流失

4. **樣本規劃**
   - 執行事前檢定力

- 建议在必要时使用适当的模糊限制语
- 区分数据（所发现的内容）和解释（其含义）

## 应用指南

### 总体方法

1. **保持建设性**
   - 指出优点和缺点
   - 提出改进建议而不仅仅是批评
   - 区分致命缺陷和微小局限
   - 承认所有研究都存在局限性

2. **保持具体性**
   - 指向具体实例（例如，“表2显示...”或“在方法部分...”）
   - 引用有问题的陈述
   - 提供问题的具体示例
   - 引用被违反的具体原则或标准

3. **保持适度性**
   - 使批评的严重性与问题的重要性相匹配
   - 区分有效性的主要威胁和次要问题
   - 考虑问题是否影响主要结论
   - 承认自身评估中的不确定性

4. **应用一致标准**
   - 对所有研究使用相同标准
   - 不对不认同的研究结果应用更严格标准
   - 承认自身潜在偏见
   - 基于方法论而非结果进行判断

5. **考虑背景**
   - 承认实际和伦理约束
   - 考虑领域内关于效应大小和方法的规范
   - 区分探索性与验证性背景
   - 在评估研究时考虑资源限制

### 提供批评时

**将反馈结构化为：**

1. **摘要：** 对所评估内容的简要概述
2. **优点：** 做得好的地方（对可信度和学习很重要）
3. **关注点：** 按严重性组织的问题
   - 关键问题（威胁主要结论的有效性）
   - 重要问题（影响解释但非致命）
   - 次要问题（值得注意但不改变结论）
4. **具体建议：** 可操作的改进建议
5. **总体评估：** 关于证据质量和可得出结论的平衡结论

**使用精确术语：**
- 指出具体的偏见、谬误和方法论问题
- 引用已建立的标准和指南
- 引用科学方法论中的原则
- 准确使用技术术语

### 不确定时

- **承认不确定性：** “可能是X或Y；需要补充Z信息”
- **提出澄清性问题：** “是否执行了[方法细节]？这会影响解释”
- **提供有条件评估：** “若执行了X，则Y成立；否则需关注Z”
- **注明解决不确定性所需的额外信息**

- **`references/scientific_method.md`** - 科学方法论核心原则、科学过程、批判性评估标准、科学主张中的危险信号、因果推断标准、同行评审及开放科学原则

- **`references/common_biases.md`** - 认知、实验、方法论、统计和分析偏见的综合分类，含检测与缓解策略

- **`references/statistical_pitfalls.md`** - 常见统计错误和误解，包括p值误读、多重比较问题、样本量问题、效应量错误、相关/因果混淆、回归陷阱及荟萃分析问题

- **`references/evidence_hierarchy.md`** - 传统证据等级、GRADE系统、研究质量评估标准、领域特定考量、证据综合原则及实用决策框架

- **`references/logical_fallacies.md`** - 科学论述中常见的逻辑谬误，按类型（因果、概括、权威、相关性、结构、统计）分类，含示例与检测策略

- **`references/experimental_design.md`** - 全面实验设计检查清单，涵盖研究问题、假设、研究设计选择、变量、抽样、盲法、随机化、对照组、流程、测量、偏见最小化、数据管理、统计规划、伦理考量、有效性威胁及报告标准

**何时查阅参考资料：**
- 需要详细框架时将参考资料载入上下文
- 使用grep搜索特定主题：`grep -r "pattern" references/`
- 参考资料提供深度；SKILL.md提供流程指导
- 查阅参考资料获取完整列表、详细标准和具体示例

## 谨记

**科学批判性思维关乎：**
- 运用既定原则进行系统评估
- 推动科学进步的建设性批评
- 与证据强度相称的信心
- 对不确定性和局限性的透明态度
- 标准的一致应用
- 承认所有研究均有局限性
- 在怀疑精神与证据开放性间保持平衡

**始终区分：**
- 数据（观察所得）与解释（其含义）
- 相关性与因果关系
- 统计显著性与实际重要性
- 探索性与验证性发现
- 已知与未知
- 反对主张的证据与支持零假设的证据

**批判性思维目标：**
1. 准确识别优缺点
2. 确定支持的结论
3. 认识局限性与不确定性
4. 为未来工作提出改进建议
5. 推动科学理解
