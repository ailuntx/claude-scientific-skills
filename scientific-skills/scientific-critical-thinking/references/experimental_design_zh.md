# 实验设计检查清单

## 研究问题构建

### 问题表述是否清晰？
- [ ] **具体性：** 明确定义变量及相互关系
- [ ] **可解答性：** 可用现有方法解决
- [ ] **相关性：** 填补知识空白或满足实际需求
- [ ] **可行性：** 资源、时间和伦理条件允许
- [ ] **可证伪性：** 若错误可被证伪

### 是否完成文献综述？
- [ ] 确认已知研究成果
- [ ] 发现待解决的空白或矛盾
- [ ] 借鉴方法论成功与失败经验
- [ ] 确定合适的结局指标
- [ ] 明确领域内典型效应量

## 假设建立

### 假设是否可检验？
- [ ] 提出具体量化预测
- [ ] 变量具备操作化定义
- [ ] 明确预期关系的方向/性质
- [ ] 可通过潜在观察证伪

### 假设类型
- [ ] **零假设 (H₀)：** 不存在效应/关系
- [ ] **备择假设 (H₁)：** 存在效应/关系
- [ ] **方向性与非方向性：** 单尾检验 vs 双尾检验

## 研究设计选择

### 适用何种研究类型？

**实验性（干预）研究：**
- [ ] **随机对照试验 (RCT)：** 因果关系的金标准
- [ ] **准实验设计：** 非随机分组但实施干预
- [ ] **组内设计：** 相同参与者经历所有条件
- [ ] **组间设计：** 不同参与者分配至不同条件
- [ ] **因子设计：** 包含多个自变量
- [ ] **交叉设计：** 参与者顺序接受多种干预

**观察性研究：**
- [ ] **队列研究：** 长期追踪群体
- [ ] **病例对照研究：** 比较有无结局的群体
- [ ] **横断面研究：** 单时间点快照
- [ ] **生态学研究：** 基于群体水平数据

**需考虑：**
- [ ] 能否随机分配参与者？
- [ ] 能否操纵自变量？
- [ ] 结局是否罕见（倾向病例对照）或常见？
- [ ] 是否需要确定时间序列？
- [ ] 伦理与实际限制下的可行性？

## 变量控制

### 自变量（操纵/预测变量）
- [ ] 明确定义与操作化
- [ ] 选择适当水平/类别
- [ ] 操纵强度足以检验假设
- [ ] 计划操纵检查（如适用）

### 因变量（结局/响应变量）
- [ ] 直接测量目标构念
- [ ] 测量工具经过效度信度验证
- [ ] 灵敏度可检测预期效应
- [ ] 适用于计划统计方法
- [ ] 明确指定主要结局指标

### 控制变量
- [ ] **识别混杂变量：**
  - 同时影响自变量与因变量的变量
  - 研究结果的替代解释
- [ ] **控制策略：**
  - 随机化
  - 匹配
  - 分层
  - 统计校正
  - 限制（纳入/排除标准）
  - 盲法

### 额外变量
- [ ] 识别潜在干扰源
- [ ] 标准化流程以最小化影响
- [ ] 控制环境因素
- [ ] 统一时间、场地、设备

## 抽样设计

### 总体定义
- [ ] **目标总体：** 拟推论的群体
- [ ] **可及总体：** 实际可抽样群体
- [ ] **样本：** 实际参与者
- [ ] 记录上述差异

### 抽样方法
- [ ] **概率抽样（优先保证可推广性）：**
  - 简单随机抽样
  - 分层抽样
  - 整群抽样
  - 系统抽样
- [ ] **非概率抽样（常用但限制可推广性）：**
  - 便利抽样
  - 目的抽样
  - 滚雪球抽样
  - 配额抽样

### 样本量
- [ ] **进行先验功效分析**
  - 预期效应量（来自文献或预实验）
  - 期望功效（通常0.80或0.90）
  - 显著性水平（通常0.05）
  - 拟采用的统计检验
- [ ] 考虑预期脱落率
- [ ] 满足计划亚组分析需求
- [ ] 说明实际限制条件

### 纳入/排除标准
- [ ] 明确定义并论证合理性
- [ ] 不过度严格（限制可推广性）
- [ ] 基于理论或实际考量
- [ ] 处理伦理问题
- [ ] 记录并一致执行

## 盲法与随机化

### 随机化
- [ ] **随机化对象：**
  - 参与者分组
  - 条件顺序（组内设计）
  - 呈现的刺激/项目
- [ ] **随机化方法：**
  - 计算机生成随机数
  - 随机数字表
  - 抛硬币（极小规模研究）
- [ ] **分配隐藏：**
  - 招募前生成序列
  - 入组后揭晓分配
  - 使用编号密封信封（如需要）
- [ ] **分层随机化：**
  - 平衡组间重要变量
  - 区组随机确保组间均衡
- [ ] **随机化检验：**
  - 基线比较组间差异
  - 报告任何显著差异

### 盲法
- [ ] **单盲：** 参与者不知分组
- [ ] **双盲：** 参与者与研究者均不知
- [ ] **三盲：** 参与者、研究者、数据分析师均不知
- [ ] **盲法可行性：**
  - 是否可实现真盲？
  - 需要安慰剂/假手术对照？
  - 干预措施外观是否一致？
- [ ] **盲法检验：**
  - 评估盲法维持情况
  - 让参与者/研究者猜测分组

## 对照组与条件

### 对照类型
- [ ] **无处理对照：** 自然病程对照
- [ ] **安慰剂对照：** 惰性治疗对照
- [ ] **阳性对照：** 标准治疗对照
- [ ] **等待列表对照：** 延迟治疗对照
- [ ] **注意对照：** 匹配接触时间但无活性成分

### 多条件设计
- [ ] 因子设计检验多因素
- [ ] 剂量反应关系评估
- [ ] 成分分析验证机制

## 操作流程

### 方案制定
- [ ] **详细书面方案：**
  - 分步操作流程
  - 标准化指导语脚本
  - 问题处理决策规则
  - 数据采集表格
- [ ] 正式研究前进行预实验
- [ ] 人员培训达标
- [ ] 计划依从性监测

### 标准化
- [ ] 统一参与者指导语
- [ ] 统一设备与材料
- [ ] 尽可能统一环境
- [ ] 统一评估时间点
- [ ] 记录方案偏离情况

### 数据收集
- [ ] **收集时点：**
  - 基线测量
  - 干预后测量
  - 随访时间点
- [ ] **执行人员：**
  - 培训合格的研究者
  - 尽可能实施盲法
  - 建立评估者间信度
- [ ] **收集方式：**
  - 有效可靠的工具
  - 标准化实施流程
  - 多方法交叉验证（如可能）

## 测量方法

### 效度
- [ ] **表面效度：** 看似测量目标构念
- [ ] **内容效度：** 覆盖构念所有维度
- [ ] **效标效度：** 与金标准相关性
  - 同时效度
  - 预测效度
- [ ] **构念效度：** 测量理论构念
  - 收敛效度（与相关测量相关）
  - 区分效度（与无关测量不相关）

### 信度
- [ ] **重测信度：** 时间一致性
- [ ] **内部一致性：** 条目测量相同构念（Cronbach's α）
- [ ] **评估者间信度：** 评估者间一致性（Cohen's κ, ICC）
- [ ] **平行版本信度：** 替代版本一致性

### 测量考量
- [ ] 尽可能采用客观测量
- [ ] 优先使用验证工具
- [ ] 关键构念多指标测量
- [ ] 考虑对变化的敏感性
- [ ] 避免地板/天花板效应
- [ ] 选择适当应答形式
- [ ] 设置合理回忆周期
- [ ] 考虑文化适应性

## 偏倚控制

### 选择偏倚
- [ ] 尽可能随机抽样
- [ ] 明确定义合格标准
- [ ] 记录拒绝者及原因
- [ ] 减少自选择

### 实施偏倚
- [ ] 标准化操作流程
- [ ] 干预实施者设盲
- [ ] 监测方案依从性
- [ ] 记录操作偏离

### 检测偏倚
- [ ] 结局评估者设盲
- [ ] 尽可能采用客观测量
- [ ] 标准化评估流程
- [ ] 多评估者信度检验

### 脱落偏倚
- [ ] 减少脱落的策略
- [ ] 追踪脱落原因
- [ ] 比较脱落者与完成者
- [ ] 计划意向性治疗分析

### 报告偏倚
- [ ] 预注册研究与分析方案
- [ ] 区分主要与次要结局
- [ ] 承诺报告所有结局
- [ ] 区分预设分析与探索性分析

## 数据管理

### 数据收集
- [ ] 设计测试数据采集表
- [ ] 使用REDCap/Qualtrics等平台
- [ ] 设置范围检查与验证规则
- [ ] 定期备份
- [ ] 安全存储（符合HIPAA/GDPR）

### 数据质量
- [ ] 实时数据验证
- [ ] 定期质量检查
- [ ] 监测缺失数据模式
- [ ] 识别调查异常值
- [ ] 记录方案偏离

### 数据安全
- [ ] 去标识化流程
- [ ] 访问权限控制
- [ ] 审计追踪
- [ ] 符合监管要求（IRB, HIPAA, GDPR）

## 统计分析规划

### 分析方案（数据收集前预设）
- [ ] **主要分析：**
  - 明确统计检验方法
  - 清晰陈述假设
  - 设定显著性水平（通常α=0.05）
  - 单尾/双尾检验
- [ ] **次要分析：**
  - 明确标注为次要
  - 探索性分析特别注明
- [ ] **多重比较：**
  - 指定校正方法（如需要）
  - 主要结局控制I类错误

### 前提假设
- [ ] 识别统计检验前提
- [ ] 计划检验前提条件
- [ ] 准备非参数替代方法
- [ ] 考虑数据转换方案

### 缺失数据
- [ ] 预估缺失量
- [ ] 缺失机制（MCAR, MAR, MNAR）
- [ ] 处理策略：
  - 完整案例分析
  - 多重插补法
  - 最大似然法
- [ ] 计划敏感性分析

### 效应量
- [ ] 确定合适效应量指标
- [ ] 与p值同时报告
- [ ] 计划置信区间

### 统计软件
- [ ] 选定软件（R, SPSS, Stata, Python等）
- [ ] 记录版本号
- [ ] 提前准备分析脚本
- [ ] 公开可用（开放科学）

## 伦理考量

### 伦理审批
- [ ] 获得IRB/伦理委员会批准
- [ ] 研究注册（ClinicalTrials.gov等）
- [ ] 方案遵循《赫尔辛基宣言》

### 知情同意
- [ ] 自愿参与原则
- [ ] 提供易懂说明
- [ ] 披露风险与获益
- [ ] 无责退出权
- [ ] 说明隐私保护措施
- [ ] 告知补偿条款

### 风险获益评估
- [ ] 潜在获益大于风险
- [ ] 最小化风险
- [ ] 保护弱势群体
- [ ] 高风险研究实施数据安全监测

### 保密性
- [ ] 数据去标识化
- [ ] 安全存储
- [ ] 限制访问权限
- [ ] 报告避免再识别

## 效度威胁

### 内部效度（因果推断）
- [ ] **历史因素：** 测量间外部事件
- [ ] **成熟效应：** 参与者随时间自然变化
- [ ] **测试效应：** 重复测量影响
- [ ] **测量工具变化：** 测量方法随时间改变
- [ ] **均值回归：** 极端分数趋近均值
- [ ] **选择偏倚：** 基线组间差异
- [ ] **脱落偏倚：** 差异性退出
- [ ] **干预扩散：** 对照组接触干预要素

### 外部效度（可推广性）
- [ ] 样本代表总体
- [ ] 环境真实自然
- [ ] 干预符合现实实施
- [ ] 结局指标具生态效度
- [ ] 时间框架合理

### 构念效度（测量）
- [ ] 测量真实反映目标构念
- [ ] 操作匹配理论定义
- [ ] 无构念混淆
- [ ] 充分覆盖构念维度

### 统计结论效度
- [ ] 统计功效充足
- [ ] 满足检验前提
- [ ] 采用适当检验方法
- [ ] α水平设置合理
- [ ] 处理多重比较问题

## 报告与透明度

### 预注册
- [ ] 研究预注册（OSF, ClinicalTrials.gov, AsPredicted）
- [ ] 先验陈述假设
- [ ] 记录分析方案
- [ ] 区分验证性与探索性分析

### 报告规范
- [ ] **RCT：** CONSORT清单
- [ ] **观察性研究：** STROBE清单
- [ ] **系统综述：** PRISMA清单
- [ ] **诊断研究：** STARD清单
- [ ] **质性研究：** COREQ清单
- [ ] **病例报告：** CARE指南

### 透明度
- [ ] 报告所有测量工具
- [ ] 披露所有操纵措施
- [ ] 说明样本量确定依据
- [ ] 报告排除标准及数量
- [ ] 记录脱落情况
- [ ] 注明方案偏离
- [ ] 公开利益冲突

### 开放科学
- [ ] 计划数据共享（符合伦理时）
- [ ] 共享分析代码
- [ ] 公开研究材料
- [ ] 发布预印本
- [ ] 尽可能开放获取发表

## 研究后考量

### 数据分析
- [ ] 遵循预注册方案
- [ ] 明确标注偏离与探索性分析
- [ ] 检验统计前提
- [ ] 报告所有结局
- [ ] 报告效应量及CI，而非仅p值

### 结果解读
- [ ] 结论有数据支持
- [ ] 承认研究局限性
- [ ] 考虑替代解释
- [ ] 讨论可推广性
- [ ] 说明临床/实际意义

### 成果传播
- [ ] 无论结果均发表（减少发表偏倚）
- [ ] 会议报告成果
- [ ] 向参与者反馈结果（适当时）
- [ ] 通报相关利益方
- [ ] 提供通俗摘要

### 后续步骤
- [ ] 是否需要重复验证？
- [ ] 确定后续研究方向
- [ ] 规划机制研究
- [ ] 考虑临床应用

## 常见陷阱规避

- [ ] 未做功效分析→检验力不足
- [ ] 见数据后形成假设（HARKing）
- [ ] 可行时未实施盲法→偏倚
- [ ] p值操纵（数据捕捞、选择性停止）
- [ ] 多重检验未校正→假阳性
- [ ] 对照组设置不当
- [ ] 未处理混杂因素
- [ ] 使用未验证工具
- [ ] 高脱落率未处理
- [ ] 选择性报告结果
- [ ] 相关数据使用因果表述
- [ ] 忽略统计检验前提
- [ ] 未预注册助长文献偏倚
- [ ] 未披露利益冲突
