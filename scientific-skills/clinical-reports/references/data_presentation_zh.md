# 临床报告中的数据呈现

## 临床数据表格

### 表格设计原则

**通用准则：**
- 清晰简洁的标题描述表格内容
- 列标题包含单位
- 行标签左对齐，数据合理对齐（数值右对齐，文本左对齐）
- 脚注说明缩写、统计符号和特殊情况
- 统一小数位数（百分比通常1-2位，连续变量1-3位）
- 全文格式保持一致

**标题位置：**
- 位于表格上方
- 顺序编号（表1、表2等）
- 描述性足够强，可独立理解

**脚注符号（顺序）：**
- *, †, ‡, §, ||, ¶, #
- 或使用上标字母（a, b, c...）
- 若不会与参考文献混淆，可使用上标数字

**关键要素：**
- 各组样本量（N=）
- 连续变量：均值（标准差）、中位数（四分位距）、范围
- 分类变量：n（%）
- 不呈现基线比较的p值（存在争议但通常不建议）

  n（%）                       78 (52.0)   25 (17.2)   -         <0.001

**统计呈现：**
- 点估计值及精确度度量（标准误或置信区间）

- 注明显著性水平（如p<0.05, p<0.01, p<0.001）

## 临床数据图表

### 图表设计原则

**通用准则：**
- 图表下方标注清晰简洁的标题/图例
- 顺序编号（图1、图2等）
- 坐标轴标签包含单位
- 可读字号（最小8-10磅）
- 高分辨率（印刷300dpi，网页150dpi）
- 色盲友好配色方案
- 兼容黑白打印（使用不同符号/图案）

**图例说明：**
- 描述图表内容
- 解释符号、误差线和统计标注
- 定义缩写词
- 提供解读背景

### 卡普兰-迈耶生存曲线

**目的：** 展示时间-事件数据

**要素：**
- X轴：时间（周、月、年）
- Y轴：无事件生存概率（0至1或0%至100%）
- 不同治疗组的独立曲线
- 删失观测值标记（常用垂直刻度）
- 图表下方设置风险人数表
- 标注中位生存时间
- 对数秩检验p值
- 风险比及95%置信区间

**图例示例：**
```
图1. 总生存期的卡普兰-迈耶曲线

治疗组与对照组的卡普兰-迈耶总生存期估计。
刻度标记表示删失观测值。图表下方显示风险人数。
对数秩检验p<0.001。中位生存期：治疗组24.5个月（95%CI:22.1-26.8），
对照组18.2个月（95%CI:16.5-20.1）。风险比0.68（95%CI:0.55-0.84）。
```

### 森林图

**目的：** 展示亚组分析或荟萃分析结果

**要素：**
- 点估计值（方块或菱形）
- 符号大小与精确度（反方差）或样本量成比例
- 95%置信区间的水平线
- 无效效应垂直线（HR=1.0, OR=1.0或差值=0）
- 左侧标注亚组标签
- 右侧标注效应量数值
- 总体估计值（荟萃分析时）
- 异质性统计量（I², p值）

**图例示例：**
```
图2. 亚组治疗效应的森林图

预设亚组中治疗组相对于对照组主要终点的效应。
方块代表点估计值；水平线代表95%置信区间。
方块大小与亚组样本量成比例。菱形表示总体效应。
交互作用p值检验各亚组治疗效应的异质性。
```

### 箱线图

**目的：** 展示连续变量的分布

**要素：**
- 箱体：四分位距（25%至75%分位数）
- 箱内线：中位数
- 须线：延伸至1.5×IQR内的极端数据点
- 离群值：须线外的点（常以圆圈表示）
- X轴：分组或时间点
- Y轴：带单位的连续变量

### 带回归的散点图

**目的：** 展示两个连续变量的关系

**要素：**
- X轴：自变量
- Y轴：因变量
- 个体数据点
- 回归线（如适用）
- 回归方程
- R²值
- 斜率p值
- 回归线的95%置信区间（可选，以阴影区表示）

### 意大利面条图

**目的：** 展示个体随时间的变化轨迹

**要素：**
- X轴：时间
- Y轴：结局变量
- 个体患者连线（常为半透明）
- 平均轨迹（加粗线）
- 不同治疗组使用不同颜色

### 条形图

**目的：** 比较组间比例或均值

**要素：**
- 条形间清晰分隔
- 误差线（标准误或95%置信区间）
- Y轴从0开始（条形图勿截断）
- X轴标注分组标签
- Y轴标注数值及单位
- 标注统计显著性（p值或星号）

**避免：**
- 3D条形图（扭曲感知）
- 过度装饰
- 截断Y轴

### 折线图

**目的：** 展示随时间的变化趋势

**要素：**
- X轴：时间（等距间隔）
- Y轴：结局变量
- 不同组别的独立折线（不同颜色/图案）
- 数据点标记（圆圈、方块、三角）
- 各时间点误差线（标准误或95%置信区间）
- 图例标识组别
- 网格线（可选，浅灰色）

### 直方图

**目的：** 展示连续变量的分布

**要素：**
- X轴：变量（划分区间）
- Y轴：频数或密度
- 合适的区间宽度（不宜过少或过多）
- 叠加正态分布曲线（如检验正态性）

## 临床数据的特殊考量

### 比例呈现

**分子与分母：**
- 始终同时提供：25/100（25%）
- 勿仅呈现百分比（25%）

**百分比：**
- 若 n<100 则保留整数
- 若 n≥100 则保留一位小数
- 百分比始终不超过一位小数

**比例置信区间：**
- 使用威尔逊区间或精确二项分布（小样本优于沃尔德法）
- 始终以百分比形式报告

### 连续型数据呈现

**集中趋势度量：**
- 正态分布数据使用均值
- 偏态数据或有序数据使用中位数
- 分布不明确时同时报告两者

**离散程度度量：**
- **标准差 (SD)**：描述数据变异性
- **标准误 (SE)**：描述均值估计的精确度
- **95%置信区间**：推论统计首选
- **四分位距 (IQR)**：与中位数配合用于偏态数据
- **极差**：最小值至最大值

**使用场景：**
- 描述性统计 → 均值(SD) 或 中位数(IQR)
- 推论性统计 → 均值(95% CI) 或 均值(SE)
- 禁止单独使用 ± 符号（必须标注 SD/SE/CI）

### P值呈现规范

**报告准则：**
- 精确报告2-3位小数的p值（如p=0.042）
- 极小时使用p<0.001（禁用p=0.000）
- 禁用"NS"或"p=NS"表述
- 不显著结果需报告精确p值（如p=0.18，禁用p>0.05）
- 默认双尾检验（单尾需预先声明）
- 必要时进行多重比较校正
- 注明显著性阈值（默认α=0.05）

**避免：**
- p<0.05（应报告精确值）
- p=0.00（不可能值）
- 过多小数位（如p=0.04235891）

### 统计显著性标识

**选项：**
1. 表格中直接报告p值
2. 星号标注法（需附图例）：
   - *p<0.05
   - **p<0.01
   - ***p<0.001
3. 置信区间法（推荐首选）

### 置信区间

**报告规范：**
- 标准采用95% CI
- 格式：(下限, 上限)
- 或：下限至上限
- 或：下限-上限

**解读：**
- 差值CI排除0 → 显著
- 比值CI排除1 → 显著
- CI宽度反映精确度

### 缺失数据处理

**明确标注：**
- 脚注说明缺失数据
- 声明是否采用完整案例分析
- 若使用填补法需描述方法
- 分变量报告缺失数据量

### 小数位与舍入规则

**通用原则：**
- 按测量精度保留位数
- 同一表格内小数位一致
- p值保留2-3位小数
- 百分比保留0-1位小数
- 均值/中位数保留1-2位小数
- 保留有效数字

## 图表制作软件

**统计软件：**
- R (ggplot2) - 高度可定制
- GraphPad Prism - 生物医学领域易用
- SAS/Stata/SPSS - 综合统计套件
- Python (matplotlib/seaborn) - 灵活强大

**通用图形软件：**
- Adobe Illustrator - 出版级专业工具
- Inkscape - 免费矢量编辑器
- PowerPoint - 基础图表易操作
- BioRender - 生物示意图专用

## 配色方案

**色盲友好调色板：**
- 避免红绿组合
- 采用蓝橙/蓝黄搭配
- 添加形状/纹理差异
- 灰度模式测试图表

**推荐方案：**
- ColorBrewer（数据可视化专用）
- Viridis（感知均匀）
- IBM色盲安全调色板

## 图像质量标准

**分辨率：**
- 印刷出版：300 dpi
- 网页/屏幕：150 dpi
- 图表优先矢量格式

**文件格式：**
- 印刷：TIFF/EPS
- 网页：PNG
- 矢量图：PDF
- 照片：高质量JPEG

**图像编辑：**
- 禁止篡改原始数据
- 仅允许全局调整：亮度/对比度/色彩平衡
- 记录所有调整步骤
- 按要求提供原始图像
