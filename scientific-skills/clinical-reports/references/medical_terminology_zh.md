# 医学术语与编码标准

## 标准化命名系统

### SNOMED CT（医学系统命名法 - 临床术语）

**目的：** 电子健康记录的综合性临床术语系统

**覆盖范围：**
- 临床表现
- 症状
- 诊断
- 操作流程
- 身体结构
- 微生物
- 物质
- 药品
- 标本

**结构：**
- 带唯一标识符的概念
- 描述（首选术语与同义词）
- 概念间关系
- 层级化组织

**示例：**
- 概念：心肌梗死
- SNOMED CT代码：22298006
- 上级概念：心脏疾病
- 下级概念：急性心肌梗死、陈旧性心肌梗死

**优势：**
- 实现语义互操作性
- 支持临床决策辅助
- 促进数据分析
- 国际标准

### LOINC（逻辑观测标识符命名与编码系统）

**目的：** 实验室及临床观测的通用编码系统

**LOINC代码组成要素：**
1. **成分**（分析物或测量项）：测量对象
2. **属性**：特征（质量、体积等）
3. **时间**：测量时点（即时、24小时）
4. **系统**：标本或系统（血清、尿液、动脉血）
5. **标度**：结果类型（定量、有序、名义）
6. **方法**：测量方式（与结果解读相关时）

**示例：**
- **血清或血浆中葡萄糖[质量/体积]**：2345-7
  - 成分：葡萄糖
  - 属性：质量浓度
  - 时间：即时
  - 系统：血清/血浆
  - 标度：定量

- **血液中糖化血红蛋白/总血红蛋白**：4548-4
  - 成分：糖化血红蛋白/总血红蛋白
  - 属性：质量分数
  - 时间：即时
  - 系统：血液
  - 标度：定量

**LOINC组成部分：**
- 文档类型
- 调查工具
- 临床附件
- 放射学编码
- 病理学编码

### ICD-10-CM（国际疾病分类第十版临床修订版）

**目的：** 用于计费、流行病学及健康统计的诊断与操作编码

**结构：**
- 字母数字代码（3-7位字符）
- 首位字符：字母（U除外）
- 第2-3位：数字
- 第4-7位：字母数字（第3位后为小数点）
- 指定偏侧性、严重程度、就诊类型

**代码结构示例：**
- **S72.001A**：右侧股骨颈未特指部位骨折，初次就诊
  - S：损伤类别
  - 72：股骨
  - 001：颈未特指部位
  - A：闭合性骨折初次就诊
  - 第5位"1"表示右侧

**常见类别：**
- A00-B99：传染病
- C00-D49：肿瘤
- E00-E89：内分泌、营养、代谢疾病
- F01-F99：精神和行为障碍
- G00-G99：神经系统疾病
- I00-I99：循环系统疾病
- J00-J99：呼吸系统疾病
- K00-K95：消化系统疾病
- M00-M99：肌肉骨骼系统疾病
- N00-N99：泌尿生殖系统疾病
- S00-T88：损伤、中毒

**第七位扩展符：**
- A：初次就诊
- D：后续就诊
- S：后遗症

**占位符X：**
- 当代码需7位但不足6位时使用
- 示例：T36.0X5A（青霉素不良反应，初次就诊）

**组合代码：**
- 单一代码描述两个诊断或诊断伴临床表现
- 示例：E11.21（2型糖尿病伴糖尿病肾病）

### CPT（现行操作术语）

**目的：** 操作与服务的计费编码

**维护机构：** 美国医学会（AMA）

**类别：**
- **I类**：操作与服务（5位数字代码）
- **II类**：绩效评估（4位数字+F）
- **III类**：新兴技术（4位数字+T）

**I类分项：**
- 00100-01999：麻醉
- 10000-69990：外科
- 70000-79999：放射学
- 80000-89999：病理学与实验室
- 90000-99999：内科
- 99000-99607：评估与管理（E/M）

**常用E/M代码：**
- **99201-99215**：门诊就诊（新患/复诊）
- **99221-99239**：住院服务
- **99281-99285**：急诊就诊
- **99291-99292**：重症监护
- **99304-99318**：护理机构服务

**修饰符：**
- 附加于CPT代码的两位代码
- 表示服务有调整但未改变性质
- 示例：
  - -25：显著且独立的E/M服务
  - -50：双侧操作
  - -59：独立操作服务
  - -76：同医师重复操作
  - -RT/LT：右侧/左侧

### RxNorm

**目的：** 临床药物及给药器械的标准化命名

**结构：**
- 包含品牌名与通用名
- 剂型
- 规格
- 关联其他药物词表（NDC、SNOMED CT）

**示例：**
- 概念：阿莫西林500毫克口服胶囊
- RxNorm CUI：308191
- 成分：阿莫西林
- 规格：500毫克
- 剂型：口服胶囊

## 医学缩写

### 可接受标准缩写

**时间：**
- q：每（q4h=每4小时）
- qd：每日（避免使用，改用"每日"）
- bid：每日两次
- tid：每日三次
- qid：每日四次
- qhs：睡前
- prn：按需
- ac：餐前
- pc：餐后
- hs：睡前

**给药途径：**
- PO：口服
- IV：静脉注射
- IM：肌内注射
- SC/SQ/subcut：皮下注射
- SL：舌下
- PR：直肠给药
- NG：鼻胃管
- GT：胃造瘘管
- TD：透皮
- inh：吸入

**频率：**
- stat：立即
- now：立即
- continuous：持续
- PRN：按需

**实验室：**
- CBC：全血细胞计数
- BMP：基础代谢套餐
- CMP：综合代谢套餐
- LFTs：肝功能测试
- PT/INR：凝血酶原时间/国际标准化比值
- PTT/aPTT：部分凝血活酶时间/活化PTT
- ESR：红细胞沉降率
- CRP：C反应蛋白
- ABG：动脉血气
- UA：尿液分析
- HbA1c：糖化血红蛋白

**诊断：**
- HTN：高血压
- DM：糖尿病
- CHF：充血性心力衰竭
- CAD：冠状动脉疾病
- COPD：慢性阻塞性肺疾病
- CVA：脑血管意外
- MI：心肌梗死
- PE：肺栓塞
- DVT：深静脉血栓
- UTI：尿路感染
- CKD：慢性肾脏病
- ESRD：终末期肾病

**体格检查：**
- HEENT：头眼耳鼻喉
- PERRLA：瞳孔等大等圆，对光及调节反射存在
- EOMI：眼球运动正常
- JVP：颈静脉压
- RRR：心律齐
- CTAB：双肺听诊清音
- BS：肠鸣音或呼吸音（依语境）
- NT/ND：无压痛/无膨隆
- FROM：关节活动度正常

**生命体征：**
- BP：血压
- HR：心率
- RR：呼吸频率
- T或Temp：体温
- SpO2：血氧饱和度
- Wt：体重
- Ht：身高
- BMI：体重指数

### 禁用缩写（联合委员会）

**禁用缩写：**

| 缩写 | 原意 | 问题 | 替代写法 |
|------|------|------|----------|
| U | 单位 | 易误认为0、4或cc | 写"单位" |
| IU | 国际单位 | 易误认作IV或10 | 写"国际单位" |
| Q.D., QD, q.d., qd | 每日 | 相互混淆 | 写"每日" |
| Q.O.D., QOD, q.o.d., qod | 隔日 | 易误认作QD或QID | 写"隔日" |
| 尾随零（X.0 mg） | X mg | 小数点易遗漏 | 小数点后不写零（写X mg） |
| 前导零缺失（.X mg） | 0.X mg | 小数点易遗漏 | 小数点前加零（写0.X mg） |
| MS, MSO4, MgSO4 | 硫酸吗啡或硫酸镁 | 相互混淆 | 写"硫酸吗啡"或"硫酸镁" |

**其他问题缩写：**
- µg：微克（易误认为mg）→ 写"mcg"
- cc：立方厘米 → 写"mL"
- hs：半量或睡前 → 写"半量"或"睡前"
- TIW：每周三次 → 写"每周三次"
- SC, SQ：皮下 → 写"皮下"
- D/C：出院或停用 → 写完整词
- AS, AD, AU：左耳、右耳、双耳 → 写"左耳"、"右耳"、"双耳"
- OS, OD, OU：左眼、右眼、双眼 → 写"左眼"、"右眼"、"双眼"

## 药物命名规范

### 通用名与商品名

**最佳实践：** 医疗文书中使用通用名

**示例：**
- 对乙酰氨基酚（通用名） vs 泰诺（商品名）
- 布洛芬（通用名） vs 雅维、美林（商品名）
- 阿托伐他汀（通用名） vs 立普妥（商品名）
- 二甲双胍（通用名） vs 格华止（商品名）
- 赖诺普利（通用名） vs 捷赐瑞、普利宁（商品名）

**需注明商品名的情况：**
- 患者教育（便于识别）
- 无通用名的新药
- 治疗窗狭窄且生物等效性存疑的药物
- 生物制品

### 剂型

**固体口服：**
- 片剂
- 胶囊
- 囊片
- 咀嚼片
- 口腔崩解片（ODT）
- 缓释剂（ER, XR, SR）
- 肠溶剂（DR）

**液体口服：**
- 溶液
- 混悬液
- 糖浆
- 酏剂
- 滴剂

**注射剂：**
- 注射液
- 注射用粉末（需配制）
- 静脉输注液
- 肌内注射液
- 皮下注射液

**外用：**
- 乳膏
- 软膏
- 凝胶
- 洗剂
- 糊剂
- 贴剂（透皮）
- 泡沫剂
- 喷雾剂

**其他：**
- 栓剂（直肠、阴道）
- 吸入剂（MDI, DPI）
- 雾化溶液
- 眼用制剂（滴眼液、眼膏）
- 耳用制剂（滴耳液）
- 鼻喷雾剂

### 处方书写要素

**完整处方包含：**
1. 患者姓名与出生日期
2. 日期
3. 药品名称（首选通用名）
4. 规格/浓度
5. 剂型
6. 调配量
7. 用法说明（Sig）
8. 续配次数
9. 处方者签名与资质
10. DEA编号（管制药品）

**Sig（用法说明）：**
- 清晰具体的指导
- 给药途径
- 频率
- 疗程（如适用）
- 特殊说明

**示例：**
- "每日两次，每次一片，随餐口服，持续10天"
- "患处薄涂，每日三次"
- "清醒时每4小时每眼滴入1滴"

## 解剖学术语

### 方位术语

**上/下：**
- 上：朝向头部
- 下：朝向足部
- 颅侧：朝向头部
- 尾侧：朝向尾部/足部

**前/后：**
- 前：朝向腹侧
- 后：朝向背侧
- 腹侧：朝向腹部
- 背侧：朝向背部

**内侧/外侧：**
- 内侧：朝向中线
- 外侧：远离中线

**近端/远端：**
- 近端：靠近躯干或起点
- 远端：远离躯干或起点

**浅层/深层：**
- 浅层：朝向体表
- 深层：远离体表

### 解剖平面

**矢状面：** 将身体分为左右两部分
- 正中矢状面：正中央切面
- 旁矢状面：平行于正中面

**冠状面（额状面）：** 将身体分为前后两部分

**横断面（轴状面）：** 将身体分为上下两部分

### 标准解剖姿势

- 直立站立
- 双足平行
- 双臂自然下垂
- 掌心向前
- 面部朝前

## 实验室单位与换算

### 常用实验室单位

**血液学：**
- 红细胞：×10⁶/μL 或 ×10¹²/L
- 白细胞：×10³/μL 或 ×10⁹/L
- 血红蛋白：g/dL 或 g/L
- 血细胞比容：% 或 分数
- 血小板：×10³/μL 或 ×10⁹/L
- 平均红细胞体积：fL
- 平均红细胞血红蛋白浓度：g/dL 或 g/L

**化学：**
- 葡萄糖：mg/dL 或 mmol/L
- 血尿素氮：mg/dL 或 mmol/L
- 肌酐：mg/dL 或 μmol/L
- 钠、钾、氯：mEq/L 或 mmol/L
- 钙：mg/dL 或 mmol/L
- 白蛋白：g/dL 或 g/L
- 胆红素：mg/dL 或 μmol/L
- 胆固醇：mg/dL 或 mmol/L

**治疗药物浓度：**
- 通常：mcg/mL、ng/mL 或 μmol/L

### 单位换算（选录）

**葡萄糖：**
- mg/dL ÷ 18 = mmol/L
- mmol/L × 18 = mg/dL

**肌酐：**
- mg/dL × 88.4 = μmol/L
- μmol/L ÷ 88.4 = mg/dL

**胆红素：**
- mg/dL × 17.1 = μmol/L
- μmol/L ÷ 17.1 = mg/dL

**胆固醇：**
- mg/dL × 0.0259 = mmol/L
- mmol/L × 38.67 = mg/dL

**血红蛋白：**
- g/dL × 10 = g/L
- g/L ÷ 10 = g/dL

## 分级与分期系统

### 癌症分期（TNM）

**T（原发肿瘤）：**
- TX：无法评估
- T0：无原发肿瘤证据
- Tis：原位癌
- T1-T4：原发肿瘤大小/范围

**N（区域淋巴结）：**
- NX：无法评估
- N0：无区域淋巴结转移
- N1-N3：区域淋巴结受累

**M（远处转移）：**
- M0：无远处转移
- M1：存在远处转移

**分期组合：**
- 0期：Tis N0 M0
- I-III期：不同T/N组合，M0
- IV期：任意T/N，M1

### NYHA心力衰竭分级

- **I级**：无活动限制。日常体力活动不引发症状
- **II级**：轻度受限。静息舒适，日常活动引发症状

- **Ⅲ级**：明显受限。静息时舒适，轻微活动即诱发症状
- **Ⅳ级**：静息时即有症状，无法进行任何体力活动

### Child-Pugh评分（肝病）

**参数：** 胆红素、白蛋白、INR、腹水、脑病

**分级：**
- **A级（5-6分）**：代偿良好
- **B级（7-9分）**：显著功能失代偿
- **C级（10-15分）**：失代偿期

### 格拉斯哥昏迷量表

**睁眼反应（1-4分）：**
- 4分：自主睁眼
- 3分：呼唤睁眼
- 2分：疼痛刺激睁眼
- 1分：无反应

**言语反应（1-5分）：**
- 5分：定向正常
- 4分：言语混乱
- 3分：用词不当
- 2分：发音不清
- 1分：无反应

**运动反应（1-6分）：**
- 6分：遵嘱动作
- 5分：定位疼痛
- 4分：躲避疼痛
- 3分：异常屈曲
- 2分：异常伸展
- 1分：无反应

**总分：** 3-15分（3=最差，15=最佳）
- 重度：≤8分
- 中度：9-12分
- 轻度：13-15分

## 医学前缀与后缀

### 常用前缀

- **a-/an-**：无，缺乏（贫血、失语症）
- **brady-**：缓慢（心动过缓）
- **dys-**：异常，困难（呼吸困难、排尿困难）
- **hyper-**：过度，高于（高血压、高血糖）
- **hypo-**：低于，不足（低血压、低血糖）
- **poly-**：多（多尿症、烦渴）
- **tachy-**：快速（心动过速、呼吸急促）
- **macro-**：巨大（巨头畸形）
- **micro-**：微小（小头畸形）
- **hemi-**：半侧（偏瘫）
- **bi-/di-**：双（双侧、复视）

### 常用后缀

- **-algia**：疼痛（关节痛、神经痛）
- **-ectomy**：切除术（阑尾切除术、胆囊切除术）
- **-emia**：血液状态（贫血、白血病）
- **-itis**：炎症（阑尾炎、关节炎）
- **-oma**：肿瘤（癌、黑色素瘤）
- **-osis**：病理状态（肝硬化、骨质疏松）
- **-pathy**：疾病（神经病变、肾病）
- **-penia**：减少症（血小板减少、中性粒细胞减少）
- **-plasty**：成形术（鼻整形术、血管成形术）
- **-scopy**：镜检查（结肠镜检查、支气管镜检查）
- **-stomy**：造口术（结肠造口、气管造口）
