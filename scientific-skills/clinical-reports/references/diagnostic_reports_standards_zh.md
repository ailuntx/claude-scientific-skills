# 诊断报告标准

## 影像学报告标准

### 美国放射学会（ACR）指南

ACR为影像诊断报告提供全面的实践参数，以确保质量、一致性和沟通有效性。

#### 影像报告核心要素

**1. 患者人口统计学信息**
- 患者姓名和/或唯一标识符
- 出生日期或年龄
- 性别
- 病历号
- 检查日期与时间
- 转诊医师

**2. 检查项目**
- 具体实施的检查
- 解剖区域
- 侧别（右、左、双侧）
- 技术与方案
- 示例："脑部MRI平扫+增强"

**3. 临床指征**
- 检查原因
- 相关临床病史
- 具体临床问题
- ICD-10编码（如需要）
- 示例："头痛伴视觉障碍。排除颅内占位。"

**4. 对比分析**
- 既往相关影像研究
- 既往检查日期
- 既往检查模态
- 可对比性说明
- 示例："对比：6个月前（2023年1月15日）无增强头部CT"

**5. 技术参数**
- 成像参数与方案
- 造影剂使用详情：
  - 类型（碘剂、钆剂）
  - 途径（静脉、口服、直肠）
  - 使用剂量
  - 成像时间点
- 技术质量声明
- 辐射剂量（CT适用）
- 局限性或技术问题
- 示例：
  ```
  技术：通过脑部获取多平面T1/T2加权序列平扫及静脉增强成像。
  静脉注射钆基造影剂15mL。技术质量符合要求。
  ```

**6. 影像发现**
- 影像发现的系统性描述
- 按解剖区域或器官系统组织
- 异常测量值（尺寸、体积）
- 特定描述术语
- 相关阳性发现
- 相关阴性发现
- 与既往检查对比（如可行）

**组织方式：**
- 逐器官（腹部/盆腔）
- 逐区域（胸部）
- 逐系统（脊柱）
- 逐分区（肌肉骨骼）

**7. 印象/结论**
- 关键发现总结
- 诊断或鉴别诊断
- 临床问题解答
- 关注等级或紧急程度
- 与既往对比（改善/稳定/恶化）
- 进一步影像或临床处理建议
- 清晰简洁（常采用编号列表）

示例：
```
印象：
1. 右额叶3.2cm强化肿块伴周围血管源性水肿，高度提示高级别胶质瘤。
   不排除转移瘤可能。建议临床关联分析及组织取样。
2. 未见急性颅内出血或脑疝。
3. 建议神经外科会诊。
```

**8. 危急结果通报**
- 需立即处理的紧急或意外发现
- 与申请医师直接沟通的记录
- 口头沟通时间、日期及接收人
- 示例："危急结果：急性肺栓塞。已于[日期]14:35呼叫Smith医生。"

### 结构化报告系统

#### Lung-RADS（肺部CT筛查报告与数据系统）

用于肺癌筛查CT判读。

**分类：**
- **Lung-RADS 0**：不完整 - 需补充影像
- **Lung-RADS 1**：阴性 - 无结节或明确良性结节
- **Lung-RADS 2**：良性表现 - 恶性概率极低结节
- **Lung-RADS 3**：可能良性 - 建议短期随访
- **Lung-RADS 4A**：可疑 - 3个月随访或PET/CT
- **Lung-RADS 4B**：高度可疑 - 3个月随访或PET/CT，考虑活检
- **Lung-RADS 4X**：伴附加特征的高度可疑，考虑活检

**每类包含管理建议**

#### BI-RADS（乳腺影像报告与数据系统）

乳腺影像（钼靶、超声、MRI）标准化术语体系。

**分类：**
- **BI-RADS 0**：不完整 - 需补充影像
- **BI-RADS 1**：阴性 - 无异常
- **BI-RADS 2**：良性发现
- **BI-RADS 3**：可能良性 - 短期随访（6个月）
- **BI-RADS 4**：可疑 - 建议活检
  - 4A：低度可疑
  - 4B：中度可疑
  - 4C：高度可疑
- **BI-RADS 5**：高度提示恶性 - 建议活检
- **BI-RADS 6**：活检确诊恶性

**描述符：**
- 肿块：形态、边缘、密度
- 钙化：形态学、分布
- 不对称：类型与特征
- 相关表现

#### LI-RADS（肝脏影像报告与数据系统）

用于肝细胞癌高风险患者的肝脏观察报告。

**分类：**
- **LI-RADS 1**：明确良性
- **LI-RADS 2**：可能良性
- **LI-RADS 3**：恶性中等概率
- **LI-RADS 4**：可能肝细胞癌
- **LI-RADS 5**：明确肝细胞癌
- **LI-RADS M**：可能或明确恶性（非肝细胞癌特异性）
- **LI-RADS TIV**：静脉内瘤栓

**主要评估特征：**
- 尺寸
- 强化模式（动脉期高强化、廓清）
- 包膜表现
- 阈值增长

#### PI-RADS（前列腺影像报告与数据系统）

用于前列腺多参数MRI。

**评估分类：**
- **PI-RADS 1**：极低 - 临床显著癌可能性极低
- **PI-RADS 2**：低 - 临床显著癌可能性低
- **PI-RADS 3**：中等 - 不确定
- **PI-RADS 4**：高 - 临床显著癌可能性高
- **PI-RADS 5**：极高 - 临床显著癌可能性极高

**评估方法：**
- 外周区：以DWI/ADC为主要判定依据
- 移行区：以T2加权为主要判定依据
- DCE（动态增强）：用于外周区PI-RADS 3级病灶

### RadLex与标准化术语

**RadLex**是由北美放射学会（RSNA）开发的放射学综合术语体系。

**优势：**
- 标准化术语
- 提升沟通效率
- 支持数据挖掘与分析
- 促进决策支持系统
- 统一报告结构

**常用RadLex术语：**
- 解剖结构
- 影像学观察
- 疾病实体
- 操作流程

### 影像学测量

**线性测量：**
- 采用二维（长×宽）或三维（长×宽×高）
- 报告结节/肿块最大径
- 随访采用一致测量方法
- 尽可能垂直测量

**容积测量：**
- 对不规则病灶随访更准确
- 自动化/半自动化软件
- 尤其适用于肺结节

**疗效评估：**
- RECIST 1.1（实体瘤疗效评价标准）
  - 靶病灶：最长径总和（最多5个病灶，每器官2个）
  - 完全缓解、部分缓解、疾病稳定、疾病进展

## 病理报告标准

### 美国病理学家协会（CAP）方案

CAP癌症方案为癌症标本提供标准化摘要报告模板。

#### 摘要报告要素

**所有癌症标本核心要素：**

**1. 标本信息**
- 操作类型（活检、切除、根治术）
- 标本侧别
- 标本完整性与充分性

**2. 肿瘤部位**
- 解剖位置及亚部位
- 器官内精确定位

**3. 肿瘤大小**
- 最大径（厘米）
- 三维测量值（如适用）
- 测量方法（大体/镜下）

**4. 组织学类型**
- WHO分类
- 具体亚型
- 混合性肿瘤中各成分占比

**5. 组织学分级**
- 分级系统（如Nottingham、Fuhrman、Gleason）
- 分级类别（高/中/低分化 或 G1/G2/G3）
- 各组分评分（如适用）

**6. 浸润范围**
- 浸润深度（毫米）
- 邻近结构侵犯
- 脉管侵犯（存在/未发现）
- 神经侵犯（存在/未发现）

**7. 切缘**
- 最近切缘距离
- 各评估切缘状态（阴性/阳性）
- 阳性切缘具体位置

**8. 淋巴结**
- 检测淋巴结总数
- 转移淋巴结数量
- 最大转移灶尺寸
- 结外侵犯（存在/缺失）

**9. 病理分期（pTNM）**
- pT：原发肿瘤范围
- pN：区域淋巴结
- pM：远处转移（如已知）
- 所用AJCC癌症分期手册版本

**10. 附加发现**
- 治疗效果（如新辅助治疗后）
- 相关病变（异型增生、原位癌）
- 背景组织（肝硬化、炎症）

**11. 辅助检查**
- 免疫组化结果
- 分子/基因检测结果
- 生物标志物状态（如乳腺ER/PR/HER2；结肠MSI）
- FISH或其他细胞遗传学结果

#### 器官特异性CAP方案

**乳腺癌：**
- 组织学类型（浸润性导管癌、小叶癌、特殊类型）
- Nottingham分级（腺管形成、核多形性、核分裂计数）
- ER/PR状态（百分比与强度）
- HER2状态（IHC评分，必要时FISH）
- Ki-67增殖指数
- DCIS成分（如存在）
- 新辅助治疗反应（残余肿瘤负荷）

**结直肠癌：**
- 组织学类型（腺癌、粘液腺癌等）
- 分级
- 浸润深度（粘膜下层、固有肌层、结肠周组织等）
- 肿瘤沉积
- 淋巴结（阳性数/检测总数）
- 切缘（近端、远端、环周）
- MSI/MMR状态
- KRAS、NRAS、BRAF突变

**前列腺癌：**
- Gleason评分（主要+次要模式）
- 分级组别（1-5级）
- 组织受累百分比
- 前列腺外侵犯
- 精囊侵犯
- 手术切缘状态
- 淋巴结（如取样）

**肺癌：**
- 组织学类型（腺癌、鳞癌、小细胞癌等）
- 分级（非小细胞肺癌适用）
- 浸润深度
- 脏层胸膜侵犯
- 切缘距离
- 淋巴结
- 分子标志物（EGFR、ALK、ROS1、PD-L1）

### 大体病理描述

**核心要素：**
- 标本标签与标识
- 标本类型
- 尺寸与重量
- 方位标记（如存在）
- 外表面描述
- 切面表现
- 病灶描述：
  - 尺寸（三维）
  - 位置
  - 颜色
  - 质地
  - 边界（局限/浸润）
  - 距切缘距离
- 取样方法（组织切片与送检方式）

**示例：**
```
大体描述：
接收新鲜标本，标签为患者姓名及"左乳肿块切除术"。定向切除标本
尺寸8.5×6.0×4.0cm，缝线标记上切缘。墨染：上-蓝、下-黑、内-绿、
外-红、前-橙、后-黄。连续切片见质硬灰白肿块2.1×1.8×1.5cm，
距上切缘2.5cm、下切缘3.0cm、内侧切缘2.0cm、外侧切缘3.5cm、
前切缘1.5cm、后切缘1.8cm。代表性切片送检：A1-A3肿瘤组织、
A4上切缘、A5内侧切缘、A6后切缘。
```

### 镜下描述

**关键要素：**
- 组织结构模式
- 细胞学特征
  - 细胞类型
  - 核特征（大小、形态、染色质、核仁）
  - 胞浆特征
  - 核分裂活性
- 分化程度
- 浸润模式
- 特殊表现（坏死、出血、钙化）
- 间质与背景组织
- 脉管或神经侵犯
- 切缘（距离与状态）
- 淋巴结（转移灶描述）

### 冰冻切片报告

**适用场景：**
- 术中诊断
- 切缘评估
- 淋巴结评估
- 组织分选

**报告格式：**
- 明确标注"冰冻切片诊断"
- 术中会诊记录
- 冰冻切片时间
- 标本描述
- 冰冻切片诊断
- 备注："最终诊断以石蜡切片为准"

**冰冻切片免责声明：**
- 受冰冻伪影限制
- 最终诊断依据石蜡切片
- 建议以石蜡切片为确诊标准

### 诊断确定性表述

**确定性：**
- "符合..."
- "确诊为..."
- "阳性提示..."

**可能性：**
- "倾向..."
- "最可能为..."
- "符合..."

**不确定性：**
- "提示..."
- "不能排除..."
- "鉴别诊断包括..."

**待定：**
- "建议..."
- "需补充..."
- "待进一步检查..."

## 实验室报告标准

### 临床实验室标准协会（CLSI）指南

CLSI提供实验室检测与报告标准。

#### 实验室报告要素

**1. 患者人口统计学**
- 患者姓名与标识
- 出生日期或年龄
- 性别
- 申请医师

**2. 标本信息**
- 标本类型（全血、血清、血浆、尿液、脑脊液等）
- 采集日期与时间
- 接收日期与时间
- 标本状态
- 空腹状态（如相关）

**3. 检测信息**
- 检测全称（非缩写）
- 检测代码
- 检测方法
- 标本编号

**4. 结果**
- 定量数值及单位
- 定性结果（阳性/阴性、检出/未检出）
- 参考范围
- 异常结果标记
  - H = 偏高
  - L = 偏低
  - 危急值重点标注

**5. 参考区间**
- 年龄特异性
- 性别特异性
- 人群特异性（如适用）
- 方法特异性
- 单位明确标注

**示例：**
```
检测：糖化血红蛋白
结果：8.2%（H）
参考范围：4.0-5.6%（非糖尿病患者）
方法：高效液相色谱法
解读：符合糖尿病控制不良
```

**6. 解读性注释**
- 结果需背景说明时
- 建议补充检测
- 解释干扰或局限性
- 提供临床指导

**7. 质量控制**
- 差值核查（与既往值对比）
- 危急值及复述流程
- 标本质量问题（溶血、脂血、黄疸）
- 稀释操作说明
- 复测说明（如需要）

### LOINC（观测指标逻辑命名与编码系统）

实验室与临床观测指标的标准化编码系统。

**LOINC代码组成：**
- 成分（检测物）
- 属性（质量、物质浓度等）
- 时间（时点值、24小时值）
- 系统（标本类型）
- 标度（定量、有序、名义）
- 方法（如相关）

**示例：**
- 血液糖化血红蛋白：4548-4
- 血清/血浆葡萄糖：2345-7
- 血清/血浆肌酐：2160-0

### 危急值报告

**定义：** 提示危及生命需立即临床干预的检测结果。

**危急值示例：**
- 血糖：<40 mg/dL 或 >500 mg/dL
- 血钾：<2.5 mEq/L 或 >6.5 mEq/L
- 血钠：<120 mEq/L 或 >160 mEq/L
- 血钙：<6.0 mg/dL 或 >13.0 mg/dL
- 白细胞：<1.0 × 10³/μL 或 >50 × 10³/μL
- 血红蛋白：<5.0 g/dL
- 血小板：<20 × 10³/μL
- INR：>5.0（华法林治疗中）
- 血培养阳性
- 脑脊液培养或革兰染色阳性

**危急值处理流程：**
1. 实验室识别结果
2. 立即联系申请医师或其授权人
3. 复述确认
4. 记录：
   - 日期与时间
   - 联系人
   - 结果接收人
   - 检测项目与结果

5. 遵循无法联系到提供者时的机构政策

### 微生物学报告

**培养报告：**
- 样本类型与来源
- 已识别微生物
- 数量（少量、中等、大量生长）
- 抗菌药物敏感性结果
- 判读结果（敏感、中介、耐药）
- 适用时提供最低抑菌浓度（MIC）值

**革兰氏染色报告：**
- 存在细菌（革兰氏阳性/阴性，形态学特征）
- 数量与细胞背景
- 存在白细胞或其他细胞

**初步报告：**
- 最终鉴定前发布
- 明确标注"初步报告"
- 最终报告后续出具

**最终报告：**
- 明确微生物鉴定结果
- 完整的药敏试验组合
- 解释性注释

### 分子病理学/基因组学报告

**组成部分：**
- 检测基因
- 检出变异
- 分类（致病性、可能致病性、意义不明、可能良性、良性）
- 等位基因频率
- 检测方法（NGS、Sanger测序、PCR等）
- 参考序列
- 临床意义与解释
- 建议（治疗影响、家族检测）
- 检测局限性

**示例：**
```
检测项目: BRCA1/BRCA2全基因测序
结果: 检出致病性变异
基因: BRCA1
变异: c.68_69delAG (p.Glu23ValfsTer17)
分类: 致病性
解释: 该变异与乳腺癌和卵巢癌风险增加相关。建议进行遗传咨询并采取风险降低策略。应考虑家族成员检测。
```

### 床旁检测（POCT）

**要求：**
- 与中心实验室同等质量标准
- 操作员资质证明文件
- 质量控制记录文件
- 设备维护记录
- 结果录入医疗档案

**常见床旁检测项目：**
- 血糖
- 血红蛋白/红细胞压积
- 国际标准化比值（INR）
- 血气分析
- 妊娠试验
- 尿液分析
- 链球菌快速检测
- 流感检测

## 诊断报告质量指标

### 放射学质量指标

- 报告周转时间（常规 vs 紧急）
- 危急结果通报时效
- 报告错误率
- 补充报告率
- 转诊医师满意度

**基准值：**
- 常规报告：<24小时
- 紧急报告：<4小时
- 即刻报告：<1小时
- 危急发现：立即口头通报

### 病理学质量指标

- 不同标本类型的周转时间（TAT）
- 冰冻切片准确率
- 报告修正率
- 标本合格率
- 免疫组化质量控制

**周转时间基准：**
- 常规外科病理：2-3天
- 复杂外科病理：5-7天
- 细胞学：1-2天
- 术中冰冻切片：15-20分钟

### 实验室质量指标

- 标本采集至结果的周转时间
- 危急值通报时效
- 标本拒收率
- 能力验证表现
- 结果波动检查失败率

**周转时间基准：**
- 紧急实验室检测：<60分钟
- 常规实验室检测：2-4小时
- 外送检测：依参考实验室标准
