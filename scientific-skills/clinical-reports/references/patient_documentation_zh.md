# 患者文档规范

## SOAP 病历

SOAP（主观、客观、评估、计划）是临床实践中病程记录的标准格式。

### 目的与用途

**SOAP 病历适用场景：**
- 住院每日病程记录
- 门诊就诊记录
- 专科会诊记录
- 复诊随访记录
- 治疗反应记录

**优势：**
- 标准化结构
- 条理清晰的临床推理
- 促进团队协作
- 支持计费编码
- 法律依据文件

### SOAP 构成要素

#### S - 主观信息

**定义：** 患者主诉信息（症状、担忧、病史）

**需包含要素：**
- 主诉或就诊原因
- 现病史（HPI）
- 相关系统回顾（ROS）
- 症状描述
- 既往治疗反应
- 功能影响
- 患者疑虑或问题

**现病史要素（疼痛/症状采用 OPQRST 法）：**
- **O**起病：何时开始？突发或渐进？
- **P**诱因/缓解：加重或减轻因素？
- **Q**性质：何种感受？（锐痛、钝痛、灼烧感等）
- **R**部位/放射：疼痛位置？是否扩散？
- **S**程度：疼痛强度？（0-10分级）
- **T**时间：持续或间歇？持续时间？发作频率？

**伴随症状：**
- 与主诉相关的其他症状
- 关键阴性症状（预期症状的缺失）

**治疗反应：**
- 用药及效果
- 既往干预措施及结果
- 治疗依从性

**主观信息示例：**
```
S: 患者主诉持续咳嗽5天，咳黄色痰液。伴发热（昨日自测101.5°F）。否认气促、胸痛或咯血。2天前急诊启用阿奇霉素，症状改善不明显。诉食欲减退但能维持水分摄入。否认近期旅行或接触病患。
```

#### O - 客观信息

**定义：** 可测量、可观察的临床数据

**需包含要素：**

**生命体征：**
- 体温（°F/°C）
- 血压（mmHg）
- 心率（bpm）
- 呼吸频率（次/分）
- 血氧饱和度（%）
- 身高体重（计算BMI）
- 疼痛评分（如适用）

**一般状况：**
- 整体外观（良好、病态、痛苦）
- 年龄相符度
- 营养状态
- 个人卫生
- 情感与行为

**分系统体格检查：**
- 按头到脚或分系统组织
- 主诉相关阳性/阴性体征
- 包含关键阳性/阴性发现

**标准检查系统：**
1. **头眼耳鼻喉（HEENT）**
2. **颈部**（甲状腺、淋巴结、颈静脉怒张、颈动脉）
3. **心血管**（心音、杂音、外周脉搏、水肿）
4. **呼吸系统**（呼吸音、呼吸做功）
5. **腹部**（肠鸣音、压痛、脏器肿大、包块）
6. **四肢**（水肿、脉搏、关节活动度、畸形）
7. **神经系统**（精神状态、颅神经、运动、感觉、反射、步态）
8. **皮肤**（皮疹、皮损、创面）
9. **精神系统**（情绪、情感、思维过程/内容）

**检验与影像结果：**
- 相关检测结果
- 异常值标注参考范围
- 注明检测时间与就诊关系

**客观信息示例：**
```
O: 生命体征：T 100.8°F，BP 128/82，HR 92，RR 18，SpO2 96%（室内空气）
一般状况：警觉，轻度呼吸窘迫，呈病容
头眼耳鼻喉：口咽无充血渗出，双侧鼓膜清晰
颈部：无淋巴结肿大，无颈静脉怒张
心血管：律齐无杂音
呼吸系统：右下肺呼吸音减弱，叩诊浊音，羊鸣音阳性。无哮鸣音。
腹部：软，无压痛，无脏器肿大
四肢：无水肿，双侧脉搏2+
神经系统：警觉，定向力x3，无局灶性缺损

检验（今日）：
白细胞 14.2 x10³/μL (H) [参考值 4.5-11.0]
血红蛋白 13.5 g/dL
血小板 245 x10³/μL
C反应蛋白 8.5 mg/dL (H) [参考值 <0.5]

胸片：右下肺实变符合肺炎表现
```

#### A - 评估

**定义：** 临床印象、诊断及病情评价

**需包含要素：**
- 主要诊断/问题
- 次要诊断/问题
- 不确定时的鉴别诊断
- 严重程度评估
- 治疗目标进展
- 并发症或新发问题

**格式：**
- 问题列表（编号）
- 每个问题附简要评估
- 计费需要时标注ICD-10编码

**评估示例：**
```
A: 
1. 社区获得性肺炎（CAP），右下肺（J18.1）
   - 中度（CURB-65评分1分）
   - 适合门诊治疗
   - 阿奇霉素疗效欠佳，可能为细菌性感染
   
2. 轻度脱水（E86.0）
   - 继发于经口摄入减少
   
3. 2型糖尿病（E11.9）
   - 控制良好，维持原用药
```

#### P - 计划

**定义：** 诊断与治疗干预措施

**需包含要素：**
- 诊断计划（进一步检查、影像、转诊）
- 治疗计划（药物、操作、疗法）
- 患者教育与指导
- 随访安排
- 具体医嘱
- 返诊预警（何时需紧急就诊）

**药物记录规范：**
- 药品名（首选通用名）
- 剂量与给药途径
- 频次
- 疗程
- 适应症

**计划组织方式：**
- 按问题分类（与评估对应）
- 按干预类型分类（诊断、治疗、教育）

**计划示例：**
```
P:
1. 社区获得性肺炎：
   诊断措施：暂无需追加
   治疗措施：
   - 停用阿奇霉素
   - 启用阿莫西林克拉维酸875/125mg 口服 每日两次×7天
   - 支持治疗：充分补水、休息、退热用对乙酰氨基酚
   教育内容：
   - 解释细菌性肺炎诊断及换药原因
   - 告知48-72小时内预期改善
   - 返诊预警：呼吸困难加重、高热>103°F、意识模糊
   随访：48小时电话评估疗效，1周后门诊复诊
   
2. 脱水：
   - 鼓励经口补液，目标2升/日
   - 可饮用运动饮料或电解质溶液
   
3. 2型糖尿病：
   - 继续二甲双胍1000mg 口服 每日两次
   - 居家血糖监测
   - 按计划内分泌科随访

患者口头确认理解并同意治疗方案。
```

### SOAP 病历最佳实践

**记录规范：**
- 手写需字迹清晰
- 仅使用标准缩写
- 标注每次记录日期时间
- 签名并注明资质
- 实时或尽快完成记录
- 避免复制粘贴错误
- 定期审核更新问题清单

**计费注意事项：**
- 记录医疗必要性
- 文档内容与计费等级匹配
- 包含E/M编码必备要素
- 按时间计费需记录时长

**法律注意事项：**
- 记录事实而非主观判断
- 重要患者陈述用引文
- 客观记录不依从行为
- 严禁篡改记录
- 修正时使用补充备注

## 病史与体格检查（H&P）

### 目的

- 全面基线评估
- 记录入院或初诊状态
- 指导诊疗方案制定
- 入院24小时内必需完成（TJC要求）

### H&P 构成要素

#### 基本信息栏

- 姓名、出生日期、病历号
- 检查日期时间
- 入院诊断
- 主治医师
- 科室
- 位置（急诊、病房、ICU）

#### 主诉（CC）

**定义：** 患者就医原因的简要陈述

**格式：**
- 单句概括
- 引用患者原话（引号标注）
- 示例：主诉："我喘不上气"

#### 现病史（HPI）

**目的：** 当前病情的详细时序性叙述

**计费必备要素：**
- 部位
- 性质
- 程度
- 持续时间
- 时间特征
- 背景
- 影响因素
- 相关体征/症状

**结构：**
- 开篇陈述（人口学特征、就诊问题）
- 时序性描述
- 症状特征化
- 既往诊疗经过
- 本次就诊直接原因

**示例：**
```
现病史：Smith先生，65岁男性，有心衰病史（射血分数35%），主诉劳力性呼吸困难进行性加重3天。患者诉目前行走10英尺即出现气促（基线水平为1-2个街区）。伴端坐呼吸（现需3个枕头，基线为1个枕头）及下肢水肿。否认胸痛、心悸或晕厥。自述坚持用药但呋塞米于2天前用完。近1周体重增加8磅。未坚持居家每日称重。今日静息状态下气促加重遂至急诊就诊。
```

#### 既往史（PMH）

**包含：**
- 慢性疾病
- 既往住院史
- 重大疾病
- 外伤史
- 相关儿童期疾病

**格式：**
```
既往史：
1. 射血分数降低型心衰（2018年），6月前超声示EF 35%
2. 冠状动脉疾病，冠脉搭桥术后（2019年）
3. 2型糖尿病（2010年）
4. 高血压（2005年）
5. 慢性肾脏病3期（基线肌酐1.8 mg/dL）
6. 高脂血症
```

#### 手术史（PSH）

**包含：**
- 所有手术及操作
- 日期（年份可接受）
- 相关并发症

**格式：**
```
手术史：
1. 冠脉搭桥术×4（2019年），术后房颤并发症
2. 胆囊切除术（2015年）
3. 阑尾切除术（儿童期）
```

#### 用药史

**记录规范：**
- 首选通用名
- 剂量、途径、频次
- 适应症（非显而易见时）
- 包含非处方药
- 草本补充剂
- 注明患者无法提供清单

**格式：**
```
用药：
1. 呋塞米 40mg 口服 每日一次（2天前用完）
2. 卡维地洛 12.5mg 口服 每日两次
3. 赖诺普利 20mg 口服 每日一次
4. 螺内酯 25mg 口服 每日一次
5. 二甲双胍 1000mg 口服 每日两次
6. 阿托伐他汀 40mg 口服 每日一次
7. 阿司匹林 81mg 口服 每日一次
8. 复合维生素 每日一次
```

#### 过敏史

**记录：**
- 药物过敏及反应
- 食物过敏
- 环境过敏
- 无过敏注明NKDA

**格式：**
```
过敏史：
1. 青霉素 → 过敏性休克（儿童期）
2. 贝类 → 荨麻疹
3. ACEI类 → 血管性水肿
```

#### 家族史（FH）

**包含：**
- 一级亲属（父母、兄弟姐妹、子女）
- 在世者健康状况/去世者年龄及死因
- 相关遗传性疾病
- 主诉疾病的家族史（如相关）

**格式：**
```
家族史：
父亲：冠心病，58岁心梗，现85岁在世
母亲：乳腺癌，72岁去世
兄长：2型糖尿病
妹妹：健康
子女：2子均健康
```

#### 社会史（SH）

**包含：**
- 吸烟史（当前、既往、从未；如适用标注包年）
- 饮酒史（周饮酒量，必要时CAGE问卷）
- 违禁药物（当前、既往、从未；种类及方式）
- 职业
- 居住状况（独居、与家人同住、辅助生活等）
- 婚姻状况
- 性史（如相关）
- 运动习惯
- 饮食
- 功能状态

**格式：**
```
社会史：
吸烟：既往吸烟者，10年前戒烟（30包年）
饮酒：每周2-3瓶啤酒，否认酗酒
违禁药物：否认
职业：退休电工
居住：与妻子同住独立屋（两层，卧室在楼上）
婚姻：已婚
运动：因呼吸困难无法锻炼
饮食：通常坚持低钠饮食
功能状态：日常生活活动基线水平可自理
```

#### 系统回顾（ROS）

**目的：** 按身体系统进行症状筛查

**要求：**
- 全面检查至少10个系统
- 关键阳性/阴性症状
- 可注明"其余系统回顾阴性"

**系统分类：**
1. **全身症状**：发热、寒战、盗汗、体重变化、乏力
2. **眼部**：视力变化、疼痛、分泌物
3. **耳鼻喉**：听力下降、耳鸣、鼻窦问题、咽痛
4. **心血管**：胸痛、心悸、水肿、间歇性跛行
5. **呼吸系统**：咳嗽、呼吸困难、喘鸣、咯血
6. **消化系统**：恶心、呕吐、腹泻、便秘、腹痛
7. **泌尿生殖**：排尿困难、尿频、血尿、尿失禁
8. **肌肉骨骼**：关节痛、肿胀、僵硬、无力
9. **皮肤**：皮疹、皮损、瘙痒、痣变化
10. **神经系统**：头痛、头晕、晕厥、癫痫、无力、麻木
11. **精神系统**：情绪变化、抑郁、焦虑、睡眠障碍
12. **内分泌**：畏热/畏寒、多尿、烦渴
13. **血液/淋巴**：易瘀伤、出血、淋巴结肿大
14. **过敏/免疫**：季节性过敏、反复感染

**格式：**
```
系统回顾：
全身症状：否认发热寒战。诉乏力及体重增加（8磅）。
心血管：诉呼吸困难、端坐呼吸、下肢水肿。否认胸痛、心悸、晕厥。
呼吸系统：否认咳嗽、喘鸣、咯血。
消化系统：否认恶心呕吐、腹泻便秘、腹痛。
其余系统回顾阴性。
```

#### 体格检查

**总体组织：**
- 先记录生命体征
- 一般状况
- 头到脚系统检查

**生命体征：**
```
生命体征：T 98.2°F，BP 142/88，HR 105，RR 24，SpO2 88%（室内空气）→ 经2升鼻导管给氧升至95%
身高：5英尺10英寸，体重：195磅（基线187磅），BMI 28
```

**系统检查：**

**一般状况：** 发育正常，肥胖男性，中度呼吸窘迫，直坐位

**头眼耳鼻喉：**
- 头部：正常头型，无外伤
- 眼部：瞳孔等大等圆对光反射灵敏，眼外肌运动完整，无巩膜黄染
- 耳部：双侧鼓膜清晰
- 鼻部：鼻腔通畅，无分泌物
- 喉部：口咽无充血渗出

**颈部：** 柔软，无淋巴结肿大，颈静脉压升高至12cm，无甲状腺肿大

**心血管：**
- 视诊：未见心尖搏

- 感觉：轻触觉完好
- 反射：2+，对称
- 步态：因呼吸窘迫延迟检查
- 小脑功能：指鼻试验完好

**精神状况：** 焦虑情绪与病情相符，思维过程正常

#### 实验室与影像学检查

**包含：**
- 所有相关实验室检查结果（附参考范围）
- 影像学检查关键发现
- 心电图结果
- 其他诊断性检查

**示例：**
```
实验室数据：
全血细胞计数：白细胞8.5，血红蛋白11.2(低)，红细胞压积34%，血小板245
基础代谢组：钠132(低)，钾3.2(低)，氯98，二氧化碳30，尿素氮45(高)，肌酐2.1(高，基线1.8)，血糖145
肌钙蛋白：<0.04（正常）
B型利钠肽：1250 pg/mL（高，升高）

影像学：
胸部X光：心脏扩大，双侧胸腔积液，肺血管充血
符合容量负荷过重表现

心电图：窦性心动过速105次/分，左心室肥厚，无急性ST-T改变
```

#### 评估与诊疗计划

**格式：** 基于问题的编号清单

**示例：**
```
评估与诊疗计划：

65岁男性，有慢性心力衰竭史（射血分数35%），现表现为急性失代偿性心力衰竭。

1. 急性失代偿性心力衰竭（I50.23）
   - NYHA心功能IV级症状
   - 查体及影像学显示容量负荷过重
   - 诱因：未遵医嘱用药（呋塞米用完）
   - B型利钠肽升高至1250
   诊断措施：
   - 超声心动图评估当前射血分数及瓣膜功能
   - 每日称重及严格记录出入量
   治疗方案：
   - 呋塞米40mg静脉注射每日两次，目标每日负平衡1-2升
   - 继续卡维地洛、赖诺普利、螺内酯
   - 吸氧2升/分鼻导管，目标血氧饱和度>92%
   - 低钠饮食（<2克/天），限液1.5升/天
   - 心电监护
   随访：利尿后重新评估，目标3-5日内出院

2. 慢性肾病3期基础上急性肾损伤（N17.9, N18.3）
   - 肌酐2.1（基线1.8），可能因前向血流不足导致肾前性损伤
   - 每日监测，预计利尿后改善
   - 停用肾毒性药物

3. 低钾血症（E87.6）
   - 血钾3.2，可能源于既往利尿剂使用
   - 补钾40mEq口服一次，后重新评估
   - 继续螺内酯保钾治疗

4. 低钠血症（E87.1）
   - 血钠132，可能因容量负荷过重导致稀释性低钠
   - 预计利尿后改善
   - 按上述限液

5. 2型糖尿病（E11.9）
   - 控制良好
   - 继续院外二甲双胍方案
   - 住院期间监测血糖

6. 冠状动脉疾病（I25.10）
   - 病情稳定，无急性冠脉综合征
   - 继续阿司匹林、他汀、β受体阻滞剂

代码状态：全力抢救
处置：收入心电监护病房
```

## 出院小结

### 目的

- 向门诊医生传达住院治疗情况
- 记录住院过程及结局
- 确保护理连续性
- 满足监管要求（TJC、CMS）

### 时限要求

**规定：**
- 出院后30天内完成（CMS要求）
- 多数医院要求24-48小时内完成
- 随访就诊时需可获取
