## 解读/备注

**贫血示例：**
```
正细胞性贫血伴白细胞升高。鉴别诊断包括慢性病性贫血、近期失血或溶血。
建议进行网织红细胞计数、铁代谢检查和外周血涂片评估。需结合临床分析。
```

**电解质异常示例：**
```
检测到低钾血症（K+ 3.2 mEq/L）。常见原因包括利尿剂使用、胃肠道丢失或摄入不足。
建议补钾并随访检测。存在中度氮质血症，符合急性肾损伤或慢性肾病表现。
建议结合患者病史及既往结果进行临床分析。
```
