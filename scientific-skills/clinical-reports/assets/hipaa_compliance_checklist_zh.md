# 临床报告的HIPAA合规性检查清单

## 18项HIPAA标识符 - 去标识化检查清单

验证以下所有标识符是否已被移除或修改：

- [ ] **1. 姓名** - 患者姓名、家庭成员、医疗保健提供者（除非必要且已获得同意）

- [ ] **2. 小于州级的地理分区**
  - 无街道地址
  - 无城市（除非人口>20,000，且邮政编码部分可保留，如果该地区人口>20,000）
  - 无县名  
  - 仅当地理单元人口>20,000时，可保留邮政编码前三位
  - 邮政编码其余部分必须移除

- [ ] **3. 日期**（年份除外）
  - 无确切出生日期（仅保留年份；89岁以上患者的出生年份必须汇总处理）
  - 无入院日期
  - 无出院日期
  - 无服务日期
  - 无死亡日期
  - 使用相对时间段（如"3个月前"）或仅保留年份

- [ ] **4. 电话号码**
  - 无任何类型的电话号码
  - 包括患者、家属、提供者的联系电话

- [ ] **5. 传真号码**
  - 无传真号码

- [ ] **6. 电子邮件地址**
  - 无患者或相关人员的电子邮件地址

- [ ] **7. 社会安全号码**
  - 无SSN或部分SSN

- [ ] **8. 病历号码**
  - 无病历号、医院ID或诊所编号
  - 如需使用，采用编码研究ID或病例编号

- [ ] **9. 健康计划受益人号码**
  - 无保险ID号
  - 无保单号

- [ ] **10. 账号**
  - 无账单账号
  - 无财务账户信息

- [ ] **11. 证书/执照号码**
  - 无驾驶证号码
  - 无专业执照号码（作者资质证明除外）

- [ ] **12. 车辆标识符和序列号**
  - 无车牌号
  - 无车辆识别号(VIN)

- [ ] **13. 设备标识符和序列号**
  - 无心脏起搏器序列号
  - 无植入设备序列号
  - 通用设备描述可接受（如"植入式心律转复除颤器"）

- [ ] **14. 网页URL**
  - 无个人网站
  - 无可识别个人的URL

- [ ] **15. IP地址**
  - 无IP地址

- [ ] **16. 生物识别标识符**
  - 无指纹
  - 无声纹
  - 无视网膜扫描
  - 无其他生物特征数据

- [ ] **17. 全脸照片及类似图像**
  - 无未经同意的全脸照片
  - 如必须展示，需裁剪或模糊面部
  - 移除识别特征（非临床相关的珠宝、纹身、胎记）
  - 仅用黑条遮盖眼部不足够
  - 确保无反光或背景识别信息

- [ ] **18. 任何其他唯一识别特征或代码**
  - 无可能识别个体的独特特征
  - 无可能识别个体的罕见疾病组合
  - 评估剩余数据点的组合是否可能识别个体

## 额外去标识化注意事项

### 年龄与日期

- [ ] 年龄≤89岁患者：可接受确切年龄或年龄范围
- [ ] 年龄>89岁患者：必须汇总为"90岁及以上"或">89岁"
- [ ] 日期：仅使用年份或相对时间段
  - 示例："就诊前3个月"替代"2023年1月15日"
  - 示例："2023年入院"替代"2023年3月10日入院"

### 地理信息

- [ ] 州或国家名称可接受
- [ ] 移除具体城市（除非人口>20,000且无其他识别信息）
- [ ] 移除医院/诊所名称
- [ ] 使用通用描述："中西部某社区医院"或"某三级医疗中心"

### 罕见病症与组合

- [ ] 评估极罕见疾病本身是否可能识别患者
- [ ] 评估以下组合是否可能识别患者：
  - 年龄+诊断+地理区域+时间段
- [ ] 可能需模糊处理某些独特细节
- [ ] 平衡临床信息提供与隐私保护

### 图像与图表

- [ ] 图像头文件/元数据中所有患者标识符已移除
- [ ] DICOM数据已剥离
- [ ] 图像日期已移除
- [ ] 病历号已移除
- [ ] 面部已裁剪、模糊或遮蔽
- [ ] 识别性标记已移除或遮蔽：
  - 纹身
  - 珠宝
  - 胎记或独特疤痕（非临床相关）
- [ ] 比例尺和标注不含识别信息
- [ ] 背景环境已去标识（房间号、名牌等）

### 语音与视频

- [ ] 无包含患者声音的录音（除非获得同意）
- [ ] 无显示可识别特征的视频（除非获得同意）
- [ ] 如必须使用视频，面部必须遮蔽

## 知情同意检查清单（用于病例报告/发表）

### 同意要求

- [ ] 提交发表前已获得知情同意
- [ ] 直接获得患者同意（如具备能力）
- [ ] 如患者去世或无行为能力，需获得法定代表或近亲同意
- [ ] 儿科病例需获得父母/监护人同意

### 同意书要素

知情同意书必须包含：

- [ ] 发表目的（教育、医学知识传播）
- [ ] 发表内容（病例详情、图像、结果）
- [ ] 期刊或发表平台（如已知）
- [ ] 开放获取与订阅模式（公开范围）
- [ ] 解释去标识化措施
- [ ] 承认存在再识别可能性
- [ ] 不影响临床治疗
- [ ] 撤销同意权利（时间限制说明）
- [ ] 问题咨询联系方式
- [ ] 患者签名及日期
- [ ] 见证人签名（如需要）

### 同意文件记录

- [ ] 已存档签署的同意书
- [ ] 向患者提供副本
- [ ] 同意书可供编辑审查
- [ ] 稿件中声明已获同意

**稿件声明示例：**
"已获得患者签署的书面知情同意书，用于发表本病例报告及任何随附图像。书面同意书的副本可供本刊主编在要求时查阅。"

## 安全港方法与专家判定方法

### 安全港方法

- [ ] 所有18项标识符已移除
- [ ] 无证据表明剩余信息可识别个体
- [ ] 最直接的方法
- [ ] 推荐用于多数临床报告

### 专家判定方法

- [ ] 经合格统计师/专家判定再识别风险极低
- [ ] 方法学已记录
- [ ] 分析方法已明确
- [ ] 结论已记录
- [ ] 可保留部分数据元素
- [ ] 需统计专业知识

**采用方法：** [ ] 安全港方法  [ ] 专家判定方法

---

## 最低必要标准

### 使用与披露

- [ ] 仅使用特定目的所需的最少量PHI
- [ ] 披露目的明确定义
- [ ] 仅限相关信息
- [ ] 考虑采用去标识化数据或有限数据集替代

### 最低必要标准例外

最低必要标准不适用于：
- 治疗目的（提供者可能需要完整信息）
- 患者授权的披露
- 法律要求的披露
- 向HHS提交合规调查的披露

---

## PHI使用/披露授权

### 需授权的情形

以下情况需要授权：
- [ ] 研究（除非获得IRB豁免）
- [ ] 营销目的
- [ ] PHI销售
- [ ] 心理治疗笔记
- [ ] 超出治疗、支付、运营(TPO)范围的使用

### 授权要素

如需授权，必须包含：

- [ ] 拟使用/披露PHI的具体描述
- [ ] 授权披露方
- [ ] 信息接收方
- [ ] 披露目的
- [ ] 有效期或终止事件
- [ ] 撤销权利及方式
- [ ] 拒绝签署权利
- [ ] 接收方可能再披露的风险
- [ ] 患者签名及日期

## 有限数据集

### 有限数据集选项

有限数据集移除18项标识符中的16项，但可保留：
- [ ] 日期（入院、出院、服务、出生、死亡）
- [ ] 地理信息（城市、州、邮政编码）

### 有限数据集要求

- [ ] 需签订数据使用协议(DUA)
- [ ] DUA明确许可用途
- [ ] 仅限研究、公共卫生或医疗运营
- [ ] 接收方同意不再识别
- [ ] 接收方同意保护数据安全

## 安全防护措施检查清单

### 管理性防护

- [ ] 建立安全管理流程
- [ ] 实施人员安全措施
- [ ] 访问管理（基于角色）
- [ ] 人员安全培训
- [ ] 事件响应程序

### 物理性防护

- [ ] 设施访问控制
- [ ] 工作站使用政策
- [ ] 工作站安全措施
- [ ] 设备与介质控制
- [ ] 安全处置程序

### 技术性防护

- [ ] 访问控制（唯一用户ID、密码）
- [ ] 审计控制与日志记录
- [ ] 完整性控制
- [ ] 传输安全（加密）
- [ ] 闲置自动注销

## 违规通知检查清单

### 发生未授权披露时

- [ ] 判定是否构成违规（未授权访问/使用/披露）
- [ ] 评估对个体的潜在伤害风险
- [ ] 若影响<500人：
  - 60天内通知个人

  - 60天内通知个人
  - 60天内通知HHS
  - 如影响某州/辖区≥500人需通知媒体
- [ ] 记录违规及应对措施
- [ ] 实施整改行动
