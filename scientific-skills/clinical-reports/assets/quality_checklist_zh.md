# 临床报告质量保证清单

## 通用质量标准

### 完整性
- [ ] 所有必填章节齐全
- [ ] 无空白字段或信息缺失
- [ ] 包含所有相关临床信息
- [ ] 事件时间线清晰完整
- [ ] 所有诊断检查及结果均有记录
- [ ] 所有治疗及干预措施均有记录
- [ ] 随访计划明确

### 准确性
- [ ] 患者人口统计学信息正确
- [ ] 日期时间准确无误
- [ ] 实验室数值含正确单位和参考范围
- [ ] 药物名称、剂量及频次正确
- [ ] 诊断编码正确（ICD-10）
- [ ] 操作编码正确（如适用CPT）
- [ ] 无矛盾信息

### 清晰性
- [ ] 语言清晰专业
- [ ] 医学术语使用恰当
- [ ] 缩写已定义或符合标准
- [ ] 逻辑组织与流程合理
- [ ] 字迹清晰（如手写）
- [ ] 无歧义表述
- [ ] 临床推理阐述明确

### 及时性
- [ ] 实时或接诊后立即记录
- [ ] 出院小结24-48小时内完成
- [ ] 危急结果即时通报
- [ ] 符合监管报告时限要求

---

## 病例报告质量清单

### CARE指南合规性
- [ ] 标题含"病例报告"
- [ ] 提供关键词（2-5个MeSH术语）
- [ ] 结构化摘要要素齐全
- [ ] 引言阐明创新性
- [ ] 患者信息完整且去标识化
- [ ] 临床发现记录完整
- [ ] 提供时间线（表格或图示）
- [ ] 诊断评估详尽
- [ ] 治疗干预措施描述清晰
- [ ] 随访及结局报告完整
- [ ] 含文献综述的讨论
- [ ] 包含患者视角（如可能）
- [ ] 知情同意声明完备

### 隐私与伦理
- [ ] 知情同意已获取并记录
- [ ] 所有18项HIPAA标识符已移除
- [ ] 日期已删除或模糊化
- [ ] 年龄报告规范（>89岁合并报告）
- [ ] 地理信息限定至州级
- [ ] 影像资料去标识化或获授权
- [ ] 如适用，IRB批准完备

### 科学质量
- [ ] 创新性明确确立
- [ ] 文献检索全面
- [ ] 鉴别诊断已考量
- [ ] 因果关系已阐述
- [ ] 局限性已说明
- [ ] 学习要点具可操作性
- [ ] 参考文献时效性强且相关

## 临床试验报告质量清单

### 严重不良事件（SAE）报告清单
- [ ] 所有管理信息完整
- [ ] 受试者去标识化（仅ID号）
- [ ] 事件描述详尽
- [ ] 应用MedDRA编码
- [ ] 严重性标准记录完整
- [ ] 严重程度评估完成
- [ ] 结局明确
- [ ] 因果关系评估含依据
- [ ] 预期性判定完成
- [ ] 研究药物处理措施记录
- [ ] 事件治疗描述清晰
- [ ] 叙述全面且按时间顺序
- [ ] 如适用，危急结果已通报
- [ ] 符合监管时限（7日/15日）

### 临床研究报告（CSR）清单

- [ ] 缩写已定义
- [ ] 伦理审批记录完备
- [ ] 研究者名单完整
- [ ] 研究设计描述清晰
- [ ] 样本量有依据
- [ ] 统计方法明确
- [ ] 包含CONSORT流程图
- [ ] 基线人口统计表
- [ ] 主要终点结果
- [ ] 所有次要终点报告完整
- [ ] 不良事件汇总
- [ ] 包含个体SAE叙述
- [ ] 讨论与结论完备
- [ ] 附件完整（方案、CRF等）

- [ ] 确保法规合规
- [ ] 确认所有必要签署
- [ ] 核实分发流程
- [ ] 妥善归档副本
