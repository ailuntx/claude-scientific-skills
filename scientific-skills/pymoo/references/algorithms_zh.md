# Pymoo 算法参考指南

pymoo 中可用优化算法的全面参考。

## 单目标优化算法

### 遗传算法 (GA)
**用途：** 通用单目标进化优化  
**最佳适用：** 连续、离散或混合变量问题  
**算法类型：** (μ+λ) 遗传算法  

**关键参数：**  
- `pop_size`：种群规模（默认：100）  
- `sampling`：初始种群生成策略  
- `selection`：父代选择机制（默认：锦标赛选择）  
- `crossover`：重组算子（默认：SBX）  
- `mutation`：变异算子（默认：多项式变异）  
- `eliminate_duplicates`：移除冗余解（默认：True）  
- `n_offsprings`：每代子代数  

**用法：**  
```python
from pymoo.algorithms.soo.nonconvex.ga import GA
algorithm = GA(pop_size=100, eliminate_duplicates=True)
```

### 差分进化 (DE)
**用途：** 单目标连续优化  
**最佳适用：** 具有良好全局搜索能力的连续参数优化  
**算法类型：** 基于种群的差分进化  

**变体：** 支持多种 DE 策略（rand/1/bin, best/1/bin 等）  

### 粒子群优化 (PSO)
**用途：** 通过群体智能实现单目标优化  
**最佳适用：** 连续问题，在平滑地形上快速收敛  

### CMA-ES
**用途：** 协方差矩阵自适应进化策略  
**最佳适用：** 连续优化，尤其适用于噪声或病态问题  

### 模式搜索
**用途：** 直接搜索方法  
**最佳适用：** 梯度信息不可用的问题  

### 内尔德-米德法
**用途：** 基于单纯形的优化  
**最佳适用：** 连续函数的局部优化  

## 多目标优化算法

### NSGA-II（非支配排序遗传算法 II）
**用途：** 2-3 目标的多目标优化  
**最佳适用：** 需要均匀分布帕累托前沿的双/三目标问题  
**选择策略：** 非支配排序 + 拥挤距离  

**关键特性：**  
- 快速非支配排序  
- 拥挤距离保持多样性  
- 精英保留策略  
- 二元锦标赛交配选择  

**关键参数：**  
- `pop_size`：种群规模（默认：100）  
- `sampling`：初始种群策略  
- `crossover`：连续变量默认 SBX  
- `mutation`：默认多项式变异  
- `survival`：RankAndCrowding  

**用法：**  
```python
from pymoo.algorithms.moo.nsga2 import NSGA2
algorithm = NSGA2(pop_size=100)
```

**适用场景：**  
- 2-3 个目标  
- 需要帕累托前沿上的分布解  
- 标准多目标基准测试  

### NSGA-III
**用途：** 多目标优化（4+ 目标）  
**最佳适用：** 需要均匀覆盖帕累托前沿的 4+ 目标问题  
**选择策略：** 基于参考方向的多样性维护  

**关键特性：**  
- 参考方向引导种群  
- 在高维目标空间保持多样性  
- 通过参考点实现小生境保护  
- 欠代表参考方向选择  

**关键参数：**  
- `ref_dirs`：参考方向（必需）  
- `pop_size`：默认为参考方向数量  
- `crossover`：默认 SBX  
- `mutation`：默认多项式变异  

**用法：**  
```python
from pymoo.algorithms.moo.nsga3 import NSGA3
from pymoo.util.ref_dirs import get_reference_directions

ref_dirs = get_reference_directions("das-dennis", n_dim=4, n_partitions=12)
algorithm = NSGA3(ref_dirs=ref_dirs)
```

**NSGA-II 与 NSGA-III 对比：**  
- 2-3 目标用 NSGA-II  
- 4+ 目标用 NSGA-III  
- NSGA-III 提供更均匀分布  
- NSGA-II 计算开销更低  

### R-NSGA-II（基于参考点的 NSGA-II）
**用途：** 支持偏好表达的多目标优化  
**最佳适用：** 决策者指定帕累托前沿偏好区域时  

### U-NSGA-III（统一 NSGA-III）
**用途：** 处理多种场景的改进版本  
**最佳适用：** 需要额外鲁棒性的多目标问题  

### MOEA/D（基于分解的多目标进化算法）
**用途：** 基于分解的多目标优化  
**最佳适用：** 可有效分解为标量子问题的情况  

### AGE-MOEA
**用途：** 自适应几何估计  
**最佳适用：** 具有自适应机制的多目标问题  

### RVEA（参考向量引导进化算法）
**用途：** 基于参考向量的多目标优化  
**最佳适用：** 需要自适应参考向量的多目标问题  

### SMS-EMOA
**用途：** S 度量选择进化多目标算法  
**最佳适用：** 超体积指标关键的问题  
**选择机制：** 使用支配超体积贡献度  

## 动态多目标算法

### D-NSGA-II
**用途：** 动态多目标问题  
**最佳适用：** 目标函数或约束随时间变化的情况  

### KGB-DMOEA
**用途：** 知识引导的动态多目标优化  
**最佳适用：** 利用历史信息的动态问题  

## 约束优化

### SRES（随机排序进化策略）
**用途：** 单目标约束优化  
**最佳适用：** 强约束问题  

### ISRES（改进型 SRES）
**用途：** 增强型约束优化  
**最佳适用：** 复杂约束地形  

## 算法选择指南

**单目标问题：**  
- 通用问题首选 GA  
- 连续优化用 DE  
- 平滑问题快速收敛用 PSO  
- 困难/噪声地形用 CMA-ES  

**多目标问题：**  
- 2-3 目标：NSGA-II  
- 4+ 目标：NSGA-III  
- 偏好表达：R-NSGA-II  
- 分解友好：MOEA/D  
- 超体积优先：SMS-EMOA  

**约束问题：**  
- 基于可行解的生存选择（兼容多数算法）  
- 强约束：SRES/ISRES  
- 罚函数法提升算法兼容性  

**动态问题：**  
- 时变问题：D-NSGA-II  
- 需历史知识：KGB-DMOEA
