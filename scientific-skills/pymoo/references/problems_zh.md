# Pymoo测试问题参考

pymoo中基准优化问题的综合参考。

## 单目标测试问题

### Ackley函数
**特性：**
- 高度多峰
- 众多局部最优解
- 测试算法跳出局部极小值的能力
- 连续变量

### Griewank函数
**特性：**
- 多峰且局部极小值均匀分布
- 乘积项引入变量间相互依赖
- 全局最小值位于原点

### Rastrigin函数
**特性：**
- 高度多峰且局部极小值规则分布
- 对基于梯度的方法具有挑战性
- 测试全局搜索能力

### Rosenbrock函数
**特性：**
- 单峰但通往全局最优的狭窄山谷
- 测试算法在复杂地形中的收敛性
- 连续优化的经典基准

### Zakharov函数
**特性：**
- 单峰
- 单一全局最小值
- 测试基本收敛能力

## 多目标测试问题（2-3目标）

### ZDT测试套件
**目的：** 双目标优化的标准基准  
**构造：** f₂(x) = g(x) · h(f₁(x), g(x))，其中帕累托最优解处g(x)=1

#### ZDT1
- **变量：** 30个连续变量
- **边界：** [0, 1]
- **帕累托前沿：** 凸形
- **目的：** 基础收敛性与多样性测试

#### ZDT2
- **变量：** 30个连续变量
- **边界：** [0, 1]
- **帕累托前沿：** 非凸（凹形）
- **目的：** 测试非凸前沿处理能力

#### ZDT3
- **变量：** 30个连续变量
- **边界：** [0, 1]
- **帕累托前沿：** 非连通（5个独立区域）
- **目的：** 测试非连续前沿的多样性保持

#### ZDT4
- **变量：** 10个连续变量（x₁ ∈ [0,1], x₂₋₁₀ ∈ [-10,10]）
- **帕累托前沿：** 凸形
- **难度：** 21⁹个局部帕累托前沿
- **目的：** 测试含大量局部最优解的全局搜索

#### ZDT5
- **变量：** 11个离散变量（比特串）
- **编码：** x₁占30比特，x₂₋₁₁各占5比特
- **帕累托前沿：** 凸形
- **目的：** 测试离散优化及欺骗性地形

#### ZDT6
- **变量：** 10个连续变量
- **边界：** [0, 1]
- **帕累托前沿：** 非凸且密度非均匀
- **目的：** 测试偏置解分布的处理

**用法：**
```python
from pymoo.problems.multi import ZDT1, ZDT2, ZDT3, ZDT4, ZDT5, ZDT6
problem = ZDT1()  # 或 ZDT2(), ZDT3() 等
```

## 多目标测试问题（4+目标）

### DTLZ测试套件
**目的：** 可扩展的多目标基准  
**目标数：** 可配置（通常3-15）  
**变量数：** 可扩展

#### DTLZ1
- **帕累托前沿：** 线性（超平面）
- **难度：** 11^k个局部帕累托前沿
- **目的：** 测试含大量局部最优解的收敛性

#### DTLZ2
- **帕累托前沿：** 球形（凹面）
- **难度：** 直接收敛
- **目的：** 基础多目标多样性测试

#### DTLZ3
- **帕累托前沿：** 球形
- **难度：** 3^k个局部帕累托前沿
- **目的：** 融合DTLZ1的多峰性与DTLZ2的几何特性

#### DTLZ4
- **帕累托前沿：** 球形且密度偏置
- **难度：** 非均匀解分布
- **目的：** 测试偏置下的多样性保持

#### DTLZ5
- **帕累托前沿：** 退化（M维空间中的曲线）
- **目的：** 测试退化前沿处理

#### DTLZ6
- **帕累托前沿：** 退化曲线
- **难度：** 收敛难度高于DTLZ5
- **目的：** 挑战性退化前沿

#### DTLZ7
- **帕累托前沿：** 非连通区域
- **难度：** 2^(M-1)个非连通区域
- **目的：** 测试非连通前沿的多样性

**用法：**
```python
from pymoo.problems.many import DTLZ1, DTLZ2
problem = DTLZ1(n_var=7, n_obj=3)  # 7个变量，3个目标
```

### WFG测试套件
**目的：** Walking Fish Group可扩展基准  
**特性：** 比DTLZ更复杂，含多种前沿形状和难度  

**变体：** WFG1-WFG9具有不同特性
- 不可分离
- 欺骗性
- 多峰
- 偏置
- 缩放前沿

## 自定义问题定义

通过扩展基类定义自定义问题：

```python
from pymoo.core.problem import ElementwiseProblem
import numpy as np

class MyProblem(ElementwiseProblem):
    def __init__(self):
        super().__init__(
            n_var=2,           # 变量数量
            n_obj=2,           # 目标数量
            n_ieq_constr=0,    # 不等式约束
            n_eq_constr=0,     # 等式约束
            xl=np.array([0, 0]),   # 下界
            xu=np.array([1, 1])    # 上界
        )

    def _evaluate(self, x, out, *args, **kwargs):
        # 定义目标函数
        f1 = x[0]**2 + x[1]**2
        f2 = (x[0]-1)**2 + x[1]**2

        out["F"] = [f1, f2]

        # 可选：约束条件
        # out["G"] = constraint_values  # <= 0
        # out["H"] = equality_constraints  # == 0
```

## 问题选择指南

**算法开发：**
- 简单收敛性：DTLZ2, ZDT1
- 多峰性：ZDT4, DTLZ1, DTLZ3
- 非凸性：ZDT2
- 非连通性：ZDT3, DTLZ7

**全面测试：**
- 双目标：ZDT套件
- 多目标：DTLZ套件
- 复杂地形：WFG套件
- 约束问题：MW/DAS-CMOP

**实际场景验证：**
- 工程问题（二维桁架，焊接梁）
- 根据应用领域匹配问题特性

**变量类型：**
- 连续：多数问题
- 离散：ZDT5
- 混合：定义自定义问题
