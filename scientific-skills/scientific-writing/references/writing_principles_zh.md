# 科学写作原则

## 概述

有效的科学写作需要掌握确保清晰性、精确性和影响力的基本原则。与创意或叙事写作不同，科学写作优先考虑准确性、简洁性和客观性。本指南涵盖区分优秀科学写作与拙劣写作的核心原则，并提供实用的改进策略。

## 科学写作的三大支柱

### 1. 清晰性

**定义：** 目标读者能立即理解且无歧义或困惑的写作。

**重要性：** 科学本身已足够复杂，无需模糊的写作增添困惑。读者应专注于理解科学内容，而非解读文字。

#### 清晰性策略

**使用精确无歧义的语言：**
```
拙劣："该药物似乎帮助了不少患者。"
改进："该药物使68%（32/47）的患者症状减轻。"
```

**首次使用技术术语时定义：**
```
"我们测量了脑源性神经营养因子（BDNF），这是一种参与神经元存活和可塑性的蛋白质。"
```

**保持段落内外的逻辑连贯：**
- 每个段落聚焦一个核心观点
- 主题句点明段落重点
- 支撑句展开论述
- 过渡句衔接段落

**主动语态优先（当提升清晰度时）：**
```
被动（欠清晰）："样本由研究人员分析。"
主动（更清晰）："研究人员分析了样本。"
```

但在方法部分，当动作比执行者更重要时，被动语态可接受且常用：
```
"分别在基线和6周后采集血样。"
```

**拆分冗长复杂句：**
```
拙劣："我们这项招募自三家医院200名参与者、采用验证问卷每4周评估一次、持续随访12个月的研究结果显示干预组有显著改善。"

改进："我们招募了来自三家医院的200名参与者。研究采用验证问卷每4周评估一次，持续随访12个月。干预组显示出显著改善。"
```

**使用具体动词：**
```
模糊："该研究关注青少年抑郁症。"
明确："该研究探讨了导致青少年抑郁症的因素。"
```

#### 常见清晰性问题

**指代不明：**
```
拙劣："A组接受药物，B组接受安慰剂。他们出现改善。"
（"他们"指谁？）

改进："A组接受药物，B组接受安慰剂。药物治疗组出现改善。"
```

**修饰语错位：**
```
拙劣："我们测量了患者使用自动监测仪的血压。"
（是患者使用还是我们使用？）

改进："使用自动监测仪，我们测量了患者的血压。"
```

**指代不清：**
```
拙劣："表达量增加伴随增殖减少，这出乎意料。"
（"出乎意料"指代减少、伴随关系还是两者？）

改进："表达量增加伴随增殖减少。这种反向关系出乎意料。"
```

### 2. 简洁性

**定义：** 在不牺牲清晰度或完整性的前提下，用最简练的文字表达观点。

**重要性：** 简洁写作尊重读者时间。每个冗余词汇都是丧失清晰度和影响力的机会。正如原则所述："我们珍视简洁写作，因为我们珍视时间。"

#### 简洁性策略

**删除冗余词汇：**

| 冗长 | 简洁 |
|-------|---------|
| "due to the fact that" | "因为" |
| "in order to" | "为了" |
| "it is important to note that" | [删除] |
| "a total of 50 participants" | "50名参与者" |
| "completely eliminate" | "消除" |
| "has been shown to be" | "是" |
| "in the event that" | "如果" |
| "at the present time" | "当前" |
| "conduct an investigation into" | "调查" |
| "give consideration to" | "考虑" |

**避免铺垫性短语：**
```
冗长："值得注意的是，我们的研究结果表明..."
简洁："我们的结果表明..." 或 "结果显示..."
```

**用强动词替代名词组合：**

| 冗长 | 简洁 |
|-------|---------|
| "make a decision" | "决定" |
| "perform an analysis" | "分析" |
| "conduct a study" | "研究" |
| "make an assessment" | "评估" |
| "provide information about" | "说明" |

**删除不必要强化词：**
```
冗长："结果非常显著。"
简洁："结果显著。"（p值已体现显著程度）
```

**避免信息重复：**
```
冗余："结果显示，接受治疗干预的干预组参与者有更好结局。"
简洁："干预组有更好结局。"
```

**选用简短结构：**
```
冗长："尽管样本量很小的事实..."
简洁："虽然样本量很小..."
```

#### 必要长度与冗余长度

**非所有长句皆劣：**
```
此详细句合理："我们使用沃特世Acquity UPLC系统联用Xevo TQ-S质谱仪（沃特世公司，米尔福德，马萨诸塞州），通过液相色谱-串联质谱法（LC-MS/MS）分析血样。"

原因：每个要素均为必要信息。
```

**关键准则：** 删除任何词汇是否不损失含义或精确度？若是，则删除。

### 3. 准确性

**定义：** 对数据、方法和解释的精确正确呈现。

**重要性：** 科学可信度取决于准确性。不准确报告会破坏整个科学事业。

#### 准确性策略

**报告精确值并合理保留位数：**
```
拙劣："均值约为25。"
改进："均值为24.7±3.2（标准差）。"
```

**精度需匹配测量能力：**
```
不当："平均年龄45.237岁"（暗示错误精度）
恰当："平均年龄45.2岁"
```

**全文术语一致：**
```
不一致：引言称"认知功能"，方法称"心理表现"，结果称"智力能力"

一致：全文使用"认知功能"，或明确定义："认知功能（亦称心理表现）"
```

**区分观察与解读：**
```
观察："平均血压从145降至132 mmHg（p=0.003）"
解读："这表明干预措施有效降低血压。"
```

**明确不确定性：**
```
模糊："这些测量可能存在误差。"
明确："根据仪器规格，测量标准误差为±2.5 mmHg。"
```

**使用正确统计术语：**
```
错误："相关性高度显著（p=0.03）。"
正确："相关性具有统计学意义（p=0.03）。"
（p=0.03非"高度"显著，该词保留给p<0.001）
```

**核验所有数值：**
- 核对正文与图表数据一致性
- 验证样本量总和正确性
- 确认百分比计算无误
- 复核全部统计结果

#### 常见准确性问题

**过度泛化：**
```
拙劣："锻炼预防抑郁症。"
改进："本研究中，随机分配至锻炼干预组的参与者比对照组抑郁症状更少（BDI-II量表平均差3.2分，95% CI:1.5-4.9, p<0.001）。"
```

**无依据的因果断言：**
```
拙劣（观察性研究）："补充维生素D降低癌症风险。"
改进："该队列中维生素D水平与癌症发病率呈负相关（HR=0.82, 95% CI:0.71-0.95）。"
```

**数值描述模糊：**
```
模糊："许多参与者退出。"
精确："15/50（30%）参与者在研究完成前退出。"
```

## 其他关键原则

### 4. 客观性

**定义：** 不带偏见、不夸大、无主观臆断地呈现信息。

**策略：**

**无偏呈现结果：**
```
偏颇："如预期，我们的优越方法表现更佳。"
客观："方法A比方法B准确率更高（87% vs. 76%, p=0.02）。"
```

**承认矛盾证据：**
```
"我们的发现与Smith等（2022）报告无显著效应相悖。这种差异可能源于干预强度或人群特征差异。"
```

**避免情绪化或评价性语言：**
```
主观："结果令人失望且担忧。"
客观："干预未显著减轻症状（p=0.42）。"
```

**区分事实与推测：**
```
"观察到的细胞活性下降伴随caspase-3活性升高，提示细胞凋亡可能是细胞死亡的主要机制。"
（使用"提示"和"可能"表明解读性质）
```

### 5. 一致性

**全文保持统一：**

**术语：**
- 相同概念使用相同术语（勿为求变用同义词）
- 缩写首次定义后全文统一
- 基因、蛋白质、化学品采用标准命名法

**符号：**
- 统计符号（p值格式、置信区间呈现）
- 计量单位
- 数字格式（小数位数）

**时态：**
- 特定研究动作用过去时
- 既定事实用现在时
- 详见IMRAD结构参考中的时态指南

**格式：**
- 严格遵循期刊格式要求
- 文献引用格式
- 标题大小写
- 数字与文字表达规范

### 6. 逻辑组织

**构建清晰的"主线逻辑"：**

**段落结构：**
1. 主题句（核心观点）
2. 支撑句（证据、阐释）
3. 总结/过渡句（衔接下个观点）

**章节衔接：**
- 每节承上启下自然递进
- 引言提出的问题在结果部分解答
- 结果呈现的发现在讨论部分阐释

**路标语句：**
```
"首先，我们检验了..."
"接着，我们探究了..."
"最后，我们评估了..."
```

**平行结构：**
```
非平行："目标为(1)测量血压，(2)评估认知功能，及(3)我们想评价情绪。"

平行："目标为(1)测量血压，(2)评估认知功能，(3)评价情绪。"
```

## 科学写作的动词时态

### 通用准则

**现在时用于：**
- 既定事实与普遍真理
  - "DNA由核苷酸组成。"
- 当前得出的结论
  - "这些发现表明..."
- 引用图表时
  - "图1显示分布情况..."

**过去时用于：**
- 已完成研究的具体发现（他人及自身）
  - "Smith等（2022）发现..."
  - "我们观察到显著下降..."
- 已执行的方法
  - "参与者在基线时完成问卷。"

**现在完成时用于：**
- 具有现实意义的近期进展
  - "近期研究已证实..."
- 研究领域背景
  - "已有多种方案被提出..."

### 章节特定时态

| 章节 | 主要时态 | 示例 |
|---------|---------------|----------|
| **摘要-背景** | 现在时/现在完成时 | "抑郁症影响数百万人"/"研究表明..." |
| **摘要-方法** | 过去时 | "我们招募了100名参与者" |
| **摘要-结果** | 过去时 | "干预减轻了症状" |
| **摘要-结论** | 现在时 | "这些发现表明..." |
| **引言-背景** | 现在时（事实）、现在完成时（研究） | "锻炼有益健康"/"研究显示..." |
| **引言-空白** | 现在时/现在完成时 | "然而，相关认知仍有限..." |
| **引言-本研究** | 过去时/现在时 | "我们探究了..."/"本研究探讨..." |
| **方法** | 过去时 | "我们采集了样本..." |
| **结果** | 过去时 | "平均年龄45岁" |
| **讨论-研究发现** | 过去时 | "我们发现..." |
| **讨论-解读** | 现在时 | "这表明..." |
| **讨论-前人工作** | 过去时/现在时 | "Smith发现..."/"先前研究证实..." |

## 常见写作陷阱

### 1. 术语滥用

**问题：** 过度使用未定义的技术术语

**示例：**
```
拙劣："我们采用qRT-PCR通过SYBR-Green荧光检测法在oligo-dT引物合成总RNA的cDNA后定量mRNA表达。"

改进："我们使用定量逆转录PCR（qRT-PCR）检测mRNA表达。总RNA经oligo-dT引物逆转录为互补DNA（cDNA），随后采用SYBR Green荧光检测法扩增。"
```

### 2. 名词化

**问题：** 动词名词化导致行文臃肿间接

**示例：**

| 名词化 | 直接表达 |
|-------------|--------|
| "give consideration to" | "考虑" |
| "make an assumption" | "假设" |
| "perform an investigation" | "调查" |
| "conduct an examination" | "检查" |
| "achieve a reduction" | "减少" |

### 3. 模糊化过度或不足

**过度模糊化（显得不确定）：**
```
"该干预在某些条件下或许可能对症状产生某种潜在影响。"
```

**模糊化不足（结论绝对化）：**
```
"该干预治愈抑郁症。"
```

**适度模糊化：**
```
"该干预显著减轻本样本的抑郁症状，提示其或可有效治疗轻中度抑郁症。"
```

**合理使用的模糊化词汇：**
- 提示/表明/暗示（相关数据勿用证明/证实）
- 可能/或许/能够（表达可能性）
- 似乎/看似（需验证的观察）
- 很可能/大概/可能（确定程度）

### 4. 拟人化

**问题：** 赋予非人实体人类特征

**示例：**

| 拟人化 | 科学表达 |
|----------------|-----------|
| "本研究希望探讨..." | "我们旨在探讨..." 或 "本研究探讨..." |
| "数据暗示它们需要..." | "数据暗示..." |
| "本文将要证明..." | "本文证实..." |
| "表1告诉我们..." | "表1显示..." |

### 5. 缩写滥用

**问题：**
- 过多缩写增加读者负担
- 仅出现1-2次的术语被缩写
- 首次使用未定义缩写

**准则：**
- 仅缩写出现≥3-4次的术语
- 摘要中首次使用需定义（若摘要出现）
- 正文首次使用需定义
- 标题禁用缩写
- 尽量限制每篇论文新缩写≤3-4个
- 标准缩写（DNA/RNA/HIV等）无需定义

**示例：**
```
拙劣："我们测量基线脑源性神经营养因子（BDNF）。BDNF水平升高。"
（仅出现两次，无需缩写）

改进："我们测量基线脑源性神经营养因子水平。其水平升高。"
```

## 具体句式问题

### 悬垂修饰语

**问题：**
```
"孵育2小时后，我们测量吸光度。"
（暗示"我们"被孵育）

改进："样本孵育2小时后，我们测量吸光度。"
或："经2小时孵育后，我们测量吸光度。"
```

### 逗号错位

**常见错误：**

**主谓之间：**
```
错误："干预组的参与者们，显示出改善。"
正确："干预组的参与者们显示出改善。"
```

**复合谓语中：**
```
错误："我们测量了血压，并记录了症状。"
正确："我们测量了血压并记录了症状。"
（连接非独立分句时"and"前不加逗号）
```

### 代词一致性

```
错误："每位参与者完成了他们的问卷。"
正确："每位参与者完成了他或她的问卷。"
更佳："参与者们完成了各自的问卷。"
```

### 主谓一致

```
错误："这群参与者是异质的。"
正确："这群参与者是异质的。"
（主语为"群"[单数]，非"参与者"）

但："参与者们是异质的。"（复数主语）
```

## 选词规范

### 科学写作中易混淆词汇

| 常见误用词汇 | 正确用法 |
|---------------|---------------|
| **affect / effect** | Affect (动词): 影响; Effect (名词): 结果; Effect (动词): 实现 |
| **among / between** | Among: 三者及以上; Between: 两者之间 |
| **continual / continuous** | Continual: 反复发生; Continuous: 持续不间断 |
| **data is / data are** | Data 为复数形式; datum 为单数形式 |
| **fewer / less** | Fewer: 可数名词; Less: 不可数量词 |
| **i.e. / e.g.** | i.e. (即): 重申说明; e.g. (例如): 举例说明 |
| **imply / infer** | Imply: 暗示; Infer: 推断 |
| **parameter / variable** | Parameter: 总体参数; Variable: 测量变量 |
| **principal / principle** | Principal: 主要的; Principle: 原理或原则 |
| **significant** | 仅用于表示统计显著性，而非重要性 |
| **that / which** | That: 限定性从句; Which: 非限定性从句 |

### 应避免或谨慎使用的词汇

**避免非正式表达：**
- "a lot of" → 改用 "many" 或 "substantial"
- "got" → 改用 "obtained" 或 "became"
- "showed up" → 改用 "appeared" 或 "was evident"

**避免模糊量词：**
- "some" → 需明确具体数量
- "often" → 需明确频率
- "recently" → 需明确时间范围

**避免冗余修饰语：**
- "very significant" → 简化为 "significant" (p值体现程度)
- "quite large" → 简化为 "large" 或明确尺寸
- "rather interesting" → 删除或解释原因

## 数字与单位规范

### 数字与文字使用场景

**使用阿拉伯数字：**
- 所有 ≥10 的数字
- 带单位的数字 (5 mg, 3 mL)
- 统计值 (p=0.03, t=2.14)
- 年龄、日期、时间
- 分数与量表
- 百分比 (15%)

**使用文字表述：**
- <10 且不带单位的数字 (五名受试者)
- 句首数字 (需拼写或调整句式)

**示例：**
```
"五名受试者退出" 或 "共有5例退出情况"
(避免："5名受试者退出")

"我们在3个时间点测试了15份样本"
"平均年龄为45岁"
```

### 单位与格式规范

**准则：**
- 数字与单位间留空格 (5 mg，非5mg)
- 单位后不加句点 (mg 非 mg.)
- 优先采用国际单位制 (SI)，领域惯例除外
- 小数位数保持一致
- 千位分隔符使用逗号 (12,500 非 12500)

**范围表示：**
- 用短横线(–)表示范围: 15–20 mg
- 单位仅置于末尾: 15–20 mg (非 15 mg–20 mg)

## 段落结构

### 理想段落长度

**准则：**
- 通常3-7个句子
- 每段落聚焦一个核心观点
- 过短(<2句): 需拓展观点或合并段落
- 过长(>10句): 需拆分段落

### 段落连贯性技巧

**1. 主题句引导：**
```
"运动训练通过多种机制改善心血管功能。
[后续句子具体阐释这些机制]"
```

**2. 过渡短语：**
- 首先、其次、再次、最后
- 此外、而且、另外
- 然而、不过、相反
- 因此、因而、所以
- 例如、具体而言、特别是

**3. 核心术语复现：**
```
"...这种作用机制。该机制可解释..."
(避免："...这种机制。该过程可解释...")
```

**4. 平行结构：**
```
"A组接受药物。B组接受安慰剂。C组不接受治疗。"
(避免："A组接受药物。安慰剂给予B组。第三组未获治疗。")
```

## 期刊特化写作风格

### 四大写作风格类别

1. **大众可读型** (Nature, Science, PNAS)
2. **临床专业型** (NEJM, Lancet, JAMA)
3. **技术专精型** (领域特定期刊)
4. **机器学习会议型** (NeurIPS, ICML, ICLR, CVPR)

### 写作风格对比

| 维度 | 大众期刊 | 医学期刊 | 专业期刊 | ML会议 |
|--------|---------------|---------|-------------|---------------|
| **句长** | 15-20词 | 12-18词 | 18-25词 | 12-20词 |
| **词汇** | 最小化术语 | 临床术语 | 领域专有 | 技术术语+数学符号 |
| **语气** | 引人入胜 | 严谨保守 | 正式规范 | 直白贡献导向 |
| **关键短语** | "本研究证明" | "我们开展" | "为阐明" | "我们提出"、"本文贡献" |

**ML会议风格特征：**
- 直白技术语言配合数学符号
- 贡献点明确（常编号列出）
- 默认读者具备ML专业知识（CNN, Transformer等）
- 强调创新性与性能提升
- 需提供伪代码与公式

**范例开篇(NeurIPS风格)：**
```
视觉Transformer在图像分类中达到顶尖水平，但其二次复杂度限制了高分辨率图像应用。我们提出Efficient-ViT，在保持精度同时将复杂度降至O(n log n)。本文贡献：(1)新型稀疏注意力机制，(2)理论分析证明表达能力保留，(3)ImageNet实验验证提速15%且精度相当。
```
- 技术背景中提出问题
- 预告解决方案
- 编号列出贡献点
- 量化性能声明

### 核心写作差异

| 维度 | 大众期刊 | 医学期刊 | 专业期刊 | ML会议 |
|--------|---------------|---------|-------------|---------------|
| **段长** | 3-5句 | 5-7句 | 6-10句 | 4-6句 |
| **公式使用** | 最小化 | 极少 | 适度 | 必需 |
| **语态** | 主动优先 | 混合 | 被动可接受 | 主动优先 |
| **谨慎表述** | 适度 | 保守 | 详尽 | 最小化（明确声明贡献） |
| **图表整合** | 紧密 | 系统化 | 详细 | 密集嵌入正文 |

### 期刊评审重点

| 期刊类型 | 核心评审标准 |
|-------|------------------------|
| **大众期刊** | 非专业人士可读？普适价值明确？叙事吸引力？ |
| **医学期刊** | 临床相关性？专业语气？方法完整性？ |
| **专业期刊** | 技术精确性？领域专业性？方法细节？ |
| **ML会议** | 贡献点清晰？实验支撑结论？可复现性？ |

**常见退稿原因：**
- 写作质量差/表述不清
- 风格与期刊不匹配
- 结论过度夸大
- 方法缺乏复现性
- 关键细节缺失（ML需基线/消融实验；期刊需统计验证）

### 风格快速转换指南

| 转换方向 | 核心调整 |
|-----------|-------------|
| **期刊→ML会议** | 增加贡献点编号；补充公式/伪代码；强调量化提升；精简行文 |
| **ML会议→期刊** | 删除贡献编号；扩展研究背景；分离结果与讨论；减少正文公式 |
| **专业→大众** | 简化语言；突出普适意义；解释技术概念；补充背景知识 |
| **大众→专业** | 增加技术细节；自由使用术语；深化机制讨论；引用领域文献 |
| **基础→临床** | 补充临床背景；采用临床术语；强调治疗意义；引用临床证据 |

### 投稿前风格自检

**通用要求：**
- [ ] 写作风格匹配目标期刊近3-5篇论文
- [ ] 句长符合期刊特征
- [ ] 术语难度恰当
- [ ] 语气与期刊一致
- [ ] 无夸大表述

**ML会议附加：**
- [ ] 引言中贡献点明确编号
- [ ] 数学符号正确且统一
- [ ] 关键算法提供伪代码
- [ ] 性能声明量化（如"提速15%"、"精度提升2.3%"）
- [ ] 声明研究局限性

## 核心原则

高效科学写作需持续实践，基本原则包括：

1. **清晰性**高于复杂性
2. **简洁性**尊重读者时间
3. **准确性**建立可信度
4. **客观性**维护科学诚信
5. **一致性**促进理解
6. **逻辑组织**引导阅读
7. **期刊适配**提升发表成功率

**谨记：** 目标非炫耀词汇或复杂度，而是清晰精确地传递科学发现，使读者能理解、评估并延续您的工作。根据目标期刊的预期与读者调整写作风格。
