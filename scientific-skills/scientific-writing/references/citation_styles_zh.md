# 引文格式指南

## 概述

引文格式为学术写作中的文献引用提供了标准化规范。不同学科领域偏好不同格式，期刊通常明确指定所采用的格式。科学领域最常见的五种引文格式是AMA、Vancouver、APA、Chicago和IEEE。

## 选择合适格式

| 格式 | 主要学科领域 | 文内引用格式 |
|-------|-------------------|----------------|
| AMA | 医学、健康科学 | 上标数字¹ |
| Vancouver | 生物医学 | 方括号数字 [1] |
| APA | 心理学、社会科学、教育学 | 作者-日期 (Smith, 2023) |
| Chicago | 人文学科、历史学、部分科学领域 | 注释-参考文献或作者-日期 |
| IEEE | 工程学、计算机科学 | 方括号数字 [1] |
| ACS | 化学 | 上标数字¹ 或 (1) |
| NLM | 生命科学、PubMed | 方括号数字 [1] |

**默认建议**：不确定时请查阅期刊投稿指南。大多数生物医学期刊采用Vancouver或AMA格式。

## AMA格式（美国医学会）

### 概述
- 主要用于医学研究
- 基于《AMA格式手册》（第11版，2020年）
- 采用上标数字序号
- 参考文献按出现顺序编号排列

### 文内引用

**基本格式**：数字上标位于句号逗号外，分号冒号内。

**示例：**
```
多项研究证实了此效应。¹

结果尚无定论²，但Smith等³报告了相反结论。

这些发现³⁻⁵表明存在相关性。

一项荟萃分析⁶发现显著异质性；然而合并效应具有显著性。⁷
```

**多文献引用**：用逗号或连字符表示范围
```
多项研究¹,³,⁵⁻⁷已确认此现象。
```

**同源多次引用**：始终使用相同编号

### 参考文献格式

**期刊论文：**
```
1. 作者AA, 作者BB, 作者CC. 文章标题. 期刊名称. 年份;卷号(期号):起止页码. doi:xx.xxxx
```

**示例：**
```
1. Smith JD, Johnson AB, Williams CD. Effectiveness of cognitive behavioral therapy for anxiety disorders. JAMA Psychiatry. 2023;80(5):456-464. doi:10.1001/jamapsychiatry.2023.0123
```

**书籍：**
```
2. 作者AA. 书名. 版次. 出版社; 年份.
```

**书籍章节：**
```
3. 章节作者AA. 章节标题. 见: 编者AA, 编者BB, 编. 书名. 版次. 出版社; 年份:起止页码.
```

**网络资源：**
```
4. 机构名称. 页面标题. 网站名. 发布日期. 更新日期. 访问日期. URL
```

### 特殊情况

**超6位作者**：列前3位后加"et al"
```
Smith JD, Jones AB, Williams CD, et al.
```

**无作者**：以标题开头

**在线优先出版**：
```
Published online 月 日, 年份. doi:xx.xxxx
```

## Vancouver格式

### 概述
- 由国际医学期刊编辑委员会(ICMJE)制定
- 详见《医学期刊学术工作实施、报告、编辑与出版建议》
- 亦称"作者-数字格式"
- 方括号数字编号
- 参考文献按序号排列

### 文内引用

**基本格式**：相关文本后方括号数字，位于句号逗号前。

**示例：**
```
多项研究显示此效应[1]。

结果尚无定论[2]，但Smith等[3]报告相反结论。

这些发现[3-5]表明存在相关性。

多项研究[1,3,5-7]已确认此现象。
```

### 参考文献格式

**期刊论文：**
```
1. 作者AA, 作者BB, 作者CC. 文章标题. 期刊名称. 年份;卷号(期号):起止页码.
```

**示例：**
```
1. Smith JD, Johnson AB, Williams CD. Effectiveness of cognitive behavioral therapy for anxiety disorders. JAMA Psychiatry. 2023;80(5):456-464.
```

**书籍：**
```
2. 作者AA, 作者BB. 书名. 版次. 出版地: 出版社; 年份.
```

**书籍章节：**
```
3. 章节作者AA, 章节作者BB. 章节标题. 见: 编者AA, 编者BB, 编. 书名. 版次. 出版地: 出版社; 年份. p. 起止页码.
```

**电子资源：**
```
4. 作者AA. 页面标题[网络资源]. 出版地: 出版社; 出版日期[引用日期]. 获取地址: URL
```

### 特殊情况

**超6位作者**：列前6位后加"et al."

**期刊名缩写**：采用PubMed/Index Medicus缩写
- *The Journal of the American Medical Association* → *JAMA*
- *Nature Medicine* → *Nat Med*

**无卷期号**：仅用年份和页码

**待刊文章**：使用"[Epub ahead of print]"标注

## APA格式（美国心理学会）

### 概述
- 广泛应用于心理学、教育学及社会科学
- 基于《APA出版手册》（第7版，2020年）
- 文内引用采用作者-日期格式
- 参考文献按作者姓氏字母排序

### 文内引用

**基本格式**：(作者, 年份)

**示例：**
```
一项研究发现显著效应(Smith, 2023)。

Smith(2023)发现显著效应。

多项研究(Jones, 2020; Smith, 2023; Williams, 2024)支持此结论。
```

**两位作者**：括号内用"&"，叙述中用"和"
```
(Smith & Jones, 2023)
Smith和Jones(2023)证实...
```

**三位及以上作者**：首作者后加"et al."
```
(Smith et al., 2023)
Smith等(2023)报告...
```

**同作者同年多作品**：添加字母
```
(Smith, 2023a, 2023b)
```

**直接引文**：包含页码
```
(Smith, 2023, p. 45)
"引文内容"(Smith, 2023, p. 45)。
Smith(2023)指出："引文内容"(p. 45)。
```

### 参考文献格式

**期刊论文：**
```
作者, A. A., 作者, B. B., & 作者, C. C. (年份). 文章标题. 期刊名称, 卷号(期号), 起止页码. https://doi.org/xx.xxxx
```

**示例：**
```
Smith, J. D., Johnson, A. B., & Williams, C. D. (2023). Effectiveness of cognitive behavioral therapy for anxiety disorders. JAMA Psychiatry, 80(5), 456-464. https://doi.org/10.1001/jamapsychiatry.2023.0123
```

**书籍：**
```
作者, A. A. (年份). 书名: 副标题(版次). 出版社. https://doi.org/xx.xxxx
```

**书籍章节：**
```
章节作者, A. A., & 章节作者, B. B. (年份). 章节标题. 见 E. E. 编者 & F. F. 编者 (编), 书名 (pp. 起止页码). 出版社.
```

**网站：**
```
作者, A. A. (年份, 月 日). 页面标题. 网站名称. URL
```

### 大小写规则
- 文章及书名采用句子式（仅首词和专有名词大写）
- 期刊名采用标题式（所有实词大写）

**示例：**
```
Smith, J. D. (2023). Effects of stress on cognitive performance: A meta-analysis. Journal of Experimental Psychology: General, 152(3), 456-478.
```

### 特殊情况

**无作者**：将标题移至作者位
```
作品标题. (年份). 期刊名称...
```

**无日期**：用(n.d.)
```
Smith, J. D. (n.d.). 标题...
```

**20位以内作者**：全部列出，末位前加"&"
**21位及以上作者**：列前19位，加"..."，再列末位作者

## Chicago格式

### 概述
- 基于《芝加哥格式手册》（第17版，2017年）
- 两套系统：注释-参考文献与作者-日期
- 注释-参考文献系统多用于人文学科
- 作者-日期系统多用于科学领域

### 注释-参考文献系统

**文内**：脚注/尾注上标数字
```
一项研究证实此效应。¹
```

**注释格式：**
```
1. John D. Smith, Alice B. Johnson, and Carol D. Williams, "Effectiveness of Cognitive Behavioral Therapy for Anxiety Disorders," JAMA Psychiatry 80, no. 5 (2023): 456-64.
```

**参考文献格式：**
```
Smith, John D., Alice B. Johnson, and Carol D. Williams. "Effectiveness of Cognitive Behavioral Therapy for Anxiety Disorders." JAMA Psychiatry 80, no. 5 (2023): 456-64.
```

### 作者-日期系统

**文内**：类似APA
```
(Smith, Johnson, and Williams 2023)
Smith, Johnson, and Williams (2023)发现...
```

**参考文献**：类似APA但标点不同
```
Smith, John D., Alice B. Johnson, and Carol D. Williams. 2023. "Effectiveness of Cognitive Behavioral Therapy for Anxiety Disorders." JAMA Psychiatry 80 (5): 456-64.
```

### 特点
- 参考文献用全名（非缩写）
- 用"and"而非"&"
- 标点与APA不同

## IEEE格式

### 概述
- 用于工程学、计算机科学与技术领域
- 由电气电子工程师学会发布
- 方括号数字编号
- 参考文献按序号排列

### 文内引用

**格式**：方括号数字

**示例：**
```
多项研究证实此效应[1]。

该算法由Smith描述[2]，后经改进[3],[4]。

已有多种实现方案[1]-[4]。
```

### 参考文献格式

**期刊论文：**
```
[1] A. A. 作者, B. B. 作者, and C. C. 作者, "文章标题," 期刊名称, vol. 卷号, no. 期号, pp. 起止页码, 月份 年份.
```

**示例：**
```
[1] J. D. Smith, A. B. Johnson, and C. D. Williams, "Effectiveness of cognitive behavioral therapy for anxiety disorders," JAMA Psychiatry, vol. 80, no. 5, pp. 456-464, May 2023.
```

**书籍：**
```
[2] A. A. 作者, 书名, 版次. 城市, 州: 出版社, 年份.
```

**会议论文：**
```
[3] A. A. 作者, "论文标题," 见 会议名称, 城市, 州, 年份, pp. 起止页码.
```

**网络资源：**
```
[4] A. A. 作者. "标题." 网站. URL (访问于 月. 日, 年份).
```

### 特点
- 作者名缩写
- 末位作者前用"and"（非逗号）
- 月份缩写（Jan., Feb.等）
- 卷期前加"vol."和"no."
- 页码前加"pp."

## 其他格式

### ACS格式（美国化学会）

**文内**：上标数字或括号数字
```
此反应已被深入研究。¹
此反应已被深入研究(1)。
```

**参考文献格式：**
```
(1) Smith, J. D.; Johnson, A. B.; Williams, C. D. 文章标题. J. Am. Chem. Soc. 2023, 145, 1234-1245.
```

**特点：**
- 作者间用分号
- 期刊名缩写
- 年份加粗
- 无期号

### NLM格式（美国国家医学图书馆）

**与Vancouver高度相似**，用于PubMed/MEDLINE

**关键区别：**
- 采用PubMed期刊缩写
- 电子出版物有特定格式
- 可包含PMID或PMCID

**示例：**
```
Smith JD, Johnson AB, Williams CD. Effectiveness of cognitive behavioral therapy for anxiety disorders. JAMA Psychiatry. 2023 May;80(5):456-64. doi: 10.1001/jamapsychiatry.2023.0123. PMID: 12345678.
```

## 通用引用规范

### 跨格式通则

**何时引用：**
- 直接引文
- 他人观点的转述
- 来自他处的统计数据或图表
- 他人提出的理论模型
- 非常识性信息

**引用密度：**
- 引言：充分引用以建立背景
- 方法：引用既有方案或工具
- 结果：极少引用（聚焦自身发现）
- 讨论：频繁引用以对比前人工作

**文献质量：**
- 首选同行评审期刊论文
- 尽可能引用原始文献（非二次引用）
- 采用近期文献（活跃领域5-10年内）
- 确保来源可靠且相关

**常见错误：**
- 格式不一致
- 遗漏必要元素（DOI、页码等）
- 引用未实际阅读的文献
- 过度依赖综述而非原始研究
- 包含未引用文献或遗漏已引文献
- 作者姓名或缩写错误
- 出版年份错误
- 标题截断

### 文献管理

**文献管理软件：**
- **Zotero**：免费开源，浏览器集成
- **Mendeley**：免费，PDF标注，社交功能
- **EndNote**：商业版，功能强大，机构支持
- **RefWorks**：网页版，机构订阅

**软件优势：**
- 自动多格式排版
- 文内引用插入
- 参考文献生成
- PDF文件管理
- 共享协作功能

### 引用核查

**投稿前检查：**
1. 每个文内引用均有对应参考文献
2. 每篇参考文献均被引用
3. 全文格式统一
4. 作者姓名及缩写正确
5. 标题准确无误
6. 期刊缩写符合要求
7. 卷期页码正确
8. 包含DOI（如要求）
9. 网址链接有效
10. 序号格式排序正确

## DOI（数字对象标识符）

### 何为DOI？
永久标识数字内容的唯一字母数字串。

**格式：**
```
doi:10.1001/jamapsychiatry.2023.0123
或
https://doi.org/10.1001/jamapsychiatry.2023.0123
```

### 何时使用：
- 多数期刊要求近期出版物必须包含
- 优先于URL（DOI永久有效）
- 若未提供，可在https://www.crossref.org/查询

### 格式规范：
- **AMA**：`doi:10.xxxx/xxxxx`
- **APA**：`https://doi.org/10.xxxx/xxxxx`
- **Vancouver**：常省略或按期刊要求添加
- **Chicago**：`https://doi.org/10.xxxx/xxxxx`

## 期刊论文格式速查

| 格式 | 规范 |
|-------|--------|
| **AMA** | 作者AA, 作者BB. 文章标题. *期刊*. 年份;卷(期):起止页. doi:xx |
| **Vancouver** | 作者AA, 作者BB. 文章标题. 期刊. 年份;卷(期):起止页. |
| **APA** | 作者, A. A., & 作者, B. B. (年份). 文章标题. *期刊*, 卷(期), 起止页. https://doi.org/xx |
| **Chicago A-D** | 作者, A. A., and B. B. 作者. 年份. "标题." *期刊* 卷 (期): 起止页. |
| **IEEE** | A. A. 作者 and B. B. 作者, "标题," *期刊*, vol. 卷号, no. 期号, pp. 起止页, 月份缩写 年份. |

## 常用缩写

### 期刊缩写
遵循期刊指定系统（通常为Index Medicus或ISO）：
- *The Journal of Biological Chemistry* → *J Biol Chem*
- *Proceedings of the National Academy of Sciences* → *Proc Natl Acad Sci USA*
- *Nature Medicine* → *Nat Med*

### 月份缩写

- 一月、二月、三月、四月、五月、六月、七月、八月、九月、十月、十一月、十二月
- 部分格式使用不带句点的三字母缩写

### 版本缩写
- 第1版、第2版、第3版等
- 或：第一版、第二版

## 特殊出版物类型

### 预印本
```
APA: 作者, A. A. (年份). 标题 [预印本]. 存储库名称. https://doi.org/xx.xxxx
```

### 学位论文
```
APA: 作者, A. A. (年份). 标题 [博士论文, 大学名称]. 存储库名称. URL
```

### 会议论文集
```
IEEE: A. A. 作者, "标题," in Proc. 会议名称, 城市, 年份, pp. XX-XX.
```

### 软件/代码
```
APA: 作者, A. A. (年份). 标题 (版本 X.X) [计算机软件]. 出版商. URL
```

### 数据集
```
APA: 作者, A. A. (年份). 数据集标题 (版本 X) [数据集]. 存储库. https://doi.org/xx.xxxx
```

## 格式转换指南

转换引文格式时：

1. **使用文献管理软件**实现自动转换
2. **重点检查以下差异项**：
   - 文内引用格式（编号制 vs 作者-日期制）
   - 作者姓名格式（缩写 vs 全名）
   - 标题大小写规则（句子首字母大写 vs 标题式大写）
   - 期刊名格式（缩写 vs 全称）
   - 标点符号（句点、逗号、分号）
   - 斜体与粗体使用规范
   - 元素排列顺序
3. **自动转换后需人工复核**
4. **查阅期刊指南**确认特殊要求

## 期刊特定引文格式要求

### 识别期刊引文格式的方法

**步骤1：查阅作者指南**
- 所有期刊均提供投稿指南（通常标注为"投稿须知"或"作者指南"）
- 引文格式通常在"参考文献"或"引用"章节说明
- 查找期刊提供的格式示例

**步骤2：分析近期刊文**
- 研读目标期刊的3-5篇近期论文
- 注意文内引用格式（编号制 vs 作者-日期制）
- 对比参考文献列表格式
- 检查期刊特有变体

**步骤3：确认期刊特有规范**
部分期刊采用修改版标准格式：
- 期刊名缩写与全称规则
- DOI收录要求
- 文章标题大小写规范
- 作者人数上限（et al.启用条件）

### 常见期刊及其引文格式

| 期刊 | 引文格式 | 核心特征 |
|---------|---------------|--------------|
| **JAMA及JAMA系列期刊** | AMA | 上标数字、期刊名缩写、无期号 |
| **新英格兰医学杂志** | 修订版温哥华格式 | 方括号编号、期刊名缩写、作者上限3人（后接et al） |
| **柳叶刀** | 温哥华格式 | 方括号编号、PubMed缩写 |
| **英国医学杂志** | 温哥华格式 | 文内编号、必须包含DOI |
| **Nature及Nature系列期刊** | Nature格式（编号制） | 上标编号、期刊名缩写、部分期刊不列文章标题 |
| **Science** | Science格式（编号制） | 文内编号、缩写格式 |
| **Cell及Cell Press期刊** | Cell格式（作者-年份制） | 作者-日期、多文献引用特殊格式 |
| **PLOS系列期刊** | 温哥华格式 | 方括号编号、部分PLOS期刊用期刊全称 |
| **生物化学杂志** | JBC格式（编号制） | 文内编号、特定缩写规则 |
| **心理学期刊** | APA | 作者-日期、必须包含DOI |
| **IEEE期刊** | IEEE | 方括号编号、会议论文特定格式 |
| **ACS期刊** | ACS | 上标或编号、作者间用分号分隔 |

### 同出版社期刊格式一致性

**同出版社期刊常采用统一格式：**

**Elsevier期刊：**
- 差异较大，需查阅具体期刊
- 多采用温哥华编号制
- 部分接受作者-日期制

**Springer Nature期刊：**
- Nature系列：Nature格式（编号制、缩写）
- Springer期刊：按领域采用编号制或作者-日期制
- BMC期刊：温哥华格式（期刊全称）

**Wiley期刊：**
- 因领域而异
- 生物医学期刊多采用温哥华格式
- 心理学/社会科学期刊常用APA格式

**美国化学会(ACS)期刊：**
- 所有ACS期刊采用ACS格式
- 美国化学会志、分析化学等期刊保持统一

### 高影响力期刊与会议偏好

| 出版机构 | 领域 | 引文偏好 | 核心特征 |
|-------|-------|-------------------|--------------|
| **Nature/Science** | 多学科 | 编号制、缩写 | 节省篇幅、普适性强 |
| **Cell系列** | 生命科学 | 作者-日期制或编号制 | 突出贡献归属 |
| **NEJM/柳叶刀/JAMA** | 医学 | 温哥华/AMA编号制 | 医学领域标准 |
| **NeurIPS/ICML/ICLR** | 机器学习 | 编号[1]或(作者,年份) | 按会议模板调整 |
| **CVPR/ICCV/ECCV** | 计算机视觉 | 编号[1]，类IEEE格式 | 紧凑格式 |
| **ACL/EMNLP** | 自然语言处理 | 作者-年份制（ACL格式） | 强调贡献归属 |

### 期刊转换时的格式调整

**被拒稿或撤稿后转投其他期刊：**

**文献管理软件操作流程：**
1. 将文献导入Zotero/Mendeley/EndNote
2. 从软件库选择目标期刊格式
3. 自动生成引文与参考文献列表
4. 人工核验格式是否符合期刊范例

**格式转换检查要点：**
- 文内格式切换（编号制 ↔ 作者-日期制）
- 期刊名缩写规范
- 文章标题大小写
- 作者姓名格式（缩写 vs 全名）
- DOI格式与收录要求
- 期号收录规则
- 页码格式

**必须人工核验的特殊文献：**
- 预印本等非标准来源
- 软件/数据集引用
- 会议论文集
- 学位论文

### 出版机构特定评估标准

**内容要求：**
- **高影响力期刊**：近5年文献占比>50%；优先引用原始文献
- **医学期刊**：近期临床证据；重视系统综述
- **机器学习会议**：近2-3年文献；接受预印本（arXiv）
- **自引率**：所有出版机构均要求<20%

**格式合规性（常自动化检测）：**
- 严格匹配目标格式
- 文内引用与参考文献完全对应
- 按要求包含DOI（期刊）或arXiv ID（机器学习会议）
- 使用正确缩写（医学用PubMed缩写，机器学习用标准缩写）

**机器学习会议特殊要求：**
- **NeurIPS/ICML/ICLR**：广泛引用arXiv预印本；重视近期成果
- **严格页数限制**：引文格式影响篇幅
- **补充材料**：可包含扩展文献
- **双盲评审**：审稿期间避免明显自引模式

### 不同出版机构的引文密度

| 出版机构类型 | 预期引文量 | 核心说明 |
|-----------|-------------------|-----------|
| **Nature/Science研究论文** | 30-50篇 | 精选高影响力文献 |
| **医学期刊（随机对照试验）** | 25-40篇 | 近期临床证据 |
| **专业领域期刊** | 30-60篇 | 全面覆盖领域文献 |
| **机器学习会议（8页）** | 20-40篇 | 篇幅受限，侧重近期成果 |
| **综述文章** | 100-300+篇 | 全面覆盖领域文献 |

**机器学习会议引用惯例：**
- **NeurIPS/ICML**：8页论文通常25-40篇参考文献
- **研讨会论文**：15-25篇参考文献
- **arXiv预印本**：广泛接受并引用
- **相关工作**：简洁全面；常移至附录
- **时效性关键**：相关文献应引用近1-2年成果

### 投稿前引文检查清单

**内容要求：**
- [ ] 近5-10年文献≥50%（机器学习会议需近2-3年）
- [ ] 自引率<20%；保持观点平衡
- [ ] 引用原始文献（避免转引）
- [ ] 所有论点均有文献支撑

**格式要求：**
- [ ] 严格匹配目标格式（检查模板）
- [ ] 文内引用与参考文献完全对应
- [ ] 按要求包含DOI/arXiv ID
- [ ] 缩写符合目标规范

**机器学习会议附加项：**
- [ ] arXiv预印本格式正确
- [ ] 双盲评审时匿名化自引
- [ ] 参考文献符合页数限制
