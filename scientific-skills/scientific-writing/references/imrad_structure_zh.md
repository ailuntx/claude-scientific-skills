# IMRAD结构指南

## 概述

IMRAD（引言、方法、结果与讨论）是原创性科研论文的主流组织结构。自1970年代起被广泛采用，现已成为医学、健康、生物、化学、工程及计算机科学领域的标准格式。

## 为何采用IMRAD？

IMRAD结构映射科学方法：
- **引言**：你提出了什么问题？
- **方法**：你如何研究它？
- **结果**：你发现了什么？
- **讨论**：这意味着什么？

这种逻辑流程使科学论文更易于撰写、阅读和评估。

## 完整稿件构成

完整的科研稿件通常按顺序包含以下部分：

1. **标题**
2. **摘要**
3. **引言**
4. **方法**（亦称材料与方法、方法论）
5. **结果**
6. **讨论**（有时与结果合并）
7. **结论**（有时属于讨论部分）
8. **致谢**
9. **参考文献**
10. **补充材料**（如适用）

## 标题

### 目的
吸引读者并准确反映论文内容。

### 准则
- 简洁而具描述性（通常10-15词）
- 包含关键变量与研究关系
- 避免缩写、行话和疑问句式（除非期刊允许）
- 足够具体以区别于其他研究
- 包含可检索的关键词

### 示例
- 优秀范例："高强度间歇训练对老年人心血管功能的影响"
- 过于模糊："运动与健康"
- 过于详细："一项随机对照试验：比较高强度间歇训练与中等强度持续训练对60-75岁成人VO2 Max测量心血管功能的影响"

## 摘要

### 目的
提供完整独立的概要，帮助读者判断全文相关性。

### 格式：连贯段落（默认）

**⚠️ 关键要求：摘要应写成连贯段落，而非带标签的分段形式。**

多数科研论文采用**非结构化摘要**，由一至两个连贯段落组成。这是Nature、Science、Cell、PNAS及大多数专业期刊的标准格式。

❌ **错误 - 带标签的结构化摘要：**
```
背景：医院获得性感染仍是主要致病因素。
方法：我们开展了为期12个月的前后对照研究...
结果：干预后表面污染减少47%...
结论：UV-C消毒显著降低感染率。
```

✅ **正确 - 连贯段落格式：**
```
医院获得性感染仍是主要致病因素，但最佳消毒策略尚未明确。我们在500张床位的教学医院开展为期12个月的前后对照研究，评估在标准清洁流程基础上增加UV-C消毒的效果。每月对环境表面进行培养，并通过监测数据追踪感染率。干预后表面污染减少47%（95% CI: 38-56%, p<0.001），导管相关尿路感染率从每1000导管日3.2例降至1.8例（RR=0.56, 95% CI: 0.38-0.83, p=0.004）。未观察到不良反应。这些发现表明UV-C消毒能显著降低环境污染物和感染率，可作为医院感染控制项目的有效补充。
```

### 摘要结构（作为统一段落）

虽以连贯行文呈现，摘要应按顺序包含以下要素：

1. **背景与问题**（1-2句）：研究意义及现存空白
2. **研究描述**（1-2句）：研究内容与方法（研究设计）
3. **关键发现**（2-4句）：含具体定量数据的主要结果
4. **意义阐述**（1-2句）：解读、启示与结论

### 长度
- 通常150-300词（需核对期刊要求）
- 部分期刊允许至350词

### 核心规则
- **最后撰写**摘要（完成其他部分后）
- **采用连贯段落** - 禁用标签分段
- 确保脱离全文仍可理解
- 摘要中不引用参考文献
- 避免缩写或首次使用时定义
- 方法结果用过去时，结论用现在时
- 包含带统计指标的关键定量结果
- 使用过渡词自然衔接句子

### 结构化摘要适用场景（例外）

仅当符合以下条件时采用带标签分段（背景/目的、方法、结果、结论）：
- 期刊在投稿指南中**明确要求**结构化摘要
- 常见于部分医学期刊（JAMA、BMJ、Annals of Internal Medicine）
- 务必在排版前核对期刊要求

即使采用结构化摘要，每部分也需用完整句子而非片段。

### 示例：连贯段落摘要

```
转录组衰老时钟通过捕捉动态细胞状态及对扰动的急性反应，为评估生物年龄提供独特优势。基于ARCHS4数据库（含超120万人类样本的统一处理RNA-seq数据），我们开发了通过基因表达谱预测实际年龄的深度神经网络模型。最佳模型在保留测试集上达到4.2年平均绝对误差（R²=0.89），显著优于弹性网络回归（MAE=6.8年）和随机森林（MAE=5.9年）等传统机器学习方法。特征重要性分析显示衰老、炎症和线粒体功能通路富集基因是最强预测因子。跨组织验证表明肺与血液样本预测最准，而肝脏样本变异最大。这些发现确立了深度学习在转录组年龄预测中的优势地位，并为生物衰老评估提供了候选生物标志物。
```

## 引言

### 目的
说服读者本研究采用恰当方法解决重要问题。

### 结构与内容

**首段：宏观背景**
- 确立广阔研究领域
- 阐明课题重要性
- 既定事实用现在时
- 确保非专业人士可理解

**第2-3段：聚焦领域**
- 综述相关前期研究
- 说明已知结论
- 指出现有工作的争议或局限
- 逻辑递进至研究空白

**第4段：研究空白**
- 明确尚未解决的问题
- 解释该知识缺口的弊端
- 关联至宏观重要性

**末段：本研究**
- 阐明具体研究问题或假设
- 简述整体研究思路
- 说明如何填补空白
- 可选：预告关键发现（部分期刊不鼓励）

### 长度
- 通常1.5-2页（依期刊而定）
- 约4-5个段落
- 快报类文章可缩短

### 动词时态
- **现在时**：既定事实（"运动改善心血管健康"）
- **过去时**：前人研究及发现（"Smith等发现..."）
- **现在/过去时**：研究目标（"本研究旨在探究..."或"本研究探究了..."）

### 常见错误
- 开篇过于宽泛（如"自远古以来..."）
- 冗长文献综述（保留给综述文章）
- 引用无关或过时文献
- 未明确研究空白
- 研究理由不充分
- 未提出清晰研究问题或假设
- 包含方法或结果（应属后续章节）

### 需回答的关键问题
1. 该领域已知什么？
2. 未知什么？（研究空白）
3. 该空白为何重要？
4. 本研究旨在发现什么？

## 方法

### 目的
提供充足细节以供他人复现研究并评估有效性。

### 核心原则
同领域专家应能完全复现你的实验。

### 标准子章节

#### 研究设计
- 说明整体设计（如随机对照试验、队列研究、横断面调查）
- 若非显而易见需论证设计选择
- 如适用需说明盲法、随机化或对照

#### 参与者/受试者/样本
- 定义目标人群
- 精确描述纳入与排除标准
- 报告样本量及确定依据（功效分析）
- 说明招募方法与场景
- 动物研究：明确物种、品系、年龄、性别、饲养条件

#### 材料与设备
- 列出所有材料、试剂和设备
- 标注制造商名称与所在地（括号内）
- 特殊物品注明目录编号
- 说明软件名称及版本

#### 操作流程
- 按时间顺序描述操作步骤
- 包含足够复现细节
- 复杂流程使用子标题组织
- 明确时间参数（如"37°C孵育2小时"）
- 问卷/访谈：描述工具、验证方法及实施过程

#### 测量指标与结果
- 定义所有测量变量
- 明确主要与次要结局指标
- 说明测量工具及其效度
- 标注计量单位

#### 统计分析
- 列出所有统计检验方法
- 论证检验方法选择
- 说明显著性水平（通常α=0.05）
- 报告样本量功效分析
- 注明统计软件及版本
- 描述缺失数据处理方式
- 如适用需说明多重比较校正

#### 伦理考量
- 声明伦理委员会批准号
- 提及知情同意程序
- 人类研究：遵循赫尔辛基宣言
- 动物研究：遵循相关指南（如ARRIVE）

### 长度
- 通常2-4页
- 与研究复杂度成正比

### 动词时态
- **过去时**：已执行操作（"我们测量了..."，"受试者完成了..."）
- **现在时**：既定流程（"PCR可扩增..."，"该问卷包含..."）

### 常见错误
- 复现细节不足
- 方法首次出现在结果部分
- 包含结果或讨论
- 遗漏统计检验
- 未定义缩写
- 缺少伦理批准声明

## 结果

### 目的
客观呈现发现，不作解读。

### 核心原则
展示而不解读。解读保留至讨论部分。

### 结构与内容

**开篇段落**
- 描述参与者/样本特征
- 报告招募流程（如筛选、纳入、完成情况）
- 建议包含CONSORT式流程图

**后续段落**
- 按逻辑顺序呈现结果（通常先报告主要结局）
- 遵循引言所述目标顺序
- 按主题或时间线组织（以清晰为准）
- 按编号引用图表

**每项发现应包含：**
- 观测结果
- 效应方向
- 效应量级
- 统计显著性
- 置信区间

**示例**："干预组收缩压平均降低12 mmHg，对照组降低3 mmHg（差值：9 mmHg，95% CI：4-14 mmHg，p=0.002）。"

### 图表整合

**适用场景：**
- **图**：趋势、模式、分布、比较、关联
- **表**：精确数值、人口学数据、多变量

**引用规范：**
- "图1显示...分布"（非"下图1"）
- "表2呈现基线特征..."
- 勿在正文复述表内全部数据，强调关键发现
- 每个图表均需在正文引用

### 图表准则
- 按引用顺序连续编号
- 包含完整独立的标题
- 在标题或脚注中定义所有缩写
- 注明样本量（n）
- 标注统计显著性（*号、p值）
- 保持格式统一

### 统计报告

**必备要素：**
- 检验统计量（t、F、χ²等）
- 自由度
- p值（p>0.001时报告精确值，否则"p<0.001"）
- 效应量与置信区间
- 样本量

**示例**："组间测试表现差异显著（t(48)=3.21, p=0.002, Cohen's d=0.87, 95% CI: 0.34-1.40）。"

### 长度
- 通常2-4页
- 约等于方法部分长度

### 动词时态
- **过去时**：研究发现（"平均值为..."，"受试者表现出..."）

### 常见错误
- 解读结果（保留至讨论）
- 正文复述图表数据
- 提出新方法
- 统计细节不足
- 单位或符号不一致
- 未报告阴性或意外结果
- 选择性报告（应报告所有检验假设）

### 组织策略

**按目标：**
```
干预对主要结局的影响
干预对次要结局A的影响
干预对次要结局B的影响
```

**按分析类型：**
```
描述性统计
单变量分析
多变量分析
```

**按时间：**
```
基线特征
短期结局（1个月）
长期结局（6个月）
```

## 讨论

### 目的
解读发现、关联现有知识、说明局限性、提出未来方向。

### 结构与内容

**首段：主要发现概要**
- 重申主要目标或假设
- 用2-4句概括核心发现
- 避免复述结果细节
- 明确说明假设是否成立

**第2-4段：背景解读**
- 与前人研究对比
- 解释与既有成果的异同
- 提出发现的作用机制
- 讨论意外结果
- 考虑替代解释
- 评估发现对现有理论的支持/反驳

**第5段：优势与局限**
- 如实说明研究局限
- 解释局限如何影响解读
- 提及研究优势（设计、样本、方法）
- 避免泛泛而谈（如"需更大样本"）——具体说明

**第6段：启示**
- 临床启示（医学研究）
- 实际应用
- 政策建议
- 理论贡献

**末段：结论与未来方向**
- 总结核心结论
- 提出解决空白/局限的具体未来研究
- 以有力陈述收尾

### 长度
- 通常3-5页
- 常为最长章节

### 动词时态
- **过去时**：研究发现（"我们发现..."，"结果显示..."）
- **现在时**：既定事实与解读（"这表明..."，"这些发现意味着..."）
- **将来时**：启示与未来研究（"未来研究应探索..."）

### 讨论策略

**与前人研究对比：**
```
"症状减少30%的发现与Smith等（2023年）使用类似干预报告的28%降幅一致。但Jones等（2022年）因方案强度较低未发现显著效果。"
```

**提出机制：**
```
"观察到的认知功能改善可能源于脑血流量增加，前额叶皮层功能MRI信号同步增强可佐证。此解读符合认知增强的血管假说。"
```

**说明局限：**
```
"横断面设计无法推断因果关系。且单一学术医疗中心的便利样本可能限制结果向社区推广。虽通过结构化访谈尽量减少，但自我报告指标可能引入回忆偏倚。"
```

### 常见错误
- 单纯复述结果未解读
- 过度解读或妄断因果关系
- 忽视矛盾或阴性结果
- 未与现有文献对比
- 引入新数据或方法
- 局限讨论笼统肤浅
- 结论过度推广至研究人群外
- 遗漏"意义阐述"——未解释重要性

### 需回答的关键问题
1. 这些发现意味着什么？
2. 与前期研究有何异同？
3. 差异存在的原因？
4. 有哪些替代解释？
5. 研究局限是什么？
6. 实际启示为何？
7. 未来研究应探索什么？

## 结论

### 目的
简要总结核心发现及其意义。

### 位置
- 可为独立章节或讨论末段（需核对期刊要求）

### 内容
- 最多1-2段
- 重申主要发现
- 强调意义或启示
- 以有力陈述收尾
- **禁止**引入新信息

### 示例
```
本随机试验表明，为期12周的正念干预能显著降低大学生焦虑症状，且效果持续至6个月随访期。这些发现支持将正念课程纳入高校心理健康服务体系。鉴于团体正念训练的可扩展性与成本效益，该方法为应对高等教育日益严重的心理健康危机提供了可行策略。
```

## 其他章节

### 致谢
- 鸣谢资助方（注明项目编号）
- 致谢未达署名标准的重大贡献者
- 感谢提供材料、设备或协助者
- 声明利益冲突

### 参考文献

- 按期刊格式排版（参见 `citation_styles.md`）
- 核对所有引用的准确性
- 确保正文中出现的引用与参考文献列表一一对应
- 原创研究参考文献典型范围：20-50篇

### 补充材料
- 附加图表或数据集
- 详细实验方案或问卷
- 视频或音频文件
- 大型数据集或代码仓库

## 时态使用摘要

| 章节 | 动词时态 |
|------|----------|
| 摘要 - 背景 | 现在时（既定事实）或过去时（先前研究） |
| 摘要 - 方法 | 过去时 |
| 摘要 - 结果 | 过去时 |
| 摘要 - 结论 | 现在时 |
| 引言 - 总体背景 | 现在时 |
| 引言 - 先前研究 | 过去时 |
| 引言 - 研究目标 | 现在时或过去时 |
| 方法 | 过去时（你的操作），现在时（通用流程） |
| 结果 | 过去时 |
| 讨论 - 研究发现 | 过去时 |
| 讨论 - 结果阐释 | 现在时 |
| 讨论 - 先前工作 | 现在时或过去时 |
| 结论 | 现在时 |

## IMRAD结构变体

### 结果与讨论合并
- 部分期刊允许或要求此格式
- 结果呈现与解释交织进行
- 每项结果展示后立即讨论
- 适用于含多组实验的复杂研究

### 无独立结论的IMRaD
- 结论整合至讨论部分末段
- 多数期刊的常见做法

### 扩展版IMRaD (ILMRaD)
- 新增独立"文献综述"章节
- 多见于学位论文

## 不同研究类型的IMRAD调整

### 临床试验
- 结果部分添加CONSORT流程图
- 方法部分注明试验注册号
- 结果部分报告不良事件

### 系统综述/荟萃分析
- 方法描述检索策略与纳入标准
- 结果包含PRISMA流程图与数据整合
- 可增设章节（如偏倚风险评估）

### 病例报告
- 引言：疾病背景介绍
- 病例展示：替代方法与结果章节
- 讨论：关联病例与文献

### 观察性研究
- 遵循STROBE指南
- 方法部分重点标注潜在混杂因素
- 讨论部分阐明因果性局限

## 不同出版载体的结构要求

### 期刊与会议格式对比

| 载体类型 | 篇幅 | 结构 | 方法章节位置 | 核心侧重点 |
|----------|------|------|--------------|------------|
| **Nature/Science** | 2,000-4,500词 | 改良IMRAD | 补充材料 | 广泛意义 |
| **医学期刊** | 2,700-3,500词 | 严格IMRAD | 正文 | 临床结局 |
| **专业期刊** | 3,000-6,000词 | 标准IMRAD | 正文 | 技术深度 |
| **ML会议** | 8-9页（约6,000词） | 引言-方法-实验-结论 | 正文（精简） | 创新贡献 |

### ML会议结构（NeurIPS/ICML/ICLR）

**典型8页结构：**
1. **摘要**（150-200词）：问题、方法、关键结果
2. **引言**（1页）：动机、贡献概述、相关工作概览
3. **方法**（2-3页）：技术路径、架构、算法
4. **实验**（2-3页）：设置、数据集、基线、结果、消融研究
5. **相关工作**（0.5-1页，常置于附录）：详细文献对比
6. **结论**（0.25-0.5页）：总结、局限、未来方向
7. **参考文献**（计入或不计入页限视会议而定）
8. **附录/补充材料**（不限页）：附加实验、证明、细节

**与期刊的主要差异：**
- **贡献点罗列**：引言常采用编号列表（如"我们的贡献：(1)...(2)...(3)..."）
- **无独立结果/讨论**：整合于实验章节
- **消融研究**：验证关键要素的核心环节
- **算力需求**：常需注明（训练时长、GPU、内存）
- **代码可获取性**：日益成为硬性要求

### 章节篇幅占比

| 载体 | 引言 | 方法 | 结果/实验 | 讨论/结论 |
|------|------|------|-----------|-----------|
| **Nature/Science** | 10% | 15%* | 40% | 35% |
| **医学期刊（NEJM/JAMA）** | 10% | 25% | 30% | 35% |
| **专业期刊** | 20% | 25% | 30% | 25% |
| **ML会议** | 12-15% | 30-35% | 40-45% | 5-8% |

*Nature/Science期刊方法常置于补充材料

**医学期刊特征：**
- NEJM/柳叶刀/JAMA：严格IMRAD；临床导向；结构化讨论；符合CONSORT/STROBE
- 明确主/次要结局指标；预先统计方案

**ML会议特征：**
- 引言含编号贡献列表
- 方法含伪代码/公式细节
- 丰富实验：主结果、消融研究、分析
- 简短结论（标注局限）
- 相关工作常入附录

### 不同载体的写作风格

| 载体 | 受众 | 引言重点 | 方法细节 | 结果/实验 | 讨论/结论 |
|------|------|----------|----------|-----------|-----------|
| **Nature/Science** | 非专业人士 | 广泛意义 | 简略，入补充材料 | 故事化叙述 | 宏观影响 |
| **医学期刊** | 临床医师 | 临床问题 | 全面详尽 | 首要结局优先 | 临床相关性 |
| **专业期刊** | 领域专家 | 领域背景 | 完整技术细节 | 按实验组织 | 机制深度 |
| **ML会议** | ML研究者 | 创新贡献 | 可复现性 | 基线对比、消融研究 | 简略，标注局限 |

**ML会议侧重点：**
- **引言**：明确问题；编号贡献；定位前人工作
- **方法**：数学符号；伪代码；架构图；复杂度分析
- **实验**：数据集描述；多基线对比；消融研究；误差分析
- **结论**：总结；承认局限；社会影响（如需）

### 跨载体评审要点

**通用审核项：**
- **适配度**：符合载体范围与受众
- **篇幅**：符合限制（会议尤其严格）
- **清晰度**：写作质量达标；论点有据
- **可复现性**：方法支持复现
- **完整性**：报告全部结果；承认局限

**常见拒稿原因：**
- 研究意义不足
- 方法细节缺失致无法复现
- 结果不支持结论
- 讨论过度解读
- 超页/超字数（会议严格执行）

**ML会议特有评审：**
- 问题定义与动机清晰
- 创新性与贡献表述明确
- 基线模型全面且公平
- 消融研究验证有效性
- 代码/数据可获取性（日益重要）
- 复现信息（随机种子、超参数）

### 快速调整指南

**期刊 → ML会议：**
- 精简引言；添加编号贡献
- 方法保持简洁；增伪代码
- 合并结果与讨论 → 实验章节
- 增加消融研究与基线对比
- 结论简略标注局限

**ML会议 → 期刊：**
- 扩展引言背景
- 独立方法章节补充细节
- 拆分实验为结果与讨论
- 删除贡献编号
- 深化局限讨论

**专业期刊 → 综合期刊：**
- 简化引言；突出广泛意义
- 技术方法移入补充材料
- 结果组织故事化
- 讨论聚焦宏观影响

**综合期刊 → 专业期刊：**
- 增加详细文献综述
- 完整方法置于正文
- 按实验组织结果
- 补充机制深度讨论
