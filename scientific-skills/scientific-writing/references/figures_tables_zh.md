# 图表最佳实践

## 概述

图表是科学论文的核心组成部分，用于展示数据模式、总结结果并为结论提供证据。有效的视觉呈现能增强理解力，维持读者兴趣，同时揭示难以通过文字单独传达的趋势、模式和关联。

《自然·细胞生物学》最新检查清单（2025年）强调：创建清晰且引人入胜的科学图表对于精准、可访问且具备卓越设计地传递复杂数据至关重要。

## 何时使用表格与图表

### 使用表格的场景：
- 呈现读者需要查阅的精确数值
- 跨多变量比较精确测量值
- 展示详细统计输出
- 数据无法用1-2句话充分概括
- 读者需要获取特定数据点
- 显示人口统计学或基线特征
- 呈现多项关联性统计检验

**典型用例：**
- 参与者基线特征（年龄、性别、诊断等）
- 详细统计模型输出（系数、p值、置信区间）
- 含精确值的剂量反应数据
- 特定基因的表达水平
- 化学成分或浓度

### 使用图表的场景：
- 展示时间趋势
- 显示关系或相关性
- 可视化组间比较
- 说明数据分布
- 呈现数值难以体现的模式
- 展示图像（显微成像、放射影像等）
- 显示工作流程、示意图

**典型用例：**
- 生长曲线或时间序列
- 剂量反应曲线
- 显示相关性的散点图
- 比较治疗组的条形图
- 展示分布的直方图
- 跨条件显示模式的热图
- 显微图像或蛋白质印迹

### 通用决策规则

**信息能否用1-2句话表述？**
- 是 → 仅用文字
- 否，且需精确值 → 用表格
- 否，且模式/趋势最重要 → 用图表

## 核心设计原则

### 1. 自解释性展示项

**每个图表必须脱离正文独立存在。**

**必备要素：**
- 完整描述性标题
- 所有缩写需定义（在标题或脚注中）
- 明确标注计量单位
- 报告样本量（n）
- 说明统计学显著性标记
- 包含图例（多数据序列图表）

**自解释标题示例：**
```
图1. 干预组与对照组12周内平均收缩压（SBP）变化。
误差线代表均值标准误（SEM）。星号表示各时间点组间显著差异
（*p < 0.05, **p < 0.01, ***p < 0.001，双尾t检验）。每组n=48。
BP=血压；SEM=均值标准误。
```

### 2. 避免冗余

**不要在文字、表格和图表间重复信息。**

**错误示范：**
```
"A组平均年龄45.2岁，B组47.8岁。A组平均BMI 26.3，B组28.1。
A组平均收缩压132 mmHg..."
[同时展示在表1中]
```

**正确示范：**
```
"组间基线特征相似（表1），年龄、BMI及血压均无显著差异（所有p>0.15）。"
[细节见表1]
```

**核心原则：** 文字应强调图表关键发现，而非复述所有数据。

### 3. 一致性

**所有展示项保持统一格式：**
- 字体类型与大小
- 配色方案
- 术语与缩写
- 坐标轴标签与单位
- 统计标注方法
- 图表风格（同类图表样式统一）

**需避免的不一致示例：**
- 图1用"标准误"而图2用"SE"
- 图1采用蓝/红色系而图2用绿/黄色系
- 表1标注"p=0.023"而表2用"p-value=.023"

### 4. 数量优化

**遵循"每1000词配1个展示项"原则。**

**典型稿件：**
- 3000-4000词 → 总计3-4个图表
- 5000-6000词 → 总计5-6个图表

**质量优于数量：** 少量精心设计、信息丰富的展示项优于大量冗余或低质图表。

### 5. 清晰简洁

**避免杂乱或过度复杂的展示：**
- 单图勿包含过多变量
- 使用清晰易读字体（最终尺寸最小8-10磅）
- 元素间保留充足间距
- 采用高对比度（尤其考虑色觉障碍群体）
- 移除非必要网格线、边框或装饰
- 最大化数据墨水比（Tufte原则：最小化非数据墨水）

## 图表类型及适用场景

### 条形图

**最佳场景：**
- 比较离散类别或组别
- 显示计数或频率
- 展示带误差线的均值

**设计指南：**
- y轴从零开始（除非展示大数值中的微小差异）
- 按逻辑排序（按大小、字母或时间）
- 统一使用误差线（SD/SEM/CI）
- 标注样本量
- 避免3D效果（扭曲视觉感知）

**常见错误：**
- 未从零开始（夸大差异）
- 类别过多（考虑改用表格）
- 缺失误差线

**应用示例：**
- 跨组织类型的平均基因表达
- 治疗组间比较
- 不良事件发生频率

### 折线图

**最佳场景：**
- 展示连续变量（通常为时间）趋势
- 多组数据同轴显示
- 说明剂量反应关系

**设计指南：**
- 不同组别采用线型/颜色区分
- 稀疏数据添加数据点标记
- 显示误差线或置信区间阴影
- 坐标轴标注含单位
- x轴间隔保持一致

**常见错误：**
- 错误连接离散数据点
- 线条过多导致图表不可读
- 未标注的不规则时间间隔

**应用示例：**
- 生长曲线
- 时间进程实验
- 生存曲线（Kaplan-Meier图）
- 药代动力学曲线

### 散点图

**最佳场景：**
- 展示两连续变量关系
- 显示相关性
- 识别异常值

**设计指南：**
- 添加趋势线/回归线及方程与R²
- 报告相关系数与p值
- 数据重叠时采用半透明点
- 大范围数据考虑对数刻度
- 标记相关异常值

**常见错误：**
- 未显示个体数据点
- 误用于分类数据
- 缺失相关性统计值

**应用示例：**
- 生物标志物间相关性
- 剂量与反应关系
- 方法学比较（Bland-Altman图）

### 箱线图

**最佳场景：**
- 展示数据分布与离散度
- 跨组别比较分布
- 识别异常值

**设计指南：**
- 明确定义箱体元素（中位数、四分位、须线）
- 显式标注异常值
- 小样本考虑小提琴图
- n<20时叠加原始数据点

**常见错误：**
- 未说明须线含义
- 小样本未展示原始数据
- 未标记异常值

**应用示例：**
- 治疗组间分布比较
- 测量值变异性展示
- 质量控制数据

### 热图

**最佳场景：**
- 展示数据矩阵
- 跨多条件显示模式
- 呈现聚类分组

**设计指南：**
- 采用感知均匀的色阶
- 包含带单位的色阶条
- 行/列考虑层次聚类
- 选用合适配色方案（发散型/连续型）
- 确保坐标轴标签可读

**常见错误：**
- 配色不当（彩虹色阶易误导）
- 行列过多导致标签不可读
- 缺失色阶条

**应用示例：**
- 跨样本基因表达
- 相关性矩阵
- 多变量时间序列数据

### 图像（显微、凝胶、印迹）

**最佳场景：**
- 展示代表性样本
- 呈现形态学或定位
- 显示凝胶电泳或蛋白质印迹

**设计指南：**
- 添加比例尺（非放大倍数）
- 代表性图像配独立量化面板
- 箭头/标签标注关键特征
- 确保分辨率充足（通常300+dpi）
- 展示完整未处理图像（裁剪需注明）
- 包含所有相关对照

**常见错误：**
- 无比例尺
- 过度处理或篡改图像
- 未量化仅选取最佳图像
- 分辨率不足

**应用示例：**
- 组织切片
- 免疫荧光
- 蛋白质印迹
- 凝胶电泳

### 森林图

**最佳场景：**
- 展示荟萃分析结果
- 呈现效应量及置信区间
- 比较多研究或亚组

**设计指南：**
- 包含各研究点估计值及CI
- 清晰显示合并效应值
- 标注无效线（通常为1.0或0）
- 列明研究细节或权重

**应用示例：**
- 荟萃分析
- 系统评价
- 亚组分析

### 流程图

**最佳场景：**
- 研究参与者流程（CONSORT图）
- 系统评价检索流程（PRISMA图）
- 实验工作流

**设计指南：**
- 遵循报告规范模板（CONSORT/PRISMA）
- 统一使用图形与连接符
- 各阶段标注数量
- 清晰显示纳入排除标准

## 表格设计指南

### 结构

**基本构成：**
1. **表格编号与标题**（表上方）
2. **列标题**（含单位）
3. **行标签**
4. **数据单元格**（精度适当）
5. **脚注**（表下方说明缩写、统计、注释）

### 格式最佳实践

**列标题：**
- 使用清晰简洁的标签
- 单位置于括号内
- 谨慎使用缩写（脚注定义）

**数据呈现：**
- 列内小数点对齐
- 统一小数位数（均值通常1-2位）
- 行/列间保持相同精度
- "不适用"用短横线（–）
- 采用适当精度（避免过度报告）

**统计标注：**
- 脚注用上标字母（ᵃ, ᵇ, ᶜ）或符号（*, †, ‡）
- 明确定义p值阈值
- 尽量报告精确p值（p=0.032，非p<0.05）

**脚注：**
- 定义所有缩写
- 说明所用统计检验
- 注明缺失数据
- 非原始数据标注来源

### 表格格式示例

```
表1. 研究参与者基线特征

特征                干预组(n=50)    对照组(n=48)    p值
───────────────────────────────────────────────────────
年龄(岁)             45.3 ± 8.2      47.1 ± 9.1     0.28
男性,n(%)            28 (56)         25 (52)        0.71
BMI(kg/m²)           26.3 ± 3.8      27.1 ± 4.2     0.32
当前吸烟者,n(%)       12 (24)         15 (31)        0.42
收缩压(mmHg)         132 ± 15        134 ± 18       0.54
───────────────────────────────────────────────────────

数据表示为均值±标准差或n(%)。连续变量p值来自独立t检验，
分类变量来自χ²检验。BMI=体重指数；BP=血压；SD=标准差。
```

### 常见表格错误

1. **过度复杂**（行列过多）
2. **背景信息不足**（缺失单位、缩写不明）
3. **精度冗余**（p值报告5位小数）
4. **缺失样本量**
5. **未进行必要统计比较**
6. **多表间格式不一致**
7. **与图表或文字信息重复**

## 图表中的统计呈现

### 报告要求

**每次比较需报告：**
1. **点估计值**（均值、中位数、比例）
2. **变异度量**（SD/SEM/CI）
3. **样本量**（n）
4. **检验统计量**（t/F/χ²等）
5. **p值**（p>0.001时报告精确值）
6. **效应量**（适用时）

### 误差线

**选择合适的度量：**

| 度量       | 含义             | 适用场景         |
|------------|------------------|------------------|
| **SD**     | 数据变异性       | 展示数据离散度   |
| **SEM**    | 均值估计精度     | 显示测量精确度   |
| **95% CI** | 包含真实均值的范围 | 展示统计显著性 |

**关键原则：** 必须说明所用度量。

**标题示例：**
```
"误差线代表95%置信区间。"
错误示范："误差线代表标准误。"
```

**建议：** 优先选用95% CI（非重叠CI表明显著差异）。

### 显著性标识

**通用标注：**
```
* p < 0.05
** p < 0.01
*** p < 0.001
n.s. 或 NS = 无显著差异
```

**替代方案：** 在表格或标题中显示精确p值

**最佳实践：** 在每个图表标题或表格脚注中定义显著性标识。

## 无障碍设计考量

### 色觉友好设计

**建议：**
- 采用色觉无障碍调色板
- 勿仅依赖颜色（添加图案、形状或标签）
- 灰度模式测试图表
- 避免红绿组合

**色觉安全调色板：**
- 蓝-橙
- 紫-黄
- Colorbrewer2.org调色板
- Viridis/Plasma/Inferno（热图专用）

### 高对比度

**确保可读性：**
- 浅底深字（或深底浅字）
- 避免低对比配色（灰底灰字）
- 线条足够粗（最小0.5-1磅）
- 文字足够大（缩放后最小8-10磅）

### 屏幕与印刷兼容性

**双媒介设计：**
- 优先使用矢量格式（PDF/EPS/SVG）
- 栅格图像最小300dpi（TIFF/PNG）
- 按最终印刷尺寸测试效果
- 确保彩色图表灰度印刷仍可读

## 技术要求

### 文件格式

**矢量格式**（图表首选）：
- **PDF**：通用，保真度高
- **EPS**：封装PostScript，出版标准
- **SVG**：可缩放矢量图形，网页友好

**栅格格式**（照片类）：
- **TIFF**：无损，高质量，文件大
- **PNG**：无损压缩，屏幕显示佳
- **JPEG**：有损压缩，避免用于数据图

**避免：**
- 低分辨率截图
- 演示文稿复制图（通常分辨率不足）
- 高压缩JPEG（存在伪影）

### 分辨率要求

**最低标准：**
- **线条图**（图表/示意图）：300-600 dpi
- **半色调图**（照片/灰度图）：300 dpi
- **复合图**（带标注图像）：300-600 dpi

**最佳实践：** 按最终尺寸和分辨率创建图表。

### 尺寸规格

**遵循期刊要求：**
- **单栏**：通常宽8-9厘米（3-3.5英寸）
- **双栏**：通常宽17-18厘米（6.5-7英寸）
- **全页**：因刊而异

**建议：** 优先设计适配单栏的图表。

### 图像处理规范

**允许操作：**
- 全图统一亮度/对比度调整
- 色彩平衡调整
- 裁剪（需注明）
- 旋转

**禁止操作：**
- 选择性编辑（如增强凝胶条带）
- 移除背景伪影
- 未标注的图像拼接
- 任何掩盖、消除或歪曲数据的处理

**伦理要求：** 方法部分报告所有图像调整。

## 图表编号规范

### 编号体系

**图表：**
- 按正文首次提及顺序连续编号
- 阿拉伯数字：图1、图2、图3...
- 补充图表：图S1、图S2...

**表格：**
- 独立于图表编号
- 阿拉伯数字：表1、表2、表3...
- 补充表格：表S1、表S2...

### 正文引用格式

**规范：**
```
"结果如图1所示。"
"参与者特征见表2。"
"多重分析验证该发现（图3-5）。"
```

**错误示范：**

```markdown
## 图注说明

### 图注结构

**图表说明：**
```
图1. [单句标题]。[补充说明句子，提供背景信息、定义缩写、解释子图、描述统计检验并注明样本量]
```

**表格说明：**
```
表1. [描述性标题]
[表格内容]
[脚注定义缩写、统计方法及补充说明]
```

### 图注内容要素

**必备信息：**
1. 展示内容（简短标题）
2. 内容详细描述
3. 所有缩写和符号定义
4. 样本量
5. 使用的统计检验方法
6. 误差线或标注含义
7. 多子图标签说明

**完整图注示例：**
```
图3. 治疗12周后认知能力显著改善。(A) 治疗组（蓝色）与安慰剂组（灰色）在基线、6周和12周时的简易精神状态检查量表（MMSE）平均得分。(B) 治疗组个体参与者变化轨迹。误差线代表95%置信区间。星号表示组间显著差异（*p < 0.05, **p < 0.01, ***p < 0.001；经Bonferroni校正的重复测量方差分析）。治疗组n=42，安慰剂组n=40。MMSE评分范围0-30分，分数越高表示认知功能越好。
```

## 常见问题规避

### 内容问题
1. 正文/表格/图表间**内容重复**
2. **背景信息不足**（展示内容不明确）
3. 单图表**信息过载**
4. **关键信息缺失**（样本量、单位、统计值）
5. **选择性呈现**数据（未展示全貌）

### 设计问题
6. **配色不当**（非色盲友好）
7. 图表间**格式不统一**
8. **布局杂乱拥挤**
9. 最终尺寸下**文字过小**
10. **误导性可视化**（截断坐标轴、3D失真）

### 技术问题
11. **分辨率不足**（印刷模糊）
12. **错误文件格式**（有损压缩、非矢量图）
13. **未声明的图像处理**
14. 图像**缺少比例尺**
15. 图表**不支持灰度印刷**（期刊黑白印刷时）

## 图表制作工具

### 绘图软件
- **R (ggplot2)**：高度定制化，出版级质量，可复现
- **Python (matplotlib, seaborn)**：灵活可编程，广泛使用
- **GraphPad Prism**：用户友好，集成统计，生命科学常用
- **Origin**：高级绘图，物理/工程领域流行
- **Excel**：基础图表，普及度高，定制性有限
- **MATLAB**：技术计算，适合复杂可视化

### 图像处理
- **ImageJ/Fiji**：免费强大，显微成像领域主流
- **Adobe Photoshop**：行业标准，功能全面
- **GIMP**：免费Photoshop替代品
- **Adobe Illustrator**：矢量图形，图表组装
- **Inkscape**：免费矢量编辑器

### 软件选择最佳实践
- 优先选择支持矢量输出的绘图工具
- 精通一种工具而非浅尝多种
- 脚本化图表生成确保可复现性
- 原始数据文件与图表文件分开保存

## 期刊图表规范详解

### 理解期刊要求

**不同期刊对图表有截然不同的要求。** 创建前务必查阅目标期刊的投稿指南。

### 期刊常见差异对照表

| 要素 | 期刊差异 | 代表期刊 |
|------|----------|----------|
| **数量限制** | 研究论文限4-10个图表 | Nature(4-6), PLOS ONE(不限), Science(4-5) |
| **文件格式** | TIFF/EPS/PDF/AI等 | Nature(线稿用EPS/PDF), Cell(首选TIFF) |
| **分辨率** | 300-1000 dpi（依类型） | JAMA(300-600 dpi), Nature(300+ dpi) |
| **色彩模式** | RGB与CMYK | 印刷期刊：CMYK；在线期刊：RGB |
| **尺寸规范** | 单栏/双栏宽度 | Nature(89mm/183mm), Science(专用模板) |
| **图注要求** | 字数限制/特定格式 | 部分期刊：每图注≤150词 |
| **表格格式** | 可编辑文本或图片 | 多数要求可编辑表格 |

### 出版平台要求概要

| 平台类型 | 图表限制 | 格式 | 分辨率 | 核心特征 |
|----------|----------|------|--------|----------|
| **Nature/Science** | 4-6主图 | EPS/PDF/TIFF | 300+ dpi | 支持扩展数据；多子图设计 |
| **医学期刊** | 3-5图表 | TIFF/EPS | 300-600 dpi | CONSORT流程图；保守设计 |
| **PLOS ONE** | 数量不限 | TIFF/EPS/PDF | 300+ dpi | 须兼容灰度模式 |
| **ML会议** | 8页内限4-6图 | PDF(矢量优先) | 印刷级 | 紧凑型信息密集图 |

**机器学习会议图表要求：**

**NeurIPS/ICML/ICLR:**
- 图表计入页数限制（通常8页含参考文献）
- 优先使用矢量图（PDF）
- 要求高信息密度
- 补充材料存放额外图表
- 提供LaTeX模板（使用neurips_2024.sty等）
- 灰度印刷时须保持可读性

**计算机视觉会议(CVPR/ICCV/ECCV):**
- 定性结果图至关重要
- 并列对比为标准形式
- 必须展示失败案例
- 补充材料存放视频/额外示例
- 8页论文通常含6-8主图

**机器学习会议制图惯例：**
- **消融研究**：展示组件贡献的紧凑表格/图表
- **架构图**：清晰专业的模块示意图
- **性能图**：包含误差线/置信区间
- **定性示例**：呈现多样代表性样本
- **对比表格**：简明突出最佳结果

### 跨平台评审标准

**审稿人关注点：**
- **必要性**：每图表支撑结论
- **质量**：专业外观，分辨率达标
- **清晰度**：图注自明；标签规范
- **统计规范**：误差线、样本量、显著性标识
- **一致性**：图表格式统一

**常见退稿原因：**
- 分辨率或图像质量差
- 缺失误差线或样本量
- 标签不清晰或缺失
- 图表数量超限
- 图表与正文信息重复

**机器学习会议特殊要求：**
- **消融研究**：必须证明组件贡献
- **基线对比**：需与前沿工作比较
- **误差线**：需提供置信区间/标准差
- **架构图**：必须清晰易懂
- **空间效率**：严格页限下重视信息密度

### 平台图注风格对照

| 平台类型 | 风格 | 典型特征 |
|----------|------|----------|
| **Nature/Science** | 简洁 | 简练；*P<0.05；最少方法描述 |
| **医学期刊** | 正式 | 标题首字母大写；95%置信区间；统计检验全称 |
| **PLOS/BMC** | 详尽 | 完整句子；定义所有缩写 |
| **ML会议** | 技术流 | 架构细节；超参数；数据集信息 |

**机器学习会议图注示例：**
```
图1. 提出模型的架构。(a) 含12层Transformer的编码器。
(b) 注意力可视化。(c) ImageNet数据集上对比基线的性能（误差线：3次实验的95%置信区间）。
```
- 技术精确性
- 相关超参数说明
- 数据集/实验配置细节
- 为节省空间高度凝练

### 跨平台转换指南

**平台转换策略：**
- **期刊→ML会议**：压缩图表；提升信息密度；图注增加超参数
- **ML会议→期刊**：扩展图注；拆分密集图表；补充方法细节
- **专业期刊→综合期刊**：简化设计；增加解释性子图；图注定义术语
- **综合期刊→专业期刊**：补充技术细节；采用领域标准图表类型
```
