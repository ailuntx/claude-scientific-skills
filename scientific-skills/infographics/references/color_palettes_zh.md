## 对比度检查  

### WCAG 2.1 要求  

| 对比度比率 | 要求 |  
|------------|------|  
| 4.5:1 | 常规文本（小于18pt） |  
| 3:1 | 大号文本（18pt以上或14pt加粗） |  
| 3:1 | 图形及UI组件 |  

### 常用安全组合  

**白色背景 (#FFFFFF)：**  
| 文字颜色 | Hex | 对比度比率 |  
|----------|-----|------------|  
| 黑色 | `#000000` | 21:1 ✓ |  
| 深灰 | `#333333` | 12.6:1 ✓ |  
| 海军蓝 | `#1E3A5F` | 11.2:1 ✓ |  
| 深绿 | `#1B4332` | 10.9:1 ✓ |  
| 深蓝 | `#0072B2` | 5.7:1 ✓ |  
| 中灰 | `#666666` | 5.7:1 ✓ |  
| 红色 | `#CC0000` | 5.5:1 ✓ |  

**深色背景 (#1A1A2E)：**  
| 文字颜色 | Hex | 对比度比率 |  
|----------|-----|------------|  
| 白色 | `#FFFFFF` | 17.1:1 ✓ |  
| 浅灰 | `#E5E5E5` | 13.8:1 ✓ |  
| 浅青 | `#90E0EF` | 10.2:1 ✓ |  
| 黄色 | `#F0E442` | 12.5:1 ✓ |  
| 浅蓝 | `#56B4E9` | 7.8:1 ✓ |  

### 需避免的颜色组合  

以下组合对比度差或对色盲用户不友好：  

- 红与绿（最常见色盲类型）  
- 蓝与紫（难以区分）  
- 浅绿与黄（低对比度）  
- 红与橙（色调相近）  
- 蓝与灰（易混淆）  
- 粉与灰（明度相似）

## 色彩测试  

### 在线工具  

1. **对比度检查器：**  
   - WebAIM对比度检查器：https://webaim.org/resources/contrastchecker/  
   - Coolors对比度检查器：https://coolors.co/contrast-checker  

2. **色盲模拟器：**  
   - Coblis：https://www.color-blindness.com/coblis-color-blindness-simulator/  
   - Sim Daltonism（Mac应用）  
   - Color Oracle（桌面应用）  

3. **调色板生成器：**  
   - Coolors：https://coolors.co/  
   - Adobe Color：https://color.adobe.com/  
   - Paletton：https://paletton.com/  

### 快速灰度测试  

将信息图转为灰度。若所有元素仍清晰可辨，则配色符合无障碍要求。
