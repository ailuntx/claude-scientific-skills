# 信息图类型参考指南

本参考为每种信息图类型提供扩展模板、示例和提示模式。

---

## 1. 统计/数据驱动型信息图

### 目的
以引人入胜的视觉形式呈现定量数据、统计数据、调查结果和数值比较。

### 视觉元素
- **柱状图**：横向或纵向比较
- **饼图/环形图**：展示比例和百分比
- **折线图**：显示时间趋势
- **大数字标注**：突出关键统计
- **图标**：视觉化呈现类别
- **进度条**：显示百分比或完成度

### 布局模式
- **单数据焦点**：一个核心数据配支持信息
- **多数据网格**：3-6个数据点网格布局
- **图表中心式**：大型可视化配辅助文本
- **对比柱状图**：并排柱状比较

### 提示模板

**单数据焦点：**
```
关于[主题]的统计信息图，突出一个核心数据：
主数据：[大数字][单位/背景]
支持信息：[2-3句说明重要性]
中央粗体数字，下方辅助文本，
相关图标或插图，[颜色]强调色，
简洁极简设计，白色背景。
```

**多数据网格：**
```
呈现[主题]数据的统计信息图：
数据1：[数字][标签]（图标：[图标]）
数据2：[数字][标签]（图标：[图标]）
数据3：[数字][标签]（图标：[图标]）
数据4：[数字][标签]（图标：[图标]）
2x2网格布局，粗体大数字，每项上方小图标，
[配色方案]，现代简洁排版，白色背景。
```

**图表聚焦式：**
```
展示[主题]的[图表类型]统计信息图：
数据点：[值1], [值2], [值3], [值4]
标签：[标签1], [标签2], [标签3], [标签4]
以大型[柱状/饼状/环形]图为主元素，
顶部标题，图表下方图例，[配色方案]，
图表数据标签，简洁专业设计。
```

## 2. 时间轴信息图

### 目的
按时间顺序展示事件、里程碑或发展进程。

### 视觉元素
- **时间轴线**：横向或纵向基准线
- **日期标记**：年份、月份或具体日期
- **事件节点**：各时间点的圆形/图标/图片
- **描述框**：每个事件的简要说明
- **连接元素**：线条、箭头或路径

### 布局模式
- **横向时间轴**：从左至右推进
- **纵向时间轴**：从上至下推进
- **蛇形时间轴**：多事件的S型曲线
- **环形时间轴**：循环或重复事件

### 提示模板

**横向时间轴：**
```
展示[主题]从[起始年]到[结束年]的横向时间轴信息图：
[年份1]：[事件1] - [简述]
[年份2]：[事件2] - [简述]
[年份3]：[事件3] - [简述]
[年份4]：[事件4] - [简述]
左至右时间轴配圆形事件节点，
节点间连接线，节点上方图标，
[颜色]从过去到现在的渐变，日期标签在下，
现代简洁设计，白色背景。
```

**纵向时间轴：**
```
展示[主题]的纵向时间轴信息图：
顶部（最早）：[年份] - [事件]
中部事件：[年份] - [事件], [年份] - [事件]
底部（最新）：[年份] - [事件]
从上至下流线，左右交替事件框，
中央垂直线连接所有事件，
含日期的圆形节点，[配色方案]，
专业简洁设计，白色背景。
```

**项目里程碑时间轴：**
```
[项目名称]项目时间轴信息图：
阶段1：[日期] - [里程碑]（状态：完成）
阶段2：[日期] - [里程碑]（状态：进行中）
阶段3：[日期] - [里程碑]（状态：待启动）
阶段4：[日期] - [里程碑]（状态：计划中）
甘特式横向进度条，状态颜色编码，
绿色完成，黄色进行中，灰色待启动，
项目名称标题，专业简洁设计。
```

## 3. 流程/操作指南信息图

### 目的
分步解释操作流程、工作流、指令或方法。

### 视觉元素
- **步骤编号**：清晰顺序标识
- **箭头/连接线**：显示流向
- **动作图标**：图解每个步骤
- **简要描述**：精炼动作说明
- **起止标识**：明确开始与结束

### 布局模式
- **垂直流**：步骤从上至下
- **水平流**：从左至右推进
- **循环流程**：步骤形成闭环
- **分支流**：含备选方案的决策点

### 提示模板

**线性流程：**
```
流程信息图：如何[达成目标]
步骤1：[动作] - [简述]（图标：[图标]）
步骤2：[动作] - [简述]（图标：[图标]）
步骤3：[动作] - [简述]（图标：[图标]）
步骤4：[动作] - [简述]（图标：[图标]）
步骤5：[动作] - [简述]（图标：[图标]）
带编号圆形箭头连接，每步配图标，
[垂直/水平]流向，[配色方案]，
清晰步骤标签，简洁教学设计，白色背景。
```

**循环流程：**
```
展示[周期名称]的循环流程信息图：
步骤1：[动作] 导向
步骤2：[动作] 导向
步骤3：[动作] 导向
步骤4：[动作] 返回步骤1
箭头形成闭环的环形布局，
各点配图标和步骤编号，[配色方案]，
连续流设计，白色背景。
```

**决策流程图：**
```
[场景]决策流程图信息图：
开始：[初始问题]
是：[路径A] → [结果A]
否：[路径B] → [结果B]
菱形决策框，矩形动作框，
元素间箭头连接，[配色方案]，
清晰是/否标签，流程图风格，白色背景。
```

## 4. 对比信息图

### 目的
并排比较两个或多个选项、产品、概念或选择。

### 视觉元素
- **分割布局**：选项间明确分隔
- **匹配行**：相同类别公平对比
- **对勾/叉号**：快速视觉标识
- **评分系统**：星级、条形或数值
- **标题栏**：清晰标识各选项

### 布局模式
- **双栏分割**：左 vs 右
- **表格形式**：行与列
- **维恩图**：重叠比较
- **特性矩阵**：多选项对比网格

### 提示模板

**双选项对比：**
```
对比信息图：[选项A] vs [选项B]
标题：左侧[选项A] | 右侧[选项B]
行1 - [类别1]：[A值] | [B值]
行2 - [类别2]：[A值] | [B值]
行3 - [类别3]：[A值] | [B值]
行4 - [类别4]：[A值] | [B值]
行5 - [类别5]：[A值] | [B值]
分割布局，左侧[颜色A]，右侧[颜色B]，
选项标题配图标，优势项用对勾标识，
简洁对称设计，白色背景。
```

**多选项矩阵：**
```
[主题]对比矩阵信息图：
选项：[选项1], [选项2], [选项3]
特性1：[各选项✓/✗]
特性2：[各选项✓/✗]
特性3：[各选项✓/✗]
特性4：[各选项✓/✗]
表格布局配选项彩色标题栏，
单元格内对勾与叉号，[配色方案]，
简洁网格设计，白色背景。
```

**优缺点对比：**
```
[主题]优缺点信息图：
优点（左侧绿色）：
- [优点1]
- [优点2]
- [优点3]
缺点（右侧红色）：
- [缺点1]
- [缺点2]
- [缺点3]
分割布局，左绿右红，
优点配拇指朝上图标，缺点配拇指朝下，
视觉权重平衡，白色背景。
```

## 5. 列表/信息型信息图

### 目的
以结构化、易读格式呈现技巧、事实、要点或信息。

### 视觉元素
- **编号/符号**：清晰列表标识
- **图标**：每项视觉化呈现
- **精炼文本**：简明描述
- **标题**：主题引导
- **统一风格**：所有项目一致处理

### 布局模式
- **垂直列表**：标准从上至下
- **双栏列表**：长列表适用
- **图标网格**：图标配下方标签
- **卡片式**：每项独立卡片/框

### 提示模板


## 6. 地理/地图类信息图

### 用途
展示基于位置的数据、区域统计数据或地理趋势。

### 视觉元素
- **地图可视化**：世界、国家或区域
- **色彩编码**：按区域显示数据强度
- **数据标注**：关键区域统计数据
- **图例**：色彩比例说明
- **标签**：区域或国家名称

### 布局模式
- **全幅地图**：地图作为主要元素
- **带侧边栏地图**：附带数据摘要
- **区域聚焦**：放大地图局部
- **多地图组合**：展示不同数据的多张地图

### 提示模板

**世界地图数据：**
```
地理信息图展示全球[主题]：
最高：[区域/国家] - [数值]
中等：[区域] - [数值范围]
最低：[区域/国家] - [数值]
色彩编码的世界地图，
[深色]代表最高值，[浅色]代表最低值，
含色彩比例图例和关键统计数据标注，
简洁制图设计，浅灰背景。
```

**国家/区域聚焦：**
```
地理信息图展示[国家/区域]的[主题]：
区域1：[数值]
区域2：[数值]
区域3：[数值]
[国家/区域]地图配色彩编码区域，
关键区域数据标签，[颜色]渐变，
含数值比例的图例，简洁地图设计。
```

## 行业风格差异

### 企业/商务风格
- 色彩：海军蓝、灰、金
- 排版：简洁无衬线体（Arial、Helvetica）
- 设计：极简、专业、结构化
- 元素：图表、图标、利落线条

### 医疗/健康风格
- 色彩：蓝、青绿、绿、白
- 排版：清晰易读
- 设计：可信赖、洁净、临床感
- 元素：医疗图标、解剖图、研究图像

### 科技/数据风格
- 色彩：深色背景、霓虹点缀、蓝/紫
- 排版：现代无衬线体，数据用等宽字体
- 设计：未来感、简洁、深色模式友好
- 元素：电路纹、数据可视化、光效

### 教育/学术风格
- 色彩：中性调、柔蓝、暖色点缀
- 排版：易读，略传统
- 设计：条理清晰、层级分明、易理解
- 元素：书籍、灯泡、毕业图标

### 营销/创意风格
- 色彩：鲜明、活力、潮流混搭
- 排版：混合标题与正文字体
- 设计：吸睛、动感、趣味
- 元素：抽象图形、渐变、插画
