# 信息图设计原则

本参考涵盖了创建有效、专业信息图的基本设计原则。

---

## 视觉层次

视觉层次引导观众视线按特定顺序浏览信息图，确保关键信息优先被看到。

### 层次金字塔

1. **主要元素**（首先看到）
   - 标题与主标题
   - 大型数字或关键统计数据
   - 主视觉图或核心插图
   - 行动号召元素

2. **次要元素**（其次看到）
   - 副标题与分区标题
   - 图表与图形
   - 图标与视觉标记
   - 关键辅助文本

3. **三级元素**（最后看到）
   - 正文与描述
   - 图例与标签
   - 来源引用
   - 细则与脚注

### 创建层次

**尺寸**：较大元素优先吸引注意
- 标题：比正文大200-300%
- 关键数据：数字比标签大2-4倍
- 重要图标：比辅助图标大1.5-2倍

**色彩**：鲜艳对比色吸引视线
- 少量使用强调色突出重点
- 最亮色彩保留给最重要元素
- 辅助信息使用柔和色彩

**位置**：左上与中心区域优先被注意
- 核心内容置于顶部或中心
- 辅助细节靠近底部或边缘
- 阅读流向：自上而下，从左至右（西方文化）

**对比**：高对比元素更突出
- 关键文本用深底浅字或浅底深字
- 彩色元素置于中性背景上
- 边框与阴影提升关键元素

**留白**：隔离产生注意力
- 重要元素周围保留空间
- 避免关键信息拥挤
- 用间距关联同类项目

## 布局模式

### F型布局

适用场景：文本密集型信息图、列表、文章

```
┌─────────────────────────────────────┐
│ ████████████████████████████████████│  ← 顶部水平扫描
├─────────────────────────────────────┤
│ █████████████████                   │  ← 二次水平扫描
├─────────────────────────────────────┤
│ █████                               │
│ █████                               │  ← 左侧垂直扫描
│ █████                               │
│ █████                               │
└─────────────────────────────────────┘
```

**应用方法：**
- 标题跨顶部全宽放置
- 重要副标题置于第二行
- 关键内容左对齐
- 次要内容靠右放置

### Z型布局

适用场景：极简内容、落地页、单一信息图

```
┌─────────────────────────────────────┐
│ ●────────────────────────────────→ ●│  ← 左上开始向右扫描
├─────────────────────────────────────┤
│      ╲                              │
│        ╲                            │  ← 对角线扫描
│          ╲                          │
├─────────────────────────────────────┤
│ ●────────────────────────────────→ ●│  ← 左下向右扫描
└─────────────────────────────────────┘
```

**应用方法：**
- 标识/标题置于左上
- 核心视觉图在右上
- 视线对角线穿过中心
- 行动号召置于右下

### 单列布局

适用场景：移动端适配、滚动内容、流程信息图

```
┌───────────────┐
│    页眉       │
├───────────────┤
│   部分1       │
├───────────────┤
│   部分2       │
├───────────────┤
│   部分3       │
├───────────────┤
│   部分4       │
├───────────────┤
│    页脚       │
└───────────────┘
```

**应用方法：**
- 垂直滚动内容
- 分步流程展示
- 时间轴信息图
- 移动优先设计

### 多列布局

适用场景：对比分析、功能列表、复杂数据

```
┌─────────────────────────────────────┐
│           页眉/标题                 │
├──────────────┬──────────────────────┤
│   列1        │        列2           │
│   --------   │      --------        │
│   内容       │        内容          │
│   内容       │        内容          │
│   内容       │        内容          │
├──────────────┴──────────────────────┤
│             页脚                    │
└─────────────────────────────────────┘
```

**应用方法：**
- 并排对比
- 优缺点列表
- 功能矩阵
- 双类别信息展示

### 网格布局

适用场景：权重均等项目、统计数据、图标网格

```
┌─────────────────────────────────────┐
│           页眉/标题                 │
├───────────┬───────────┬─────────────┤
│   项1     │   项2     │    项3      │
├───────────┼───────────┼─────────────┤
│   项4     │   项5     │    项6      │
├───────────┼───────────┼─────────────┤
│   项7     │   项8     │    项9      │
├───────────┴───────────┴─────────────┤
│             页脚                    │
└─────────────────────────────────────┘
```

**应用方法：**
- 多组统计数据（2x2, 3x3, 2x3网格）
- 图标集合
- 功能亮点展示
- 团队成员展示

### 模块化/卡片布局

适用场景：多样内容类型、灵活信息、现代设计

```
┌─────────────────────────────────────┐
│           页眉/标题                 │
├───────────────────┬─────────────────┤
│                   │     卡片2       │
│     卡片1         ├─────────────────┤
│    （大尺寸）      │     卡片3       │
├───────────────────┼─────────────────┤
│     卡片4         │     卡片5       │
└───────────────────┴─────────────────┘
```

**应用方法：**
- 混合内容类型
- 差异化重要层级
- 现代仪表盘风格
- 杂志式布局

## 60-40法则

优质信息图需平衡视觉与文本内容：

- **60%视觉元素**：图标、图表、插图、图像、形状
- **40%文本内容**：标题、标签、描述、数据

### 重要性

- 文本过多：像文档而非信息图
- 视觉过量：缺乏实质与清晰度
- 恰当平衡：兼具吸引力与信息量

### 应用法则

**视觉元素（60%）**
- 图表与图形
- 图标与符号
- 插图
- 照片
- 装饰形状
- 色块
- 线条与连接符

**文本元素（40%）**
- 标题与主标题
- 副标题
- 数据标签
- 简要描述
- 来源引用
- 行动号召

## 留白（负空间）

留白是元素之间的空白区域。这不是浪费空间——而是设计工具。

### 留白功能

1. **提升可读性**：为视觉提供休息间隔
2. **创造焦点**：隔离元素吸引注意
3. **内容分组**：关联项目视觉聚合
4. **增添优雅感**：提升设计高级感
5. **减少杂乱**：避免观众信息过载

### 留白指南

**页边距**：信息图整体外围空间
- 宽度/高度的5-10%最小值
- 页边距越大越显高级
- 各边距保持统一

**内边距**：元素内部空间（框体、卡片）
- 最小值等于文本行高
- 重要元素增加内边距
- 同类元素保持统一

**间隙**：元素间距离
- 关联项目：小间隙（8-16px）
- 非关联项目：大间隙（24-48px）
- 分区间隔：最大间隙（48-72px）

**行间距**：文本行间距离
- 正文：字体大小的1.4-1.6倍
- 标题：字体大小的1.1-1.3倍
- 列表：字体大小的1.5-2倍

## 排版

### 字体选择

**无衬线字体**（信息图推荐）
- 简洁现代外观
- 屏幕可读性更佳
- 专业质感
- 示例：Arial, Helvetica, Open Sans, Roboto, Montserrat

**衬线字体**（谨慎使用）
- 传统权威感
- 正式场景标题适用
- 示例：Georgia, Times New Roman, Playfair Display

**展示字体**（仅限标题）
- 标题高冲击力
- 禁用于正文
- 示例：Impact, Bebas Neue, Oswald

### 字体搭配规则

1. 每张信息图最多使用**2-3种字体**
2. **对比是关键**：搭配不同风格（衬线+无衬线）
3. **明确分工**：一种用于标题，一种用于正文，一种用于点缀
4. **保持统一**：相同用途字体始终一致

**安全搭配：**
- Montserrat（标题）+ Open Sans（正文）
- Playfair Display（标题）+ Roboto（正文）
- Bebas Neue（标题）+ Lato（正文）
- Oswald（标题）+ Source Sans Pro（正文）

### 字体尺寸

| 元素         | 尺寸范围    | 字重       |
|--------------|-------------|------------|
| 主标题       | 36-72pt     | 粗体       |
| 分区标题     | 24-36pt     | 粗体/半粗体|
| 副标题       | 18-24pt     | 半粗体     |
| 正文         | 12-16pt     | 常规       |
| 标注/标签    | 10-14pt     | 常规/细体  |
| 细则         | 8-10pt      | 细体       |

### 排版最佳实践

1. **正文左对齐**（比居中更易阅读）
2. **标题居中对齐**（增强冲击力）
3. **控制行长**在45-75字符内
4. **谨慎使用粗体**强调
5. **避免正文全大写**（难以阅读）
6. **短标题/标签可全大写**
7. **保持文本与背景对比度**（最低4.5:1）

## 故事结构

每张优质信息图包含三部分叙事：

### 1. 开场（吸引点）

**目的**：抓住注意，确立主题

**元素：**
- 吸睛标题
- 抢眼主视觉
- 关键数据或提问
- 主题引入

**最佳实践：**
- 设计令人无法忽视
- 承诺价值（"了解如何..."）
- 制造好奇心
- 占总空间10-15%

### 2. 主体（内容）

**目的**：传递核心信息

**元素：**
- 数据与统计
- 分步内容
- 对比分析
- 辅助视觉

**最佳实践：**
- 逻辑流（时间/重要性/类别排序）
- 清晰分区
- 平衡图文
- 占总空间70-80%

### 3. 结尾（要点）

**目的**：总结，行动号召

**元素：**
- 核心要点总结
- 行动号召
- 来源引用
- 品牌标识

**最佳实践：**
- 强化核心信息
- 明确观众下一步
- 勿引入新信息
- 占总空间10-15%

## 对齐与网格

### 网格系统

使用隐形网格保持元素对齐一致：

**列网格**（最常用）
- 2、3、4或6列
- 元素跨单列或多列
- 列间留沟槽（间隙）
- 营造有序专业感

**模块化网格**
- 列+行构成模块
- 适应多样化内容
- 适合复杂布局
- 仪表盘风格设计

### 对齐类型

**左对齐**
- 文本最常用
- 形成清晰左边缘
- 便于扫视
- 专业外观

**居中对齐**
- 适合标题
- 创造对称性
- 文本慎用
- 单元素适用

**右对齐**
- 主内容极少使用
- 适合表格数字
- 西方设计中显非常规
- 需有意为之

### 对齐最佳实践

1. **选择主要对齐方式**并贯彻始终
2. **关联元素对齐**同一边缘或中心
3. **使用隐形网格线**保持一致性
4. **避免随机摆放**——所有元素应对齐基准
5. **通过对齐建立**视觉关联

## 色彩运用

### 色彩功能

1. **建立层次**：重要项用亮色
2. **项目分组**：同色即同类
3. **创造对比**：区分不同元素
4. **唤起情绪**：色彩蕴含心理意义
5. **强化品牌**：保持品牌一致性

### 色彩分布

**60-30-10法则：**
- **60%** 主色（背景、大面积）
- **30%** 辅色（支持元素）
- **10%** 强调色（高亮、行动号召）

### 色彩心理学

| 颜色   | 关联概念           | 适用场景               |
|--------|--------------------|------------------------|
| 蓝色   | 信任、专业、冷静   | 企业、科技、医疗       |
| 绿色   | 成长、自然、财富   | 环保、金融、健康       |
| 红色   | 紧迫、活力、激情   | 警示、促销、食品       |
| 橙色   | 友好、自信、创意   | 行动号召、年轻品牌     |
| 黄色   | 乐观、警示、注意   | 高亮、警告             |
| 紫色   | 奢华、创意、智慧   | 高端品牌、教育         |
| 黑色   | 精致、力量、优雅   | 奢侈品、正式场合       |
| 白色   | 洁净、简约、空间感 | 背景、呼吸空间         |

### 对比度要求

无障碍标准（WCAG 2.1 AA）：
- **常规文本**：最低4.5:1对比度
- **大文本**（18pt以上）：最低3:1对比度
- **图形与界面**：最低3:1对比度

对比度检测工具：
- WebAIM对比度检查器
- Coolors对比度检查器
- Adobe色彩无障碍工具

## 图标使用

### 图标风格

**线性图标**（轮廓）
- 简洁现代感
- 小尺寸表现佳
- 极简设计首选
- 线宽一致关键

**填充图标**（实心）
- 视觉冲击更强
- 识别速度更快
- 适合作焦点
- 小尺寸更易辨

**插画图标**
- 个性鲜明独特
- 视觉权重更高
- 活泼设计适用
- 缩放适应性弱

### 图标最佳实践

1. **全图保持**统一风格
2. **确保可识别性**——图标应直观易懂
3. **同级图标**尺寸一致
4. **含义模糊时**添加标签
5.

- 尽可能直接标注数据

### 色盲友好的设计

- 使用色盲友好的调色板（参见 color_palettes.md）
- 通过色盲模拟器测试
- 添加图案或纹理辅助区分
- 使用标签和直接标注

### 阅读无障碍性

- 清晰的层次结构与流程
- 简洁的文本
- 简明的语言
- 适当的间距
- 符合逻辑的阅读顺序

## 质量检查清单

在最终确定信息图前，请验证：

### 布局
- [ ] 清晰的视觉层次
- [ ] 一致的对齐（基于网格）
- [ ] 足够的留白
- [ ] 符合逻辑的阅读流
- [ ] 平衡的构图

### 排版
- [ ] 最多使用 2-3 种字体
- [ ] 可读的字体大小
- [ ] 足够的文本对比度
- [ ] 相同元素样式统一
- [ ] 正文文本左对齐

### 颜色
- [ ] 60-30-10 分布原则
- [ ] 色盲友好的调色板
- [ ] 足够的对比度（文本 4.5:1）
- [ ] 颜色含义保持一致
- [ ] 避免视觉过载

### 内容
- [ ] 清晰的故事结构（开头、主体、结尾）
- [ ] 约 60% 视觉元素，40% 文本
- [ ] 关键信息突出
- [ ] 数据准确且注明来源
- [ ] 包含行动号召

### 图标与图形
- [ ] 统一的图标风格
- [ ] 恰当的尺寸
- [ ] 易于识别的含义
- [ ] 避免过度使用

### 无障碍性
- [ ] 灰度模式下可识别
- [ ] 图案/标签辅助颜色区分
- [ ] 目标尺寸下清晰可读
- [ ] 脱离视觉线索仍具逻辑流

---

将这些原则作为基础框架，根据具体内容与受众需求灵活调整。
