# 发表级图表制作指南

## 核心原则

科学图表必须清晰、准确且易于理解。发表级图表遵循以下基本原则：

1. **清晰性**：信息应一目了然
2. **准确性**：数据呈现必须真实无篡改
3. **可访问性**：所有读者（包括视觉障碍者）均可解读
4. **专业性**：符合同行评审期刊要求的整洁精致外观

## 分辨率与文件格式

### 分辨率要求
- **位图图像（照片、显微图像）**：最终印刷尺寸下300-600 DPI
- **线条图与图表**：600-1200 DPI（或矢量格式）
- **组合图**：300-600 DPI

### 文件格式
- **矢量格式（图表首选）**：PDF、EPS、SVG
  - 无限缩放不失真
  - 线条图文件体积更小
  - 适用于：曲线图、示意图、原理图

- **位图格式**：TIFF、PNG（科研数据禁用JPEG）
  - 适用于：照片、显微图像、连续色调图像
  - TIFF：无损压缩，广泛兼容
  - PNG：无损压缩，适合网络及补充材料
  - **禁用JPEG**：有损压缩会产生伪影

### 尺寸规范
- **单栏**：宽度85-90毫米（3.35-3.54英寸）
- **1.5栏**：宽度114-120毫米（4.49-4.72英寸）
- **双栏**：宽度174-180毫米（6.85-7.08英寸）
- **最大高度**：通常230-240毫米（9-9.5英寸）

## 排版规范

### 字体指南
- **字体族**：多数期刊推荐无衬线字体（Arial、Helvetica、Calibri）
  - 部分期刊有特定要求（请查阅指南）
  - 全文图表保持字体统一

- **最终印刷尺寸下的字号**：
  - 坐标轴标签：最小7-9磅
  - 刻度标签：最小6-8磅
  - 图例：6-8磅
  - 分图标签（A、B、C）：8-12磅，加粗
  - 标题：多分图通常省略

- **字重**：正文常规字重；仅分图标签加粗

### 文本最佳实践
- 坐标轴标签使用句首大写（如"时间(小时)"而非"TIME(HOURS)"）
- 单位置于括号内
- 避免缩写（空间受限时需在图注中定义）
- 最终尺寸下文本不小于5-6磅

## 色彩运用

### 配色原则
1. **色觉友好**：约8%男性有色觉缺陷
   - 避免红绿组合
   - 采用蓝橙、蓝黄配色或添加纹理/图案
   - 使用色盲模拟工具测试

2. **功能性用色**：色彩应传递信息而非仅装饰
   - 用色区分类别或突出关键数据
   - 跨图表保持配色一致性（相同元素用相同颜色）

3. **印刷考量**：
   - 屏幕与印刷色彩存在差异
   - 印刷用CMYK色彩空间，电子版用RGB
   - 确保足够对比度（尤其灰度转换后）

### 推荐配色方案
- **分类数据**：ColorBrewer、Okabe-Ito调色板
- **序列数据**：Viridis、Cividis、Blues、Oranges
- **发散数据**：RdBu、PuOr、BrBG（确保色觉安全）

### 灰度兼容性
- 所有图表需在灰度模式下可解读
- 使用不同线型（实线、虚线、点线）和标记点
- 柱状图/区域图添加纹理/填充图案

## 布局与构图

### 多分图规范
- **分图标签**：左上角使用加粗大写字母（A、B、C）
- **间距**：分图间保留充足留白
- **对齐**：尽可能沿边缘或坐标轴对齐
- **尺寸**：相关分图保持尺寸一致
- **排列**：符合逻辑流（从左至右，从上至下）

### 图表元素

#### 坐标轴
- **轴线**：0.5-1磅粗细
- **刻度线**：方向统一（向内或向外）
- **刻度密度**：可读不杂乱（通常4-7个主刻度）
- **轴标签**：必须标注单位
- **轴范围**：柱状图纵轴从零开始（科学依据除外）

#### 线条与标记点
- **线宽**：数据线1-2磅；参考线0.5-1磅
- **标记点尺寸**：3-6磅，大于线宽
- **标记类型**：多数据序列需区分（圆形、方形、三角形）
- **误差线**：0.5-1磅宽；必要时添加端帽

#### 图例
- **位置**：空间允许时置于图区内，否则外置
- **边框**：可选；使用则细线（0.5磅）
- **顺序**：与数据出现顺序一致（从上至下或从左至右）
- **内容**：简明描述；详情见图注

### 留白与边距
- 清除图表周围多余空白
- 保持边距一致性
- matplotlib中使用`tight_layout()`或`constrained_layout=True`

## 数据呈现最佳实践

### 统计严谨性
- **误差线**：标注不确定性（SD、SEM、CI）并在图注中说明
- **样本量**：图中或图注标明n值
- **显著性**：明确标记（*、**、***）
- **重复实验**：尽可能展示原始数据点而非仅统计摘要

### 适用图表类型
- **柱状图**：离散类别对比；纵轴从零开始
- **折线图**：时间序列或连续关系
- **散点图**：变量相关性；可添加回归线
- **箱线图**：分布比较；显示离群值
- **热力图**：矩阵数据、相关性、表达模式
- **小提琴图**：分布形态比较（双峰数据优于箱线图）

### 避免失真
- **禁用3D效果**：扭曲数值感知
- **去除冗余装饰**：禁用渐变、阴影等图表垃圾
- **统一比例尺**：可比分图使用相同比例
- **禁止截断坐标轴**：除非明确标注且科学合理
- **线性/对数尺度**：合理选择并清晰标注

## 可访问性

### 色觉考量
- 使用在线模拟工具测试（如Coblis、Color Oracle）
- 除色彩外添加图案/纹理
- 必要时在补充材料提供替代方案

### 视觉障碍支持
- 元素间高对比度
- 最小线宽0.5磅
- 布局清晰简洁

### 数据可用性
- 补充材料包含数据表
- 提供图表源数据文件
- 在线补充材料可考虑交互式图表

## 常见错误规避

1. **字号过小**：印刷尺寸下无法辨识
2. **分辨率不足**：图像模糊锯齿
3. **图表冗余**：多余网格线、3D效果、装饰元素
4. **配色不当**：红绿组合、低对比度
5. **要素缺失**：无坐标标签、无单位、无误差线
6. **风格不一**：单图或多图间字体/尺寸不一致
7. **数据失真**：截断坐标轴、不当比例尺、3D效果
8. **JPEG压缩**：文本线条周边出现伪影
9. **信息过载**：单图包含过多数据序列
10. **图例越界**：导出后图例超出图表边界

## 图表检查清单

投稿前请验证：

- [ ] 分辨率符合期刊要求（位图300+ DPI）
- [ ] 文件格式合规（图表用矢量，图像用TIFF/PNG）
- [ ] 图表尺寸符合期刊规范
- [ ] 所有文本在最终尺寸下可读（最小6-7磅）
- [ ] 字体统一且已嵌入（PDF/EPS文件）
- [ ] 配色方案色觉友好
- [ ] 灰度模式下可解读
- [ ] 所有坐标轴标注单位
- [ ] 包含误差线或不确定性标识
- [ ] 如适用已标记统计显著性
- [ ] 分图标签完整一致（A、B、C）
- [ ] 图例清晰完整
- [ ] 无冗余图表元素
- [ ] 文件名符合期刊规范
- [ ] 图注描述全面
- [ ] 源数据可获取

## 期刊特定要求

务必查阅目标期刊的作者指南，常见差异包括：

- **Nature系列**：RGB色彩，最低300 DPI，特定尺寸要求
- **Science**：EPS或高分辨率TIFF，特定字体要求
- **Cell Press**：首选PDF/EPS，Arial或Helvetica字体
- **PLOS**：TIFF/EPS，特定色彩空间要求
- **ACS期刊**：原始文件（AI、EPS）或高分辨率TIFF

详见`journal_requirements.md`获取主要出版商的详细规范。
