# NeurIPS/ICML 引言范例

本范例展示了机器学习会议引言中具有编号贡献和技术精确性的独特结构。

---

## 完整引言范例

**论文主题**：高效长上下文Transformer

---

### 段落1：问题动机

```
大型语言模型（LLM）在自然语言理解、代码生成和推理任务中展现出卓越能力[1,2,3]。
这些能力随模型规模和上下文长度同步扩展——更长的上下文可处理完整文档、
多轮对话及跨越多步骤的复杂推理链[4,5]。然而标准Transformer注意力机制[6]
具有随序列长度N呈O(N²)级增长的时间和内存复杂度，成为处理长序列的根本瓶颈。
对于10万标记的上下文窗口，计算完整注意力需100亿标量运算，仅注意力矩阵就占用40GB内存，
在当前硬件上导致训练和推理成本过高。
```

**关键特征**：
- 阐明研究意义（LLM能力）
- 关联扩展性（更长上下文=更好性能）
- 具体数据（O(N²)、10万标记、100亿运算、40GB）
- 引用文献确立可信度

---

### 段落2：现有方法的局限性

```
先前研究通过三大类方法提升注意力效率：稀疏注意力模式[7,8,9]通过限制注意力于局部窗口、
固定步长模式或学习稀疏掩码，将复杂度降至O(N√N)或O(N log N)；线性注意力近似[10,11,12]
利用核特征映射重构注意力实现O(N)计算，但牺牲了建模任意成对交互的能力；低秩分解[13,14]
将注意力矩阵近似为小矩阵乘积，以表达能力换取效率。尽管这些方法降低了理论复杂度，
但其引入的近似误差在深度网络中累积，通常在长程建模基准上导致2-5%的精度损失[15]。
更重要的是，它们从根本上改变了注意力机制，难以兼容标准注意力的创新
（如旋转位置编码、分组查询注意力）。
```

**关键特征**：
- 对先前工作的系统分类
- 每类方法复杂度说明
- 明确指出的局限性
- 量化缺陷（2-5%精度损失）
- 揭示深层问题（与创新不兼容）

---

### 段落3：本文方法（高层概述）

```
我们采用不同路径：不近似注意力，而是通过优化内存访问模式加速精确注意力计算。
关键发现是：在现代GPU上，注意力的瓶颈在于内存带宽而非算力。读写N×N注意力矩阵至
GPU高带宽内存（HBM）占主导耗时，而GPU张量核心利用率不足。我们提出LongFlash——
一种内存感知的精确注意力算法，在快速片上SRAM中分块计算注意力，避免在HBM中实例化
完整注意力矩阵。通过精细设计分块模式并将softmax计算与矩阵乘法融合，LongFlash将
HBM访问量从O(N²)降至O(N²d/M)（d为头维度，M为SRAM容量），实现渐近最优I/O复杂度。
```

**关键特征**：
- 明确区别于先前工作（"不同路径"）
- 核心洞见清晰表述
- 技术机制阐释
- 复杂度改进量化
- 方法命名引入

---

### 段落4：贡献（关键部分）

```
我们的贡献如下：

• 提出LongFlash——内存感知精确注意力算法，在1K至128K标记序列上较FlashAttention[16]
  加速2-4倍，较标准PyTorch注意力提升最高9倍（第3节）。

• 理论分析证明LongFlash在精确注意力算法中达到最优O(N²d/M) I/O复杂度，
  并界定算法最大收益场景（第3.3节）。

• 引入序列并行技术，使LongFlash能在多GPU上处理100万+标记序列，
  实现近线性弱扩展效率（第4节）。

• 验证LongFlash使同硬件支持8倍更长上下文：在原本仅限16K标记的内存条件下，
  成功训练70亿参数模型处理128K标记上下文（第5节）。

• 开源优化CUDA内核（在A100/H100 GPU达理论峰值FLOPS的80%），
  提供PyTorch/JAX接口，详见[匿名链接]（第6节）。
```

**关键特征**：
- 编号/项目符号格式
- 每项贡献具体量化
- 声明对应章节索引
- 方法性与实证性贡献兼备
- 代码发布说明
- 自包含条目（每条独立成立）

## 备选开篇段落

### 方法类论文

```
可扩展优化算法是现代机器学习的基础。随机梯度下降（SGD）及其变体[1,2,3]
支持了数十亿参数模型在海量数据集上的训练。然而这些一阶方法在病态问题上收敛缓慢，
常需数千次迭代，而二阶方法仅需数十次即可收敛[4,5]。
```

### 应用类论文

```
药物研发是耗时费力的过程，平均每种新药需10-15年及26亿美元[1]。机器学习通过预测分子特性、
筛选候选化合物及计算优化先导物，有望加速此进程[2,3]。近期蛋白质结构预测[4]与分子生成[5]
的成功证明深度学习能捕捉复杂化学规律，为ML驱动的药物发现带来希望。
```

### 理论类论文

```
解释深度神经网络为何在参数量远超训练样本时仍具良好泛化性，是现代机器学习核心难题之一[1,2]。
经典统计学习理论预言此类过参数化模型应严重过拟合，但实践中经SGD训练的大规模网络却表现出优异测试精度[3]。
这种理论与实践的差距催生了隐式正则化[4]、神经正切核[5]和特征学习[6]等丰富研究，完整理论框架仍待建立。
```

## 贡献条目模板

### 新方法类

```
• 提出[方法名]——新型[方法类型]，通过[核心创新]在[基准]上较[基线]实现[性能提升]。
```

### 理论分析类

```
• 首次证明[命题]，为[问题场景]提供[结果类型]类结论，解决了[先前研究]的开放性问题。
```

### 实证研究类

```
• 在[M]个数据集对[N]种方法进行全面评估，揭示[关键发现]并识别[失败模式/最佳实践]。
```

### 代码/数据发布类

```
• 开源[资源名]——包含[规模/范围]的[描述]，访问地址[URL]。该资源支持[未来工作/可复现性]。
```

## 常见错误规避

### 模糊贡献

❌ **错误示范**：
```
• 提出新型注意力方法
• 证明方法优于基线
• 提供理论分析
```

✅ **正确示范**：
```
• 提出LongFlash，较FlashAttention加速2-4倍
• 证明LongFlash达到最优O(N²d/M) I/O复杂度
• 在固定硬件预算下支持8倍更长上下文训练
```

### 缺失量化

❌ **错误**："本方法显著优于先前工作"
✅ **正确**："本方法在GLUE和SuperGLUE基准分别提升3.2%和4.1%准确率"

### 重复条目

❌ **错误**： 
```
• 提出新注意力机制
• 引入LongFlash注意力
• 我们的创新注意力方案...
```
(三者表述雷同)

### 贡献埋没

❌ **错误**：贡献条目置于第2页末尾
✅ **正确**：贡献条目在第1页末尾清晰可见
