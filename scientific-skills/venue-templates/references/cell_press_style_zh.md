# Cell Press写作风格指南

Cell、Neuron、Immunity、Molecular Cell、Developmental Cell、Cell Reports等Cell Press期刊的综合性写作指南。

**最后更新**：2024年

---

## 概述

Cell Press期刊强调**机制深度**、**严谨实验**和**生物学洞见**。与《自然》《科学》追求广泛可读性不同，Cell论文面向重视技术细节和全面数据的生物学家群体。

### 核心理念

> "Cell论文需通过详尽的实验支持，讲述完整的机制性故事。"

**首要目标**：通过广泛的实验验证提供深刻的生物学洞见，推动对基础机制的理解。

---

## Cell Press特色要素

Cell Press拥有其他期刊不具备的独特元素：

### 1. 概要（非摘要）

Cell使用"概要"而非"摘要"——功能相似但更强调综合阐述。

### 2. 图文摘要（强制要求）

出现在目录页的视觉化概要。**所有Cell Press期刊均强制要求提供。**

### 3. 电子目录摘要

电子目录中30-50词的"电梯演讲"式简介。

### 4. 亮点

3-4个要点（每项≤85字符），概括核心发现。

### 5. 一句话概要

论文的单句总结。

---

## 读者定位与行文风格

### 目标读者

- 相关领域的专业生物学家
- 熟悉技术方法与术语
- 期待全面数据和机制深度
- 重视严谨性与可重复性

### 风格特征

| 特征          | 描述                     |
|---------------|--------------------------|
| **专业性**    | 使用领域内规范术语       |
| **机制导向**  | 聚焦"如何"与"为何"       |
| **全面性**    | 问题探讨深入彻底         |
| **数据密集**  | 提供充分的实验支持       |
| **精准性**    | 术语与量化表述精确       |

### 语态要求

- **接受第一人称("我们")**："我们证明..."
- **鼓励主动语态**："我们发现..."  
- **自信而克制**：重大主张需强有力证据支撑

## 概要（摘要）

### 格式要求

- **Cell限150词**（其他期刊要求不同）
- **连贯段落**（非结构化分节）
- **信息密集**：每句传递核心观点
- **机制聚焦**：阐明发现内容及其作用原理

### 结构框架

1. **背景**（1句）：生物学问题/挑战
2. **方法**（1句）：研究策略
3. **核心发现**（2-4句）：含机制的主要结果
4. **意义**（1句）：对生物学的启示

### 范例概要（Cell风格）

```
细胞衰老是一种通过增殖停滞促进组织重塑的应激反应，但其调控机制尚不明确。
本研究鉴定出转录因子FOXO4是衰老细胞存活的关键调控因子。FOXO4在衰老细胞中
高表达，通过隔离p53使其无法到达线粒体，从而抑制细胞凋亡。利用可穿透细胞的
多肽干扰FOXO4-p53相互作用后，我们在体外和体内均实现了衰老细胞的特异性凋亡。
该多肽治疗使老年小鼠恢复活力，改善毛发密度与肾功能。这些发现揭示了FOXO4-p53
作为衰老细胞的脆弱靶点，为靶向清除衰老细胞的抗衰老疗法提供了概念验证。
```

## 图文摘要

### 目的

以单图形式在目录页呈现论文核心信息的视觉化概要。

### 要求

- **尺寸**：正方形格式（通常1200×1200像素）
- **布局**：简洁无冗余
- **内容**：展示工作流程、核心发现与机制
- **文字**：最小化标签，字体清晰可辨
- **色彩**：鲜明而专业

### 设计要素

```
典型图文摘要构成：
1. 起始点（细胞/生物体/初始状态）
2. 干预措施（箭头/符号表示）
3. 关键观测指标
4. 结果/结论（视觉化呈现）
5. 连接要素的简要文字标注
```

### 范例描述（示意图生成）

```
"图文摘要显示：左图-正常细胞中FOXO4（蓝色）与p53（绿色）分离；
中图-衰老细胞中FOXO4结合p53抑制凋亡；右图-FOXO4多肽破坏结合，
使p53到达线粒体触发凋亡。底部箭头展示：老年小鼠→治疗→年轻化小鼠"
```

## 亮点

### 格式

3-4个要点，每项≤85字符（含空格）

### 内容准则

- 以动词或核心名词起始
- 包含具体发现
- 确保每项独立完整
- 覆盖论文不同维度

### 范例亮点

```
• FOXO4在衰老细胞中特异性表达

• FOXO4隔离p53抑制衰老细胞凋亡

• FOXO4靶向多肽诱导衰老细胞选择性死亡

• 清除衰老细胞疗法恢复老年小鼠机能
```

## 电子目录摘要

### 格式

电子目录用30-50词简介

### 撰写准则

- 作者撰写（编辑可能修改）
- 以作者姓名或核心发现起始
- 形成完整吸引人的句子
- 突出最激动人心的创新点

### 范例电子目录摘要

```
Baar等发现FOXO4是衰老细胞的脆弱靶点，并开发出可诱导衰老细胞
靶向凋亡的多肽。该清除衰老细胞疗法使老年小鼠恢复活力并改善器官功能。
```

## 引言

### 长度与结构

- **4-6段落**（800-1200词）
- 比《自然》《科学》更全面
- 可包含更多技术细节与文献

### 段落框架指南

**首段：生物学背景**
- 确立生物学过程或系统
- 阐明研究重要性
- 介绍关键因子与机制

**第2-3段：领域现状**
- 详述相关前期工作
- 明确已知机制
- 比《自然》《科学》更全面

**第4段：研究空白**
- 未解之谜或争议点
- 为何这是关键问题
- 阻碍进展的因素

**第5段：研究策略**
- 解决问题的路径
- 采用的技术/系统
- 方法适用性论证

**末段：核心发现预览**
- 简要陈述研究成果
- 对领域的推动作用
- 为结果部分做铺垫

### 范例引言段落

```
细胞衰老以稳定的细胞周期停滞、显著的染色质改变及被称为衰老相关分泌表型
(SASP)的复杂分泌表型为特征(Coppé等, 2008; Rodier和Campisi, 2011)。
衰老细胞在衰老过程中及病理部位积累，通过SASP介导的炎症反应和组织结构破坏
导致功能障碍(van Deursen, 2014)。清除衰老细胞（Senolysis）已成为有前景的
治疗策略，遗传学和药理学方法在衰老及年龄相关疾病小鼠模型中已证实其益处
(Baker等, 2011, 2016; Chang等, 2016)。
```

## 结果

### 组织结构

Cell论文通常包含**5-8个结果章节**，每章配描述性标题：

```
结果
├── 章节1：现象发现
├── 章节2：机制解析  
├── 章节3：分子元件鉴定
├── 章节4：功能验证
├── 章节5：体内验证
├── 章节6：治疗概念验证
└── 章节7：广泛意义
```

### 标题风格

Cell采用**陈述性标题**直接阐明发现：

❌ "FOXO4表达分析"（描述性-避免）
✅ "FOXO4在衰老细胞中选择性上调"（陈述性）

### 结果撰写风格

- **细节全面**：比《自然》要求更多方法学背景
- **按图叙述**：每个主图常对应结果章节
- **统计严谨**：所有量化数据附统计学分析
- **生物学解读**：比纯结果章节融入更多解释

### 范例结果段落

```
为鉴定调控衰老细胞存活的转录因子，我们对增殖期和衰老期人成纤维细胞
（IMR90细胞通过复制性衰竭、电离辐射或癌基因诱导衰老）进行RNA测序。
差异表达分析显示47个转录因子在所有衰老模式中均显著上调（错误发现率<0.05，
倍数变化>2；图1A及附表S1）。其中FOXO4上调幅度最大且最稳定（12.3±2.1倍；
图1B），该结果经定量RT-PCR（图1C）和免疫印迹（图1D）验证。免疫荧光显微
技术显示FOXO4在衰老细胞核内积累，增殖期细胞无此现象（图1E,F）。
```

## 讨论

### 结构框架

Cell讨论部分需**深入且机制化**：

**首段：总结**
- 重述核心发现
- 整合核心信息

**第2-4段：机制阐释**
- 深度解析发现与已知生物学的关联
- 提出理论模型
- 详细探讨分子机制

**第5段：文献对比**
- 发现与前期工作的关系
- 解决表面矛盾

**第6段：应用前景**
- 治疗意义
- 广泛影响

**第7段：局限性**
- 客观评估不足
- 遗留问题

**末段：结论**
- 宏观启示
- 未来方向

## 实验方法 / STAR方法

### STAR方法格式

Cell采用结构化**STAR方法**章节：

```
资源可用性
  通讯作者
  材料可用性
  数据与代码可用性

实验模型与研究对象
  细胞系
  动物模型
  人类受试者

方法细节
  [各项技术详细方案]

量化与统计分析
```

## 图表规范

### 图表理念

Cell论文**图表密集**且包含大量复合图：

- **主图6-8个**为典型配置
- **复合图格式**：每图含6-12子图常见
- **数据密集**：提供全面的实验支持
- **扩展数据**：补充图表用于额外验证

### 子图标注

子图采用小写字母标注：**(A)**、**(B)**、**(C)**

### 图例格式

```
图3. FOXO4在衰老细胞核内隔离p53

(A) 增殖期（左）与衰老期（右）IMR90细胞的p53（绿色）和FOXO4（红色）
免疫荧光显微图。DAPI（蓝色）标记细胞核。比例尺：10μm。

(B) 增殖期与衰老期细胞核内p53强度量化。数据为均值±标准误；
n=3次生物学重复，>100细胞/组。***p<0.001，双尾t检验。

(C和D) 增殖期(C)与衰老期(D)细胞裂解液的FOXO4-p53共免疫沉淀。
IgG为免疫球蛋白G对照。

(E) FOXO4-p53相互作用的邻近连接检测。红点示互作事件。比例尺：10μm。

(F) 衰老细胞中FOXO4介导p53隔离的机制模型。

另见图S3及表S2。
```

## 参考文献

### 引用格式

- **作者-年份制**：(Smith等, 2023) 或 Smith等 (2023)
- **多文献引用**：(Smith等, 2020; Jones等, 2021)
- **双作者**：(Smith和Jones, 2023)
- **三作者及以上**：(Smith等, 2023)

### 文献格式

```
Baker, D.J., Wijshake, T., Tchkonia, T., LeBrasseur, N.K., Childs, B.G., 
van de Sluis, B., Kirkland, J.L., and van Deursen, J.M. (2011). Clearance 
of p16Ink4a-positive senescent cells delays ageing-associated disorders. 
Nature 479, 232–236.
```

## 常见错误

1. **机制阐述不足**：描述现象未解原理
2. **对照缺失**：关键对照实验遗漏
3. **表型验证薄弱**：仅用单一方法验证
4. **缺少体内实验**：通常需动物实验支持
5. **图表不完整**：未展示全部相关条件
6. **遗漏图文摘要**：强制要求元素
7. **亮点超字数**：每项需≤85字符

## 投稿前核查清单

### 必备要素
- [ ] 图文摘要（正方形格式）
- [ ] 亮点（3-4项，每项≤85字符）
- [ ] 电子目录摘要（30-50词）
- [ ] 概要（≤150词）
- [ ] 关键试剂表

### 内容要求
- [ ] 全篇保持机制深度
- [ ] 采用多种互补方法
- [ ] 含体内验证（如适用）
- [ ] 使用陈述性标题
- [ ] 图表内容完整

### 格式规范
- [ ] 术语表述精准
- [ ] 作者-年份引用制
- [ ] 图例完整独立
- [ ] STAR方法格式正确
