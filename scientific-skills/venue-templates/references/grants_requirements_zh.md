# 资助申请要求

主要联邦及私人基金会资助项目的全面要求与格式指南。

**最后更新**：2024年

---

## NSF（美国国家科学基金会）

### 概述

**机构**：美国国家科学基金会  
**典型资助额度**：每年10万-50万美元，持续3-5年  
**成功率**：20-25%（因项目而异）  
**评审标准**：学术价值 + 广泛影响（权重相等）

---

### NSF标准资助申请

**页数限制（NSF PAPPG - 提案与资助政策及程序指南）**：

| 组成部分         | 页数限制 | 字体          | 行距     |
|------------------|----------|---------------|----------|
| **项目摘要**     | 1页      | 任意可读字体，10磅以上 | 任意     |
| **项目描述**     | 15页     | Times Roman 11磅或类似 | 单倍行距 |
| **参考文献**     | 无限制   | Times Roman 11磅 | 单倍行距 |
| **个人履历**     | 每人3页  | Times Roman 11磅 | 单倍行距 |
| **预算说明**     | 3-5页    | 任意可读字体   | 任意     |
| **当前及待定资助** | 无限制   | Times Roman 11磅 | 单倍行距 |
| **设施设备**     | 2页      | 任意可读字体   | 任意     |
| **数据管理计划** | 2页      | 任意可读字体   | 任意     |

**页边距**：四边均为1英寸（2.54厘米）（严格执行）

---

### NSF项目摘要（1页）

**必填部分**（明确标注）：

1. **概述**（1-2段）
   - 研究活动简述
   - 目标与方法

2. **学术价值**（1段）
   - 项目如何推动知识进步
   - 创新性与变革潜力
   - 研究团队资质

3. **广泛影响**（1段）
   - 社会效益
   - 扩大参与度
   - 成果传播与推广

**格式**：可整页文本或分栏  
**受众**：非专业人士（广泛科学群体）  
**模板**：`assets/grants/nsf_project_summary.tex`

---

### NSF项目描述（15页）

**典型结构**：

1. **引言/背景**（2-3页）
   - 当前知识现状
   - 研究空白
   - 前期工作/可行性
   - 团队资质

2. **研究计划**（8-10页）
   - 目标与假设
   - 方法与路径
   - 时间线与里程碑
   - 预期成果

3. **广泛影响**（1-2页）
   - 教育活动
   - 扩大参与（弱势群体）
   - 成果传播（出版物、会议、公众推广）
   - 社会效益

4. **既往NSF资助成果**（1页，如适用）
   - 若PI过去5年获NSF资助则必填
   - 既往工作的学术价值与广泛影响
   - 既往NSF资助的出版物

**核心要求**：
- 学术价值与广泛影响贯穿全文
- 允许图表（计入页数限制）
- 引用参考文献（使用"参考文献"部分）

**模板**：`assets/grants/nsf_proposal_template.tex`

---

### NSF个人履历（3页）

**必填部分**：
1. **专业背景**：机构、学位、领域
2. **任职经历**：当前及既往职位
3. **成果**：最多5项相关成果 + 5项其他重要成果
   - 可含出版物、数据集、软件、专利
4. **协同活动**：最多5项研究外影响力案例

**格式**：
- 必须使用NSF模板（SciENcv或NSF批准格式）
- 不再使用"出版物"而用"成果"

---

### NSF广泛影响

**NSF认可类别**（需证明≥1项）：
1. **促进教学与科研协同发展**
2. **扩大弱势群体参与**
3. **广泛传播以提升科技认知**
4. **社会效益**（经济、健康、环境、国家安全）
5. **培养科研队伍及基础设施**

**最佳实践**：
- 明确可量化成果
- 说明评估方法
- 与研究内容融合（非附加项）
- 为广泛影响活动编列预算

**示例**：
- K-12外展项目
- 课程开发
- 培训弱势学生
- 公众科普传播
- 开源软件开发

---

### NSF预算

**典型类别**：
- **高级人员**：PI、共同PI（投入比例、薪资）
- **其他人员**：博士后、研究生、本科生
- **附加福利**：机构标准费率
- **设备**：单价>$5,000物品
- **差旅**：国内与国际
- **参与者支持**：研讨会、会议（单独类别）
- **其他直接成本**：材料、出版、子合同
- **间接成本**：机构管理费率

**预算说明**：逐项解释必要性

---

### NSF数据管理计划（2页）

**必填内容**：
- 生成数据类型
- 数据格式与元数据标准
- 访问与共享政策
- 再利用与再分发政策
- 归档与保存计划

**可行方案**：
- 存入领域专用存储库
- 机构存储库
- 依申请提供数据（需说明限制理由）

---

### NSF评审流程

**评审标准**（权重相等）：

1. **学术价值**：
   - 推动知识的潜力？
   - 构思与组织完善度？
   - PI及团队资质？
   - 资源可用性？

2. **广泛影响**：
   - 潜在社会效益？
   - 实现广泛影响的适配度？

**专家评审**：由专家小组评议  
**时间线**：通常自截止日起6个月公布结果

---

- **个人履历**：使用NSF SciENcv或模板

**资源**：

## NIH（美国国立卫生研究院）

### 概述

**机构**：美国国立卫生研究院  
**资助机制**：
- **R01**：研究项目资助（最常见）
- **R21**：探索性/发展性研究资助
- **K类资助**：职业发展奖项  
**成功率**：10-20%（因研究所及机制而异）

---

### NIH R01研究资助

**页数限制**（研究策略部分）：

| 组成部分       | 页数限制 | 字体          | 页边距         |
|----------------|----------|---------------|----------------|
| **具体目标**   | 1页      | Arial 11磅以上 | 任意           |
| **研究策略**   | 12页     | Arial 11磅以上 | 最小0.5英寸    |
| - 重要性       | 含于12页 |               |                |
| - 创新性       | 含于12页 |               |                |
| - 研究方法     | 含于12页 |               |                |
| **参考文献**   | 无限制   | Arial 11磅    |                |
| **个人履历**   | 每人5页  | Arial 11磅    |                |

**页边距**：四边最小0.5英寸  
**纸张尺寸**：Letter（8.5×11英寸）

---

### NIH具体目标页（1页）

**最核心部分**

**结构**（建议）：

1. **开篇段落**（2-3句）
   - 切入点：问题重要性
   - 空白：未知领域

2. **长期目标**（1句）
   - 总体研究愿景

3. **目标**（1-2句）
   - 本提案将实现什么
   - 核心假设

4. **依据**（2-3句）
   - 预期成功理由
   - 支持假设的初步数据

5. **具体目标**（通常3个）
   - **目标1**：[标题]。[1-2句描述。工作假设。预期结果。]
   - **目标2**：[标题]。[1-2句描述。工作假设。预期结果。]
   - **目标3**：[标题]。[1-2句描述。工作假设。预期结果。]

6. **收尾段落**（2-3句）
   - 影响与重要性
   - 创新性
   - 未来方向

**最佳实践**：
- 清晰有力的叙述
- 明确陈述假设
- 解释预期结果
- 体现创新与影响

**模板**：`assets/grants/nih_specific_aims.tex`

---

### NIH研究策略（12页）

**必填部分**：

#### 1. 重要性（通常2-3页）
- **关键性**：进展的核心障碍
- **知识空白**：未知领域
- **影响**：如何推动领域发展
- **严谨性**：科学前提/既往工作
- **参考文献**：引用关键文献

#### 2. 创新性（通常1-2页）
- **新颖性**：新概念、方法、技术
- **挑战范式**：转变思维方式
- **改进/新方法**：技术创新
- **新应用**：现有工具的新用途

#### 3. 研究方法（通常7-9页）
**每个目标需含**：
- **依据**：目标设定理由
- **实验设计**：详细方法
- **预期结果**：结果意义
- **潜在问题与替代方案**：应对策略
- **严谨性与可重复性**：对照、重复、统计
- **时间线**：各目标完成节点

**附加内容**：
- 初步数据（R01关键）
- 样本量功效分析
- 统计分析计划
- 引用研究的严谨性

---

### NIH个人履历（5页）

**部分**（NIH格式）：
1. **个人陈述**（4句说明资质）
2. **职位、荣誉与学术任命**
3. **科学贡献**（最多5项贡献，每项最多4篇出版物）
4. **研究资助**（当前及已完成项目，检查重叠）

**格式**：必须使用NIH模板（可填PDF或格式页）

---

### NIH评审标准

**评分标准**（1-9分，1=最佳）：
1. **重要性**：意义、影响
2. **研究者**：资质、履历
3. **创新性**：新概念、方法
4. **研究方法**：可行性、严谨性、设计
5. **环境**：机构支持、资源

**附加考量**（不计分但记录）：
- 脊椎动物
- 生物危害
- 人类受试者保护
- 女性、少数群体、儿童纳入
- 预算合理性

**综合影响分**：1-9分（整合所有标准）

---

### NIH R21（探索性资助）

**与R01主要差异**：
- **研究策略**：6页（R01为12页）
- **周期**：最长2年
- **预算**：两年总成本≤27.5万美元
- **初步数据**：非必需（探索性质）
- **目的**：高风险高回报项目；新方向

**选择R21或R01**：
- R21：早期阶段，初步数据有限，高风险
- R01：成熟研究方向，强有力初步数据

---

### NIH K类资助（职业发展）

**机制**：
- **K01**：导师制科研发展奖
- **K08**：导师制临床科研发展奖
- **K23**：导师制患者导向研究发展奖
- **K99/R00**：独立之路奖（博士后到教职）

**核心要素**：
- **职业发展计划**：培训目标、时间线
- **研究计划**：6-12页（因机制而异）
- **导师**：支持信、指导计划
- **机构承诺**：环境、资源
- **保障时间**：通常75%科研投入

---

### NIH预算

**模块化与详细预算**：
- **模块化**：每年直接成本≤25万美元（2.5万增量）
- **详细预算**：每年直接成本>25万美元

**模块化预算**：仅需说明人员、合作方、>2.5万美元设备

**预算周期**：逐年编制（R01通常5年）

---

## DOE（美国能源部）

### 概述

**机构**：美国能源部  
**下属部门**：
- **科学办公室**：基础研究（BES, BER, ASCR, NP, HEP, FES）
- **ARPA-E**：高风险高回报能源技术
- **EERE**：能效与可再生能源

**典型资助额度**：每年20万-100万美元，持续3年  
**成功率**：10-30%（因项目而异）

---

### DOE科学办公室提案

**页数限制**（典型值，因FOA而异）：

| 组成部分         | 页数限制   | 格式                  |
|------------------|------------|-----------------------|
| **项目陈述**     | 10-20页    | Times 11磅，1英寸页边距 |
| **参考文献**     | 无限制     |                       |
| **预算说明**     | 3-5页      |                       |
| **个人履历**     | 每人2-3页  |                       |
| **当前及待定资助** | 无限制     |                       |
| **设施与资源**   | 无限制     |                       |
| **数据管理计划** | 2页        |                       |

---

### DOE项目陈述结构

**典型部分**：

1. **背景与重要性**（2-3页）
   - 能源相关性
   - 当前知识现状
   - 研究需求

2. **前期工作**（1-2页）
   - 团队资质
   - 相关既往成果

3. **研究计划**（10-15页）
   - **目标**：明确方向
   - **技术路径**：详细方法
   - **里程碑与交付物**：具体可量化
   - **时间线**：常用甘特图
   - **团队与管理**：角色、协作

4. **广泛影响**（1-2页）
   - 人才队伍建设
   - 技术转化潜力
   - 成果发表与传播

---

### DOE特殊要求

**能源相关性**：必须明确关联DOE使命
- 基础科学：能源应用的基础认知
- 应用方向：能效、可再生能源、电网、储能

**技术成熟度（TRL）**：常需标注
- **TRL 1-3**：基础研究、概念验证
- **TRL 4-6**：组件/子系统验证
- **TRL 7-9**：系统演示、部署

**国家实验室合作**：鼓励
- 纳入实验室科学家作为共同PI或合作者
- 附实验室合作函

**成本分摊**：有时要求（需查FOA）
- 可为实物形式（设备、时间）
- 需书面证明

---

### DOE预算考量

**允许成本**：
- 人员（薪资、福利）
- 设备
- 差旅（尤其赴DOE国家实验室）
- 材料与耗材
- 分包合同
- 间接成本（协商管理费率）

**禁止成本**：
- 基建
- 招待费
- 部分间接成本（因机构类型而异）

---

## DARPA（美国国防高级研究计划局）

### 概述

**机构**：美国国防高级研究计划局（隶属国防部）

**使命**：高风险、高回报的国家安全研究  
**典型资助额度**：每年50万至500万美元，持续2-4年  
**成功率**：5-15%（竞争激烈）  

---

### DARPA BAA（广泛机构公告）回应  

**页数限制**（典型值，因BAA而异）：  

| 组成部分 | 页数限制 | 格式 |  
|-----------|-----------|--------|  
| **技术与管理工作计划书** | 20-25页 | Times 12号字体，1英寸页边距 |  
| **成本计划书** | 独立成册 | |  

---

### DARPA技术计划书结构  

**核心章节**：  

1. **执行摘要**（1页）  
   - 愿景与影响力  
   - 技术方法概述  
   - 团队资质  

2. **海尔迈耶问答**（1-2页）  
   DARPA要求回答以下问题：  
   - **目标是什么？** 用非专业术语阐明目标  
   - **现有方法如何实现？有何局限？** 当前实践与缺陷  
   - **你的方法有何创新？** 创新点  
   - **谁将受益？** 成功后的影响  
   - **若成功，将带来何种变革？** 颠覆性意义  
   - **存在哪些风险？** 技术风险与应对措施  
   - **成本预估？** 预算概览  
   - **时间规划？** 时间线  
   - **中期与终期考核标准？** 成功里程碑  

3. **技术方案**（10-15页）  
   - 详细技术路线  
   - 任务分解  
   - 风险规避  
   - 创新性论证  

4. **管理计划**（2-3页）  
   - 团队组织架构  
   - 核心人员职责  
   - 协作机制  
   - 里程碑甘特图  

5. **能力与经验**（2-3页）  
   - 团队资质  
   - 相关设施与设备  
   - 过往类似项目  

6. **转化计划**（1-2页）  
   - 国防部转化路径  
   - 终端用户定位  
   - 技术转移方案  

---

### DARPA特殊考量  

**与项目经理（PM）沟通**：  
- **强烈建议**提交前联系PM  
- 讨论方案与项目目标的契合度  
- PM可提供方法反馈  

**颠覆性影响**：  
- 必须展现"改变游戏规则"的潜力  
- 非渐进式改进  

**技术风险**：  
- 高风险方案可接受（甚至受鼓励）  
- 需展示风险缓释策略  

**国家安全相关性**：  
- 明确国防应用关联  
- 军民两用价值常受重视  

**成功指标**：  
- 可量化里程碑  
- "通过/否决"决策点  

---

### DARPA预算  

**全成本核算**：需详细论证  
- **人力**：时薪标准、任务工时  
- **材料**：分项列支  
- **设备**：购置合理性说明  
- **差旅**：具体行程与目的  
- **分包**：分包商详细预算  
- **间接成本**：协议费率  

**成本合理性**：预算需符合实际工作需求  

---

### DARPA LaTeX模板

## 私人基金会  

### 盖茨基金会  

**重点领域**：全球健康、扶贫、教育  
**典型资助**：差异极大（10万至1000万美元以上）  

**提案要求**：  
- **意向书**（2-3页）：初筛材料  
- **完整提案**（受邀后）：10-15页  
- **变革理论**：干预如何产生影响力  
- **监测与评估**：指标与数据收集  

**核心关注**：  
- 可扩展性与可持续性  
- 资源匮乏地区的实效  
- 本地组织合作  
- 数据驱动决策  

---

### 惠康基金会  

**重点**：生物医学研究、全球健康  
**地域**：英国与国际  
**典型资助**：10万至500万英镑  

**提案格式**（因项目而异）：  
- **研究者奖**：学术履历与研究愿景  
- **项目资助**：具体研究课题  
- **职业发展**：支持中早期科研人员  

**要求**：  
- 研究计划  
- 过往成就  
- 成本效益论证  
- 患者与公众参与

### 霍华德·休斯医学研究所（HHMI）  

**类型**：研究员聘任（非资助）  
**额度**：7年约900万美元（可续期）  
**重点**：生物医学研究、早期科研人员  

**遴选标准**：  
- 机构提名  
- 创新成果履历  
- 未来5-7年研究愿景  
- 科学领导力潜力

## 通用最佳实践  

### 高效提案撰写  

1. **尽早启动**：至少预留2-3个月  
2. **精读指南**：严格遵循要求  
3. **了解评审**：面向专家写作  
4. **构建故事线**：逻辑清晰的叙述框架  
5. **具体明确**：目标、方法、成果具象化  
6. **论证可行性**：预研数据、专业资质  
7. **直面弱点**：承认并规避风险  

### 常见错误规避  

1. **目标模糊**："研究X" → "验证X是否导致Y"  
2. **创新不足**：渐进改进 vs 颠覆变革  
3. **社会影响薄弱**（NSF）：泛泛而谈、脱离主线  
4. **核心目标缺陷**（NIH）：最关键页面！  
5. **缺少预研数据**：未证明可行性  
6. **时间规划不实**：脱离实际进度  
7. **格式违规**：可能导致直接拒稿  
8. **笔误与错误**：暗示态度敷衍  

### 提案开发时间轴  

**截止前3个月**：  
- 锁定机会  
- 组建团队  
- 拟定目标框架  

**截止前2个月**：  
- 起草核心目标  
- 初步预算  
- 联系项目官员（若允许）  

**截止前1个月**：  
- 完成初稿  
- 内部评审  
- 反馈修订  

**截止前2周**：  
- 最终修订  
- 精细校对  
- 整合材料  

**截止前1周**：  
- 机构审核/批准  
- 预算定稿  
- 系统上传  

**截止前2天**：  
- 终检  
- 提交（勿拖至最后一刻！）

## 总结  

**核心要点**：  

1. **了解机构**：不同使命，不同侧重  
2. **严守规则**：页数、字体、边距强制生效  
3. **讲述动人故事**：问题清晰→方案创新→计划可行  
4. **证明影响力**：学术价值（NSF/NIH）或使命契合（DOE/DARPA）  
5. **展现可行性**：预研数据、团队专长、资源保障  
6. **预算务实**：逐项成本论证  
7. **精细校对**：笔误损害可信度  
8. **提前提交**：技术故障时有发生  

**谨记**：基金撰写是长期修炼的技能。寻求反馈、反复修改、持之以恒！
