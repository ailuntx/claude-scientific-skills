# 自然与科学写作风格指南

适用于《自然》《科学》及相关高影响力多学科期刊（《自然·通讯》《科学进展》《美国国家科学院院刊》）的综合性写作指南。

**最后更新**：2024年

---

## 概述

《自然》与《科学》是全球顶尖的多学科科学期刊。在此发表的论文必须吸引所有学科领域的科学家，而不仅是本领域专家。这从根本上决定了写作风格。

### 核心理念

> "如果结构生物学家无法理解你的粒子物理学论文为何重要，它就不会发表在《自然》上。"

**首要目标**：向受过教育但非本领域专家的读者传达突破性科学发现。

---

## 受众与语气

### 目标读者

- 具备**任何**领域博士水平的科学家
- 熟悉科学方法论
- **非**你特定子领域的专家
- 通过广泛阅读了解科学前沿动态

### 语气特征

| 特征         | 描述                     |
|--------------|--------------------------|
| **通俗易懂** | 避免术语；解释技术概念   |
| **引人入胜** | 吸引读者；讲述故事       |
| **突出意义** | 强调研究的广泛价值       |
| **表述自信** | 清晰陈述发现（适当留有余地） |
| **主动积极** | 使用主动语态；接受第一人称 |

### 语态

- **鼓励使用第一人称复数（"我们"）**："我们发现..."而非"经研究发现..."
- **首选主动语态**："我们测量了..."而非"测量被执行..."
- **直接陈述**："蛋白质X调控Y"而非"蛋白质X似乎可能调控Y"

## 摘要

### 格式要求

- **连贯段落**（禁止使用带标签的结构化格式）
- **150-200词**（《自然》）；《自然·通讯》可至250词
- **禁止引用文献**
- **禁用缩写**（若必需则首次出现时定义）
- **独立完整**：不阅读全文即可理解

### 摘要结构（隐性要求）

以流畅行文覆盖：

1. **背景**（1-2句）：该领域的重要性
2. **空白/问题**（1句）：未知或待解难题
3. **方法**（1句）：研究方案（简要）
4. **关键发现**（2-3句）：主要结果及核心数据
5. **意义**（1-2句）：研究价值与启示

### 摘要范例（《自然》风格）

```
多细胞生命的起源仍是生物学最大谜题之一。个体细胞如何首次协作形成复杂生物体
因该转变发生于6亿年前而难以研究。本文证明单细胞藻类莱茵衣藻在捕食压力下
750代内即可演化出简单多细胞结构。通过引入草履虫捕食者的实验演化，我们在
10个重复种群中有5个观察到稳定多细胞簇的形成。基因组分析揭示仅需两个编码
细胞黏附蛋白的基因突变即可触发此转变。这些结果表明多细胞性演化所需的遗传
改变可能少于既往认知，为理解生命重大转变提供新视角。
```

### 应避免的写法

❌ **过度技术化**：
> "通过CRISPR-Cas9介导的莱茵衣藻CC-125株系CAD1基因（编码钙黏蛋白-1）敲除，
> 结合HSP70A/RBCS2串联启动子调控的FLA10过表达，我们证明..."

❌ **表述模糊**：
> "我们研究了细胞成团机制。结果具有趣味性，可能对理解演化有启示。"

## 引言

### 长度与结构

- **3-5段**（约500-800词）
- **漏斗式结构**：宏观→具体→本文贡献

### 段落撰写指南

**首段：宏观背景**
- 以该领域宏观视角开篇
- 阐明研究对科学/社会的价值
- 确保所有科学家可理解

```
范例：
"仅凭序列预测蛋白质结构是生物学界逾50年的重大挑战。精准预测将变革药物研发、
解析疾病机制，并揭示分子自组装的基本规律。"
```

**第2-3段：现有认知**
- 选择性评述关键前人工作（非穷尽列举）
- 自然过渡到待解决空白
- 引用聚焦核心文献

```
范例：
"基于同源蛋白已知结构的模板法已取得显著进展。然而对于约30%无同源结构的蛋白，
预测精度仍受限。深度学习方法在基准数据集上展现出前景，但对多数蛋白家族仍未达实验精度。"
```

**第4段：研究空白**
- 清晰指出未知或未解问题
- 强调其重要性

```
范例：
"尽管存在这些进展，核心问题仍未解决：能否对全序列空间的蛋白质实现实验级精度预测？
该能力将推动结构生物学普及，加速新发现蛋白的表征。"
```

**末段：本文工作**
- 陈述研究内容及关键发现
- 点明研究意义

```
范例：
"本文提出AlphaFold2神经网络架构，可实现原子级精度的蛋白质结构预测。在CASP14盲测中，
AlphaFold2中位GDT分数达92.4，多数目标精度匹配实验水平。该系统可应用于全蛋白质组结构预测，
为规模化理解蛋白功能开辟新途径。"
```

### 引言禁忌

- ❌ 避免以"自远古以来..."或过度夸张表述开篇
- ❌ 勿作详尽文献综述（保留给专业期刊）
- ❌ 引言中不包含方法或结果
- ❌ 禁用未解释的缩写或术语

## 结果

### 组织逻辑

**以发现驱动，而非实验驱动**

按**发现**组织，而非实验时间顺序：

❌ **实验驱动**（应避免）：
> "我们首先进行实验A，接着实验B，然后实施实验C。"

✅ **发现驱动**（推荐）：
> "我们发现X现象。为探究机制，继而发现Y。由此验证Z假说，获得确证。"

### 结果写作风格

- **过去时**描述已完成工作/发现
- **现在时**指代图表（"图2显示..."）
- **客观兼具解读**：陈述发现时保持客观，但为非专家提供充分背景
- **量化表述**：包含关键数据、统计量、效应值

### 结果段落范例

```
为验证蛋白质X是否参与细胞分裂，我们通过CRISPR-Cas9构建基因敲除细胞系（图1a）。
缺失蛋白X的细胞分裂速率较对照组降低73%（P < 0.001，n=6生物学重复；图1b）。
活细胞成像显示敲除细胞停滞于中期，84%呈现纺锤体形态异常（图1c,d）。
这些结果证明蛋白质X对纺锤体正常组装及细胞分裂至关重要。
```

### 子标题

使用传达发现的描述性标题：

❌ **模糊表述**："蛋白质表达分析"
✅ **信息明确**："应激反应中蛋白质X表达上调"

## 讨论

### 结构（4-6段）

**首段：核心发现总结**
- 重述主要发现（避免重复结果部分）
- 说明假说是否得到支持

**第2-3段：解读与关联**
- 研究发现意味着什么？
- 如何与先前研究关联？
- 潜在机制是什么？

**第4段：广泛意义**
- 超越本体系的研究价值？
- 跨领域关联
- 潜在应用

**第5段：局限性**
- 如实说明局限
- 具体而非笼统

**末段：结论与展望**
- 宏观核心结论
- 简要提及未来方向

### 讨论写作技巧

- **先述意义，后谈局限**
- **建设性对比文献**："我们的发现拓展了Smith等人的工作，证明..."
- **承认其他解读**："另一种解释可能是..."
- **坦诚局限**：具体>笼统

### 局限性陈述范例

❌ **笼统**："本研究存在需未来工作解决的局限。"

✅ **具体**："我们的分析限于培养细胞，可能无法完全模拟组织微环境。此外，48小时观察窗口或遗漏慢发性表型。"

## 方法

### 《自然》方法部分位置

- **简要方法**置于正文（常位于文末）
- **扩展方法**置于补充材料
- 需提供足够复现细节

### 写作风格

- **过去时，被动语态可接受**："细胞在...条件下培养"或"我们将细胞培养于..."
- **精确且可复现**：包含浓度、时间、温度等参数
- **引用成熟方案**："参照Smith等人³的方法..."

## 图表

### 图表设计理念

《自然》重视**概念图与数据图结合**：

1. **图1**：常为展示核心概念的示意图/模型
2. **数据图**：清晰简洁
3. **末图**：常为总结性模型

### 图表设计原则

- **单栏（89mm）或双栏（183mm）**宽度
- **高分辨率**：照片300+dpi，线稿1000+dpi
- **色盲友好**：避免仅用红绿色区分
- **精简要素**：禁用3D效果、多余网格线
- **完整图注**：不读正文即可理解

### 图注格式

```
图1 | 蛋白质X通过纺锤体组装调控细胞分裂。
a，实验方案示意图。b，对照组（灰）与敲除组（蓝）细胞分裂速率量化。
数据为均值±标准误，n=6生物学重复。***P < 0.001，双尾t检验。
c,d，对照组(c)与敲除组(d)纺锤体形态代表图像。比例尺：10微米。
```

## 参考文献

### 引用格式

- **上标数字编号**：¹, ², ¹⁻³, ¹'⁵'⁷
- **《自然》格式**参考文献

### 参考文献格式

```
1. Watson, J. D. & Crick, F. H. C. Molecular structure of nucleic acids. 
   Nature 171, 737–738 (1953).

2. Smith, A. B., Jones, C. D. & Williams, E. F. Discovery of protein X. 
   Science 380, 123–130 (2023).
```

### 引用最佳实践

- **近期文献**：包含近2-3年论文
- **开创性论文**：引用奠基性工作
- **来源多样**：避免过度自引
- **原始文献**：尽可能引用原始发现而非综述

## 语言与风格技巧

### 措辞选择

| 应避免               | 推荐使用       |
|----------------------|----------------|
| utilize（利用）      | use（使用）    |
| methodology（方法学）| method（方法） |
| in order to（为了）  | to（以）       |
| a large number of（大量） | many（许多）   |
| at this point in time（此刻） | now（现在）    |
| has the ability to（能够） | can（可以）    |
| it is interesting to note that（值得注意的是） | [直接删除]     |

### 句式结构

- **长短句交替**：混合使用长短句
- **重点前置**：关键信息置于句首
- **一意一句**：复杂概念分句表述

### 段落结构

- **主题句先行**：首句点明主旨
- **论据支撑**：数据与文献支持
- **自然过渡**：衔接下一段落

## 《自然》与《科学》对比

| 特征             | 《自然》         | 《科学》           |
|------------------|------------------|--------------------|
| 摘要长度         | 150-200词       | ≤125词            |
| 引用格式         | 上标数字         | 括号数字(1, 2)    |
| 参考文献含文章名 | 是              | 否（主文献部分）  |
| 方法部分位置     | 文末或补充材料   | 补充材料          |
| 需意义陈述       | 否              | 否                |
| 开放获取选项     | 是              | 是                |

---

## 常见退稿原因

1. **普适性不足**：过于专业化，不符《自然》《科学》定位
2. **进展渐进**：缺乏变革性突破
3. **过度宣称**：数据支撑不足
4. **可读性差**：对普通读者过于技术化
5. **意义不彰**：未阐明"研究价值何在"
6. **创新不足**：类似发现已有发表
7. **方法缺陷**：结果可信度存疑
