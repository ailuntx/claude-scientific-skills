# 会议格式要求

涵盖各学科主要学术会议的全面格式要求与投稿指南。

## 机器学习与人工智能

### NeurIPS（神经信息处理系统）

**会议级别**：顶级机器学习会议  
**举办频率**：年度会议（12月）

**格式要求**：
- **页数限制**：
  - 主论文：8页（不含参考文献）
  - 参考文献：不限
  - 附录/补充材料：不限（可选，审稿时酌情考虑）
- **格式**：双栏
- **字体**：Times 或 Times New Roman，正文10磅
- **行距**：单倍行距
- **页边距**：四边各1英寸（2.54厘米）
- **栏间距**：0.25英寸（0.635厘米）
- **纸张尺寸**：US Letter（8.5 × 11英寸）
- **匿名要求**：初稿**必须**匿名（双盲评审）
  - 删除作者姓名、所属机构
  - 匿名化自引（"作者等人" → "匿名等人"）
  - 删除暴露身份的致谢内容
- **文献引用**：方括号内编号 [1], [2-4]
- **参考文献**：任何统一格式（常用编号引用）
- **图表**：
  - 高分辨率（300+ dpi）
  - 推荐使用色盲友好配色
  - 可跨双栏排版
- **表格**：确保出版尺寸下清晰可读
- **公式**：被引用时需编号
- **LaTeX模板**：`neurips_2024.sty`（每年更新）
- **补充材料**：
  - 强烈建议提交代码（GitHub，审稿用匿名仓库）
  - 附加实验、证明过程
  - 不计入页数限制

**LaTeX模板路径**：`assets/journals/neurips_article.tex`

**投稿须知**：
- 使用官方年度样式文件
- 首页需含系统生成的论文ID
- 包含"社会影响"声明（每年要求可能变化）
- 需提交可复现性检查清单

**官网**：https://neurips.cc/

## 通用会议投稿指南

### 匿名化最佳实践（双盲评审）

**需删除**：
- 首页的作者姓名、所属机构、邮箱
- 致谢章节
- 可能暴露身份的资助信息
- 任何明显暗示身份的"我们先前工作"引用

**需匿名化**：
- 自引："Smith等人[5]" → "匿名等人[5]"或"先前

- 代码仓库（评审时使用匿名GitHub）
- 补充材料
- 所有URL或链接

### 补充材料

**常见内容**：
- 源代码（GitHub仓库、压缩文件）
- 补充实验结果
- 证明与推导过程
- 扩展相关工作
- 数据集描述
- 视频演示
- 交互式演示

**最佳实践**：
- 保持补充材料组织有序
- 在主论文中清晰引用补充材料
- 确保盲审时材料匿名化
- 检查文件大小限制（通常50-100MB）

### 终稿准备

录用后：
1. **解除匿名**：添加作者姓名、所属机构
2. **添加致谢**：基金资助、贡献说明
3. **版权声明**：添加会议版权标识
4. **格式规范**：遵循终稿专用指南
5. **页数限制**：可能允许增加1-2页（需确认指南）
6. **PDF/A合规**：部分会议要求PDF/A格式

### 无障碍考量

**通用要求**：
- 使用色盲友好配色方案
- 确保足够对比度
- 为图表添加替代文本（支持时）
- 采用清晰易读的字体
- 避免仅依赖颜色区分信息

## 常见错误规避

1. **错误样式文件**：使用过期的会议样式文件
2. **超页数限制**：图表导致超出页数上限
3. **字体尺寸篡改**：调整字体以容纳更多内容
4. **页边距调整**：修改页边距获取额外空间
5. **意外解除匿名**：盲审中不慎暴露身份
6. **遗漏参考文献**：未引用相关前期工作
7. **低质量图表**：图像模糊或文字不清
8. **格式不一致**：不同章节使用不同样式

## 获取官方模板

**模板获取途径**：
1. **会议官网**："征稿启事"或"作者指南"栏目
2. **GitHub**：多数会议在GitHub托管模板
3. **Overleaf**：Overleaf平台提供众多官方模板
4. **CTAN**：LaTeX模板文件常位于CTAN仓库

**模板命名规则**：
- 会议通常每年更新模板
- 使用正确年份模板（如`neurips_2024.sty`）
- 区分"终稿版"与"投稿版"模板

---

## 注意事项

1. **年度更新**：会议要求常有变动，务必查阅当年征稿启事
2. **截止日期类型**：
   - 摘要截止（通常早于全文截止1周）
   - 全文截止（严格，通常无延期）
   - 补充材料截止（可能晚于全文截止数日）
3. **时区标注**：注意截止时区（常标注AOE - 地球任意时区）
4. **反驳意见期**：多数会议设有作者回应/反驳意见阶段
5. **双重投稿**：确认会议对并行投稿的政策
6. **海报/口头报告**：录用通知常包含展示形式说明
