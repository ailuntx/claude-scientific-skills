# 医学期刊写作风格指南

适用于《新英格兰医学杂志》《柳叶刀》《美国医学会杂志》《英国医学杂志》《内科学年鉴》等主要医学期刊的综合性写作指南。

**最后更新**：2024年

---

## 概述

医学期刊优先关注**临床相关性**、**患者结局**和**循证实践**。写作必须精确、以证据为核心，并直接适用于临床决策。

### 核心理念

> "每个句子都应帮助临床医生为患者做出更优决策。"

**首要目标**：传播能改善患者护理和临床实践的研究发现。

---

## 受众与语气

### 目标读者

- 执业医师与临床工作者
- 临床研究人员
- 医疗政策制定者
- 医学教育者
- 部分公共卫生及患者权益倡导读者

### 语气特征

| 特征 | 描述 |
|---------------|-------------|
| **循证导向** | 根据研究设计采用适当留白表述 |
| **以患者为中心** | 聚焦患者结局而非单纯生物标志物 |
| **临床实用性** | 强调实际应用价值 |
| **精确性** | 使用确切数字、置信区间、需治数(NNT) |
| **严谨性** | 主张与证据强度匹配 |

### 语态

- **被动语态常见**："患者被随机分配至..."
- **第一人称可接受**："我们开展了一项试验..."
- **患者用第三人称**："患者"而非"受试者"

## 摘要：结构化格式

### 概述

多数主流医学期刊要求带标签分节的**结构化摘要**，这是少数强制要求结构化摘要的场合。

### 标准结构（基于IMRAD框架）

```
背景：[研究必要性——1-2句话]

方法：[研究设计、环境、参与者、干预措施、
主要结局——2-4句话]

结果：[主要及关键次要结局含统计量——
3-5句话]

结论：[临床意义，含适当留白表述——
1-2句话]
```

### 期刊字数限制

| 期刊 | 摘要字数限制 |
|---------|---------------|
| NEJM | 250词 |
| Lancet | 300词 |
| JAMA | 350词 |
| BMJ | 300词 |
| Annals | 325词 |

### 结构化摘要示例（NEJM风格）

```
背景
2型糖尿病与心血管风险增加相关，但强化血糖控制
对心血管结局的影响仍不明确。

方法
我们将10,251名患有2型糖尿病且确诊心血管疾病的
患者随机分配至强化降糖治疗组（目标HbA1c<6.0%）
或标准治疗组（目标HbA1c 7.0-7.9%）。主要复合终点
包括非致死性心肌梗死、非致死性卒中或心血管原因死亡。

结果
中位随访3.5年后，强化治疗组352例患者（6.9%）
与标准治疗组371例患者（7.2%）出现主要终点事件
（风险比0.90；95%置信区间0.78至1.04；P=0.16）。
强化治疗组严重低血糖发生率更高（3.1% vs 1.0%；P<0.001）。
全因死亡率组间相似（5.0% vs 4.8%；风险比1.04；
95%置信区间0.87至1.24）。

结论
对于确诊心血管疾病的2型糖尿病患者，强化降糖治疗
较标准治疗未显著减少主要心血管事件，且与严重低血糖
风险增加相关。
```

## 证据表述规范

### 核心原则

**语言表述强度须与证据强度匹配。**

### 不同研究设计的适用表述

| 研究设计 | 适用表述 |
|-------------|---------------------|
| **RCT荟萃分析** | "治疗X可降低死亡率..." |
| **大型RCT** | "本试验中治疗X降低了死亡率..." |
| **小型RCT** | "治疗X与死亡率降低相关..." |
| **队列研究** | "治疗X与较低死亡率相关..." |
| **病例对照** | "治疗X与死亡几率降低相关..." |
| **横断面研究** | "治疗X使用与较低死亡率相关..." |
| **病例系列** | "这些病例提示治疗X可能..." |
| **病例报告** | "本病例说明治疗X可..." |

### 因果表述规则

❌ **禁止表述**（RCT除外）："治疗X预防..." / "治疗X导致..."

✅ **观察性研究适用**："治疗X与...相关" / "治疗X与...存在关联"

✅ **RCT适用**："治疗X导致..." / "治疗X降低..."

### 留白表述短语

| 确定性等级 | 适用短语 |
|----------------|---------|
| **高确定性** | "证实"、"显示"、"明确" |
| **中等确定性** | "提示"、"表明"、"支持" |
| **低确定性** | "可能"、"或许"、"潜在可能" |
| **推测性** | "可能存在"、"一种解释是" |

## 数据报告规范

### 绝对风险与相对风险

**必须同时报告绝对与相对指标。**

❌ **不完整表述**："治疗使死亡率降低50%"

✅ **完整表述**："治疗使相对死亡率降低50%（绝对风险降低2.5个百分点；需治数40）"

### 置信区间

**必须包含95%置信区间。**

❌ "风险比为0.75"

✅ "风险比为0.75（95%置信区间0.62至0.91）"

### P值

- 尽可能报告精确P值：P=0.003
- 极小时使用P<0.001
- 结合临床意义解读统计显著性

### 需治数(NNT)

重要临床结局需包含NNT：

```
"每治疗40例患者可预防1例额外死亡
（需治数=40；95%置信区间28至67）。"
```

## 引言

### 长度与结构

- **3-4段落**（500-700词）
- 聚焦临床问题与研究依据

### 段落结构

**段落1：临床问题**
- 疾病负担（发病率、患病率、死亡率）
- 对患者及医疗系统的影响
- 临床重要性

```
"全球超过4.5亿成人患2型糖尿病，该病是心血管疾病、
肾功能衰竭及过早死亡的主要诱因。尽管降糖疗法取得进展，
糖尿病患者的心血管事件风险仍较普通人群高2-4倍。"
```

**段落2：现有认知与局限**
- 现有治疗/方案
- 证据缺口
- 研究必要性

**段落3：依据与目标**
- 研究实施动因
- 明确陈述目标/假设
- 说明主要结局

```
"我们因此开展随机对照试验，评估强化降糖治疗
对比标准治疗能否降低确诊心血管疾病的2型糖尿病
患者的主要心血管事件。"
```

## 方法

### 结构（符合CONSORT/STROBE规范）

医学方法部分遵循报告指南：

```
方法
├── 研究设计
├── 环境与参与者
│   ├── 入选标准
│   └── 招募流程
├── 随机化与盲法（RCT适用）
├── 干预措施
├── 结局指标
│   ├── 主要结局
│   └── 次要结局
├── 样本量计算
├── 统计分析
├── 伦理审批
└── 试验注册
```

### 关键要素

**入选标准**
- 明确列出纳入与排除标准
- 具体化（年龄范围、疾病定义、实验室值）

**主要结局**
- 精确定义，含评估时点
- 说明测量方式

**统计分析**
- 预设分析方案
- 缺失数据处理
- 亚组分析（预设与探索性区分）

### 方法段落示例

```
我们纳入年龄≥40岁、确诊2型糖尿病（定义为HbA1c≥6.5%
或使用降糖药物）且患心血管疾病（既往心肌梗死、卒中
或血运重建术）的成人患者。排除标准包括：HbA1c<7.5%
或>11.0%、估算肾小球滤过率<30 ml/min/1.73m²、
30天内发生心血管事件。
```

## 结果

### 结构

**开篇：受试者流程**
- 筛选、入组、随机化、随访、分析
- 引用CONSORT流程图

**基线特征**
- 表1：基线人口学与临床特征
- 注明组间不平衡

**主要结局**
- 首要且突出报告
- 含点估计值、CI、P值
- 说明临床意义

**次要结局**
- 报告所有预设次要结局
- 注意多重比较问题

**不良事件**
- 系统报告严重不良事件
- 含死亡、住院、按类别统计的严重不良事件

### 结果段落示例

```
在12,537例评估合格的患者中，10,251例完成随机化：
5,128例分配至强化治疗组，5,123例至标准治疗组（图1）。
基线特征组间相似（表1）。中位随访3.5年（四分位距2.8-4.2），
99.2%患者获得生存状态。

主要终点事件发生于强化治疗组352例（6.9%）与标准治疗组
371例（7.2%）（风险比0.90；95%置信区间0.78-1.04；P=0.16）。
绝对差异为0.3个百分点（95%置信区间-0.7至1.4）。
预设亚组结果一致（图3）。
```

## 讨论

### 结构

**段落1：主要发现总结**
- 重述主要结局结果
- 说明假设是否成立

**段落2-3：解读与背景**
- 结果与既往证据的对比
- 潜在机制解读
- 临床意义阐释

**段落4：优势**
- 研究设计特点
- 普适性
- 随访完整性

**段落5：局限性**
- 具体且深入说明
- 讨论局限性对解读的影响
- 避免泛泛而谈

**末段：结论与启示**
- 临床实践意义
- 政策影响
- 未来研究方向

### 局限性段落示例

```
本研究存在若干局限。首先，尽管采用随机化，
仍不能排除未测量因素导致的残余混杂。其次，
开放标签设计可能对主观终点评估引入偏倚，
但死亡的主要结局具客观性。第三，结果可能
不适用于未确诊心血管疾病患者或资源差异的
医疗环境。第四，3.5年随访期可能不足以
检测长期显现的心血管获益。
```

## 期刊特定要求

### NEJM（新英格兰医学杂志）

- **字数限制**：2,700词（不含摘要、参考文献）
- **摘要**：250词，结构化
- **参考文献**：约40-50篇
- **图表**：4-5幅组合
- **风格**：权威性、确定性
- **重点**：重大临床试验、变革性研究

### Lancet（柳叶刀）

- **字数限制**：研究类文章3,500词
- **摘要**：300词，结构化
- **要点框(Panel)**：突出关键信息
- **研究背景**：需说明研究贡献
- **风格**：重视全球卫生视角

### JAMA（美国医学会杂志）

- **字数限制**：原创研究3,000词
- **摘要**：350词，结构化
- **关键点框**：必备摘要
- **图文摘要**：鼓励提交
- **风格**：政策相关性、公共卫生导向

### BMJ（英国医学杂志）

- **字数限制**：研究类3,000词
- **摘要**：300词，结构化
- **本文新增价值**：必备框
- **优势与局限框**：独立章节
- **风格**：实用性、循证性

### Annals of Internal Medicine（内科学年鉴）

- **字数限制**：3,000词
- **摘要**：325词，结构化
- **风格**：聚焦内科临床实践
- **临床试验与荟萃分析**：特色专栏

## 报告规范合规性

### CONSORT（随机对照试验）

**25项清单**包括：
- 试验设计、随机化、盲法
- 受试者流程（需图示）
- 所有结局含效应量及CI
- 伤害与不良事件

### STROBE（观察性研究）

**22项清单**适用于：
- 队列研究、病例对照、横断面研究
- 环境、参与者、变量、数据源
- 偏倚评估、敏感性分析

### PRISMA（系统评价）

**27项清单**包括：
- 检索策略
- 研究筛选流程（图示）
- 偏倚风险评估
- 数据合成方法

### STARD（诊断试验）

**30项条目**用于诊断准确性研究

- 风险比及95% CI
- 时序检验P值

## 医学写作常见错误

1. **过度宣称因果**：观察性数据使用"导致"表述
2. **仅报告相对风险**：忽略绝对指标
3. **遗漏置信区间**：未报告点估计值的不确定性
4. **笼统说明局限**：仅声明"存在局限"而无具体分析
5. **忽略阴性结果**：选择性报告结局
6. **混淆临床意义**：统计显著≠临床重要
7. **亚组数据挖掘**：将事后亚组分析作为确证性结果呈现
8. **缺失CONSORT/STROBE条目**：报告不完整

## 投稿前核查清单

### 必备要素
- [ ] 结构化摘要（符合期刊格式）
- [ ] 试验注册号（RCT必备）
- [ ] 伦理委员会批准声明
- [ ] 利益冲突披露
- [ ] CONSORT/STROBE清单完成

### 统计报告
- [ ] 主要结局含CI与P值
- [ ] 包含绝对与相对指标
- [ ] 报告所有预设结局
- [ ] 显著临床结局计算NNT

### 证据表述
- [ ] 主张与研究设计匹配

- [ ] 使用了恰当的谨慎措辞
- [ ] 仅对随机对照试验使用因果性表述

### 临床相关性
- [ ] 阐明了临床意义
- [ ] 强调了以患者为中心的结果
- [ ] 讨论了普适性
