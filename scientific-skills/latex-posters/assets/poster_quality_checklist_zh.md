# 研究海报质量检查清单

在打印或展示研究海报前，请使用这份全面的检查清单。

## 编译前检查

### 内容完整性
- [ ] 标题简洁且具描述性（10-15字）
- [ ] 所有作者姓名拼写正确
- [ ] 所属机构完整准确
- [ ] 包含联系邮箱
- [ ] 所有章节齐全：引言、方法、结果、结论
- [ ] 参考文献引用（5-10篇关键文献）
- [ ] 包含致谢（基金、合作者）
- [ ] 无占位文本残留（TODO、Lorem ipsum等）

### 视觉内容
- [ ] 所有图表准备就绪且高分辨率（300+ DPI）
- [ ] 图表说明文字完整且具描述性
- [ ] 机构标识可用（大学、资助机构）
- [ ] 二维码已生成并测试
- [ ] 图标/图形素材已获取（如使用）

### LaTeX配置
- [ ] 指定正确纸张尺寸（A0、A1、36×48英寸等）
- [ ] 方向正确（纵向/横向）
- [ ] 最小页边距设置（5-15毫米）
- [ ] 字体大小合适（标题72pt+，正文24pt+）
- [ ] 配色方案已定义
- [ ] 所有宏包已安装且运行正常

## 编译检查

### 成功编译
- [ ] PDF编译无报错
- [ ] .log文件无严重警告
- [ ] 所有文献引用已解析（无[?]标记）
- [ ] 所有交叉引用正常
- [ ] 参考文献生成正确（如使用BibTeX）

### 警告审查

## PDF质量检查

### 自动化检查
运行：`./scripts/review_poster.sh poster.pdf` 或手动验证：

#### 页面规格
```bash
pdfinfo poster.pdf | grep "Page size"
```
- [ ] 页面尺寸完全符合要求
- [ ] 单页文档（非多页）
- [ ] 方向正确

#### 字体嵌入
```bash
pdffonts poster.pdf
```
- [ ] "emb"列所有字体显示"yes"
- [ ] 无位图字体（应为Type 1或TrueType）

#### 图像质量
```bash
pdfimages -list poster.pdf
```
- [ ] 所有图像分辨率≥300 DPI
- [ ] 图表无JPEG压缩伪影
- [ ] 尽可能使用矢量图形

#### 文件大小
```bash
ls -lh poster.pdf
```
- [ ] 文件大小合理（通常2-50 MB）
- [ ] 数字分享时邮件可发送（<50 MB）
- [ ] 无异常小文件（<1 MB可能表示低质量）

- [ ] 无文本溢出边缘
- [ ] 全篇字体使用一致

- [ ] 无错误断字或分词

### 视觉元素

## 缩印测试（关键步骤）

### 测试打印准备
按25%比例打印：
- A0海报 → A4纸打印
- 36×48英寸海报 → Letter纸打印
- A1海报 → A5纸打印

- [ ] 标题清晰可读

**距1.2米处：**

**距0.6米处：**

## 速查指南：常见问题

| 问题 | 快速解决方案 |
|-------|-----------|
| 白边过大 | 在文档类中减小页边距：`margin=5mm` |
| 文字过小 | 增加缩放比例：beamerposter中`scale=1.5` |
| 图像模糊 | 使用矢量图（PDF）或更高分辨率（600+ DPI） |
| 色彩异常 | 检查RGB/CMYK模式，正式打印前试印 |
| 字体未嵌入 | 编译命令：`pdflatex -dEmbedAllFonts=true` |
| 内容截断 | 检查总宽度：列宽+间距+页边距=页面宽度 |
| 二维码失效 | 增大尺寸（最小2×2cm），确保高对比度 |
| 文件过大 | 压缩：`gs -sDEVICE=pdfwrite -dPDFSETTINGS=/printer ...` |
