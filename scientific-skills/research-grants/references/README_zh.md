# 科研基金申请技能

## 概述

撰写美国四大资助机构竞争性科研基金申请书的综合技能：
- **NSF**（国家科学基金会）
- **NIH**（美国国立卫生研究院）
- **DOE**（能源部）
- **DARPA**（国防高级研究计划局）

## 本技能提供内容

### 机构专项指导

各资助机构的详细参考资料包括：
- 使命与优先事项
- 评审标准与评分体系
- 申请书结构与页数限制
- 预算要求
- 提交流程
- 提升竞争力的技巧

### 核心组件

- **目标摘要页**（NIH）：关键1页目标页的模板与详细指南
- **项目摘要**（NSF）：概述、学术价值与广泛影响的必备模板
- **广泛影响**：NSF同等权重评审标准的全面策略
- **预算说明**：人员、设备、差旅和耗材的模板范例
- **评审标准**：解读各机构评审要点

### 模板资源

即用型模板：
- NSF项目摘要模板
- NIH目标摘要页模板
- 预算说明模板
- （更多模板开发中）

## 核心特性

### NSF申请书

- **学术价值+广泛影响**（同等权重）
- 实质性可量化广泛影响策略
- 研究与教育融合
- STEM领域参与度拓展
- 项目描述限15页（多数项目）

### NIH申请书

- **目标摘要页**：最关键页面（含1页详细指南）
- **研究策略**：意义、创新性、方法章节
- **前期数据**：R01申请必备要素
- 严谨性与可重复性要求
- 模块化预算与详细预算
- 重新提交策略（A1申请）

### DOE申请书

- **能源相关性**及与DOE使命契合度
- **技术成熟度**（TRL）评估
- 国家实验室合作
- 成本分摊要求（尤其ARPA-E）
- 商业化路径
- 用户设施使用权限

### DARPA申请书

- **DARPA级难题**：高风险高回报
- **海因迈尔教义**：8个关键问题
- 项目经理沟通（至关重要！）
- 分阶段里程碑结构
- 技术转化规划
- 演示与原型开发

## 成功率指标

各机构典型资助率：
- **NSF**：15-30%（因项目而异）
- **NIH R01**：总体约20%（早期研究者约27%）
- **DOE科学办公室**：20-40%（因项目而异）
- **ARPA-E**：2-5%（概念书到最终资助）
- **DARPA**：项目间差异极大

## 最佳实践

### 尽早启动
- NSF/NIH申请：截止前3-6个月启动
- DOE/DARPA申请：4-6个月（涉及国家实验室时更需提前）

### 获取反馈
- 模拟评审会
- 领域内外同行评议
- 院校基金支持办公室
- 项目官员咨询（适时进行）

### 理解评审标准
- NSF：学术价值+广泛影响（同等权重）
- NIH：意义、研究者、创新性、方法、环境（1-9分制）
- DOE：技术价值、资质、预算、相关性
- DARPA：创新性、影响力、团队、可行性、转化

### 成功关键要素

✅ 清晰有力的研究意义与创新性
✅ 扎实的前期数据（NIH/DOE）
✅ 详尽严谨的方法论
✅ 切实的时间线与预算
✅ 具体可衡量的成果
✅ 具备相关经验的强力团队
✅ 广泛影响融合（NSF）
✅ 技术转化计划（DOE/DARPA）

## 效能最大化技巧

### NSF申请书
1. 从具体目标入手（虽非必需）
2. 以研究计划同等严谨度设计广泛影响
3. 多用图表增强可读性
4. 明确回应两项评审标准
5. 寻求领域外专家反馈

### NIH申请书
1. 优先完善目标摘要页（10稿以上）
2. 包含充分前期数据
3. 明确处理严谨性与可重复性
4. 预判问题并制定替代方案
5. 确保目标独立且协同

### DOE申请书
1. 突出能源相关性与影响
2. 量化指标（成本、效率、排放）
3. 规划部署/商业化路径
4. 考虑国家实验室合作
5. 说明技术成熟度

### DARPA申请书
1. 尽早联系项目经理（关键！）
2. 参加提案日活动
3. 聚焦突破性创新（10倍而非10%改进）
4. 明确回答海因迈尔教义
5. 制定清晰转化策略

## 问题咨询

本技能设计全面但无法覆盖所有场景，使用时请注意：
1. **明确说明**机构、项目及基金类型
2. **提供背景**研究领域与职业阶段
3. **追问细节**以澄清需求
4. **索取范例**针对特定章节
