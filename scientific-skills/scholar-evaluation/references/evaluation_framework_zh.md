# ScholarEval 评估框架

## 概述

本文档详细阐述了 ScholarEval 框架各维度的评估标准、评分细则和质量指标。在对学术成果进行系统性评估时，请使用这些规范。

---

## 维度一：问题界定与研究问题

### 质量指标

**优秀 (5):**
- 研究问题具体、可衡量且表述清晰
- 问题针对文献中的显著空白，具有高影响力潜力
- 研究范围在约束条件下合理可行
- 创新贡献与现有成果明确区分
- 理论或实践意义得到有力论证

**良好 (4):**
- 研究问题清晰但存在细微模糊性
- 问题具有相关性及中等影响力潜力
- 范围总体合理，存在轻微可行性问题
- 贡献可识别但非突破性
- 意义论证充分

**合格 (3):**
- 研究问题存在但缺乏具体性
- 问题相关性不明确或仅具增量价值
- 范围可能过宽或过窄
- 贡献不明确或与现有成果高度重叠
- 意义论证薄弱

**需改进 (2):**
- 研究问题模糊或定义不清
- 问题缺乏明确相关性或重要性
- 范围不合理或不可行
- 贡献未明确阐述
- 未论证意义

**差 (1):**
- 无明确研究问题
- 问题琐碎或无关紧要
- 范围存在根本缺陷
- 无可识别贡献
- 未论证意义

### 评估清单

- [ ] 研究问题是否明确陈述？
- [ ] 所提方法能否解答该问题？
- [ ] 问题对该领域是否重要？
- [ ] 研究范围在资源限制下是否可行？
- [ ] 创新性/贡献是否清晰阐述？
- [ ] 关键假设是否明确说明？
- [ ] 是否定义成功标准或预期成果？

## 维度二：文献综述

### 质量指标

**优秀 (5):**
- 全面覆盖关键领域的相关文献
- 批判性整合揭示模式、矛盾与空白
- 文献时效性强（快速演进领域以近3-5年为主）
- 来源权威且经过同行评审
- 清晰定位当前工作在学术对话中的位置
- 识别出本研究解决的真实研究空白

**良好 (4):**
- 覆盖良好，关键领域存在微小空白
- 以整合为主，含少量描述性内容
- 文献基本及时，含部分经典奠基性著作
- 来源总体权威
- 工作定位存在但可加强
- 研究空白已识别但非关键性

**合格 (3):**
- 部分覆盖，存在显著空白
- 描述性概括多于整合分析
- 文献新旧混杂
- 权威性与非严谨来源并存
- 在现有文献中定位薄弱
- 研究空白模糊或存疑

**需改进 (2):**
- 覆盖不足，存在重大空白
- 纯描述性内容，缺乏整合
- 文献严重过时
- 来源缺乏权威性或严谨性
- 未定位当前工作
- 未识别明确研究空白

**差 (1):**
- 文献综述缺失或不充分
- 无整合分析
- 来源过时或不恰当
- 未参与学术对话
- 未识别研究空白

### 评估清单

- [ ] 综述是否覆盖所有主要相关领域？
- [ ] 文献是否经过整合而非简单罗列？
- [ ] 来源是否及时且权威？
- [ ] 是否呈现对立观点？
- [ ] 研究空白是否清晰识别？
- [ ] 当前工作是否在现有文献中定位？
- [ ] 引用平衡是否恰当（避免过度依赖少数作者）？
- [ ] 是否包含奠基性著作？

### 常见问题

- **覆盖不足**：遗漏关键论文或研究脉络
- **描述性罗列**：按顺序概述论文而缺乏整合
- **来源过时**：依赖超过5-10年的文献
- **选择性引用**：仅引用支持假设的文献
- **组织混乱**：缺乏主题或概念结构
- **空白识别薄弱**：空白点琐碎或实际不存在

## 维度三：方法论与研究设计

### 质量指标

**优秀 (5):**
- 研究设计与研究问题完全契合
- 方法严谨、有效且可靠
- 操作步骤详细至可复现程度
- 控制组、随机化或三角验证运用得当
- 潜在偏差已识别并规避
- 伦理考量全面覆盖
- 明确讨论局限性

**良好 (4):**
- 设计总体合理，存在轻微契合问题
- 方法可靠但存在微小效度问题
- 操作步骤基本可复现
- 具备部分控制或验证措施
- 主要偏差已处理
- 提及伦理考量
- 讨论部分局限性

**合格 (3):**
- 设计部分契合研究问题
- 方法存在显著效度问题
- 操作细节不足，难以完全复现
- 控制或验证措施有限
- 偏差规避不足
- 伦理问题表面化处理
- 局限性讨论不充分

**需改进 (2):**
- 设计与研究问题契合度低
- 方法存在严重效度缺陷
- 操作描述模糊，无法复现
- 无控制或验证措施
- 未处理偏差
- 未考虑伦理问题
- 未讨论局限性

**差 (1):**
- 方法论缺失或不适用
- 方法存在根本缺陷
- 不可复现
- 未考虑效度问题
- 无伦理考量
- 未承认局限性

### 评估清单

- [ ] 方法论是否契合研究问题？
- [ ] 操作步骤描述是否充分？
- [ ] 根据描述能否复现研究？
- [ ] 是否处理效度与信度问题？
- [ ] 潜在偏差是否识别并规避？
- [ ] 是否讨论伦理考量？
- [ ] 是否承认局限性？
- [ ] 样本量是否经过论证（定量研究）？
- [ ] 定性方法是否严谨（如适用）？

### 设计专项考量

**定量研究：**
- 含功效分析的样本量
- 控制组与随机化设置
- 测量效度与信度
- 统计假设检验

**定性研究：**
- 抽样策略与饱和度
- 数据收集流程
- 编码与分析框架
- 可信度标准（可信性、可转移性等）

**混合方法：**
- 整合逻辑
- 顺序合理性
- 数据融合策略

## 维度四：数据收集与来源

### 质量指标

**优秀 (5):**
- 数据来源高度可信且适用
- 样本量充分且论证完善
- 数据收集流程严谨系统
- 设置数据质量控制
- 抽样策略确保代表性
- 缺失数据极少且处理得当

**良好 (4):**
- 数据来源可信，存在微小问题
- 样本量充足
- 收集流程系统化
- 具备部分质量控制
- 抽样基本合理
- 缺失数据已处理

**合格 (3):**
- 数据来源可接受但非最优
- 样本量临界达标
- 收集流程严谨性不足
- 质量控制有限
- 抽样可能存在偏差
- 缺失数据处理基础

**需改进 (2):**
- 数据来源可信度存疑
- 样本量不足
- 收集流程随意
- 无质量控制
- 抽样存在明显偏差
- 未处理缺失数据

**差 (1):**
- 数据来源不适用或不可靠
- 样本量不足
- 收集无系统性
- 无质量考量
- 抽样存在根本缺陷
- 缺失数据过多

### 评估清单

- [ ] 数据来源是否可信且适用？
- [ ] 样本量是否足以支撑结论？
- [ ] 抽样策略是否明确描述？
- [ ] 样本是否代表目标群体？
- [ ] 数据收集流程是否系统化？
- [ ] 是否描述数据质量控制？
- [ ] 是否处理缺失数据？
- [ ] 是否讨论潜在数据偏差？

---

## 维度五：分析与阐释

### 质量指标

**优秀 (5):**
- 分析方法完美契合数据与问题
- 分析严谨且技术运用得当
- 结果阐释逻辑严密且有据可依
- 考虑替代性解释
- 主张与证据强度匹配
- 假设经过验证
- 分析透明且可复现

**良好 (4):**
- 方法总体适用，存在微小问题
- 分析可靠
- 阐释基本符合逻辑
- 考虑部分替代解释
- 主张基本匹配证据
- 关键假设已检验
- 分析基本透明

**合格 (3):**
- 方法可接受但非最优
- 分析存在技术问题
- 阐释存在逻辑断层
- 未充分探索替代解释
- 部分主张超出证据范围
- 假设未完全验证
- 分析透明度有限

**需改进 (2):**
- 方法对数据/问题不适用
- 分析存在重大技术缺陷
- 阐释缺乏依据
- 无替代解释
- 主张严重超出证据范围
- 未检验假设
- 分析不透明

**差 (1):**
- 方法不适用
- 分析存在根本缺陷
- 阐释不合逻辑
- 未考虑替代解释
- 主张无证据支持
- 无假设验证
- 分析不透明

### 评估清单

- [ ] 分析方法是否适用？
- [ ] 统计检验/定性方法是否正确运用？
- [ ] 是否检验假设？
- [ ] 阐释是否逻辑严密且有据可依？
- [ ] 是否考虑替代解释？
- [ ] 主张是否与证据强度匹配？
- [ ] 根据描述能否复现分析？
- [ ] 是否承认不确定性？

### 定量分析

- 适用统计检验
- 检验假设（正态性、同质性等）
- 报告效应量
- 提供置信区间
- 多重检验校正（如适用）
- 模型诊断

### 定性分析

- 编码框架清晰
- 评估者间信度（如适用）
- 讨论饱和度
- 检验反例
- 成员核查或验证
- 明确审计轨迹

## 维度六：结果与发现

### 质量指标

**优秀 (5):**
- 结果呈现清晰全面
- 可视化效果显著且形式恰当
- 统计或定性严谨性显著
- 关键发现突出有效
- 结果直接回应研究问题
- 清晰展示模式与关联
- 报告阴性及无效结果

**良好 (4):**
- 结果清晰，存在轻微呈现问题
- 可视化总体有效
- 严谨性达标
- 主要发现可识别
- 结果基本回应问题
- 展示模式
- 包含部分阴性结果

**合格 (3):**
- 结果呈现合格但清晰度不足
- 可视化基础或存在缺陷
- 严谨性存疑
- 发现存在但未突出
- 部分契合问题
- 模式不清晰
- 可能遗漏阴性结果

**需改进 (2):**
- 结果呈现模糊或混乱
- 可视化粗糙或误导
- 缺乏严谨性
- 发现难以识别
- 与问题契合度弱
- 无清晰模式
- 仅呈现阳性结果

**差 (1):**
- 结果呈现差或缺失
- 可视化不当或缺失
- 无严谨性证据
- 发现不明确
- 结果未回应问题
- 无识别模式
- 结果存在选择性

### 评估清单

- [ ] 结果是否清晰呈现？
- [ ] 结果是否直接回应研究问题？
- [ ] 可视化是否恰当有效？
- [ ] 是否突出关键发现？
- [ ] 是否报告阴性/无效结果？
- [ ] 是否报告适当精度（p值、置信区间、效应量）？
- [ ] 定性发现是否有数据摘录支撑？
- [ ] 是否存在选择性报告迹象？

### 呈现质量

**表格：**
- 清晰标签与标题
- 适当精度
- 逻辑化组织
- 避免过度复杂

**图表：**
- 明确坐标轴与图例
- 适用图表类型
- 专业外观
- 无障碍设计（色盲友好）

**文本：**
- 突出关键发现
- 避免与表格/图表重复
- 使用规范统计术语

## 维度七：学术写作与呈现

### 质量指标

**优秀 (5):**
- 行文清晰、简洁、精准
- 结构逻辑严密，衔接流畅
- 学术语气恰当且一致
- 语法与格式无瑕
- 术语使用准确
- 面向目标读者易懂
- 摘要/概要全面准确

**良好 (4):**
- 行文清晰，偶有生硬
- 结构逻辑清晰，衔接良好
- 语气总体恰当
- 少量语法/格式错误
- 术语基本准确
- 总体易懂
- 摘要完整

**合格 (3):**
- 内容可理解但存在清晰度问题
- 结构存在逻辑断层
- 语气不一致
- 明显语法/格式错误
- 部分术语误用
- 目标读者理解存在障碍
- 摘要不完整或模糊

**需改进 (2):**
- 行文常显模糊或冗长
- 结构与衔接差
- 语气不当
- 频繁语法/格式错误
- 术语使用问题
- 目标读者难以理解
- 摘要质量差或缺失

**差 (1):**
- 行文模糊难懂
- 无清晰结构
- 语气不当
- 普遍语法/格式错误
- 术语错误
- 难以理解
- 无合格摘要

### 评估清单

- [ ] 行文是否清晰简洁？
- [ ] 结构是否逻辑化？
- [ ] 语气是否符合学术写作？
- [ ] 语法与格式是否正确？
- [ ] 术语使用是否恰当？
- [ ] 必要时是否解释专业术语？
- [ ] 摘要是否准确概括工作？
- [ ] 章节过渡是否自然？
- [ ] 目标读者是否明确？

### 常见写作问题

- **冗长**：过度复杂或冗赘
- **被动语态滥用**：降低清晰度与直接性
- **段落结构**：缺乏主题句或连贯性
- **重复**：不必要信息复现
- **逻辑断层**：观点间过渡生硬
- **精确性**：模糊或歧义表述
- **可读性**：过于专业或不够专业

## 维度八：引用与参考文献

### 质量指标

**优秀 (5):**
- 所有主张均有恰当引用
- 来源权威且及时
- 引用准确完整
- 体现多元视角
- 引用格式一致规范
- 自引与他引平衡
- 恰当使用原始文献

**良好 (4):**
- 多数主张有引用
- 来源总体权威
- 少量引用错误
- 来源多样性合理
- 格式基本一致
- 引用平衡良好
- 原始与二手文献并用

**合格 (3):**
- 部分主张无引用支持
- 来源质量参差
- 若干引用错误
- 来源多样性有限
- 格式不一致
- 引用平衡问题
- 过度依赖二手文献

**需改进 (2):**
- 大量主张未引用
- 来源可信度存疑
- 频繁引用错误
- 来源基础狭窄
- 格式混乱
- 过度自引或窄化引用
- 来源不当（如仅二手文献）

**差 (1):**
- 引用不充分
- 来源不可靠
- 普遍引用错误
- 来源多样性极低
- 无固定格式
- 严重引用失衡
- 来源类型不当

### 评估清单

- [ ] 所有事实主张是否均有引用？
- [ ] 是否优先引用原始文献？
- [ ] 来源是否权威且经同行评审？
- [ ] 引用视角是否平衡？
- [ ] 引用是否准确（作者、年份、页码）？
- [ ] 引用格式是否一致？
- [ ] 自引是否恰当（通常<20%）？
- [ ] 来源是否及时（时效性领域）？
- [ ] 是否包含经典/奠基性著作（如相关）？

### 引用质量评估

**来源类型优先级（适用于大多数学术工作）：**
1. 同行评审期刊论文
2. 权威出版社学术专著
3. 会议论文集（依领域而定）
4. 权威机构技术报告
5

- 方法论：20%
- 数据收集：10%
- 分析：15%
- 结果：10%
- 写作：10%
- 文献引用：5%

### 总体评估阈值

- **卓越 (4.5-5.0)**：达到顶级期刊发表标准
- **优秀 (4.0-4.4)**：经少量修改即可发表
- **良好 (3.5-3.9)**：需重大修改，但具有潜力
- **合格 (3.0-3.4)**：需要显著修订
- **薄弱 (2.0-2.9)**：存在根本性问题，需彻底重写
- **较差 (<2.0)**：未经全面修订不适合发表

### 情境化调整

根据以下因素调整标准：
- **阶段**：提案 < 草稿 < 最终提交
- **发表渠道**：学生论文 < 会议论文 < 期刊 < 顶级期刊
- **类型**：理论性 < 实证性 < 元分析
- **领域**：不同学科标准各异
- **目的**：教学用途 < 专业用途 < 发表用途

## 使用框架指南

1. 开始评估前**通读全文**
2. 使用5分量表**逐项评分**
3. **记录证据**并附具体示例
4. **考量情境因素**并调整预期
5. **综合各项发现**形成整体判断
6. **按影响优先级提供可执行反馈**
