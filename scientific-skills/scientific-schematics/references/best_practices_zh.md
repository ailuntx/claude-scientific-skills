# 科学图表最佳实践

## 概述

本指南提供出版标准、可访问性准则和最佳实践，帮助创建符合期刊要求的高质量科学图表，确保有效传达给所有读者。

## 出版标准

### 1. 文件格式要求

**矢量格式（首选）**
- **PDF**：通用性强，质量无损，兼容 LaTeX
  - 适用场景：线图、流程图、框图、电路图
  - 优势：可缩放、文件小、嵌入字体
  - LaTeX 工作流标准格式

- **EPS（封装式 PostScript）**：传统格式，仍被接受
  - 适用场景：旧版出版系统
  - 兼容多数期刊
  - 可从 PDF 转换

- **SVG（可缩放矢量图形）**：适合网络，接受度渐增
  - 适用场景：在线出版物、交互式图表
  - 可用矢量软件编辑
  - 非所有期刊接受 SVG

**光栅格式（必要时使用）**
- **TIFF**：专业级光栅图标准
  - 适用场景：显微图像、含照片的复合图表
  - 最终印刷尺寸下最小 300 DPI
  - 无损压缩（LZW）

- **PNG**：适合网络，无损压缩
  - 适用场景：在线补充材料、演示文稿
  - 印刷需最小 300 DPI
  - 支持透明度

**禁止使用**
- **JPEG**：有损压缩导致图表伪影
- **GIF**：色彩有限，不适用于科学图表
- **BMP**：未压缩，文件过大

### 2. 分辨率要求

**矢量图形**
- 无限分辨率（可缩放）
- **推荐**：尽可能使用矢量格式

**光栅图形（无法使用矢量时）**
- **出版质量**：300-600 DPI
- **线条图**：600-1200 DPI
- **网络/屏幕显示**：150 DPI 可接受
- **禁止**：印刷分辨率低于 300 DPI

**DPI 计算公式**
```
DPI = 像素数 / (最终尺寸英寸数)

示例：
图像尺寸：2400 × 1800 像素
最终印刷尺寸：8 × 6 英寸
DPI = 2400 / 8 = 300 ✓ (合格)
```

### 3. 尺寸规范

**期刊特定栏宽**
- **Nature**：单栏 89 mm (3.5 in)，双栏 183 mm (7.2 in)
- **Science**：单栏 55 mm (2.17 in)，双栏 120 mm (4.72 in)
- **Cell**：单栏 85 mm (3.35 in)，双栏 178 mm (7 in)
- **PLOS**：单栏 83 mm (3.27 in)，双栏 173 mm (6.83 in)
- **IEEE**：单栏 3.5 in，双栏 7.16 in

**最佳实践**
- 按最终印刷尺寸设计（避免缩放）
- 优先使用期刊模板
- 预留裁剪边距
- 提交前测试最终尺寸效果

### 4. 排版标准

**字体选择**
- **推荐**：Arial, Helvetica, Calibri (无衬线体)
- **可接受**：Times New Roman (衬线体) 用于数学密集型图表
- **避免**：装饰字体、手写体、无法嵌入的系统字体

**字号（最终印刷尺寸）**
- **最小**：6-7 pt (依期刊而定)
- **坐标轴标签**：8-9 pt
- **图表标签**：10-12 pt
- **分图标签 (A, B, C)**：10-14 pt，加粗
- **主文本**：需与稿件正文匹配

**文本清晰度**
- 使用句首大写："时间（秒）" 而非 "TIME (SECONDS)"
- 单位置于括号内："温度 (°C)"
- 图表标题中拼写完整缩写
- 尽量避免旋转文本（y轴标签除外）
- **图表内不标序号** - 勿含 "图 1："、"Fig. 1" 等（由 LaTeX/文档系统添加）

### 5. 线宽与描边

**推荐线宽**
- **图表轮廓**：0.5-1.0 pt
- **连接线/箭头**：1.0-2.0 pt
- **强调元素**：2.0-3.0 pt
- **最小可见线宽**：最终尺寸下 0.25 pt

**一致性**
- 同类元素使用相同线宽
- 通过线宽变化体现层级
- 避免发丝线（印刷易缺失）

## 可访问性与色觉障碍

### 1. 色盲安全调色板

**冈部-伊藤调色板（推荐）**
全类型色觉障碍者最易区分：

```latex
% RGB值
橙色：     #E69F00 (230, 159,   0)
天蓝：   #56B4E9 ( 86, 180, 233)
绿色：      #009E73 (  0, 158, 115)
黄色：     #F0E442 (240, 228,  66)
蓝色：       #0072B2 (  0, 114, 178)
朱红： #D55E00 (213,  94,   0)
紫色：     #CC79A7 (204, 121, 167)
黑色：      #000000 (  0,   0,   0)
```

**替代方案：ColorBrewer 调色板**
- **定性**：Set2, Paired, Dark2
- **序列**：Blues, Greens, Oranges (避免红绿并用)
- **发散**：RdBu (红-蓝), PuOr (紫-橙)

**需避免的配色组合**
- 红-绿组合（8%男性无法区分）
- 蓝-紫组合
- 黄-浅绿组合

### 2. 冗余编码

勿仅依赖颜色。采用多重视觉通道：

**形状 + 颜色**
```
圆形 + 蓝色   = 条件 A
方形 + 橙色 = 条件 B
三角 + 绿色 = 条件 C
```

**线型 + 颜色**
```
实线 + 蓝色 = 处理 1
虚线 + 橙色 = 处理 2
点线 + 绿色 = 对照组
```

**图案填充 + 颜色**
```
纯色填充 + 蓝色 = 组 A
斜条纹 + 橙色 = 组 B
交叉线 + 绿色 = 组 C
```

### 3. 灰度兼容性

**测试要求**：所有图表在灰度模式下需可解读

**策略**
- 使用不同灰度阶（浅、中、深）
- 填充区域添加图案或纹理
- 变化线型（实线、虚线、点线）
- 元素直接标注标签
- 添加文字注释

**灰度测试**
```bash
# 转换为灰度测试
convert diagram.pdf -colorspace gray diagram_gray.pdf
```

### 4. 对比度要求

**最小对比度（WCAG 指南）**
- **常规文本**：4.5:1
- **大文本**（≥18pt）：3:1
- **图形元素**：3:1

**高对比度实践**
- 浅底深字（或深底浅字）
- 避免低对比配色（黄底白字、浅灰底白字）
- 关键文本用黑色或深灰
- 深底白字需增大字号

### 5. 替代文本与描述

**图表标题必须包含**
- 图表类型说明
- 所有缩写完整拼写
- 符号与颜色解释
- 样本量 (n) 标注
- 统计注释说明
- 详细方法参考文献（如适用）

**标题示例**
"遵循 CONSORT 指南的受试者流程图。矩形代表研究阶段，标注受试者数量 (n)。筛选阶段的排除标准列于各阶段旁。最终分析包含两组共 n=350 名受试者。"

## 设计原则

### 1. 简洁性与清晰度

**图表设计的奥卡姆剃刀原则**
- 删除无信息价值的元素
- 简化复杂关系
- 将复杂图表拆分为多面板
- 相关图表保持布局一致

**视觉层级**
- 核心元素：最大、最深、居中
- 辅助元素：较小、较浅、边缘化
- 标注：最小化，仅清晰标签

### 2. 一致性

**单图内部**
- 相同形状/颜色代表相同概念
- 同类关系使用统一箭头样式
- 均匀间距与对齐
- 同类元素字号统一

**全文图表间**
- 复用配色方案
- 保持节点样式一致
- 采用相同标记系统
- 应用统一布局原则

### 3. 专业外观

**对齐**
- 使用网格定位节点
- 节点水平或垂直对齐
- 元素均匀分布
- 标签在形状内居中

**留白**
- 避免元素拥挤
- 保留元素呼吸空间
- 利用留白分组相关项
- 图表整体保留边距

**细节优化**
- 消除锯齿线或错位元素
- 平滑曲线与精确角度
- 干净连接点
- 文本无重叠

## 常见陷阱与解决方案

### 陷阱 1：图表过度复杂

**问题**：单图信息过载
**解决方案**：
- 拆分为多面板 (A, B, C)
- 创建概览图+细节图
- 细节移至补充图表
- 采用层级化呈现

### 陷阱 2：样式不一致

**问题**：不同图表中相同元素样式不同
**解决方案**：
- 创建并使用样式模板
- 全文使用统一配色
- 记录样式选择

### 陷阱 3：标签位置不当

**问题**：标签重叠元素或难以辨识
**解决方案**：
- 优先将标签置于形状外部
- 远距离标签使用引线
- 仅在必要时旋转文本
- 确保与背景充分对比

### 陷阱 4：文本过小

**问题**：最终印刷尺寸下文字无法辨识
**解决方案**：
- 初始即按最终尺寸设计
- 最终尺寸打印测试
- 最小字号 7-8 pt
- 空间有限时简化标签

### 陷阱 5：箭头含义模糊

**问题**：箭头指向或含义不明
**解决方案**：
- 不同含义使用不同箭头样式
- 箭头添加标签
- 提供箭头类型图例
- 使用锚点精确定位

### 陷阱 6：色彩滥用

**问题**：颜色过多导致混淆或不可访问
**解决方案**：
- 限制在 3-5 种颜色内
- 色彩使用目的明确（分类/强调）
- 采用色盲安全调色板
- 提供冗余编码

## 期刊特定指南

### Nature

**图表要求**
- **尺寸**：89 mm（单栏）或 183 mm（双栏）
- **格式**：PDF、EPS 或高分辨率 TIFF
- **字体**：首选无衬线体
- **文件大小**：单文件 <10 MB
- **分辨率**：光栅图最小 300 DPI

**样式说明**
- 分图标签：小写加粗 (a, b, c)
- 简洁设计
- 最少化色彩
- 标题清晰

### Science

**图表要求**
- **尺寸**：55 mm（单栏）或 120 mm（双栏）
- **格式**：PDF、EPS、TIFF 或 JPEG（高质量）
- **分辨率**：照片 300 DPI，线条图 600 DPI
- **文件大小**：<10 MB
- **字体**：最小 6-7 pt

**样式说明**
- 分图标签：大写加粗 (A, B, C)
- 高对比度
- 小尺寸下可读

### Cell

**图表要求**
- **尺寸**：85 mm（单栏）或 178 mm（双栏）
- **格式**：首选 PDF，可接受 TIFF/EPS
- **分辨率**：最小 300 DPI
- **字体**：标签 8-10 pt
- **线宽**：最小 0.5 pt

**样式说明**
- 简洁专业
- 彩色或灰度
- 分图标签大写 (A, B, C)

### IEEE

**图表要求**
- **尺寸**：3.5 in（单栏）或 7.16 in（双栏）
- **格式**：PDF、EPS（首选矢量）
- **分辨率**：线条图 600 DPI，半色调图 300 DPI
- **字体**：最小 8-10 pt
- **色彩**：印刷用灰度，电子版可彩色

**样式说明**
- 遵循 IEEE 图形手册
- 电路图使用标准符号
- 技术精确性
- 清晰坐标轴标签

## 软件特定导出设置

### AI 生成图像

AI 生成图表导出为 PNG 格式，可通过以下方式嵌入 LaTeX：

```latex
\includegraphics[width=\textwidth]{diagram.png}
```

### Python (Matplotlib) 导出

```python
import matplotlib.pyplot as plt

# 设置出版级质量
plt.rcParams['font.family'] = 'sans-serif'
plt.rcParams['font.sans-serif'] = ['Arial']
plt.rcParams['font.size'] = 8
plt.rcParams['pdf.fonttype'] = 42  # PDF 嵌入 TrueType 字体

# 按正确 DPI 和裁剪保存
fig.savefig('diagram.pdf', dpi=300, bbox_inches='tight', 
            pad_inches=0.1, transparent=False)
fig.savefig('diagram.png', dpi=300, bbox_inches='tight')
```

### Schemdraw 导出

```python
import schemdraw

d = schemdraw.Drawing()
# ... 构建电路 ...

# 导出
d.save('circuit.svg')  # 矢量
d.save('circuit.pdf')  # 矢量
d.save('circuit.png', dpi=300)  # 光栅
```

### Inkscape 命令行

```bash
# PDF 转高分辨率 PNG
inkscape diagram.pdf --export-png=diagram.png --export-dpi=300

# SVG 转 PDF
inkscape diagram.svg --export-pdf=diagram.pdf
```

## 版本控制最佳实践

**保留源文件**
- 保存原始 .tex、.py 或 .svg 文件
- 使用含版本描述的命名
- 记录配色方案与样式选择
- 包含再生说明的 README

**目录结构**
```
图表/
├── 源文件/       # 可编辑源文件
│   ├── 图表1.tex
│   ├── 电路.py
│   └── 通路.svg
├── 生成文件/     # 自动生成输出

pdffonts diagram.pdf

# 检查图像分辨率
identify -verbose diagram.pdf
```

**对比度检查**
- WebAIM 对比度检查器：https://webaim.org/resources/contrastchecker/
- Colorable：https://colorable.jxnblk.com/

## 黄金法则摘要

1. **矢量优先**：尽可能使用矢量格式
2. **按最终尺寸设计**：避免创建后缩放
3. **色盲安全调色板**：使用 Okabe-Ito 或类似方案
4. **灰度测试**：图表在无色彩时仍须有效
5. **最小 7-8 pt 文字**：指最终印刷尺寸
6. **统一风格**：全文图表保持一致性
7. **保持简洁**：移除非必要元素
8. **高对比度**：确保可读性
9. **元素对齐**：专业外观至关重要
10. **完整图注**：解释所有内容
