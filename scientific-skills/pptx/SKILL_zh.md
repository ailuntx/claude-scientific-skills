## 设计理念

**别做无聊的幻灯片。** 白底纯文字无法打动任何人。为每页幻灯片参考以下创意：

### 开始前

- **选择大胆且契合内容的配色方案**：配色应专为当前主题设计。若将你的配色套用到完全不同的演示稿仍“适用”，说明选择不够独特。
- **主次分明**：一种颜色应占主导（60-70%视觉比重），搭配1-2种辅助色和一种鲜明点缀色。切勿让所有颜色均等分布。
- **明暗对比**：标题页和总结页用深色背景，内容页用浅色（“三明治”结构）。或全程使用深色营造高级感。
- **贯彻视觉主题**：选择一种独特元素并重复使用——圆角图片框、彩色圆圈图标、单侧粗边框。贯穿每页幻灯片。

### 配色方案

选择契合主题的颜色——勿默认使用通用蓝色。以下方案供参考：

| 主题 | 主色 | 辅色 | 点缀色 |
|-------|---------|-----------|--------|
| **午夜商务** | `1E2761` (海军蓝) | `CADCFC` (冰蓝) | `FFFFFF` (白) |
| **森林苔藓** | `2C5F2D` (森林绿) | `97BC62` (苔藓绿) | `F5F5F5` (奶油色) |
| **珊瑚能量** | `F96167` (珊瑚红) | `F9E795` (金色) | `2F3C7E` (海军蓝) |
| **暖陶土** | `B85042` (陶土红) | `E7E8D1` (沙色) | `A7BEAE` (鼠尾草绿) |
| **海洋渐变** | `065A82` (深蓝) | `1C7293` (青绿) | `21295C` (午夜蓝) |
| **炭黑极简** | `36454F` (炭灰) | `F2F2F2` (米白) | `212121` (纯黑) |
| **青蓝信任** | `028090` (青蓝) | `00A896` (海沫绿) | `02C39A` (薄荷绿) |
| **浆果奶油** | `6D2E46` (浆果紫) | `A26769` (灰玫瑰) | `ECE2D0` (奶油色) |
| **鼠尾草静谧** | `84B59F` (鼠尾草绿) | `69A297` (桉树绿) | `50808E` (石板蓝) |
| **樱桃撞色** | `990011` (樱桃红) | `FCF6F5` (米白) | `2F3C7E` (海军蓝) |

### 单页设计

**每页需有视觉元素**——图片、图表、图标或形状。纯文字幻灯片易被遗忘。

**版式选项：**
- 双栏（文字左，插图右）
- 图标+文字行（彩色圆圈图标+粗体标题+下方描述）
- 2x2或2x3网格（单侧图片+另一侧内容块）
- 半出血图片（左侧或右侧满版）加内容叠加

**数据展示：**
- 大型数据标注（60-72pt大数字+小标签）
- 对比栏（前后对比/利弊分析/选项并置）
- 时间线或流程图（带编号步骤/箭头）

**视觉优化：**
- 章节标题旁添加彩色小圆圈图标
- 关键数据或标语使用斜体强调

### 字体排版

**选择有趣字体组合**——勿默认使用Arial。标题字体需有个性，正文字体需简洁。

| 标题字体 | 正文字体 |
|-------------|-----------|
| Georgia | Calibri |
| Arial Black | Arial |
| Calibri | Calibri Light |
| Cambria | Calibri |
| Trebuchet MS | Calibri |
| Impact | Arial |
| Palatino | Garamond |
| Consolas | Calibri |

| 元素 | 字号 |
|---------|------|
| 幻灯片标题 | 36-44pt 粗体 |
| 章节标题 | 20-24pt 粗体 |
| 正文 | 14-16pt |
| 标注 | 10-12pt 浅色 |

### 间距

- 页边距至少0.5英寸
- 内容块间距0.3-0.5英寸
- 保留呼吸空间——勿填满每个角落

### 避免（常见错误）

- **勿重复相同版式**——交替使用分栏/卡片/标注
- **勿居中正文**——段落和列表左对齐；仅标题居中
- **勿弱化大小对比**——标题需36pt以上以区别于14-16pt正文
- **勿默认使用蓝色**——选择契合具体主题的颜色
- **勿随意混用间距**——统一使用0.3或0.5英寸间隙
- **勿仅设计单页**——要么彻底贯彻，要么全程保持简洁
- **勿做纯文字幻灯片**——添加图片/图标/图表；避免标题+纯文字
- **勿忽略文本框内边距**——对齐文字与形状时，文本框设`margin: 0`或偏移形状以补偿内边距
- **勿用低对比度元素**——图标和文字需与背景强对比；避免浅色背景配浅字/深色背景配深字
- **切勿在标题下加装饰线**——这是AI生成幻灯片的标志；改用留白或背景色

## 质量检查（必做）

**预设存在问题。你的任务是发现它们。**

首次渲染几乎总有缺陷。将QA视为查错而非确认步骤。若首次检查零问题，说明查得不够彻底。

### 内容检查

```bash
python -m markitdown output.pptx
```

检查内容缺失、拼写错误、顺序错误。

**使用模板时检查残留占位符：**

```bash
python -m markitdown output.pptx | grep -iE "xxxx|lorem|ipsum|this.*(page|slide).*layout"
```

若grep返回结果，修复后再宣告完成。

### 视觉检查

**⚠️ 使用子代理**——即使仅2-3页。你已长时间接触代码会产生盲点。子代理具备全新视角。

将幻灯片转为图片（见[图片转换](#converting-to-images)），使用以下指令：

```
视觉检查这些幻灯片。预设存在问题——请找出它们。

检查项：
- 元素重叠（文字穿透形状/线条穿过文字/元素堆叠）
- 文字溢出或边缘裁切
- 装饰线按单行标题定位但标题换行
- 引用或页脚与上方内容冲突
- 元素间距过近（<0.3英寸）或卡片/区块几乎接触
- 间距不均（某处大面积留白，某处拥挤）
- 页边距不足（<0.5英寸）
- 分栏或同类元素未对齐
- 低对比度文字（如浅灰字配米色背景）
- 低对比度图标（如深色图标配深背景且无对比圆环）
- 文本框过窄导致过度换行
- 残留占位内容

逐页列出问题或疑点（即使轻微）。

检查以下图片：
1. /path/to/slide-01.jpg (预期效果：[简述])
2. /path/to/slide-02.jpg (预期效果：[简述])

报告所有问题（含轻微项）。
```

### 验证循环

1. 生成幻灯片 → 转为图片 → 检查
2. **列出问题**（若无问题，需更严格复查）
3. 修复问题
4. **重新验证受影响页**——修复常引发新问题
5. 循环直至无新问题

**至少完成一次修复-验证循环才可宣告成功。**

## 图片转换

将演示稿转为单页图片以便视觉检查：

```bash
python scripts/office/soffice.py --headless --convert-to pdf output.pptx
pdftoppm -jpeg -r 150 output.pdf slide
```

生成 slide-01.jpg, slide-02.jpg 等文件。

修复后重渲特定页：

```bash
pdftoppm -jpeg -r 150 -f N -l N output.pdf slide-fixed
```
