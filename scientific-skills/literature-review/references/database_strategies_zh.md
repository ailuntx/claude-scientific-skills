# 文献数据库检索策略

本文档提供系统高效检索多个文献数据库的全面指南。

## 可用数据库与检索技能

### 生物医学与生命科学

#### PubMed / PubMed Central
- **访问方式**：使用 `gget` 技能或 WebFetch 工具
- **覆盖范围**：3500万+篇生物医学文献引文
- **最佳用途**：临床研究、生物医学研究、遗传学、分子生物学
- **检索技巧**：使用 MeSH 主题词、布尔运算符（AND/OR/NOT）、字段标签 [Title]/[Author]
- **示例**：`"CRISPR"[Title] AND "gene editing"[Title/Abstract] AND 2020:2024[Publication Date]`

#### bioRxiv / medRxiv
- **访问方式**：使用 `gget` 技能或直接 API
- **覆盖范围**：生物学与医学预印本
- **最佳用途**：获取最新未发表研究、前沿发现
- **注意**：未经同行评审；需谨慎验证结果
- **检索技巧**：按类别检索（生物信息学、基因组学等）

### 通用科学文献

#### arXiv
- **访问方式**：直接 API 访问
- **覆盖范围**：物理学、数学、计算机科学、定量生物学预印本
- **最佳用途**：计算方法、生物信息学算法、理论研究
- **分类标签**：q-bio（定量生物学）、cs.LG（机器学习）、stat.ML（统计学）
- **检索格式**：`cat:q-bio.QM AND title:"single cell"`

#### Semantic Scholar
- **访问方式**：直接 API（需 API 密钥）
- **覆盖范围**：2亿+篇跨学科论文
- **最佳用途**：跨学科检索、引文图谱、论文推荐
- **特色功能**：高影响力引文、论文摘要、相关文献
- **速率限制**：使用 API 密钥时 100次请求/5分钟

#### Google Scholar
- **访问方式**：网页抓取（谨慎使用）或手动检索
- **覆盖范围**：全学科综合文献
- **最佳用途**：查找高被引论文、会议论文集、学位论文
- **局限性**：无官方 API，存在速率限制
- **导出功能**：使用"引用"功能获取格式化引文

### 专业数据库

#### ChEMBL / PubChem
- **访问方式**：使用 `gget` 或 `bioservices` 技能
- **覆盖范围**：化合物、生物活性数据、药物分子
- **最佳用途**：药物发现、化学生物学、药物化学
- **ChEMBL**：200万+化合物生物活性数据
- **PubChem**：1.1亿+化合物检测数据

#### UniProt
- **访问方式**：使用 `gget` 或 `bioservices` 技能
- **覆盖范围**：蛋白质序列与功能信息
- **最佳用途**：蛋白质研究、序列分析、功能注释
- **检索字段**：蛋白质名称、基因名称、生物体、功能

#### KEGG（京都基因与基因组百科全书）
- **访问方式**：使用 `bioservices` 技能
- **覆盖范围**：通路、疾病、药物、基因
- **最佳用途**：通路分析、系统生物学、代谢研究

#### COSMIC（癌症体细胞突变目录）
- **访问方式**：使用 `gget` 技能或直接下载
- **覆盖范围**：癌症基因组学、体细胞突变
- **最佳用途**：癌症研究、突变分析

#### AlphaFold 数据库
- **访问方式**：使用 `gget alphafold` 命令
- **覆盖范围**：2亿+蛋白质结构预测
- **最佳用途**：结构生物学、蛋白质建模

#### PDB（蛋白质数据库）
- **访问方式**：使用 `gget` 或直接 API
- **覆盖范围**：蛋白质/核酸实验性 3D 结构
- **最佳用途**：结构生物学、药物设计、分子建模

### 引文与参考文献管理

#### OpenAlex
- **访问方式**：直接 API（免费无需密钥）
- **覆盖范围**：2.5亿+文献元数据
- **最佳用途**：引文分析、作者消歧、机构研究
- **特色功能**：开放获取，适用于文献计量学

#### Dimensions
- **访问方式**：提供免费层级
- **覆盖范围**：出版物、基金、专利、临床试验
- **最佳用途**：研究影响力、资助分析、转化研究

## 检索策略框架

### 1. 明确研究问题（PICO框架）

临床/生物医学综述适用：
- **P**opulation（人群）：研究对象？
- **I**ntervention（干预）：测试内容？
- **C**omparison（对照）：对比对象？
- **O**utcome（结果）：研究结果？

**示例**："CRISPR-Cas9基因疗法（I）治疗镰状细胞病（P）相比标准护理（C）在改善患者预后（O）方面的疗效如何？"

### 2. 制定检索词

#### 核心概念
从研究问题提取2-4个主要概念

**示例**：
- 概念1：CRISPR、Cas9、基因编辑
- 概念2：镰状细胞病、SCD、血红蛋白疾病
- 概念3：基因治疗、治疗性编辑

#### 同义词与相关术语
列出替代词、缩写及关联概念

**工具**：使用MeSH主题词浏览器获取标准化术语

#### 布尔运算符
- **AND**：缩小范围（必须同时包含）
- **OR**：扩大范围（包含任一术语）
- **NOT**：排除术语

**示例**：`(CRISPR OR Cas9 OR "gene editing") AND ("sickle cell" OR SCD) AND therapy`

#### 通配符与截词符
- `*` 或 `%`：匹配任意字符
- `?`：匹配单个字符

**示例**：`genom*` 匹配 genomic, genomics, genome

### 3. 设定纳入/排除标准

#### 纳入标准
- **时间范围**：如2015-2024（近10年）
- **语言**：英语（或多语言）
- **文献类型**：同行评审文章、综述、预印本
- **研究设计**：RCT、队列研究、荟萃分析
- **研究对象**：人类、动物模型、体外实验

#### 排除标准
- 病例报告（n<5）
- 无全文的会议摘要
- 非原创研究（社论、评论）
- 重复发表文献
- 撤稿文章

### 4. 数据库选择策略

#### 多库联合检索
至少检索3个互补数据库：

1. **核心数据库**：PubMed（生物医学）或arXiv（计算科学）
2. **预印本平台**：bioRxiv/medRxiv 或 arXiv
3. **综合数据库**：Semantic Scholar 或 Google Scholar
4. **专业数据库**：ChEMBL、UniProt 或领域特化库

#### 数据库专用语法

| 数据库 | 字段标签 | 示例 |
|----------|-----------|---------|
| PubMed | [Title], [Author], [MeSH] | "CRISPR"[Title] AND 2020:2024[DP] |
| arXiv | ti:, au:, cat: | ti:"machine learning" AND cat:q-bio.QM |
| Semantic Scholar | title:, author:, year: | title:"deep learning" year:2020-2024 |

## 检索执行流程

### 阶段1：预检索
1. 使用宽泛术语进行初始检索
2. 评估前50条结果相关性
3. 记录高频关键词与MeSH术语
4. 优化检索策略

### 阶段2：全面检索
1. 在选定数据库执行优化检索
2. 导出标准格式结果（RIS/BibTeX/JSON）
3. 记录各库检索式与检索日期
4. 统计各库结果数量

### 阶段3：去重处理
1. 合并所有结果至单一文件
2. 使用 `search_databases.py --deduplicate` 去重
3. 按DOI（主）或标题（次）识别重复项
4. 保留元数据最完整的版本

### 阶段4：筛选流程
1. **标题筛选**：排除明显无关文献
2. **摘要筛选**：应用纳入/排除标准
3. **全文筛选**：获取并评估全文
4. 记录各阶段排除原因

### 阶段5：质量评估
1. 使用标准化工具评估研究质量：
   - **RCT**：Cochrane偏倚风险评估
   - **观察性研究**：纽卡斯尔-渥太华量表
   - **系统综述**：AMSTAR 2量表
2. 证据质量分级（高/中/低/极低）
3. 考虑排除极低质量研究

## 高级检索技巧

### 高影响力论文优先策略（关键）

**始终依据被引频次、期刊质量、作者声誉优先选择论文。质量重于数量。**

#### 数据库引文指标应用

利用被引频次识别影响力文献：

| 文献年限 | 被引频次 | 分类 |
|-----------|-----------|----------------|
| 0-3年 | 20+ | 值得关注 |
| 0-3年 | 100+ | 高影响力 |
| 3-7年 | 100+ | 重要文献 |
| 3-7年 | 500+ | 里程碑 |
| 7年以上 | 500+ | 开创性 |
| 7年以上 | 1000+ | 奠基性 |

**数据库特色引文功能：**
- **Google Scholar**：按被引排序，使用"被引用"功能
- **Semantic Scholar**："高影响力引文"指标，引文增速
- **OpenAlex**：被引统计，引文上下文分析
- **PubMed**：通过PMC"被引用"功能，结合Google Scholar验证

#### 期刊质量过滤

优先选择高等级期刊：

**第一梯队（首选）：**
- Nature, Science, Cell, NEJM, Lancet, JAMA, PNAS
- Nature Medicine, Nature Biotechnology, Nature Methods
- 检索技巧：Google Scholar 使用 `source:Nature` 或 `journal:Nature`

**第二梯队（重点考虑）：**
- 高影响力专业期刊（影响因子>10）
- 顶级会议：NeurIPS, ICML, ICLR, CVPR, ACL

**第三梯队（相关时纳入）：**
- 领域权威期刊（IF 5-10）

**PubMed期刊过滤：**
```
"Nature"[Journal] OR "Science"[Journal] OR "Cell"[Journal]
```

**Google Scholar期刊过滤：**
```
source:Nature source:Science source:Cell
```

#### "被引用"功能应用

**发现影响力研究：**
1. 从已知关键文献出发
2. 点击"被引用"查看引用文献
3. 按被引频次排序
4. 高被引引用文献代表重要后续研究

**识别开创性文献：**
1. 宽泛检索主题
2. 记录高频出现的参考文献
3. 被多篇文献引用的论文多为开创性
4. 通过被引频次确认影响力

**Semantic Scholar特色：**
- "高影响力引文"显示重要衍生研究
- "引文增速"反映近期关注度
- 基于引文网络的论文推荐

### 引文链追踪

#### 前向引文检索
查找引用关键文献的论文：
- 使用Google Scholar"被引用"功能
- 使用OpenAlex或Semantic Scholar API
- 识别基于开创性研究的新成果
- **技巧**：按被引排序发现高影响力后续研究

#### 后向引文检索
追溯关键文献的参考文献：
- 提取纳入文献的参考文献
- 检索高被引文献（经典文献500+引用）
- 识别奠基性研究
- **技巧**：聚焦多篇文献共同引用的参考文献

### 滚雪球抽样法
1. 从3-5篇**第一梯队期刊**的高相关文献出发
2. 提取全部参考文献
3. 识别被多篇文献引用的参考文献
4. 评估高重叠文献（多为开创性）
5. 对新发现关键文献重复此流程
6. **每步优先选择高被引文献**

### 作者追踪
关注领域高产权威学者：
- 跨库检索作者姓名
- 查看学者档案（ORCID, Google Scholar）获取h指数与发表期刊
- 追踪近期成果与预印本
- **优先选择多篇第一梯队成果且h指数>40的学者**
- 关注公认的资深领域领袖

### 相关文献功能
多数据库提供相关文献推荐：
- PubMed"相似文献"
- Semantic Scholar"推荐论文"
- 补充关键词检索遗漏
- **按被引频次和期刊质量过滤推荐**

## 常见误区规避

1. **检索过窄**：遗漏相关文献
   - 解决方案：补充同义词、相关术语、宽泛概念

2. **检索过宽**：数千条无关结果
   - 解决方案：用AND添加限定概念，使用字段标签

3. **单库检索**：覆盖不全
   - 解决方案：至少检索3个互补数据库

4. **忽略预印本**：遗漏最新发现
   - 解决方案：纳入 bioRxiv/medRxiv/arXiv

5. **无记录**：不可复现
   - 解决方案：完整记录检索式、日期、结果量

6. **手动去重**：耗时易错
   - 解决方案：使用 search_databases.py 脚本

7. **未验证引文**：DOI失效/元数据错误
   - 解决方案：终稿运行 verify_citations.py

8. **发表偏倚**：仅纳入阳性结果
   - 解决方案：检索试验注册库，联系作者获取未发表数据
