# 治疗计划质量保证检查清单

## 概述
使用本清单确保治疗计划在完整性、质量、安全性和合规性方面符合专业标准。在最终确定计划前逐项审核各章节。

---

## 第1部分：完整性 - 必备要素

### ☐ 患者信息
- [ ] 患者标识符（共享时需去标识化）
- [ ] 年龄范围（非精确出生日期）
- [ ] 性别及相关人口统计信息
- [ ] 计划创建日期
- [ ] 医疗服务提供者姓名及资质
- [ ] 机构/诊所名称
- [ ] 包含HIPAA去标识化声明

### ☐ 诊断与评估
- [ ] 明确陈述主要诊断
- [ ] 包含ICD-10编码
- [ ] 列出次要诊断及合并症
- [ ] 记录疾病严重程度/分期
- [ ] 评估基线功能状态
- [ ] 完成风险分层（如适用）

### ☐ 治疗目标
- [ ] 设定短期目标（1-3个月）
- [ ] 设定长期目标（6-12个月）
- [ ] 目标符合SMART原则（见第2部分）
- [ ] 包含以患者为中心的目标
- [ ] 目标已排序或分类

### ☐ 干预措施
- [ ] 明确药物干预方案
- [ ] 包含非药物干预措施
- [ ] 注明操作干预或转诊安排
- [ ] 每项干预均有明确依据
- [ ] 基于循证或符合指南

### ☐ 时间线与进度
- [ ] 定义治疗阶段及持续时间
- [ ] 明确复诊频率
- [ ] 设定里程碑评估节点
- [ ] 说明预期总治疗时长

### ☐ 监测参数
- [ ] 确定需追踪的临床结局指标
- [ ] 记录基线值
- [ ] 设定目标值
- [ ] 定义监测频率
- [ ] 注明评估工具/量表

### ☐ 预期疗效
- [ ] 说明主要疗效指标
- [ ] 定义成功标准
- [ ] 标注改善时间线
- [ ] 注明治疗方案调整标准

### ☐ 随访计划
- [ ] 安排下次就诊时间
- [ ] 明确随访频率
- [ ] 概述沟通方案
- [ ] 包含紧急联络流程

### ☐ 患者教育
- [ ] 记录疾病知识宣教
- [ ] 注明自我管理技能培训
- [ ] 告知预警体征
- [ ] 列出资源与支持渠道

### ☐ 风险控制与安全
- [ ] 识别潜在不良反应
- [ ] 包含安全监测方案
- [ ] 概述应急处理流程
- [ ] 制定并发症预防措施

### ☐ 签名与日期
- [ ] 医疗服务提供者签名栏
- [ ] 提供者姓名及资质
- [ ] 计划日期
- [ ] 患者确认（如适用）

## 第2部分：SMART目标质量

逐项验证治疗目标是否符合SMART原则：

### ☐ 具体性（Specific）
- [ ] 目标明确定义预期成果
- [ ] 无模糊表述（如"改善"、"更好"）
- [ ] 说明具体结果指标

**示例**："将糖化血红蛋白从8.5%降至<7%" ✓  
**非示例**："改善糖尿病控制" ✗

### ☐ 可衡量（Measurable）
- [ ] 包含可量化指标或可观察标准
- [ ] 记录基线值
- [ ] 设定目标值

**示例**："借助助行器独立行走300英尺" ✓  
**非示例**："行走更远距离" ✗

### ☐ 可实现（Achievable）
- [ ] 符合患者状况及能力的现实目标
- [ ] 具备支持目标的资源
- [ ] 时间框架合理
- [ ] 治疗有效性支持目标达成

**示例**："6周内疼痛评分从7/10降至4/10" ✓  
**非示例**："1周内完全消除疼痛" ✗

### ☐ 相关性（Relevant）
- [ ] 符合患者价值观及优先事项
- [ ] 具有临床意义
- [ ] 解决患者功能限制
- [ ] 与整体治疗目标整合

**示例**："3个月内经调整后重返工作岗位" ✓  
**非示例**："改善实验室指标"（若患者不关注） ✗

### ☐ 时限性（Time-bound）
- [ ] 设定具体截止日期或时间段
- [ ] 定义重新评估间隔
- [ ] 明确执行频率（如适用）

**示例**："8周内"或"第3个月前" ✓  
**非示例**："最终"或"尽快" ✗

## 第3部分：临床质量

### ☐ 循证实践
- [ ] 干预措施基于最新证据
- [ ] 遵循临床实践指南
- [ ] 对指南偏离进行解释说明
- [ ] 引用文献或证据（正式计划需包含）

### ☐ 药物记录（如适用）
- [ ] 使用药物通用名
- [ ] 记录具体剂量、给药途径、频率
- [ ] 说明每项药物的适应症/依据
- [ ] 注明需监测的不良反应
- [ ] 考虑药物相互作用
- [ ] 包含剂量调整方案（如适用）

### ☐ 评估工具
- [ ] 优先使用经过验证的评估工具
- [ ] 工具适用于当前病症（如PHQ-9、FIM、Berg等）
- [ ] 记录基线评分
- [ ] 设定目标评分
- [ ] 定义重新评估计划

### ☐ 多学科协作（如适用）
- [ ] 明确团队成员职责
- [ ] 制定跨专业沟通方案
- [ ] 处理照护过渡环节
- [ ] 整合专科医生建议

### ☐ 预防性医疗整合
- [ ] 包含适龄筛查项目
- [ ] 注明疫苗接种计划
- [ ] 记录生活方式指导
- [ ] 处理健康维护事项

## 第4部分：以患者为中心的照护

### ☐ 共同决策
- [ ] 记录患者偏好
- [ ] 讨论治疗方案选项
- [ ] 解释风险与获益
- [ ] 将患者价值观融入目标设定
- [ ] 考虑替代治疗方案

### ☐ 健康素养
- [ ] 使用患者可理解的语言
- [ ] 解释或避免医学术语
- [ ] 采用或计划使用回授法
- [ ] 书面材料符合阅读水平要求

### ☐ 文化胜任力
- [ ] 考虑文化信仰与实践
- [ ] 解决语言障碍（必要时提供翻译）
- [ ] 酌情进行文化适应
- [ ] 尊重宗教/精神偏好

### ☐ 健康社会决定因素
- [ ] 筛查社会需求（食物、住房、交通）
- [ ] 识别照护障碍
- [ ] 提供社区资源
- [ ] 处理财务问题（药物费用等）

### ☐ 患者参与
- [ ] 患者积极参与目标设定
- [ ] 提供自我管理支持
- [ ] 个性化患者教育
- [ ] 考虑患者随访偏好

## 第5部分：安全与风险管理

### ☐ 用药安全
- [ ] 记录过敏史
- [ ] 审查多重用药（考虑药物精简）
- [ ] 对高风险药物进行适当监测
- [ ] 核查药物相互作用
- [ ] 必要时调整肝肾剂量

### ☐ 跌倒预防（如相关）
- [ ] 评估跌倒风险
- [ ] 包含跌倒预防策略
- [ ] 建议环境改造
- [ ] 开具辅助设备处方

### ☐ 感染预防（如相关）
- [ ] 更新疫苗接种状态
- [ ] 必要时使用预防性抗生素
- [ ] 进行感染体征患者教育

### ☐ 应急准备
- [ ] 清晰列出紧急预警体征
- [ ] 明确呼叫911的指征
- [ ] 定义联系医疗服务提供者的情形
- [ ] 提供紧急联系电话

### ☐ 自杀/暴力风险（心理健康计划）
- [ ] 记录风险评估
- [ ] 存在自杀意念时制定安全计划
- [ ] 处理自杀工具限制
- [ ] 提供危机资源（988生命热线）
- [ ] 根据风险等级设定随访频率

### ☐ 阿片类药物安全（疼痛管理计划）
- [ ] 完成阿片类药物风险评估（ORT、SOAPP）
- [ ] 记录知情同意讨论
- [ ] 签署治疗协议
- [ ] 核查处方药监控系统（PDMP）
- [ ] 联合处方纳洛酮
- [ ] 包含尿液药物筛查（UDS）计划

## 第6部分：法规合规性

### ☐ HIPAA合规
- [ ] 保护受保护健康信息（PHI）
- [ ] 采用安全港方法进行去标识化（共享时）
- [ ] 移除全部18项HIPAA标识符（去标识化时）
- [ ] 遵循最小必要原则

### ☐ 知情同意
- [ ] 记录知情同意讨论
- [ ] 确认患者理解程度
- [ ] 解释风险与获益
- [ ] 讨论替代治疗方案
- [ ] 记录患者同意情况

### ☐ 医疗必要性
- [ ] 治疗对诊断具有医疗必要性
- [ ] 干预措施符合疾病严重程度
- [ ] 证据支持治疗选择
- [ ] 频率和持续时间合理

### ☐ 计费与编码
- [ ] 包含ICD-10诊断编码
- [ ] 注明CPT操作编码（如计划操作）
- [ ] 文档支持计费等级
- [ ] 证明服务的医疗必要性

### ☐ 质量指标支持
- [ ] 要素支持质量报告（HEDIS、MIPS）
- [ ] 遵循慢性病管理规范
- [ ] 记录预防性医疗
- [ ] 处理患者安全指标

### ☐ 专科特定法规
- [ ] 符合42 CFR Part 2规定（物质使用障碍治疗）
- [ ] 遵循CDC阿片类药物指南（如开具阿片类药物）
- [ ] 满足联合委员会标准（如适用）
- [ ] 符合州特定要求

### 慢性病管理计划：

## 评分与解读

**总项目数**：约150项（因计划类型而异）

### 评分：
- 统计勾选项目数
- 计算百分比：（已勾选/总数）×100

### 解读：
- **95-100%**：优秀 - 符合最高质量标准
- **85-94%**：良好 - 高质量计划，存在微小差距
- **70-84%**：合格 - 计划基本完备，有待改进
- **<70%**：需改进 - 存在显著质量或合规性缺陷

### 关键项（必备）：
以下项目必须包含：
- ✓ 患者标识符及去标识化声明
- ✓ 含ICD-10编码的主要诊断
- ✓ 至少3项SMART目标
- ✓ 含依据的干预措施
- ✓ 监测计划
- ✓ 随访计划
- ✓ 患者教育
- ✓ 安全/风险控制
- ✓ 应急流程
- ✓ 提供者签名

任何关键项缺失时，应在修正后方可定稿。
