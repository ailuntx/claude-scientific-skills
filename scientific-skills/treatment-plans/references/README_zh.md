# 治疗计划技能

## 概述

用于生成**简洁、面向临床医生**的跨临床专科医疗治疗方案的技能。提供包含SMART目标框架、循证干预措施、法规合规性及以患者为中心的护理计划验证工具的LaTeX/PDF模板。

**默认采用单页格式**处理多数情况——定位为"快速参考卡"而非"综合教科书"。

## 包含内容

### 📋 七种治疗方案类型

1. **单页治疗方案**（首选）- 适用于多数临床场景的简洁快速参考格式
2. **通用医疗方案** - 初级护理、慢性病（糖尿病、高血压、心力衰竭）
3. **康复治疗方案** - 物理治疗、作业治疗、心肺康复
4. **心理健康方案** - 精神科护理、抑郁、焦虑、创伤后应激障碍、物质滥用
5. **慢性病管理方案** - 复杂多病症、长期护理协调
6. **围手术期护理方案** - 术前优化、ERAS协议、术后恢复
7. **疼痛管理方案** - 急慢性疼痛、多模式镇痛、阿片类药物节约策略

## 快速入门

### 生成治疗方案模板

```bash
cd .claude/skills/treatment-plans/scripts
python generate_template.py

# 或直接指定类型
python generate_template.py --type general_medical --output diabetes_plan.tex
```

可用模板类型：
- `one_page`（首选 - 多数情况使用）
- `general_medical`
- `rehabilitation`
- `mental_health`
- `chronic_disease`
- `perioperative`
- `pain_management`

### 编译为PDF

```bash
cd /path/to/your/treatment/plan
pdflatex my_treatment_plan.tex
```

### 验证治疗方案

```bash
# 完整性检查
python check_completeness.py my_treatment_plan.tex

# 综合验证
python validate_treatment_plan.py my_treatment_plan.tex
```

### 生成治疗时间线

```bash
python timeline_generator.py --plan my_treatment_plan.tex --output timeline.pdf
```

## 标准治疗方案组件

所有模板均包含以下核心章节：

### 1. 患者信息（去标识化）
- 人口统计与相关医疗背景
- 现患疾病与合并症
- 当前用药与过敏史
- 功能状态基线
- HIPAA合规去标识化

### 2. 诊断与评估摘要
- 主要诊断（ICD-10编码）
- 次要诊断
- 严重程度分级
- 功能限制
- 风险分层

### 3. 治疗目标（SMART格式）

**短期目标**（1-3个月）：
- 具体可衡量的结果
- 明确时间框架的现实目标
- 以患者为中心的优先事项

**长期目标**（6-12个月）：
- 疾病控制目标
- 功能改善目标
- 生活质量提升
- 并发症预防

### 4. 干预措施

- **药物干预**：剂量、频率、监测
- **非药物干预**：生活方式调整、行为干预、教育
- **操作程序**：计划性操作、专科转诊、诊断检测

### 5. 时间线与计划
- 分阶段治疗时间框架
- 预约频率
- 里程碑评估
- 预期治疗周期

### 6. 监测参数
- 追踪的临床结果
- 评估工具与量表
- 监测频率
- 干预阈值

### 7. 预期结果
- 主要结果指标
- 成功标准
- 改善时间线
- 长期预后

### 8. 随访计划
- 预约安排
- 沟通流程
- 紧急处理程序
- 过渡规划

### 9. 患者教育
- 疾病认知
- 自我管理技能
- 预警信号
- 资源与支持

### 10. 风险控制
- 不良反应管理
- 安全监测
- 紧急行动计划
- 跌倒/感染预防

## 常见应用场景

### 1. 2型糖尿病管理

```
目标：为新诊断糖尿病患者创建综合方案

模板：general_medical_treatment_plan.tex

核心组件：
- SMART目标：3个月内HbA1c<7%，6个月减重10磅
- 药物：二甲双胍滴定方案
- 生活方式：饮食、运动、血糖监测
- 监测：每3月HbA1c检测，季度复诊
- 教育：糖尿病自我管理教育
```

### 2. 脑卒中后康复

```
目标：为偏瘫患者制定康复方案

模板：rehabilitation_treatment_plan.tex

核心组件：
- 功能评估：FIM评分、关节活动度、肌力测试
- 物理治疗目标：12周内助行器行走150英尺
- 作业治疗目标：独立完成日常生活活动，上肢功能
- 治疗计划：每周3次PT/OT/SLP
- 家庭锻炼计划
```

### 3. 重度抑郁障碍

```
目标：创建抑郁症综合治疗方案

模板：mental_health_treatment_plan.tex

核心组件：
- 评估：PHQ-9评分16（中度抑郁）
- 目标：12周内PHQ-9降至<5分，恢复工作
- 心理治疗：每周CBT疗程
- 药物：SSRI滴定方案
- 安全计划：危机联系人、预警信号
```

### 4. 全膝关节置换术

```
目标：择期TKA围手术期护理方案

模板：perioperative_care_plan.tex

核心组件：
- 术前优化：医疗许可、药物管理
- ERAS协议实施
- 术后里程碑：术后第1天下床，2-3天出院
- 疼痛管理：多模式镇痛
- 康复计划：术后当天开始PT
```

### 5. 慢性腰痛

```
目标：多模式疼痛管理方案

模板：pain_management_plan.tex

核心组件：
- 疼痛评估：部位、强度、功能影响
- 目标：疼痛评分7/10降至3/10，恢复工作
- 药物：非阿片类镇痛药、辅助药物
- 物理治疗：核心肌群训练、McKenzie疗法
- 行为干预：疼痛认知行为疗法、正念
- 介入治疗：反应不足时考虑硬膜外注射
```

## SMART目标框架

所有治疗方案均采用SMART标准设定目标：

- **具体性**：清晰明确的结果（非模糊表述）
- **可衡量**：可量化指标或可观察行为
- **可实现**：符合患者能力与资源的现实目标
- **相关性**：与患者优先事项及价值观一致
- **时限性**：明确达成时间框架

### 示例

**合格SMART目标**：
- 3个月内HbA1c从8.5%降至<7%
- 8周内借助辅助设备独立行走150英尺
- 8周内PHQ-9抑郁评分从18分降至<10分
- 术后14天膝关节屈曲>90度
- 6周内疼痛评分从7/10降至≤4/10

**不合格目标**（非SMART）：
- "感觉好转"（不具体/不可衡量）
- "改善糖尿病"（不具体/无时限）
- "增强力量"（不可衡量）
- "恢复正常"（模糊/不具体）

## 工作流示例

### 标准治疗方案工作流

1. **患者评估** - 完成病史、体检、诊断检测
2. **选择模板** - 根据临床背景选择合适模板
3. **生成模板** - `python generate_template.py --type [类型]`
4. **定制方案** - 填写患者专属信息（去标识化）
5. **设定SMART目标** - 定义可衡量的短期与长期目标
6. **明确干预措施** - 循证药物与非药物干预
7. **创建时间线** - 安排预约、里程碑、复评
8. **定义监测** - 结果指标、评估频率
9. **验证完整性** - `python check_completeness.py 方案.tex`
10. **质量检查** - `python validate_treatment_plan.py 方案.tex`
11. **审核质量清单** - 对照`quality_checklist.md`
12. **生成PDF** - `pdflatex 方案.tex`
13. **患者复核** - 共同决策，确认理解
14. **执行与记录** - 实施计划，在临床记录中追踪进展
15. **复评与调整** - 根据结果修正方案

### 多学科护理方案工作流

1. **确定团队成员** - 初级保健医生、专科医生、治疗师、个案经理
2. **创建基础方案** - 生成主要病症模板
3. **添加专科章节** - 整合会诊建议
4. **协调目标** - 确保跨学科目标一致性
5. **定义沟通机制** - 团队会议安排、文件共享
6. **分配职责** - 明确各项干预负责人
7. **制定护理时间线** - 协调跨服务提供者预约
8. **共享方案** - 分发给全体成员及患者
9. **协同追踪** - 共享监测与结果追踪
10. **定期团队复评** - 协作调整方案

## 专业标准

### 文件要求
- 完整准确的患者信息
- 清晰诊断与正确ICD-10编码
- 循证干预措施
- 可衡量目标与结果
- 明确的监测与随访
- 提供者签名、资质与日期

### 医疗必要性
治疗方案需证明：
- 干预措施的医疗适当性
- 与诊断及严重程度的一致性
- 支持治疗选择的证据
- 预期结果与获益
- 频率与持续时间的合理性

### 法律考量
- 知情同意文件
- 患者理解与同意
- 风险披露与控制
- 职业责任保护
- 符合州/联邦法规

## 常见问题解答

### 如何选择正确模板？

根据主要临床重点匹配模板：
- **慢性内科疾病** → general_medical或chronic_disease
- **术后或创伤** → rehabilitation或perioperative
- **精神疾病** → mental_health
- **疼痛为主诉** → pain_management

### 患者患多种疾病如何处理？

对复杂多病症使用`chronic_disease_management_plan.tex`模板，或选择主要病症模板并添加合并症章节。

### 治疗方案应多久更新？

- **初始创建**：诊断或治疗启动时
- **定期更新**：慢性病每3-6个月
- **重大变更**：目标达成或治疗调整时
- **年度审核**：所有慢性病方案至少每年一次

### 能否修改LaTeX模板？

可以！模板设计支持自定义。可修改章节、添加专科内容或调整格式以满足需求。

### 如何确保HIPAA合规？

- 移除全部18项HIPAA标识符（参见安全港方法）
- 使用年龄范围替代具体年龄（如"60-65岁"而非"63岁"）
- 删除具体日期，采用相对时间线
- 省略州级以下地理标识
- 使用clinical-reports技能中的`check_deidentification.py`脚本

### 验证脚本发现问题如何处理？

审查具体问题，查阅参考文件获取指导并相应修订方案。常见问题包括：
- 必填章节缺失
- 目标不符合SMART标准
- 监测参数不足
- 药物信息不完整
