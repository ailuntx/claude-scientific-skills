# 治疗计划的目标设定框架

## 概述

有效的治疗目标是患者成功护理的基石。本参考为所有医学专科的治疗规划提供了创建SMART目标、以患者为中心的结果选择及共同决策流程的全面指导。

## SMART目标框架

### 定义

**SMART**是目标标准的助记符，确保目标明确且可实现：
- **S**pecific（具体性）
- **M**easurable（可衡量性）
- **A**chievable（可达成性）
- **R**elevant（相关性）
- **T**ime-bound（时限性）

### 1. 具体性

目标必须清晰、明确且无歧义。

**具体性要素**：
- **内容**：需达成的具体事项
- **主体**：责任方（患者、医护或双方）
- **场景**：相关环境或场所
- **范畴**：涉及健康/功能的特定方面

**示例**：

| 较差（模糊） | 良好（具体） |
|--------------|-----------------|
| "感觉好些" | "通过PHQ-9评分将抑郁症状减轻" |
| "改善糖尿病" | "将糖化血红蛋白从8.5%降至7%以下" |
| "增强力量" | "通过徒手肌力测试将右股四头肌力量从3/5提升至4/5" |
| "减重" | "体重减轻10磅（从210磅到200磅）" |
| "增加锻炼" | "每周步行5天，每次30分钟" |

### 2. 可衡量性

目标需包含可量化指标或可观察标准以追踪进展。

**衡量方式**：
- **定量**：数字、百分比、评分、量表
  - 实验室值：糖化血红蛋白、低密度脂蛋白胆固醇、估算肾小球滤过率
  - 生命体征：血压、心率、体重
  - 量表：疼痛数字评分(0-10)、PHQ-9、GAD-7、功能独立性评定量表
  - 功能性：步行距离、关节活动度、肌力分级
  
- **定性可观察**：可观察验证的行为
  - "患者展示正确的胰岛素注射技术"
  - "患者借助助行器独立行走150英尺"
  - "患者遵循两步指令"

**示例**：

| 不可衡量 | 可衡量 |
|----------------|------------|
| "改善血压" | "收缩压<130mmHg且舒张压<80mmHg" |
| "减轻疼痛" | "疼痛数字评分从7/10降至≤4/10" |
| "提升行动力" | "在监督下使用前轮助行器行走300英尺" |
| "规律服药" | "通过续药率测得药物依从性>90%" |
| "改善睡眠" | "每晚睡眠7-8小时且夜间觉醒<2次" |

### 3. 可达成性

目标需符合患者能力、资源及实际状况。

**考量因素**：
- **患者能力**：身体、认知、心理承受力
- **病情严重度**：晚期疾病改善空间有限
- **治疗有效性**：现有治疗可实现的预期效果
- **资源**：医疗、药物、设备、支持的可及性
- **时间**：达成目标的合理周期
- **动机**：患者改变意愿与参与度

**设定可达成目标**：
- 从基线评估开始
- 了解预期治疗效果（如二甲双胍可降低糖化血红蛋白1-1.5%）
- 大目标分步实施（先减5磅，再减10磅，而非直接减50磅）
- 适度挑战但不过度施压
- 根据进展调整目标

**示例**：

| 不可达成 | 可达成 |
|----------------|------------|
| "1个月内具备马拉松能力"（70岁心梗后久坐患者） | "3个月内持续行走1英里" |
| "6周内糖化血红蛋白从12%降至<6%" | "3个月内糖化血红蛋白从12%降至<9%，6个月内<7%" |
| "全膝关节置换术后3天膝关节活动度达0-140°" | "术后2周膝关节活动度0-90°，6周达0-110°" |
| "治愈慢性疼痛" | "疼痛从7/10降至4/10，功能提升30%" |

### 4. 相关性

目标需契合患者价值观、优先事项及整体治疗方向。

**相关性标准**：
- **以患者为中心**：符合患者关切事项，反映其优先需求
- **具临床意义**：达成目标可改善健康或生活质量
- **与诊断一致**：目标针对当前治疗病症
- **时机恰当**：适应当前治疗阶段
- **整体协调**：与其他治疗目标兼容

**相关性评估**：
- 询问患者："您最重视什么？""希望实现哪些能力？"
- 确保目标解决患者关注的功能限制
- 将临床指标与患者重视的结果关联（如"糖化血红蛋白<7%可降低视力丧失风险"）
- 避免医护主导但患者无共鸣的目标

**示例**：

| 相关性弱 | 相关性强 |
|---------------|---------------|
| "减少用药种类"（当前药物有效控制症状时） | "简化用药方案以提高依从性"（若因复杂漏服） |
| "完美血糖控制"（患者优先关注精力） | "通过改善血糖控制提升精力水平" |
| "行走5英里"（患者仅需独立购物） | "无需协助完成超市购物" |

### 5. 时限性

目标需设定明确截止期限或时间框架。

**时间考量**：
- **短期目标**：数天至3个月
- **中期目标**：3-6个月
- **长期目标**：6-12个月或更久（慢性病）
- **复评间隔**：定期检查进展

**时间要素**：
- 目标日期或时间段
- 进展检查节点
- 行动频率（如"每周锻炼5次，每次30分钟"）

**示例**：

| 无时限 | 有时限 |
|----------------|------------|
| "最终减重" | "6个月内减重15磅（约每周1-2磅）" |
| "参加物理治疗" | "8周内完成12次物理治疗（每周1-2次）" |
| "准备就绪后复工" | "术后12周内恢复轻量工作" |
| "改善抑郁症状" | "开始SSRI和认知行为治疗8周内PHQ-9评分从18降至<10" |

## 创建SMART目标：分步流程

### 步骤1：评估基线
- 确定现状：症状、实验室值、功能水平
- 采用标准化评估工具
- 记录量化基线数据

### 步骤2：明确期望结果
- 需改善的领域？
- 患者参与："您希望哪些方面改变？"
- 兼顾临床需求与患者优先事项

### 步骤3：具体化
- 精确定义结果
- 消除模糊表述
- 包含所有关键细节

### 步骤4：添加衡量标准
- 如何追踪进展？
- 采用何种指标或可观察行为？
- 基线值→目标值

### 步骤5：可行性核验
- 基于患者状况、资源及治疗效果是否可实现？
- 必要时调整预期
- 分阶段设定目标

### 步骤6：确保相关性
- 患者是否重视该目标？
- 是否具临床意义？
- 是否与整体治疗计划一致？

### 步骤7：设定时间表
- 目标达成时间？
- 进展评估节点？
- 必要时分解为短期/长期目标

### 步骤8：记录与沟通
- 以清晰SMART格式书写目标
- 与患者及团队共享
- 确保患者理解

## 目标层级体系

### ICF框架（国际功能、残疾和健康分类）

适用于康复与功能目标：

1. **损伤层面目标**：身体结构/功能
   - 例："肩关节屈曲活动度从90°增至140°"
   
2. **活动层面目标**：任务执行能力
   - 例："独立完成上身穿衣"
   
3. **参与层面目标**：社会角色融入
   - 例："重返教师岗位"

### 医疗结果层级

1. **生物/临床目标**：实验室值、生命体征、疾病标志物
   - 例："糖化血红蛋白<7%，血压<130/80，低密度脂蛋白<70mg/dL"
   
2. **症状目标**：患者报告症状
   - 例："日常活动时疼痛≤4/10且无呼吸困难"
   
3. **功能目标**：患者行为能力
   - 例："行走1英里，爬2层楼梯"
   
4. **生活质量目标**：整体健康状态
   - 例："恢复爱好活动，改善睡眠质量"

## 以患者为中心的结果指标（PCOMs）

### 定义
超越传统临床指标，患者最重视的结果。

### 常见PCOMs

**患者报告结果指标（PROMs）**：
- SF-36/SF-12（普适性健康相关生活质量）
- PROMIS（患者报告结果测量信息系统）
- 疾病特异性量表（如心衰用堪萨斯城心肌病问卷）

**功能结果**：
- 基础生活活动（ADLs）：沐浴、穿衣、如厕、转移、进食、控制排泄
- 工具性生活活动（IADLs）：购物、烹饪、家务、理财、交通
- 职业/教育功能
- 社交功能与关系
- 休闲娱乐参与度

**患者优先事项**：
- 个体患者最关切事项
- 可能不同于临床重点
- 示例："陪孙辈玩耍"，"参加女儿婚礼"，"避免入住护理院"

### 整合PCOMs至目标

**方法**：
1. 评估初期询问患者优先事项
2. 将临床目标与患者重视结果关联
3. 至少包含部分直接回应患者优先事项的目标
4. 记录目标时尽量采用患者原话

**整合示例**：
- **临床目标**："3个月内糖化血红蛋白从8.5%降至<7%"
- **关联患者目标**："提升精力水平以无疲劳陪伴孙辈"
- 同步记录并追踪两项目标进展

## 目标设定中的共同决策

### 何谓共同决策（SDM）？

医护与患者协作：
- 探讨治疗方案
- 权衡风险收益
- 考量患者价值观与偏好
- 共同制定决策

### 治疗目标设定中的SDM

**步骤**：

1. **选择意识**：确认多目标/多途径可能性
   - "我们可侧重强化降糖或最小化低血糖风险，您更重视哪方面？"

2. **方案呈现**：说明目标选项及利弊
   - "方案A：强化血压控制(<120/80)降低卒中风险但需更多药物；方案B：常规控制(<140/90)更易实施但卒中风险略高"

3. **价值澄清**：理解患者优先考量
   - "您对服用多种药物有何感受？""避免注射对您多重要？"

4. **偏好整合**：将偏好融入目标
   - 若患者优先避免用药→"尽可能通过生活方式干预和单药控制血压"

5. **决策**：共同确定目标
   - "您希望尝试3个月强化生活方式干预后再考虑加药，我们据此制定计划"

6. **记录**：载明共同决策过程
   - "目标经共同决策确立。患者表示偏好..."

### 决策辅助工具

促进SDM的工具：
- 方案对比表格
- 风险收益数据
- 患者故事/见证
- 视觉辅助（图片、图表）
- "您最重视什么"工作表

## 特殊人群考量

### 老年患者
- 功能独立性常优先于疾病指标
- 平衡积极治疗与治疗负担
- 考量预期寿命与获益时间
- 防跌倒、减用药可能成为关键目标
- 生活质量重于生存时长

### 儿科患者
- 符合发育阶段的目标
- 家庭为中心（纳入家长/照护者）
- 生长与发育里程碑
- 学校/社交功能
- 过渡规划（儿科转成人照护）

### 慢性疾病
- 长期可持续目标
- 平衡进取心与现实预期
- 并发症预防
- 生活质量维持
- 改善与适应并重

### 安宁疗护/临终关怀
- 以舒适与症状管理为主
- 功能目标聚焦重要活动
- 心理社会与精神需求
- 照护者支持
- 尊严与自主权

### 复杂共病
- 优先最具影响力的目标
- 跨病症协调目标（治疗重叠更佳）
- 避免冲突性治疗
- 最小化治疗负担
- 多病症下的合理预期

## 常见目标设定误区

### 误区1：医护中心化目标
**问题**：目标反映医护而非患者关切  
**对策**：接诊初期询问患者期望，采用其表述

### 误区2：目标过多
**问题**：10+目标使患者不堪重负  
**对策**：优先3-5个核心目标，逐步推进

### 误区3：全或无思维
**问题**：目标设定为"治愈"或"完美"  
**对策**：分阶段目标，重视有意义改善

### 误区4：忽视障碍
**问题**：未评估可行性即设目标（资源、支持、可及性）  
**对策**：评估阶段识别障碍，调整目标或解决问题

### 误区5：静态目标
**问题**：设定后不再审视  
**对策**：定期复评，随进展或环境变化调整

### 误区6：纯临床指标
**问题**：目标全为实验室值，无功能或生活质量目标  
**对策**：平衡临床指标与功能、症状及生活质量结果

### 误区7：缺乏患者认同
**问题**：患者质疑目标可行性或重要性  
**对策**：通过共同决策与动机访谈化解矛盾

## 病症SMART目标示例

### 糖尿病
**短期**："3个月内通过启用二甲双胍1000mg每日两次及控制每餐碳水化合物45-60g，使糖化血红蛋白从8.5%降至<7.5%"

**长期**："维持糖化血红蛋白<7%超6个月，预防微血管并发症，提升精力水平实现每日步行30分钟"

### 心力衰竭
**短期**："2周内通过优化呋塞米剂量及限钠<2000mg/天实现正常容量（无水肿，体重波动<2磅）"

**长期**："3个月内维持NYHA心功能II级，预防心衰再住院，实现无呼吸困难行走1/4英里"

### 抑郁症
**短期**："8周内通过启用艾司西酞普兰10mg/日及每周认知行为治疗，使PHQ-9评分从18降至<10"

**长期**："4个月内实现抑郁缓解（PHQ-9<5），恢复全职工作，每周与朋友社交2-3次"

### 脑卒中后康复
**短期**："4周内通过每周5次物理/作业治疗，使右上肢肌力从2/5提升至3+/5，功能独立性评分从85升至100"

**长期**："3个月内实现所有基础生活活动自理，借助手杖平地行走500英尺，并返回家中（非护理机构）"

### 慢性腰痛
**短期**："6周内通过多模式镇痛（SNRI、NSAID、物理治疗）将疼痛强度从7/10降至4/10，步行耐受时间从10分钟增至30分钟"

**长期**："3个月内恢复轻量工作，参与适应性休闲活动（钓鱼、园艺），通过简明疼痛量表将疼痛对生活的干扰降低50%"

### 高血压
**短期**："4周内通过启用赖诺普利10mg/日及限钠<2300mg/天，将血压从152/94降至<140/90 mmHg"

**长期**："实现并维持血压<130/80 mmHg，将动脉粥样硬化性心血管疾病10年风险从15%降至<10%，预防心血管事件"
