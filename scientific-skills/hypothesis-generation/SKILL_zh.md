# 科学假设生成

## 概述

假设生成是构建可检验解释的系统化过程。从观察中形成基于证据的假设，设计实验，探索竞争性解释，并制定预测。本技能适用于跨学科领域的科学探究。

## 使用场景

在以下情况使用本技能：
- 基于观察或初步数据构建假设
- 设计验证科学问题的实验
- 探索现象的竞争性解释
- 为研究制定可检验的预测
- 基于文献的假设生成
- 跨科学领域规划机制研究

## 工作流程

遵循此系统化流程生成稳健的科学假设：

### 1. 理解现象

首先明确需要解释的观察现象或问题：
- 识别需解释的核心观察或模式
- 界定现象的范围与边界
- 记录约束条件或特定背景
- 区分已知信息与不确定因素
- 确定相关科学领域

### 2. 全面文献检索

检索现有科学文献，使假设基于当前证据。生物医学主题使用PubMed，其他领域使用通用网络搜索：

**生物医学领域：**
- 通过WebFetch访问PubMed文献
- 检索近期综述、荟萃分析及原始研究
- 寻找相似现象、相关机制或类比系统

**全科学领域：**
- 使用WebSearch查找近期论文、预印本及综述
- 搜索成熟理论、机制或框架
- 识别当前认知空白

**检索策略：**
- 从广泛搜索开始了解全局
- 聚焦特定机制、路径或理论
- 寻找矛盾发现或未解争议
- 详细技术参考`references/literature_search_strategies.md`

### 3. 整合现有证据

分析并综合文献检索结果：
- 总结当前对现象的认知
- 识别适用的成熟机制或理论
- 标注矛盾证据或替代观点
- 发现空白、局限或未解问题
- 寻找相关领域的类比系统

### 4. 生成竞争性假设

构建3-5个可解释现象的独立假设。每个假设应：
- 提供机制性解释（非单纯描述）
- 与其他假设可区分
- 基于文献综合证据
- 考虑不同解释层级（分子/细胞/系统/群体等）

**假设生成策略：**
- 应用类比系统的已知机制
- 考虑多重因果路径
- 探索不同尺度解释
- 质疑现有解释的预设条件
- 创新性组合机制

### 5. 评估假设质量

参照`references/hypothesis_quality_criteria.md`标准评估：
- **可检验性**：能否实证检验？
- **可证伪性**：哪些观察可推翻它？
- **简洁性**：是否最简合理解释？
- **解释力**：覆盖现象的范围？
- **适用范围**：解释哪些观察？
- **一致性**：是否符合既有原理？
- **新颖性**：是否超越现有认知？

明确标注各假设的优缺点。

### 6. 设计实验验证

为每个可行假设设计具体验证方案。参考`references/experimental_design_patterns.md`：

**实验设计要素：**
- 测量指标与观察对象
- 所需对比组与对照
- 采用方法技术
- 样本量与统计方法
- 潜在混杂因素及解决方案

**多方法考量：**
- 实验室实验（体外/体内/计算）
- 观察性研究（横断面/纵向/病例对照）
- 临床试验（如适用）
- 自然实验或准实验设计

### 7. 制定可检验预测

为每个假设生成具体量化预测：
- 陈述假设成立时的预期观察
- 尽可能明确效应方向与强度
- 界定预测成立的条件
- 区分竞争性假设的预测
- 标注可证伪假设的关键预测

### 8. 结构化输出

使用`assets/hypothesis_report_template.tex`模板生成专业LaTeX文档。采用彩色框体视觉分区，主文本精炼（≤4页）并附详细附录。

**文档结构：**

**主文本（≤4页）：**
1. **执行摘要** - 摘要框内概述（0.5-1页）
2. **竞争性假设** - 每个假设独立彩色框：简要机制解释+关键证据（3-5个假设占2-2.5页）
   - **关键**：每个假设框前用`\newpage`防内容溢出
   - 每框≤0.6页
3. **可检验预测** - 琥珀色框呈现关键预测（0.5-1页）
4. **关键对比** - 钢灰色优先级对比框（0.5-1页）

主文本仅保留核心信息，详情见附录。

**分页策略：**
- 假设框前必用`\newpage`确保新页开始
- 防止内容跨页溢出
- LaTeX框体（tcolorbox）不支持自动分页

**附录（完整细节）：**
- **附录A**：带完整引用的文献综述
- **附录B**：含全协议的实验设计
- **附录C**：质量评估表与详细评价
- **附录D**：补充证据与类比系统

**彩色框使用规范：**

采用`hypothesis_generation.sty`自定义框环境：
- `hypothesisbox1`至`hypothesisbox5`：竞争性假设（蓝/绿/紫/青/橙）
- `predictionbox`：可检验预测（琥珀色）
- `comparisonbox`：关键对比（钢灰）
- `evidencebox`：核心证据（浅蓝）
- `summarybox`：执行摘要（蓝色）

**假设框内容（保持精炼）：**
- **机制解释**：1-2段（≤10句）说明原理
- **关键证据**：2-3个带引用要点
- **核心预设**：1-2项关键假设

详细解释、补充证据及完整讨论归入附录。

**防溢出关键措施：**
- 每个假设框前插入`\newpage`
- 单框内容≤0.6页（约15-20行）
- 超限内容移至附录A
- 严禁框体跨页导致PDF不可读

**引用规范：**
- **主文本**：仅关键证据（10-15篇引用）
- **附录A**：全面文献（40-70+篇引用）
- **总量**：参考文献≥50篇

主文本引用需精选，完整文献讨论归附录。使用`\citep{author2023}`格式。

**LaTeX编译：**

模板需XeLaTeX或LuaLaTeX渲染：
```bash
xelatex hypothesis_report.tex
bibtex hypothesis_report
xelatex hypothesis_report.tex
xelatex hypothesis_report.tex
```

**依赖包：** `hypothesis_generation.sty`需配合tcolorbox, xcolor, fontspec, fancyhdr, titlesec, enumitem, booktabs, natbib使用。

**防溢出指南：**
1. **监控框体长度**：单框内容适配单页（超0.7页将溢出）
2. **策略性分页**：大内容框前加`\newpage`
   ```latex
   \newpage
   \begin{hypothesisbox1}[假设1：标题]
   % 长内容
   \end{hypothesisbox1}
   ```
3. **主文本精炼**：
   - 假设框≤0.6页
   - 机制解释≤2段
   - 关键证据≤3要点
   - 超限内容移附录
4. **长内容拆分**：主文本保留概述，附录存放细节
5. **预判分页**：剩余空间<0.6页时启用`\newpage`
6. **附录管理**：主要章节间用`\newpage`防溢出

**格式速查：** 参见`assets/FORMATTING_GUIDE.md`获取框体示例、配色方案及常见模式。

## 质量标准

确保所有假设符合：
- **证据驱动**：基于文献并标注引用
- **可检验性**：含具体可测预测
- **机制性**：解释原理而非法现象
- **全面性**：考虑替代解释
- **严谨性**：含验证实验设计
