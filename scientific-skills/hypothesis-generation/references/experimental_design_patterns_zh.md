# 实验设计模式

## 科学假说检验的常用方法

本参考提供了跨科学领域的实验设计模式与框架。运用这些模式为生成的假说设计严谨的检验方案。

**报告结构说明：** 生成假说报告时，在正文假说框内仅需提及关键实验方法（如"体内基因敲除研究"或"前瞻性队列设计"）。完整实验方案（含详细方法、对照组、样本量、统计方法、可行性评估及资源需求）应置于**附录B：详细实验设计**中。

## 设计选择框架

根据以下要素选择实验方法：
- **假说性质：** 机制性、因果性、相关性、描述性
- **研究对象：** 体外、体内、计算模型、观察性研究
- **可行性：** 时间、成本、伦理、技术能力
- **证据需求：** 概念验证、因果论证、定量关系

## 实验室实验设计

### 体外实验

**适用场景：** 在受控系统中检验分子、细胞或生化机制。

**常见模式：**

#### 1. 剂量效应研究
- **目的：** 建立输入与效应的定量关系
- **设计：** 测试干预措施的多个浓度/剂量
- **关键要素：**
  - 阴性对照（无处理）
  - 阳性对照（已知有效处理）
  - 多剂量梯度（通常5-8个浓度点）
  - 技术重复（≥3次/条件）
  - 适当统计分析（曲线拟合、IC50/EC50测定）

**应用示例：**
"为验证化合物X是否抑制酶Y，在0、1、10、100、1000 nM浓度下测量酶活性，每个剂量n=3次重复。"

#### 2. 功能增益/缺失研究
- **目的：** 确立特定组分的因果作用
- **设计：** 添加（过表达）或移除（敲除/敲低）目标组分
- **关键要素：**
  - 野生型对照
  - 功能增益条件（过表达、组成型激活）
  - 功能缺失条件（敲除、敲低、抑制）
  - 回补实验（恢复功能缺失表型）
  - 测量下游效应

**应用示例：**
"验证蛋白X是否导致表型Y：(1)敲除X观察表型消失；(2)过表达X观察表型增强；(3)在敲除背景下回补X表达。"

#### 3. 时间进程研究
- **目的：** 理解时间动态与事件序列
- **设计：** 在多个时间点测量结果
- **关键要素：**
  - 时间0基线
  - 早期时间点（捕捉快速变化）
  - 中期时间点
  - 晚期时间点（稳态）
  - 各时间点充分重复

**应用示例：**
"在刺激后0、5、15、30、60、120分钟测量蛋白磷酸化水平，确定峰值激活时间。"

### 体内实验

**适用场景：** 在完整生物体中检验假说，评估系统生理或行为效应。

**常见模式：**

#### 4. 组间设计
- **目的：** 比较不同处理组间的差异
- **设计：** 随机分配受试对象至处理组
- **关键要素：**
  - 随机分组
  - 适当样本量（功效分析）
  - 对照组（载体、假手术或标准处理）
  - 盲法（单盲或双盲）
  - 组间标准化条件

**应用示例：**
"将20只小鼠随机分配至载体对照组或药物治疗组，每周测量肿瘤尺寸持续8周，实验人员对分组设盲。"

#### 5. 组内设计（重复测量）
- **目的：** 以自身为对照，降低个体间变异
- **设计：** 相同受试对象在多个条件/时间点测量
- **关键要素：**
  - 基线测量
  - 顺序平衡（存在顺序效应时）
  - 洗脱期（序贯处理时）
  - 适当重复测量统计

**应用示例：**
"在基线期、训练干预后及3个月随访期测量同一批参与者的认知表现。"

#### 6. 析因设计
- **目的：** 同时检验多因素及其交互作用
- **设计：** 交叉多个自变量的所有水平
- **关键要素：**
  - 明确主效应与交互作用
  - 交互检验的充分功效
  - 全因子或部分因子设计

**应用示例：**
"采用2×2析因设计（野生型vs突变型）×（载体vs药物），检验药物效应是否依赖基因型。"

### 计算/建模实验

**适用场景：** 检验复杂系统假说、进行预测或物理实验不可行时。

#### 7. 计算机模拟
- **目的：** 建模复杂系统，检验理论预测
- **设计：** 执行计算模型并调整参数
- **关键要素：**
  - 明确定义模型及假设
  - 参数敏感性分析
  - 基于已知数据验证
  - 生成可实验检验的预测

**应用示例：**
"构建基于主体的疾病传播模型，改变传播率与干预时机，将预测结果与实证流行病数据比对。"

#### 8. 生物信息学/荟萃分析
- **目的：** 利用现有数据集检验假说
- **设计：** 分析大规模数据或整合多项研究
- **关键要素：**
  - 适当统计校正（多重检验）
  - 独立数据集验证
  - 控制混杂因素与批次效应
  - 明确纳入/排除标准

**应用示例：**
"通过Cox回归分析15个癌症数据集（总样本>5000例患者），检验基因X表达是否与生存期相关（校正临床协变量）。"

## 观察性研究设计

### 物理干预不可行或不道德时适用

#### 9. 横断面研究
- **目的：** 在单时间点检测关联性
- **设计：** 在特定时间点测量目标人群变量
- **优势：** 快速、经济、可确定流行率
- **局限：** 无法确定时序性或因果关系
- **关键要素：**
  - 代表性抽样
  - 标准化测量
  - 控制混杂变量
  - 适当统计分析

**应用示例：**
"调查1000名成人，检验饮食模式与生物标志物X的关联（校正年龄、性别、BMI及体力活动）。"

#### 10. 队列研究（前瞻性/纵向）
- **目的：** 建立时序关系及潜在因果关联
- **设计：** 长期追踪群体，测量暴露因素与结局
- **优势：** 可确定时序性、计算发病率
- **局限：** 耗时、昂贵、存在失访
- **关键要素：**
  - 基线暴露评估
  - 定期随访
  - 最小化失访率
  - 校正时变混杂因素

**应用示例：**
"追踪5000名初始健康个体10年，检验基线维生素D水平是否预测心血管疾病发病率。"

#### 11. 病例对照研究
- **目的：** 通过病例与对照比较高效研究罕见结局
- **设计：** 确定结局病例，选择匹配对照，比较暴露史
- **优势：** 对罕见病高效、相对快速
- **局限：** 回忆偏倚、选择偏倚、无法计算发病率
- **关键要素：**
  - 明确病例定义
  - 适当对照选择（匹配或统计校正）
  - 回顾性暴露评估
  - 控制混杂因素

**应用示例：**
"比较200例罕见病X患者与400例匹配非患者，检验早年暴露Y是否存在组间差异。"

## 临床试验设计

#### 12. 随机对照试验（RCT）
- **目的：** 人体干预研究的金标准
- **设计：** 随机分配受试者至处理组或对照组
- **关键要素：**
  - 随机化（简单、区组或分层）
  - 分配隐藏
  - 盲法（受试者、执行者、评估者）
  - 意向治疗分析
  - 预注册方案及分析计划

**应用示例：**
"双盲RCT：随机分配300名患者接受药物X或安慰剂治疗12周，以症状改善为主要结局指标。"

#### 13. 交叉试验
- **目的：** 每名受试者序贯接受所有处理
- **设计：** 受试者在处理间交叉并设置洗脱期
- **优势：** 降低个体间变异、减少样本量
- **局限：** 顺序效应、仅适用于可逆病症、周期长
- **关键要素：**
  - 充分洗脱期
  - 随机处理顺序
  - 残留效应评估

**应用示例：**
"交叉试验：受试者接受处理A（4周）→2周洗脱→处理B（4周）（顺序随机化）。"

## 高级设计考量

### 样本量与统计功效

**核心问题：**
- 需检测的效应量是否有意义？
- 将采用何种统计检验？
- 合适的α（显著性水平）与β（功效）是多少？
- 测量指标的预期变异度？

**通用准则：**
- 实验前进行正式功效分析
- 预实验每组最小样本量≥10
- 确证性研究目标功效≥80%
- 纵向研究需考虑潜在失访

### 对照设置

**对照类型：**
- **阴性对照：** 无干预（基线）
- **阳性对照：** 已知有效干预（验证系统）
- **载体对照：** 无活性成分的递送方式
- **假处理对照：** 模拟干预但无活性组分（手术等）
- **历史对照：** 既往数据（最弱效，尽量避免）

### 盲法实施

**层级：**
- **开放标签：** 无盲法（客观指标可接受）
- **单盲：** 受试者设盲（降低安慰剂效应）
- **双盲：** 受试者与执行者设盲（减少评估偏倚）
- **三盲：** 受试者、执行者、分析者设盲（最严格）

### 重复设置

**技术重复：** 同一样本多次测量
- 降低测量误差
- 通常2-3次足够

**生物学重复：** 独立样本/受试对象
- 反映生物变异
- 对泛化至关重要
- 最小n≥3，推荐n≥5-10/组

**实验重复：** 完整实验重演
- 跨时间/设备/操作者验证结果
- 确认发现的金标准

### 混杂控制

**策略：**
- **随机化：** 使混杂因素均匀分布
- **匹配：** 跨条件配对相似受试者
- **区组化：** 按混杂因素分组后组内随机
- **统计校正：** 测量混杂因素并在分析中调整
- **标准化：** 保持组间条件恒定

## 选择合适设计

**决策树：**

1. **变量是否可操控？**
   - 是 → 实验设计（RCT、实验室实验）
   - 否 → 观察性设计（队列、病例对照、横断面）

2. **研究对象系统？**
   - 细胞/分子 → 体外实验
   - 完整生物体 → 体内实验
   - 人类 → 临床试验或观察性研究
   - 复杂系统 → 计算建模

3. **主要目标？**
   - 机制 → 功能增益/缺失、剂量效应
   - 因果 → RCT、良好对照的队列研究
   - 关联 → 横断面、病例对照
   - 预测 → 建模、机器学习
   - 时态动态 → 时间进程、纵向研究

4. **存在何种限制？**
   - 时间受限 → 横断面、体外实验
   - 预算受限 → 计算模型、观察性研究
   - 伦理考量 → 观察性、体外实验
   - 罕见结局 → 病例对照、荟萃分析

## 整合多元方法

严谨的假说检验常需组合多种设计：

**示例：检验微生物组是否影响认知功能**
1. **观察性：** 队列研究显示微生物组构成与认知的关联
2. **动物模型：** 无菌小鼠接受菌群移植后出现认知变化
3. **机制：** 体外研究显示微生物代谢物影响神经元功能
4. **临床试验：** 益生菌干预改善认知评分的RCT
5. **计算模型：** 预测影响认知的微生物组特征谱

**三角验证法：**
- 每种设计解决不同层面/局限
- 多方法证据汇聚增强因果论证
- 从观察性/体外实验起步，逐步推进至因果检验

## 常见缺陷

- 样本量不足（低功效）
- 缺乏适当对照
- 未控制混杂变量
- 统计方法不当
- p值操纵或多重检验未校正
- 主观评估未实施盲法
- 未重复验证结果
- 未预注册分析方案（临床试验）

## 假说检验实践指南

设计实验检验假说时：

1. **设计与假说匹配：** 因果主张需实验操控；关联性可用观察性设计
2. **由简入繁：** 从简单预实验起步，逐步增加复杂度
3. **精心规划对照：** 验证系统并分离特定效应
4. **考量可行性：** 平衡理想设计与现实约束
5. **规划系列实验：** 单一实验罕能确证假说
6. **预先指定分析：** 数据收集前确定统计方法
7. **内置验证机制：** 独立重复、正交方法、证据汇聚
