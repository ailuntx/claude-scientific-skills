# 分子生成

## 概述

分子生成涉及创建具有特定性质的新型分子结构。TorchDrug支持无条件生成（探索化学空间）和有条件生成（针对特定性质优化）。

## 任务类型

### AutoregressiveGeneration

通过逐步添加原子和键来生成分子。这种方法可在生成过程中实现精细控制和性质优化。

**核心特性：**
- 原子-键顺序构建
- 支持生成过程中的性质优化
- 可整合化学有效性约束
- 支持多目标优化

**生成策略：**
1. **束搜索**：每步保留top-k候选
2. **采样**：概率选择以增加多样性
3. **贪心法**：始终选择最高概率动作

**性质优化：**
- 基于目标性质的奖励塑造
- 实时约束满足
- 多目标平衡（如药效+类药性）

### GCPNGeneration（图卷积策略网络）

使用强化学习生成针对特定性质优化的分子。

**组件：**
1. **策略网络**：决定执行动作（添加原子/键）
2. **奖励函数**：评估生成分子质量
3. **训练**：基于策略梯度的强化学习

**优势：**
- 直接优化不可微分目标
- 可整合复杂领域知识
- 平衡探索与利用

**应用场景：**
- 针对特定靶点的药物设计
- 带性质约束的材料发现
- 多目标分子优化

## 生成模型

### GraphAutoregressiveFlow

通过精确似然计算实现分子生成的标准化流模型。

**架构：**
- 耦合层将简单分布转换为复杂分子分布
- 可逆变换支持密度估计
- 支持条件生成

**核心特性：**
- 精确似然计算（对比VAE的近似似然）
- 稳定训练（对比GAN的对抗训练）
- 通过可逆变换高效采样
- 可生成指定性质的分子

**训练：**
- 在分子数据集上最大似然训练
- 可选性质预测头用于条件生成
- 通常在ZINC或QM9数据集训练

**用例：**
- 生成多样化类药分子
- 已知分子间插值
- 分子空间密度估计

## 生成工作流

### 无条件生成

无特定性质目标生成多样化分子。

**工作流：**
1. 在分子数据集训练生成模型（如ZINC250k）
2. 从学习分布中采样
3. 后处理确保有效性和唯一性
4. 评估多样性指标

**评估指标：**
- **有效性**：化学有效分子百分比
- **唯一性**：有效分子中唯一分子占比
- **新颖性**：训练集中未出现分子占比
- **多样性**：基于指纹相似度的内部多样性

### 条件生成

针对特定性质优化生成分子。

**性质目标：**
- **类药性**：LogP、QED、Lipinski五规则
- **可合成性**：SA评分、逆合成可行性
- **生物活性**：预测IC50、结合亲和力
- **ADMET**：吸收、分布、代谢、排泄、毒性
- **多目标**：同时平衡多个性质

**工作流：**
1. 定义组合性质目标的奖励函数
2. 在性质数据上训练GCPN或条件流模型
3. 生成满足目标性质范围的分子
4. 验证生成分子（从计算机模拟到湿实验）

### 基于骨架的生成

围绕固定骨架或核心结构生成分子。

**应用场景：**
- 保持核心药效团的先导化合物优化
- SAR研究的R基团枚举
- 片段连接与生长

**实现方法：**
- 训练时掩蔽骨架
- 基于骨架的条件生成
- 生成后骨架嫁接

### 基于片段的生成

从已验证片段构建分子。

**优势：**
- 确保类药亚结构
- 缩小搜索空间
- 整合药物化学知识

**方法：**
- 片段库作为构建单元
- 基于词汇表的生成
- 带学习连接器的片段连接

## 性质优化策略

### 单目标优化

最大化或最小化单一性质（如结合亲和力）。

**方法：**
- 定义标量奖励函数
- 使用带强化学习的GCPN
- 生成并排序候选分子

**挑战：**
- 可能牺牲其他重要性质
- 对抗样本风险（有效但非类药）
- 需添加类药性约束

### 多目标优化

平衡多个竞争目标（如药效、选择性、可合成性）。

**加权方法：**
- **线性组合**：w1×性质1 + w2×性质2 + ...
- **帕累托优化**：寻找非支配解
- **约束满足**：设置次要目标阈值

**典型目标：**
- 高结合亲和力（目标靶点）
- 低结合亲和力（脱靶效应）
- 高可合成性（SA评分）
- 类药性质（QED）
- 低分子量

**工作流：**
```python
from torchdrug import tasks

# 定义多目标奖励函数
def reward_function(mol):
    affinity_score = predict_binding(mol)
    druglikeness = calculate_qed(mol)
    synthesizability = sa_score(mol)

    # 加权组合
    reward = 0.5 * affinity_score + 0.3 * druglikeness + 0.2 * (1 - synthesizability)
    return reward

# 带自定义奖励的GCPN任务
task = tasks.GCPNGeneration(
    model,
    reward_function=reward_function,
    criterion="ppo"  # 近端策略优化
)
```

### 基于约束的生成

生成满足硬性约束的分子。

**常见约束：**
- 分子量范围
- LogP范围
- 可旋转键数量
- 环数量限制
- 子结构包含/排除
- 合成可及性阈值

**实现方式：**
- 生成时有效性检查
- 无效分子提前终止
- 奖励函数添加惩罚项

## 训练考量

### 数据集选择

**ZINC（类药化合物）：**
- ZINC250k：25万化合物
- ZINC2M：200万化合物
- 经类药性预筛选
- 适用于药物发现场景

**QM9（小有机分子）：**
- 133,885个分子
- 包含量子化学性质
- 适用于性质预测模型

**ChEMBL（生物活性分子）：**
- 数百万生物活性化合物
- 含活性数据
- 支持靶点特异性生成

**自定义数据集：**
- 聚焦特定化学空间
- 整合专家知识
- 领域特定约束

### 数据增强

**SMILES增强：**
- 为同分子生成多SMILES表示
- 帮助模型学习规范表示
- 提升鲁棒性

**图增强：**
- 随机节点/边掩蔽
- 子图采样
- 基元替换

### 模型架构选择

**小分子（<30原子）：**
- 简单架构即足够
- 更快训练和生成
- GCN或GIN主干网络

**类药分子：**
- 深层架构（4-6层）
- 注意力机制有效
- 考虑分子指纹

**大环/聚合物：**
- 处理更大分子图
- 闭环机制关键
- 长程依赖关系

## 验证与过滤

### 计算机模拟验证

**化学有效性：**
- 化合价规则
- 芳香性规则
- 电荷中性
- 稳定亚结构

**类药性过滤器：**
- Lipinski五规则
- Veber规则
- PAINS过滤器（泛测定干扰化合物）
- BRENK过滤器（毒性/反应性子结构）

**可合成性：**
- SA评分（合成可及性）
- 逆合成预测
- 前体商业可得性

**性质预测：**
- ADMET性质
- 毒性预测
- 脱靶结合
- 代谢稳定性

### 排序与选择

**标准：**
1. 预测靶点亲和力
2. 类药性评分
3. 可合成性
4. 新颖性（与已知活性分子差异度）
5. 多样性（生成集内）
6. 预测ADMET性质

**选择策略：**
- 帕累托前沿选择
- 加权评分
- 聚类与代表性选择
- 湿实验验证的主动学习

## 最佳实践

1. **从简开始**：先无条件生成，再逐步添加约束
2. **验证化学性质**：始终检查分子有效性和类药性
3. **多样化训练数据**：使用大规模多样化数据集提升泛化能力
4. **多目标考量**：初始即考虑多性质平衡
5. **迭代优化**：生成→验证→反馈重训
6. **领域专家评审**：合成前咨询药物化学家
7. **基准测试**：对比已知活性分子和随机样本
8. **可合成性优先**：优先选择实际可合成分子
9. **可解释性**：理解模型生成特定结构的原因
10. **湿实验验证**：最终通过实验验证潜力分子

## 典型应用

### 药物发现
- 新靶点先导化合物生成
- 活性骨架先导化合物优化
- 生物电子等排体替换
- 片段扩展

### 材料科学
- 目标性质聚合物设计
- 催化剂发现
- 储能材料
- 光伏材料

### 化学生物学
- 探针分子设计
- 降解剂（PROTAC）设计
- 分子胶发现

## 工具集成

**分子对接：**
- 生成分子→靶点对接→用对接分数重训

**逆合成：**
- 按合成可及性过滤生成分子
- 为候选分子规划合成路线

**性质预测：**
- 用训练的性质预测模型作为奖励函数
- 生成与预测的多任务学习

**主动学习：**
- 生成候选→预测性质→合成最优→反馈重训
