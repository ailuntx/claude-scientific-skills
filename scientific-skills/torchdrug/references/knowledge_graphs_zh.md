# 知识图谱推理

## 概述

知识图谱以图结构表示结构化信息，包含实体和关系。TorchDrug 提供对基于嵌入模型和神经推理方法的知识图谱补全（链接预测）的全面支持。

## 可用数据集

### 通用知识图谱

**FB15k (Freebase 子集):**
- 14,951 个实体
- 1,345 种关系类型
- 592,213 个三元组
- 来自 Freebase 的通用世界知识

**FB15k-237:**
- 14,541 个实体
- 237 种关系类型
- 310,116 个三元组
- 移除反向关系的过滤版本
- 更具挑战性的基准

**WN18 (WordNet):**
- 40,943 个实体（词义）
- 18 种关系类型（词汇关系）
- 151,442 个三元组
- 语言学知识图谱

**WN18RR:**
- 40,943 个实体
- 11 种关系类型
- 93,003 个三元组
- 移除简单反向模式的过滤版 WordNet

### 生物医学知识图谱

**Hetionet:**
- 45,158 个实体（基因、化合物、疾病、通路等）
- 24 种关系类型（治疗、导致、结合等）
- 2,250,197 条边
- 整合 29 个公共生物医学数据库
- 专为药物重定位和疾病理解设计

## 任务：KnowledgeGraphCompletion

知识图谱的核心任务是链接预测——给定头实体和关系，预测尾实体（或反之）。

### 任务模式

**头实体预测:**
- 给定 (?, 关系, 尾实体)，预测头实体
- "什么会导致疾病 X？"

**尾实体预测:**
- 给定 (头实体, 关系, ?)，预测尾实体
- "基因 X 会导致哪些疾病？"

**双向预测:**
- 同时预测头尾实体
- 标准评估协议

### 评估指标

**排序指标:**
- **平均排名 (MR)**：正确实体的平均排名
- **平均倒数排名 (MRR)**：1/排名的平均值
- **Hits@K**：前 K 个预测中包含正确实体的比例
  - 通常报告 K=1, 3, 10 的结果

**过滤 vs 原始:**
- **过滤**：从排名中移除其他已知正确三元组
- **原始**：在所有可能实体中排序
- 过滤模式是标准评估方法

## 嵌入模型

### 平移模型

**TransE (平移嵌入):**
- 将关系表示为嵌入空间的平移
- h + r ≈ t (头实体 + 关系 ≈ 尾实体)
- 简单有效的基线模型
- 擅长处理 1 对 1 关系
- 难以处理多对多关系

**RotatE (旋转嵌入):**
- 在复数空间中将关系表示为旋转
- 更好处理对称和反向关系
- 多个基准上的最先进模型
- 可建模组合模式

### 语义匹配模型

**DistMult:**
- 双线性评分函数
- 天然处理对称关系
- 无法建模非对称关系
- 快速且内存高效

**ComplEx:**
- 复数值嵌入
- 建模非对称和反向关系
- 在多数图谱上优于 DistMult
- 平衡表达能力和效率

**SimplE:**
- 通过反向关系扩展 DistMult
- 完全表达能力（可表示任意关系模式）
- 每个实体有两个嵌入（标准与反向）

### 神经逻辑模型

**NeuralLP (神经逻辑编程):**
- 通过可微分操作学习逻辑规则
- 通过习得规则解释预测
- 适用于稀疏知识图谱
- 计算开销较大

**KBGAT (知识图谱注意力网络):**
- 用于知识图谱补全的图注意力网络
- 从邻域学习实体表示
- 通过归纳学习处理未见实体
- 更适用于不完整图谱

## 训练流程

### 基础流程

```python
from torchdrug import datasets, models, tasks, core

# 加载数据集
dataset = datasets.FB15k237("~/kg-datasets/")

# 定义模型
model = models.RotatE(
    num_entity=dataset.num_entity,
    num_relation=dataset.num_relation,
    embedding_dim=2000,
    max_score=9
)

# 定义任务
task = tasks.KnowledgeGraphCompletion(
    model,
    num_negative=128,
    adversarial_temperature=2,
    criterion="bce"
)

# 使用 PyTorch Lightning 或自定义循环训练
```

### 负采样

**策略:**
- **均匀采样**：随机均匀采样实体
- **自对抗采样**：根据当前模型分数加权采样
- **类型约束采样**：仅采样关系对应的有效实体类型

**参数:**
- `num_negative`：每个正样本的负样本数量
- `adversarial_temperature`：自对抗加权温度
- 温度值越高，越关注困难负样本

### 损失函数

**二元交叉熵 (BCE):**
- 独立处理每个三元组
- 正负样本间的平衡分类

**间隔损失:**
- 确保正样本分数高于负样本指定间隔
- `max(0, margin + score_neg - score_pos)`

**逻辑损失:**
- 间隔损失的平滑版本
- 具有更好的梯度特性

## 模型选择指南

### 按关系模式选择

**1 对 1 关系:**
- TransE 效果良好
- 任何模型都可能成功

**1 对多关系:**
- DistMult, ComplEx, SimplE
- 避免使用 TransE

**多对 1 关系:**
- DistMult, ComplEx, SimplE
- 避免使用 TransE

**多对多关系:**
- ComplEx, SimplE, RotatE
- 最具挑战性的模式

**对称关系:**
- DistMult, ComplEx
- RotatE（需适当初始化）

**非对称关系:**
- ComplEx, SimplE, RotatE
- 避免使用 DistMult

**反向关系:**
- ComplEx, SimplE, RotatE
- 对双向推理至关重要

**组合关系:**
- RotatE（最佳）
- TransE（尚可）
- 捕捉多跳路径

### 按数据集特性选择

**小型图谱 (< 50k 实体):**
- ComplEx 或 SimplE
- 较低嵌入维度 (200-500)

**大型图谱 (> 100k 实体):**
- DistMult（追求效率）
- RotatE（追求精度）
- 较高维度 (500-2000)

**稀疏图谱:**
- NeuralLP（从有限数据学习规则）
- 在更大图谱上预训练嵌入

**稠密完整图谱:**
- 任何嵌入模型都适用
- 根据关系模式选择

**生物医学/领域图谱:**
- 采样时考虑类型约束
- 使用领域特定负采样
- Hetionet 受益于关系特定模型

## 高级技术

### 多跳推理

链接多个关系回答复杂查询：
- "哪些药物治疗由基因 X 导致的疾病？"
- 需要基于路径或规则的推理
- NeuralLP 天然支持此功能

### 时序知识图谱

扩展至时变事实：
- 为三元组添加时间信息
- 预测未来事实
- 模型需支持时序编码

### 少样本学习

处理样本稀少的关系：
- 元学习方法
- 从相关关系迁移知识
- 对新兴知识至关重要

### 归纳学习

泛化至未见实体：
- KBGAT 等基于 GNN 的方法
- 利用实体特征/描述
- 对演化知识图谱至关重要

## 生物医学应用

### 药物重定位

预测 Hetionet 中的"药物治疗疾病"链接：
1. 基于已知药物-疾病关联训练
2. 预测新治疗候选
3. 通过机制（基因、通路参与）过滤
4. 实验验证预测结果

### 疾病基因发现

识别疾病相关基因：
1. 建模基因-疾病-通路网络
2. 预测缺失的基因-疾病链接
3. 整合蛋白互作、表达数据
4. 优先验证候选基因

### 蛋白功能预测

关联蛋白与生物过程：
1. 整合蛋白互作、GO 术语
2. 预测缺失的 GO 注释
3. 从相似蛋白迁移功能

## 常见问题与解决方案

**问题：特定关系类型性能差**
- 解决方案：分析关系模式，选择合适模型，或使用关系特定模型

**问题：小型图谱过拟合**
- 解决方案：降低嵌入维度，增强正则化，或使用更简单模型

**问题：大型图谱训练缓慢**
- 解决方案：减少负样本数量，使用 DistMult 提升效率，或实现小批量训练

**问题：无法处理新实体**
- 解决方案：使用归纳模型（KBGAT），整合实体特征，或基于邻域预计算新实体嵌入

## 最佳实践

1. 多数任务首选 ComplEx 或 RotatE
2. 采用自对抗负采样
3. 调整嵌入维度（通常 500-2000）
4. 应用正则化防止过拟合
5. 使用过滤评估指标
6. 按关系类型分析性能
7. 异构图谱考虑关系特定模型
8. 通过领域专家验证预测结果
