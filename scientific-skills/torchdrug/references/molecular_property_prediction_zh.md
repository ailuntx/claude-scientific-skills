# 分子属性预测

## 概述

分子属性预测指根据分子结构预测其化学、物理或生物特性。TorchDrug为分子图的分类和回归任务提供全面支持。

## 可用数据集

### 药物发现数据集

**分类任务：**
- **BACE**（1,513个分子）：β-分泌酶抑制的二元分类
- **BBBP**（2,039个分子）：血脑屏障穿透性预测
- **HIV**（41,127个分子）：抑制HIV复制的能力
- **Tox21**（7,831个分子）：针对12个靶点的毒性预测
- **ToxCast**（8,576个分子）：毒理学筛选
- **ClinTox**（1,478个分子）：临床试验毒性
- **SIDER**（1,427个分子）：药物副作用（27个系统器官类别）
- **MUV**（93,087个分子）：虚拟筛选的最大无偏验证

**回归任务：**
- **ESOL**（1,128个分子）：水溶性预测
- **FreeSolv**（642个分子）：水合自由能
- **Lipophilicity**（4,200个分子）：辛醇/水分配系数
- **SAMPL**（643个分子）：溶剂化自由能

### 大规模数据集

- **QM7**（7,165个分子）：量子力学性质
- **QM8**（21,786个分子）：电子光谱与激发态性质
- **QM9**（133,885个分子）：几何/能量/电子/热力学性质
- **PCQM4M**（3,803,453个分子）：大规模量子化学数据集
- **ZINC250k/2M**（25万/200万分子）：用于生成建模的类药化合物

## 任务类型

### 属性预测

支持分类和回归的图级属性预测标准任务。

**关键参数：**
- `model`：图表示模型（GNN）
- `task`：节点/边/图级预测
- `criterion`：损失函数（"mse", "bce", "ce"）
- `metric`：评估指标（"mae", "rmse", "auroc", "auprc"）
- `num_mlp_layer`：读出层的MLP层数

**工作流示例：**
```python
import torch
from torchdrug import core, models, tasks, datasets

# 加载数据集
dataset = datasets.BBBP("~/molecule-datasets/")

# 定义模型
model = models.GIN(input_dim=dataset.node_feature_dim,
                   hidden_dims=[256, 256, 256, 256],
                   edge_input_dim=dataset.edge_feature_dim,
                   batch_norm=True, readout="mean")

# 定义任务
task = tasks.PropertyPrediction(model, task=dataset.tasks,
                                 criterion="bce",
                                 metric=("auprc", "auroc"))
```

### 多标签二元分类

专为多标签场景设计（如Tox21、SIDER），每个分子可含多个二元标签。

**核心特性：**
- 优雅处理缺失标签
- 计算单标签及平均指标
- 支持不平衡数据集的加权损失

## 模型选择

### 按任务推荐模型

**小分子（<1000分子）：**
- GIN（图同构网络）
- SchNet（适用于3D结构）

**中型数据集（1k-100k分子）：**
- GCN/GAT/GIN
- NFP（神经指纹）
- MPNN（消息传递神经网络）

**大型数据集（>100k分子）：**
- 预训练模型微调
- InfoGraph或多视图对比自监督预训练
- 深层架构的GIN

**含3D结构：**
- SchNet（连续滤波卷积）
- GearNet（几何感知关系图）

## 特征工程

### 节点特征

TorchDrug自动提取原子特征：
- 原子类型
- 形式电荷
- 显式/隐式氢原子
- 杂化方式
- 芳香性
- 手性

### 边特征

键特征包括：
- 键类型（单/双/三/芳香键）
- 立体化学
- 共轭性
- 环结构归属

### 自定义特征

通过转换添加自定义特征：
```python
from torchdrug import data, transforms

# 添加自定义特征
transform = transforms.VirtualNode()  # 添加虚拟节点
dataset = datasets.BBBP("~/molecule-datasets/",
                        transform=transform)
```

## 训练流程

### 基础流程

1. **加载数据集**：选择合适数据集
2. **划分数据**：药物发现推荐骨架划分
3. **定义模型**：选择GNN架构
4. **创建任务**：配置损失函数与指标
5. **设置优化器**：通常选用Adam
6. **训练**：使用PyTorch Lightning或自定义循环

### 数据划分策略

**随机划分**：标准训练/验证/测试集划分
**骨架划分**：按Bemis-Murcko骨架分组（药物发现推荐）
**分层划分**：保持标签分布一致性

### 最佳实践

- 药物发现评估使用骨架划分
- 小数据集应用数据增强（虚拟节点/边）
- 监控多指标（分类用AUROC/AUPRC；回归用MAE/RMSE）
- 基于验证性能实施早停
- 关键应用考虑集成方法
- 小数据集微调前进行大规模预训练

## 常见问题与解决方案

**问题：不平衡数据集性能差**
- 方案：使用加权损失、焦点损失或过采样/欠采样

**问题：小数据集过拟合**
- 方案：增强正则化、简化模型、数据增强或大规模预训练

**问题：内存消耗过大**
- 方案：减小批大小、梯度累积或图采样

**问题：训练速度慢**
- 方案：GPU加速、多进程数据加载或混合精度训练
