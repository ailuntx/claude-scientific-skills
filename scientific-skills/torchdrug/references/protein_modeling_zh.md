# 蛋白质建模

## 概述

TorchDrug 为蛋白质相关任务提供广泛支持，包括序列分析、结构预测、属性预测和蛋白质-蛋白质相互作用。蛋白质被表示为图结构，其中节点代表氨基酸残基，边表示空间或序列关系。

## 可用数据集

### 蛋白质功能预测

**酶功能：**
- **EnzymeCommission**（17,562 种蛋白质）：EC 编号分类（7 个层级）
- **BetaLactamase**（5,864 条序列）：酶活性预测

**蛋白质特性：**
- **Fluorescence**（54,025 条序列）：GFP 荧光强度
- **Stability**（53,614 条序列）：热稳定性预测
- **Solubility**（62,478 条序列）：蛋白质溶解度分类
- **BinaryLocalization**（22,168 种蛋白质）：亚细胞定位（膜蛋白 vs 可溶性蛋白）
- **SubcellularLocalization**（8,943 种蛋白质）：10 类亚细胞定位预测

**基因本体：**
- **GeneOntology**（46,796 种蛋白质）：跨生物过程、分子功能和细胞组分的 GO 术语预测

### 蛋白质结构预测

- **Fold**（16,712 种蛋白质）：结构折叠分类（1,195 个类别）
- **SecondaryStructure**（8,678 种蛋白质）：3 态或 8 态二级结构预测
- **ContactPrediction** via ProteinNet：残基-残基接触图谱

### 蛋白质相互作用

**蛋白质-蛋白质相互作用：**
- **HumanPPI**（1,412 种蛋白质，6,584 次相互作用）：人类蛋白质相互作用网络
- **YeastPPI**（2,018 种蛋白质，6,451 次相互作用）：酵母蛋白质相互作用网络
- **PPIAffinity**（2,156 对蛋白质）：结合亲和力测量

**蛋白质-配体结合：**
- **BindingDB**（约 150 万条目）：综合结合亲和力数据库
- **PDBBind**（20,000+ 复合物）：基于 3D 结构的结合数据
  - 精炼集：高质量晶体结构
  - 核心集：多样化基准集

### 大规模蛋白质数据库

- **AlphaFoldDB**：访问 2 亿+预测蛋白质结构
- **ProteinNet**：用于结构预测的标准化数据集

## 任务类型

### 节点属性预测

预测残基（节点）级别的属性，如二级结构或接触图谱。

**应用场景：**
- 二级结构预测（螺旋、折叠、卷曲）
- 残基级无序区预测
- 翻译后修饰位点
- 结合位点预测

### 属性预测

预测蛋白质级别的属性，如功能、稳定性或定位。

**应用场景：**
- 酶功能分类
- 亚细胞定位
- 蛋白质稳定性预测
- 基因本体术语预测

### 相互作用预测

预测蛋白质对或蛋白质-配体对之间的相互作用。

**核心特性：**
- 支持序列和结构输入
- 处理对称（PPI）和非对称（蛋白质-配体）相互作用
- 多种负采样策略

### 接触预测

专门用于预测折叠结构中残基间空间邻近性的任务。

**应用领域：**
- 从序列预测结构
- 蛋白质折叠路径分析
- 预测结构验证

## 蛋白质表征模型

### 基于序列的模型

**ESM（进化尺度建模）：**
- 在 2.5 亿序列上预训练的 Transformer 模型
- 纯序列任务的最先进模型
- 提供多种尺寸（ESM-1b, ESM-2）
- 捕捉进化和结构信息

**ProteinBERT：**
- BERT 风格掩码语言模型
- 在 UniProt 序列上预训练
- 适用于迁移学习

**ProteinLSTM：**
- 用于序列编码的双向 LSTM
- 轻量且快速
- 序列任务的优质基线模型

**ProteinCNN / ProteinResNet：**
- 卷积架构
- 捕捉局部序列模式
- 比 Transformer 模型更快

### 基于结构的模型

**GearNet（几何感知关系图网络）：**
- 融合 3D 几何信息
- 基于序列、半径和 K 近邻的边类型
- 结构任务的最先进模型
- 支持骨架和全原子表征

**蛋白质图上的 GCN/GAT/GIN：**
- 适配蛋白质的标准 GNN 架构
- 灵活的边定义（序列、空间、接触）

**SchNet：**
- 连续滤波器卷积
- 直接处理 3D 坐标
- 适用于结构预测和蛋白质-配体结合

### 基于特征的模型

**统计特征：**
- 氨基酸组成
- 序列长度统计
- 基序计数

**物理化学特征：**
- 疏水性标度
- 电荷特性
- 二级结构倾向性
- 分子量、等电点

## 蛋白质图构建

### 边类型

**序列边：**
- 连接序列中相邻残基
- 捕捉一级结构

**空间边：**
- 3D 空间中的 K 近邻
- 半径截断（如 Cα 原子在 10Å 内）
- 捕捉三级结构

**接触边：**
- 基于重原子距离
- 典型阈值 < 8Å

### 节点特征

**残基身份：**
- 20 种氨基酸的独热编码
- 学习嵌入

**位置信息：**
- 3D 坐标（Cα, N, C, O）
- 骨架角（phi, psi, omega）
- 相对空间位置编码

**物理化学属性：**
- 疏水性
- 电荷
- 大小
- 二级结构

## 训练流程

### 预训练策略

**自监督预训练：**
- 掩码残基预测（类似 BERT）
- 残基间距离预测
- 角度预测（phi, psi, omega）
- 二面角预测
- 接触图谱预测

**预训练模型使用：**
```python
from torchdrug import models

# 加载预训练 ESM
model = models.ESM(path="esm1b_t33_650M_UR50S.pt")

# 在下游任务上微调
task = tasks.PropertyPrediction(
    model, task=["stability"],
    criterion="mse", metric=["mae", "rmse"]
)
```

### 多任务学习

同时训练多个相关任务：
- 联合预测功能、定位和稳定性
- 提升泛化能力和数据效率
- 跨任务共享表征

### 最佳实践

**纯序列任务：**
1. 从预训练 ESM 或 ProteinBERT 开始
2. 使用小学习率微调（1e-5 至 1e-4）
3. 小数据集使用冻结嵌入
4. 应用 dropout 正则化

**结构相关任务：**
1. 使用带多边类型的 GearNet
2. 包含几何特征（角度、二面角）
3. 在大型结构数据库上预训练
4. 数据增强（旋转、裁剪）

**小数据集场景：**
1. 从预训练模型迁移学习
2. 与相关任务进行多任务学习
3. 数据增强（序列突变、结构扰动）
4. 强正则化（dropout、权重衰减）

## 典型应用场景

### 酶工程
- 从序列预测酶活性
- 设计突变提升稳定性
- 筛选目标催化特性

### 抗体设计
- 预测结合亲和力
- 优化抗体序列
- 预测免疫原性

### 药物靶点识别
- 预测蛋白质功能
- 识别可成药位点
- 分析蛋白质-配体相互作用

### 蛋白质结构预测
- 从序列预测二级结构
- 生成三级结构接触图谱
- 优化 AlphaFold 预测结果

```python
from torchdrug import data

# 加载 AlphaFold 结构
protein = data.Protein.from_pdb("alphafold_structure.pdb")

# 在 TorchDrug 流程中使用
```
