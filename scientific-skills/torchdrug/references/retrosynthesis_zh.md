# 逆合成分析

## 概述

逆合成分析是从目标分子逆向规划合成路线至商业化起始原料的过程。TorchDrug提供基于学习的逆合成预测工具，将这一复杂任务分解为可管理的子任务。

## 可用数据集

### USPTO-50K

源自美国专利文献的标准逆合成基准数据集。

**统计信息：**
- 50,017个反应实例
- 单步反应
- 经过质量和规范化过滤
- 包含用于反应中心识别的原子映射

**反应类型：**
- 多样化有机反应
- 类药转化
- 常见反应类别分布均衡

**数据划分：**
- 训练集：约4万反应
- 验证集：约5千反应
- 测试集：约5千反应

**格式：**
- 产物 → 反应物
- SMILES表示法
- 用于训练的原子映射反应

## 任务类型

TorchDrug将逆合成分解为多步骤流程：

### 1. 反应中心识别

识别反应中心——正向反应中形成/断裂的化学键。

**输入：** 产物分子  
**输出：** 每个化学键属于反应中心的概率  

**目的：**
- 定位化学反应发生位点
- 指导后续合成子生成
- 显著缩小搜索空间

**模型架构：**
- 基于产物分子的图神经网络
- 键级别分类
- 注意力机制突出反应区域

**评估指标：**
- **Top-K准确率**：前K个预测中包含正确反应中心
- **键级别F1值**：化学键预测的精确率与召回率

### 2. 合成子补全

基于产物和识别的反应中心预测反应物结构（合成子）。

**输入：**
- 产物分子
- 识别的反应中心（断裂/形成的化学键）

**输出：**
- 预测的反应物分子（合成子）

**流程：**
1. 在反应中心断裂化学键
2. 修饰原子环境（价态、电荷）
3. 确定离去基团和保护基团
4. 生成完整反应物结构

**挑战：**
- 存在多组有效反应物
- 立体专一性
- 原子环境变化（杂化、电荷）
- 离去基团选择

**评估：**
- **精确匹配**：生成反应物与真实值完全一致
- **Top-K准确率**：前K个预测中包含正确反应物
- **化学有效性**：生成分子符合化学规则

### 3. 逆合成（端到端）

将反应中心识别与合成子补全整合为统一流程。

**输入：** 目标产物分子  
**输出：** 排序后的反应物集合列表（合成路径）

**工作流：**
1. 识别Top-K反应中心
2. 为每个中心生成候选反应物
3. 按模型置信度排序组合
4. 过滤商业可得且可行的路径

**优势：**
- 单一模型训练部署
- 子任务联合优化
- 考虑反应中心识别的误差传递

## 训练流程

### 基础流程

```python
from torchdrug import datasets, models, tasks

# 加载数据集
dataset = datasets.USPTO50k("~/retro-datasets/")

# 反应中心识别
model_center = models.RGCN(
    input_dim=dataset.node_feature_dim,
    num_relation=dataset.num_bond_type,
    hidden_dims=[256, 256, 256]
)

task_center = tasks.CenterIdentification(
    model_center,
    top_k=3  # 考虑前3个反应中心
)

# 合成子补全
model_synthon = models.GIN(
    input_dim=dataset.node_feature_dim,
    hidden_dims=[256, 256, 256]
)

task_synthon = tasks.SynthonCompletion(
    model_synthon,
    center_topk=3,  # 使用反应中心识别的Top3结果
    num_synthon_beam=5  # 合成子生成的束搜索宽度
)

# 端到端逆合成
task_retro = tasks.Retrosynthesis(
    model=model_center,
    synthon_model=model_synthon,
    center_topk=5,
    num_synthon_beam=10
)
```

## 模型架构

### 图神经网络

**RGCN（关系图卷积网络）：**
- 处理多类型化学键（单键、双键、三键、芳香键）
- 键类型特异性变换
- 适用于反应中心识别

**GIN（图同构网络）：**
- 强大的消息传递机制
- 捕捉结构模式
- 在合成子补全中表现优异

**GAT（图注意力网络）：**
- 注意力权重突出关键原子/键
- 可解释的反应中心预测
- 灵活适配各类反应

### 序列模型

**Transformer模型：**
- SMILES到SMILES的转换
- 捕捉长程依赖关系
- 需大规模数据集

**LSTM/GRU：**
- 反应物的序列生成
- 自回归解码
- 适用于小分子

### 混合方法

结合图与序列表征：
- 图编码器处理产物
- 序列解码器生成反应物
- 融合两种表征优势

## 反应化学考量

### 反应类别

**常见转化：**
- C-C键形成（偶联、加成）
- 官能团互变（氧化、还原）
- 杂环合成（环化）
- 保护/去保护
- 芳香取代

**稀有反应：**
- 新型偶联方法
- 复杂重排反应
- 多组分反应

### 选择性问题

**区域选择性：**
- 分子反应位点预测
- 需理解电子效应与空间位阻

**立体选择性：**
- 立体化学控制
- 非对映选择性与对映选择性
- 药物合成关键因素

**化学选择性：**
- 官能团反应优先级
- 需保护基团策略

### 反应条件

TorchDrug聚焦反应连接性，但需考虑：
- 温度与压力
- 催化剂与试剂
- 溶剂
- 反应时间
- 后处理与纯化

## 多步合成规划

### 单步逆合成

预测目标分子的直接前体。

**适用场景：**
- 后期转化步骤
- 简单分子（距商业原料1-2步）
- 初始路线探索

### 多步规划

递归应用逆合成至每个预测反应物，直至获得商业化构建模块。

**树搜索策略：**

**广度优先搜索：**
- 探索同深度所有路径
- 寻找最短路线
- 内存消耗大

**深度优先搜索：**
- 完整探索单一路径
- 内存效率高
- 可能遗漏最优路径

**蒙特卡洛树搜索（MCTS）：**
- 平衡探索与利用
- 模型置信度引导
- 多步规划前沿技术

**A*搜索：**
- 启发式引导搜索
- 优化成本、复杂度或可行性
- 高效寻找最优路径

### 路线评分

按以下维度排序合成路线：
1. **步骤数**：步骤越少越好（效率）
2. **汇聚式vs线性**：优先汇聚式路线
3. **商业可得性**：距离可购买化合物的步数
4. **反应可行性**：每步反应成功概率
5. **总产率**：端到端预估产率
6. **成本**：试剂、人力、设备
7. **绿色化学**：环境影响与安全性

### 终止条件

当满足以下条件时停止逆合成：
- **商业化合物**：供应商可得（如Sigma-Aldrich, Enamine）
- **构建模块**：标准合成中间体
- **最大深度**：如6-10步
- **低置信度**：模型不确定性过高

## 验证与过滤

### 化学有效性

检查每个预测反应：
- 反应物为有效分子
- 反应符合化学原理
- 原子映射一致
- 化学计量平衡

### 合成可行性

**过滤器：**
- 反应先例（文献案例）
- 官能团兼容性
- 典型反应条件
- 预期产率范围

**专家系统：**
- 基于规则的验证（如ARChem Route Designer）
- 检测不兼容官能团
- 识别保护/去保护需求

### 商业可得性

**数据库：**
- eMolecules：1000万+商业化合物
- ZINC：含供应商注释
- Reaxys：商业化构建模块

**考量因素：**
- 每克成本
- 纯度与质量
- 交付周期
- 最小订购量
