# 数据集参考

## 概述

TorchDrug 提供 40 多个精选数据集，涵盖多个领域：分子性质预测、蛋白质建模、知识图谱推理和逆合成。所有数据集均支持惰性加载、自动下载和可定制的特征提取。

## 数据集使用模式

### 加载数据集

```python
from torchdrug import datasets

# 基础加载
dataset = datasets.BBBP("~/molecule-datasets/")

# 带转换器
from torchdrug import transforms
transform = transforms.VirtualNode()
dataset = datasets.BBBP("~/molecule-datasets/", transform=transform)

# 蛋白质数据集
dataset = datasets.EnzymeCommission("~/protein-datasets/")

# 知识图谱
dataset = datasets.FB15k237("~/kg-datasets/")
```

### 数据分割

```python
# 随机分割
train, valid, test = dataset.split([0.8, 0.1, 0.1])

# 骨架分割（分子专用）
from torchdrug import utils
train, valid, test = dataset.split(
    utils.scaffold_split(dataset, [0.8, 0.1, 0.1])
)

# 预定义分割（部分数据集）
train, valid, test = dataset.split()
```

### 特征提取

**节点特征（分子）：**
- 原子类型（one-hot或嵌入）
- 形式电荷
- 杂化方式
- 芳香性
- 氢原子数
- 手性

**边特征（分子）：**
- 键类型（单键、双键、三键、芳香键）
- 立体化学
- 共轭性
- 环结构归属

**节点特征（蛋白质）：**
- 氨基酸类型（one-hot）
- 理化性质
- 序列位置
- 二级结构
- 溶剂可及性

**边特征（蛋白质）：**
- 边类型（序列相邻、空间相邻、接触）
- 距离
- 角度和二面角

## 数据集选择指南

### 按任务选择

**分子性质预测：**
- 入门：BBBP或HIV（中等规模，任务明确）
- 量子性质：QM9
- 回归任务：ESOL/FreeSolv

**蛋白质功能：**
- EnzymeCommission（清晰分类）
- GeneOntology（全面注释）

**药物安全性：**
- Tox21（标准基准）
- ClinTox（临床相关性）

**基于结构：**
- PDBBind（蛋白质-配体）
- ProteinNet（结构预测）

**知识图谱：**
- FB15k-237（标准基准）
- Hetionet（生物医学应用）

**生成任务：**
- ZINC250k（训练）
- QM9（带性质）

**逆合成：**
- USPTO-50k（唯一选择）

### 按规模与资源

**小型（<5k，测试用）：**
- BACE、FreeSolv、ClinTox
- PDBBind核心集

**中型（5k-100k）：**
- BBBP、HIV、ESOL、Tox21

- FB15k-237、WN18RR

**大型（>100k）：**
- QM9、MUV、PCQM4M
- GeneOntology、AlphaFoldDB
- ZINC2M、BindingDB

### 按领域

**药物发现：** BBBP、HIV、Tox21、ESOL、ZINC  
**量子化学：** QM7、QM8、QM9、PCQM4M  
**蛋白质工程：** Fluorescence、Stability、Solubility  
**结构生物学：** Fold、PDBBind、ProteinNet、AlphaFoldDB  
**生物医学：** Hetionet、GeneOntology、EnzymeCommission  
**逆合成：** USPTO-50k

## 最佳实践

1. **从小开始**：扩展前先在小数据集测试
2. **骨架分割**：用于药物发现的真实评估
3. **平衡指标**：不平衡数据使用AUROC+AUPRC
4. **多次运行**：报告多随机种子的均值±标准差
5. **数据泄露**：注意预训练模型的使用
6. **领域知识**：理解预测目标
7. **验证**：始终使用保留测试集
8. **预处理**：标准化特征，处理缺失值
