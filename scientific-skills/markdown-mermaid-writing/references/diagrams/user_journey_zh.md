# 用户旅程图

> **返回[样式指南](../mermaid_style_guide.md)** — 请先阅读样式指南了解表情符号、颜色和无障碍规则

**语法关键词：** `journey`  
**最佳适用场景：** 用户体验映射、客户旅程、流程满意度评分、入职流程  
**不适用场景：** 无满意度数据的简单流程（使用[流程图](flowchart.md)）、时序事件（使用[时间轴](timeline.md)）

---

## 示例图表

```mermaid
journey
    accTitle: 新开发者入职体验
    accDescr: 跟踪新开发者从首日配置、首周融入至首月产出的旅程图，包含各阶段满意度评分

    title 👤 新开发者入职流程
    section 📋 首日配置
        阅读入职文档       : 3 : 新开发者
        克隆代码库        : 4 : 新开发者
        配置本地环境       : 2 : 新开发者
        遇到配置问题     : 1 : 新开发者
    section 🤝 首周融入
        团队见面会             : 5 : 新开发者
        首次PR结对编程  : 4 : 新开发者, 导师
        熟悉代码库         : 2 : 新开发者
        首个PR合并           : 5 : 新开发者
    section 🚀 首月产出
        负责小型功能       : 4 : 新开发者
        参与代码评审: 4 : 新开发者
        发布生产环境        : 5 : 新开发者
```

---

## 使用技巧

- 评分标准：**1**=😤沮丧, **3**=😐中立, **5**=😄欣喜
- 评分后标注执行者：`5 : 执行者1, 执行者2`
- 使用**带表情前缀**的`section`按时间段/阶段分组
- 聚焦**痛点环节**（低分项）—— 核心洞察所在
- 保持**3-4个阶段**，每阶段**3-4个步骤**

## 模板

```mermaid
journey

    accDescr: 描述用户旅程及其揭示的体验洞察

    title 👤 旅程标题
    section 📋 阶段一

        步骤二           : 4 : 执行者
    section 🔧 阶段二
        步骤三         : 2 : 执行者
        步骤四          : 5 : 执行者
```

## 复杂案例

多角色电商旅程图，对比新客户与回头客在5个阶段的体验。两种角色经历相同流程但满意度不同，精准揭示首次用户体验需优化的环节。

```mermaid
journey
    accTitle: 电商客户旅程对比
    accDescr: 并排展示新客户与回头客在发现、购物、结算、履约、售后阶段的满意度差异，识别首次体验断层

    title 👤 电商客户旅程对比
    section 🔍 发现阶段
        查找商品         : 3 : 新客户, 回头客
        阅读评价             : 4 : 新客户, 回头客
        对比替代品     : 3 : 新客户
        访问收藏夹     : 5 : 回头客
    section 🛒 购物阶段
        加入购物车              : 4 : 新客户, 回头客
        输入优惠码        : 2 : 新客户
        使用存储优惠券        : 5 : 回头客
        选择配送方式   : 3 : 新客户, 回头客
    section 💰 结算阶段
        填写支付信息    : 2 : 新客户
        使用存储支付        : 5 : 回头客
        复核确认       : 4 : 新客户, 回头客
        收到确认通知     : 5 : 新客户, 回头客
    section 📦 履约阶段
        追踪物流           : 3 : 新客户, 回头客
        接收包裹         : 5 : 新客户, 回头客
        开箱体验            : 5 : 新客户, 回头客
    section 🔄 售后阶段
        发表评价           : 2 : 新客户
        联系客服          : 1 : 新客户
        复购同款商品        : 5 : 回头客
        推荐给朋友      : 3 : 回头客
```

### 设计解析

- **双角色同图对比** —— 新客户(2-3分)与回头客(4-5分)在结算/售后阶段的满意度断层直观可见
- **5阶段符合真实漏斗** —— 发现→购物→结算→履约→售后，每个阶段揭示新用户的体验断点
- **差异化步骤设计** —— "对比替代品"仅新客户执行，"复购同款"仅回头客执行，体现旅程中的路径分叉
- **低分项即行动信号** —— 新客户在支付/优惠券/客服环节的1-2分，正是提升转化率的关键优化点
