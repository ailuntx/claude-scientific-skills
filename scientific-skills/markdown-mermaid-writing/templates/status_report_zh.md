# 状态报告/执行简报模板

> **返回 [Markdown 风格指南](../markdown_style_guide.md)** — 请先阅读风格指南了解格式、引用和表情符号规则。

**适用场景：** 周报/月报、执行简报、项目健康报告、季度回顾、冲刺复盘，或任何向利益相关方同步进展、风险和待决策事项的文档。设计为可被决策者在5分钟内读完。

**核心特点：** 顶部设置摘要供高管快速浏览；红绿灯健康指标；明确列出"待决策"事项以暴露阻塞点；含趋势分析的指标表；带缓解措施的风险登记表。

**设计理念：** 状态报告最常见的失败模式是将关键信息埋没在成就堆中。优先呈现需要关注的事项。如果读者只有30秒，摘要和健康状态能提供必要信息；如果有5分钟，完整报告能解答所有后续疑问。永远不要让领导层费力挖掘需要行动的事项。

---

## 使用指南

1. 为每个报告周期复制此文件
2. 按日期命名：`status-2026-02-14.md` 或 `status-week-07.md`
3. **首先填写摘要** — 若无法概括说明，表明尚未理解透彻
4. 如实反映健康状态 — 绿色代表实际良好，而非"因乐观标绿"
5. 添加 [Mermaid图表](../mermaid_style_guide.md) 展示进度时间线、架构变更或风险影响流
