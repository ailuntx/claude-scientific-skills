# 操作指南/教程模板

> **返回 [Markdown 风格指南](../markdown_style_guide.md)** — 请先阅读风格指南了解格式、引用和表情符号规则。

**适用场景：** 分步教程、操作指南、入门指引、运维手册、安装说明，或任何以教学为核心目标的文档。确保读者首次尝试即可成功。

**核心特性：** 含验证命令的前置条件、带每步预期输出的编号步骤、"功能验证"检查点、常见问题排错区以及"后续步骤"路径。

**设计理念：** 当读者卡顿时，操作指南即告失败。每个步骤必须可验证——读者应在进入下一步前确认操作正确。预判读者产生"这步成功了吗？"疑虑的时刻，并在此设置检查点。需包含实际可见的错误信息，而非仅展示理想路径。

---

## 使用说明

1. 复制本文件至您的项目
2. 将所有`[方括号占位符]`替换为实际内容
3. **在全新环境中完整测试指南**——逐步骤执行。跳过此步将导致指南存在缺陷
4. 使用 [Mermaid 流程图](../mermaid_style_guide.md)展示流程概览、决策点或架构背景
5. 每个验证步骤需包含实际输出（可精简）——勿仅描述"应看到输出"
