# 光谱学与分析化学文件格式参考

本参考涵盖各类光谱技术和分析化学仪器使用的文件格式。

## 核磁共振波谱

### .fid - 核磁自由感应衰减
**描述：** Bruker、Agilent、JEOL 的原始时域核磁数据  
**典型数据：** 复数时域信号  
**应用场景：** 核磁共振波谱、结构解析  
**Python库：**  
- `nmrglue`: `nmrglue.bruker.read_fid('fid')` 或 `nmrglue.varian.read_fid('fid')`  
- `nmrstarlib`: 核磁数据处理  
**探索性数据分析方法：**  
- 时域信号衰减  
- 采样率与采集时间  
- 数据点数  
- 信噪比估算  
- 基线漂移评估  
- 数字滤波器效应  
- 采集参数验证  
- 切趾函数选择  

### .ft / .ft1 / .ft2 - 核磁频域数据
**描述：** 傅里叶变换后的核磁谱图  
**典型数据：** 处理后的频域数据  
**应用场景：** 核磁分析、峰积分  
**Python库：**  
- `nmrglue`: 频域数据读取  
- 自定义处理流程  
**探索性数据分析方法：**  
- 峰识别与积分  
- 化学位移范围  
- 基线校正质量  
- 相位校正评估  
- 参考峰识别  
- 谱图分辨率  
- 伪峰检测  
- 多重性分析  

### .1r / .2rr - Bruker 核磁处理数据
**描述：** Bruker 处理谱图（实部）  
**典型数据：** 一维或二维处理核磁谱  
**应用场景：** Bruker 软件核磁数据分析  
**Python库：**  
- `nmrglue`: Bruker 格式支持  
**探索性数据分析方法：**  
- 处理参数复核  
- 窗函数效应  
- 补零评估  
- 线性预测验证  
- 谱图伪峰  

### .dx - 核磁 JCAMP-DX 格式
**描述：** 核磁专用 JCAMP-DX 格式  
**典型数据：** 标准化核磁谱图  
**应用场景：** 软件间数据交换  
**Python库：**  
- `jcamp`: JCAMP 读取器  
- `nmrglue`: 支持导入 JCAMP  
**探索性数据分析方法：**  
- 格式合规性  
- 元数据完整性  
- 峰表验证  
- 积分值  
- 化合物标识信息  

### .mnova - Mnova 格式
**描述：** Mestrelab Research Mnova 格式  
**典型数据：** 含处理信息的核磁数据  
**应用场景：** Mnova 软件工作流  
**Python库：**  
- `nmrglue`: 有限 Mnova 支持  
- 标准格式转换工具  
**探索性数据分析方法：**  
- 多谱图处理  
- 处理流程复核  
- 定量数据  
- 结构归属  

## 质谱分析

### .mzML - 质谱标记语言
**描述：** 基于 XML 的标准质谱格式  
**典型数据：** 质谱图、色谱图、元数据  
**应用场景：** 蛋白质组学、代谢组学、脂质组学  
**Python库：**  
- `pymzml`: `pymzml.run.Reader('file.mzML')`  
- `pyteomics.mzml`: `pyteomics.mzml.read('file.mzML')`  
- `MSFileReader`: 多种封装器  
**探索性数据分析方法：**  
- 扫描次数与质谱层级分布  
- 保留时间范围与总离子流  
- m/z 范围与分辨率  
- 前体离子选择  
- 碎裂模式  
- 仪器配置  
- 质控指标  
- 数据完整性  

### .mzXML - 质谱 XML 格式
**描述：** 旧版 XML 质谱格式  
**典型数据：** 质谱图与色谱图  
**应用场景：** 蛋白质组学工作流（旧版）  
**Python库：**  
- `pyteomics.mzxml`  
- `pymzml`: 支持读取 mzXML  
**探索性数据分析方法：**  
- 类似 mzML  
- 版本兼容性  
- 转换质量评估  

### .mzData - mzData 格式
**描述：** 旧版 PSI 质谱格式  
**典型数据：** 质谱数据  
**应用场景：** 历史数据归档  
**Python库：**  
- `pyteomics`: 有限支持  
- 建议转换为 mzML  
**探索性数据分析方法：**  
- 格式转换验证  
- 数据完整性  
- 元数据提取  

### .raw - 厂商原始文件（Thermo, Agilent, Bruker）
**描述：** 专有仪器数据  
**典型数据：** 原始质谱图与元数据  
**应用场景：** 仪器直接输出  
**Python库：**  
- `pymsfilereader`: Thermo RAW 文件  
- `ThermoRawFileParser`: 命令行封装器  
- 厂商专用 API  
**探索性数据分析方法：**  
- 方法参数提取  
- 仪器性能指标  
- 校准状态  
- 扫描功能分析  
- 串联质谱质量指标  
- 动态排除评估  

### .d - Agilent 数据目录
**描述：** Agilent 质谱数据文件夹  
**典型数据：** 含方法的 LC-MS、GC-MS 数据  
**应用场景：** Agilent MassHunter 工作流  
**Python库：**  
- 社区解析器  
- Chemstation 集成  
**探索性数据分析方法：**  
- 目录结构验证  
- 方法参数  
- 校准曲线  
- 序列元数据  
- 信号质量指标  

### .wiff - AB SCIEX 数据
**描述：** AB SCIEX/SCIEX 仪器格式  
**典型数据：** 质谱数据  
**应用场景：** SCIEX 仪器工作流  
**Python库：**  
- 厂商 SDK（有限 Python 支持）  
- 转换工具  
**探索性数据分析方法：**  
- 实验类型识别  
- 扫描属性  
- 定量数据  
- 多实验结构  

### .mgf - Mascot 通用格式
**描述：** 串联质谱峰列表格式  
**典型数据：** 前体与碎片离子质量  
**应用场景：** 肽段鉴定、数据库检索  
**Python库：**  
- `pyteomics.mgf`: `pyteomics.mgf.read('file.mgf')`  
- `pyopenms`: MGF 支持  
**探索性数据分析方法：**  
- 谱图数量  
- 电荷态分布  
- 前体 m/z 与强度  
- 碎片峰数量  
- 质量精度  
- 标题与元数据解析  

### .pkl - 峰列表（二进制）
**描述：** 二进制峰列表格式  
**典型数据：** 序列化串联质谱图  
**应用场景：** 软件专用存储  
**Python库：**  
- `pickle`: 标准反序列化  
- `pyteomics`: PKL 支持  
**探索性数据分析方法：**  
- 数据结构检查  
- 转换为标准格式  
- 元数据保留  

### .ms1 / .ms2 - MS1/MS2 格式
**描述：** 简易质谱文本格式  
**典型数据：** MS1 与 MS2 扫描  
**应用场景：** 数据库检索、蛋白质组学  
**Python库：**  
- `pyteomics.ms1` 与 `ms2`  
- 简易文本解析  
**探索性数据分析方法：**  
- 按层级统计扫描数  
- 保留时间序列  
- 电荷态分析  
- m/z 范围覆盖度  

### .pepXML - 肽段 XML
**描述：** TPP 肽段鉴定格式  
**典型数据：** 肽段-谱图匹配  
**应用场景：** 蛋白质组学搜索结果  
**Python库：**  
- `pyteomics.pepxml`  
**探索性数据分析方法：**  
- 搜索结果统计  
- 分数分布  
- 修饰分析  
- 错误发现率评估  
- 酶切特异性  

### .protXML - 蛋白质 XML
**描述：** TPP 蛋白质推断格式  
**典型数据：** 蛋白质鉴定  
**应用场景：** 蛋白质组学蛋白质层级结果  
**Python库：**  
- `pyteomics.protxml`  
**探索性数据分析方法：**  
- 蛋白质组分析  
- 覆盖度统计  
- 置信度评分  
- 简约性分析  

### .msp - NIST 质谱检索格式
**描述：** NIST 谱库格式  
**典型数据：** 参考质谱图  
**应用场景：** 谱库检索  
**Python库：**  
- `matchms`: 谱库处理  
- 自定义解析器  
**探索性数据分析方法：**  
- 库规模与覆盖度  
- 元数据完整性  
- 峰数量统计  
- 化合物注释质量  

## 红外与拉曼光谱

### .spc - Galactic SPC
**描述：** Thermo Galactic 光谱格式  
**典型数据：** 红外、拉曼、紫外-可见光谱  
**应用场景：** 多种光谱仪器  
**Python库：**  
- `spc`: `spc.File('file.spc')`  
- `specio`: 多格式读取器  
**探索性数据分析方法：**  
- 波数/波长范围  
- 数据点密度  
- 多谱图处理  
- 基线特征  
- 峰识别  
- 吸光度/透射率模式  
- 仪器信息  

### .spa - Thermo Nicolet
**描述：** Thermo Fisher 傅里叶变换红外格式  
**典型数据：** 傅里叶变换红外光谱  
**应用场景：** OMNIC 软件数据  
**Python库：**  
- 自定义二进制解析器  
- 转换为 JCAMP 或 SPC  
**探索性数据分析方法：**  
- 干涉图与光谱对比  
- 背景谱验证  
- 大气补偿  
- 分辨率与扫描次数  
- 样品信息  

### .0 - Bruker OPUS
**描述：** Bruker OPUS 傅里叶变换红外格式（编号文件）  
**典型数据：** 傅里叶变换红外光谱与元数据  
**应用场景：** Bruker 傅里叶变换红外仪器  
**Python库：**  
- `brukeropusreader`: OPUS 格式解析器  
- `specio`: OPUS 支持  
**探索性数据分析方法：**  
- 多区块类型（AB, ScSm 等）  
- 样品与参考光谱  
- 仪器参数  
- 光路配置  
- 分束器与检测器信息  

### .dpt - 数据点表格
**描述：** 简易 XY 数据格式  
**典型数据：** 通用光谱数据  
**应用场景：** Renishaw 拉曼、通用导出  
**Python库：**  
- `pandas`: 类 CSV 读取  
- 文本解析  
**探索性数据分析方法：**  
- X 轴类型（波长、波数、拉曼位移）  
- Y 轴单位（强度、吸光度等）  
- 数据点间距  
- 头部信息  
- 多列数据处理  

### .wdf - Renishaw 拉曼
**描述：** Renishaw WiRE 数据格式  
**典型数据：** 拉曼光谱与图谱  
**应用场景：** Renishaw 拉曼显微  
**Python库：**  
- `renishawWiRE`: WDF 读取器  
- WDF 格式自定义解析器  
**探索性数据分析方法：**  
- 光谱与图谱数据区分  
- 激光波长  
- 累加与曝光时间  
- 空间坐标（图谱）  
- Z 轴扫描数据  
- 基线与宇宙线校正  

### .txt (光谱学)
**描述：** 仪器通用文本导出  
**典型数据：** 波长/波数与强度  
**应用场景：** 通用数据交换  
**Python库：**  
- `pandas`: 文本文件读取  
- `numpy`: 简易数组加载  
**探索性数据分析方法：**  
- 分隔符与格式检测  
- 头部解析  
- 单位识别  
- 多谱图处理  
- 注释元数据提取

## X射线与衍射

### .cif - 晶体学信息文件
**描述：** 晶体结构与衍射数据  
**典型数据：** 晶胞、原子坐标、结构因子  
**应用场景：** 晶体学、材料科学  
**Python库：**  
- `gemmi`: `gemmi.cif.read_file('file.cif')`  
- `PyCifRW`: CIF 读写  
- `pymatgen`: 材料结构分析  
**探索性数据分析方法：**  
- 晶系与空间群  
- 晶胞参数  
- 原子坐标与占位率  
- 温度因子  
- R 因子与精修质量  
- 完整性与冗余度  
- 结构验证  

### .hkl - 衍射点数据
**描述：** 米勒指数与强度  
**典型数据：** 积分衍射强度  
**应用场景：** 晶体学精修  
**Python库：**  
- 自定义解析器（格式相关）  
- 晶体学软件包（CCP4 等）  
**探索性数据分析方法：**  
- 分辨率范围  
- 壳层完整性  
- I/σ 分布  
- 系统消光  
- 孪晶检测  
- 威尔逊图  

### .mtz - MTZ 格式（CCP4）
**描述：** 二进制晶体学数据  
**典型数据：** 衍射点、相位、结构因子  
**应用场景：** 大分子晶体学  
**Python库：**  
- `gemmi`: MTZ 支持  
- `cctbx`: 综合晶体学工具  
**探索性数据分析方法：**  
- 列类型与数据  
- 分辨率限制  
- R 因子（Rwork, Rfree）  
- 相位概率分布  
- 电子密度图系数  
- 批次信息  

### .xy / .xye - 粉末衍射
**描述：** 2θ 角-强度数据  
**典型数据：** 粉末 X 射线衍射谱  
**应用场景：** 物相识别、Rietveld 精修  
**Python库：**  
- `pandas`: 简易 XY 读取  
- `pymatgen`: XRD 谱分析  
**

- 定量结果
- 系统适用性测试

## 其他分析技术

- 转变温度识别  
- 焓值计算  
- 质量损失阶段分析  
- 加热速率影响  
- 基线确定  
- 纯度评估  

### .run - ICP-MS/ICP-OES  
**描述：** 元素分析数据  
**典型数据：** 元素浓度或计数  
**使用场景：** 电感耦合等离子体质谱/光谱法
