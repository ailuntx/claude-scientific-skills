# 蛋白质组学与代谢组学文件格式参考

本文档涵盖蛋白质组学、代谢组学、脂质组学及相关组学工作流特有的文件格式。

## 基于质谱的蛋白质组学

### .mzML - 质谱标记语言
**描述：** 质谱数据的标准XML格式  
**典型数据：** MS1和MS2谱图、保留时间、强度值  
**应用场景：** 蛋白质组学、代谢组学流程  
**Python库：**  
- `pymzml`: `pymzml.run.Reader('file.mzML')`  
- `pyteomics.mzml`: `pyteomics.mzml.read('file.mzML')`  
- `pyopenms`: OpenMS的Python绑定  
**探索性数据分析(EDA)方法：**  
- 扫描次数与MS层级分布  
- 总离子流色谱图(TIC)分析  
- 基峰色谱图(BPC)  
- m/z覆盖范围与分辨率  
- 保留时间范围  
- 前体离子选择模式  
- 数据完整性  
- 质控指标（锁定质量、标准品）  

### .mzXML - 传统质谱XML格式
**描述：** 旧版基于XML的质谱格式  
**典型数据：** 含元数据的质谱图  
**应用场景：** 历史蛋白质组学数据  
**Python库：**  
- `pyteomics.mzxml`  
- `pymzml`: 支持读取mzXML  
**EDA方法：**  
- 类似mzML分析  
- 格式版本兼容性  
- 转换质量验证  
- 元数据完整性检查  

### .mzIdentML - 肽段鉴定格式
**描述：** PSI标准的肽段鉴定格式  
**典型数据：** 肽段-谱图匹配、蛋白质、得分  
**应用场景：** 搜索引擎结果、蛋白质组学流程  
**Python库：**  
- `pyteomics.mzid`  
- `pyopenms`: 支持MzIdentML  
**EDA方法：**  
- PSM数量与得分分布  
- 错误发现率(FDR)计算与过滤  
- 修饰分析  
- 漏切位点统计  
- 蛋白质推断结果  
- 搜索参数验证  
- 诱饵命中分析  
- 一级排名与次级排名比较  

### .pepXML - 跨蛋白质组学流程肽段XML
**描述：** TPP的肽段鉴定格式  
**典型数据：** 含统计验证的搜索结果  
**应用场景：** 蛋白质组学数据库搜索输出  
**Python库：**  
- `pyteomics.pepxml`  
**EDA方法：**  
- 搜索引擎比较  
- 得分分布（XCorr、期望值等）  
- 电荷态分析  
- 修饰频率  
- PeptideProphet概率值  
- 蛋白质覆盖度  
- 谱图计数  

### .protXML - 蛋白质推断结果
**描述：** TPP蛋白质层级鉴定结果  
**典型数据：** 蛋白质组、概率值、肽段  
**应用场景：** 蛋白质层级分析  
**Python库：**  
- `pyteomics.protxml`  
**EDA方法：**  
- 蛋白质组统计  
- 简约蛋白质集  
- ProteinProphet概率值  
- 蛋白质覆盖度与肽段计数  
- 唯一肽段与共享肽段  
- 蛋白质分子量分布  
- GO功能富集准备  

### .pride.xml - PRIDE XML格式
**描述：** 蛋白质组学鉴定数据库格式  
**典型数据：** 完整蛋白质组学实验数据  
**应用场景：** 公共数据存储（历史格式）  
**Python库：**  
- `pyteomics.pride`  
- 自定义XML解析器  
**EDA方法：**  
- 实验元数据提取  
- 鉴定完整性  
- 谱图交叉链接  
- 实验流程信息  
- 仪器详情  

### .tsv / .csv (蛋白质组学)
**描述：** 蛋白质组学结果的制表符/逗号分隔文件  
**典型数据：** 肽段或蛋白质定量表  
**应用场景：** MaxQuant、Proteome Discoverer、Skyline输出  
**Python库：**  
- `pandas`: `pd.read_csv()` 或 `pd.read_table()`  
**EDA方法：**  
- 鉴定数量统计  
- 定量值分布  
- 缺失值模式  
- 强度分析  
- 无标记定量评估  
- 同重标签比率分析  
- 变异系数  
- 批次效应  

### .msf - Thermo MSF数据库
**描述：** Proteome Discoverer结果数据库  
**典型数据：** 含搜索结果的SQLite数据库  
**应用场景：** Thermo Proteome Discoverer工作流  
**Python库：**  
- `sqlite3`: 数据库访问  
- 自定义MSF解析器  
**EDA方法：**  
- 数据库结构探索  
- 肽段与蛋白质表  
- 得分阈值  
- 定量数据  
- 处理节点信息  
- 置信水平  

### .pdResult - Proteome Discoverer结果
**描述：** Proteome Discoverer研究结果  
**典型数据：** 完整搜索与定量数据  
**应用场景：** PD研究导出  
**Python库：**  
- 厂商工具转换  
- 导出TSV供Python分析  
**EDA方法：**  
- 研究设计验证  
- 结果过滤标准  
- 定量比较组  
- 缺失值填补策略  

### .pep.xml - 肽段摘要
**描述：** 紧凑型肽段鉴定格式  
**典型数据：** 肽段序列、修饰、得分  
**应用场景：** 下游分析输入  
**Python库：**  
- `pyteomics`: XML解析  
**EDA方法：**  
- 唯一肽段计数  
- 翻译后修饰(PTM)位点定位  
- 保留时间可预测性  
- 电荷态偏好  

## 定量蛋白质组学

### .sky - Skyline文档
**描述：** Skyline靶向蛋白质组学文档  
**典型数据：** 离子对列表、色谱图、结果  
**应用场景：** 靶向蛋白质组学(SRM/MRM/PRM)  
**Python库：**  
- `skyline`: Python API（功能有限）  
- 导出CSV分析  
**EDA方法：**  
- 离子对选择验证  
- 色谱峰质量  
- 干扰检测  
- 保留时间一致性  
- 校准曲线评估  
- 重复样本相关性  
- 检测限/定量限确定  

### .sky.zip - 压缩Skyline文档
**描述：** 含外部文件的Skyline文档  
**典型数据：** 完整Skyline分析  
**应用场景：** 共享Skyline项目  
**Python库：**  
- `zipfile`: 解压处理  
**EDA方法：**  
- 文档结构  
- 外部文件引用  
- 结果导出与分析  

### .wiff - SCIEX WIFF格式
**描述：** SCIEX仪器定量数据  
**典型数据：** 含MRM离子对的LC-MS/MS  
**应用场景：** SCIEX QTRAP、TripleTOF数据  
**Python库：**  
- 厂商工具（Python支持有限）  
- 转换为mzML  
**EDA方法：**  
- MRM离子对性能  
- 驻留时间优化  
- 循环时间分析  
- 峰积分质量  

### .raw (Thermo)
**描述：** Thermo原始仪器文件  
**典型数据：** Orbitrap、Q Exactive的完整质谱数据  
**应用场景：** 无标记与TMT定量  
**Python库：**  
- `pymsfilereader`: Thermo RawFileReader  
- `ThermoRawFileParser`: 跨平台CLI工具  
**EDA方法：**  
- MS1与MS2采集速率  
- 自动增益控制目标与填充时间  
- 分辨率设置  
- 隔离窗口验证  
- 同步母离子选择(TMT)  
- 污染评估  

### .d (Agilent)
**描述：** Agilent数据目录  
**典型数据：** LC-MS与GC-MS数据  
**应用场景：** Agilent仪器工作流  
**Python库：**  
- 社区解析器  
- 导出为mzML  
**EDA方法：**  
- 方法一致性  
- 校准状态  
- 序列运行信息  
- 保留时间稳定性  

## 代谢组学与脂质组学

### .mzML (代谢组学)
**描述：** 代谢组学标准质谱格式  
**典型数据：** 全扫描MS、靶向MS/MS  
**应用场景：** 非靶向与靶向代谢组学  
**Python库：**  
- 同蛋白质组学mzML工具  
**EDA方法：**  
- 特征检测质量  
- 质量精度评估  
- 保留时间对齐  
- 空白扣除  
- QC样本一致性  
- 同位素模式验证  
- 加合物形成分析  
- 源内裂解检查  

### .cdf / .netCDF - ANDI-MS
**描述：** 质谱分析数据交换格式  
**典型数据：** GC-MS、LC-MS色谱数据  
**应用场景：** 代谢组学、GC-MS工作流  
**Python库：**  
- `netCDF4`: 底层访问  
- `pyopenms`: 支持CDF  
- 通过R集成`xcms`  
**EDA方法：**  
- TIC与提取离子色谱图  
- 跨样本峰检测  
- 保留指数计算  
- 质谱图匹配  
- 库搜索准备  

### .msp - 质谱图格式(NIST)
**描述：** NIST谱库格式  
**典型数据：** 参考质谱图  
**应用场景：** 代谢物鉴定、谱库匹配  
**Python库：**  
- `matchms`: 谱图匹配  
- 自定义MSP解析器  
**EDA方法：**  
- 谱库覆盖度  
- 元数据完整性(InChI、SMILES)  
- 谱图质量指标  
- 碰撞能标准化  
- 前体类型注释  

### .mgf (代谢组学)
**描述：** Mascot通用MS/MS格式  
**典型数据：** 代谢物鉴定的MS/MS谱图  
**应用场景：** 谱库搜索  
**Python库：**  
- `matchms`: 代谢组学谱图分析  
- `pyteomics.mgf`  
**EDA方法：**  
- 谱图质量过滤  
- 前体离子分离纯度  
- 碎片m/z精度  
- 中性丢失模式  
- MS/MS完整性  

### .nmrML - NMR标记语言
**描述：** NMR代谢组学标准XML格式  
**典型数据：** 含元数据的1D/2D NMR谱图  
**应用场景：** 基于NMR的代谢组学  
**Python库：**  
- `nmrml2isa`: 格式转换  
- 自定义XML解析器  
**EDA方法：**  
- 谱图质量指标  
- 分箱一致性  
- 参考化合物验证  
- pH与温度效应  
- 代谢物鉴定置信度  

### .json (代谢组学)
**描述：** 代谢组学结果的JSON格式  
**典型数据：** 特征表、注释、元数据  
**应用场景：** GNPS、MetaboAnalyst等网络工具  
**Python库：**  
- `json`: 标准库  
- `pandas`: JSON标准化  
**EDA方法：**  
- 特征注释覆盖度  
- GNPS聚类结果  
- 分子网络统计  
- 加合物与源内碎片关联  
- 推定鉴定置信度  

### .txt (代谢组学表格)
**描述：** 制表符分隔的特征表  
**典型数据：** 跨样本的m/z、保留时间、强度  
**应用场景：** MZmine、XCMS、MS-DIAL输出  
**Python库：**  
- `pandas`: 文本文件读取  
**EDA方法：**  
- 特征数量与质量  
- 缺失值填补  
- 数据标准化评估  
- 批次校正验证  
- PCA与聚类质控  
- 倍数变化计算  
- 统计检验准备  

### .featureXML - OpenMS特征格式
**描述：** OpenMS检测特征  
**典型数据：** 含质量评分的LC-MS特征  
**应用场景：** OpenMS工作流  
**Python库：**  
- `pyopenms`: 支持FeatureXML  
**EDA方法：**  
- 特征检测参数  
- 单特征质量指标  
- 同位素模式拟合  
- 电荷态分配  
- 半峰宽与峰不对称性  

### .consensusXML - OpenMS共识特征
**描述：** 跨样本关联特征  
**典型数据：** 含分组信息的对齐特征  
**应用场景：** 多样本LC-MS分析  
**Python库：**  
- `pyopenms`: 支持ConsensusXML  
**EDA方法：**  
- 特征对应质量  
- 保留时间对齐  
- 缺失值模式  
- 强度标准化需求  
- 批次间特征一致性  

### .idXML - OpenMS鉴定格式
**描述：** 肽段/代谢物鉴定  
**典型数据：** 含得分的MS/MS鉴定  
**应用场景：** OpenMS鉴定流程  
**Python库：**  
- `pyopenms`: 支持IdXML  
**EDA方法：**  
- 鉴定率  
- 得分分布  
- 谱图匹配质量  
- 错误发现评估  
- 注释转移验证  

## 脂质组学特有格式

### .lcb - LipidCreator批次
**描述：** LipidCreator离子对列表  
**典型数据：** 靶向质谱的脂质离子对  
**应用场景：** 靶向脂质组学  
**Python库：**  
- 导出CSV处理  
**EDA方法：**  
- 脂质类别的离子对覆盖  
- 保留时间预测  
- 碰撞能优化  
- 类别特异性碎片模式  

### .mzTab - 蛋白质组学/代谢组学表格格式
**描述：** PSI表格摘要格式  
**典型数据：** 蛋白质/肽段/代谢物定量  
**应用场景：** 发表与数据共享  
**Python库：**  
- `pyteomics.mztab`  
- `pandas`处理类TSV结构  
**EDA方法：**  
- 数据完整性  
- 元数据段验证  
- 定量方法  
- 鉴定置信度  
- 软件与参数  
- 质量指标摘要  

### .csv (LipidSearch, LipidMatch)
**描述：** 脂质鉴定结果  
**典型数据：** 脂质注释、等级、强度  
**应用场景：** 脂质组学软件输出  
**Python库：**  
- `pandas`: CSV读取  
**EDA方法：**  
- 脂质类别分布  
- 鉴定等级/置信度  
- 脂肪酸组成分析  
- 双键与链长模式  
- 强度相关性  
- 内标标准化  

### .sdf (代谢组学)
**描述：** 代谢物结构数据文件  
**典型数据：** 含性质的化学结构  
**应用场景：** 代谢物数据库构建  
**Python库：**  
- `RDKit`: `Chem.SDMolSupplier('file.sdf')`  
**EDA方法：**  
- 结构验证  
- 性质计算(logP、分子量、TPSA)  
- 分子式一致性  
- 互变异构枚举  
- 保留时间预测特征  

### .mol (代谢组学)
**描述：** 单分子结构文件  
**典型数据：** 代谢物化学结构  
**应用场景：** 基于结构的搜索  
**Python库：**  
- `RDKit`: `Chem.MolFromMolFile('file.mol')`  
**EDA方法：**  
- 结构正确性  
- 立体化学验证  
- 电荷态  
- 隐式氢处理  

## 数据处理与分析

### .h5 / .hdf5 (组学)
**描述：** 大型组学数据集HDF5格式  
**典型数据：** 特征矩阵、谱图、元数据  
**应用场景：** 大规模研究、云计算  
**Python库：**  
- `h5py`: HDF5访问  
- `anndata
