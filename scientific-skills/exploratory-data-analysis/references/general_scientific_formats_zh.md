# 通用科学数据格式参考

本文档涵盖跨学科通用的科学数据格式。

## 数值与数组数据

### .npy - NumPy数组
**描述：** NumPy二进制数组格式  
**典型数据：** 任意数据类型的N维数组  
**应用场景：** 数值数据快速I/O，中间结果存储  
**Python库：**  
- `numpy`：`np.load('file.npy')`，`np.save()`  
- 内存映射访问：`np.load('file.npy', mmap_mode='r')`  
**EDA分析要点：**  
- 数组形状与维度  
- 数据类型与精度  
- 统计摘要（均值、标准差、最小值、最大值、百分位数）  
- 缺失值或无效值（NaN、inf）  
- 内存占用  
- 数值分布与直方图  
- 稀疏性分析  
- 相关结构分析（针对二维数组）  

### .npz - 压缩NumPy归档
**描述：** 多数组单文件存储  
**典型数据：** 关联数组集合  
**应用场景：** 多数组联合存储，压缩存储  
**Python库：**  
- `numpy`：`np.load('file.npz')`返回类字典对象  
- `np.savez()`或`np.savez_compressed()`  
**EDA分析要点：**  
- 包含数组列表  
- 单数组分析  
- 数组间关系  
- 总文件大小与压缩率  
- 命名规范  
- 数据一致性检查  

### .csv - 逗号分隔值
**描述：** 纯文本表格数据  
**典型数据：** 实验测量值，结果表格  
**应用场景：** 通用数据交换，电子表格导出  
**Python库：**  
- `pandas`：`pd.read_csv('file.csv')`  
- `csv`：内置模块  
- `polars`：高性能CSV读取  
- `numpy`：`np.loadtxt()`或`np.genfromtxt()`  
**EDA分析要点：**  
- 行列计数  
- 数据类型推断  
- 缺失值模式与频率  
- 列统计（数值型：均值/标准差；类别型：频次）  
- 异常值检测  
- 相关矩阵  
- 重复行检测  
- 表头与索引验证  
- 编码问题检测  

### .tsv / .tab - 制表符分隔值
**描述：** 制表符分隔表格数据  
**典型数据：** 类CSV格式但以制表符分隔  
**应用场景：** 生物信息学，文本处理输出  
**Python库：**  
- `pandas`：`pd.read_csv('file.tsv', sep='\t')`  
**EDA分析要点：**  
- 同CSV格式  
- 制表符与空格验证  
- 引号处理  

### .xlsx / .xls - Excel电子表格
**描述：** 微软Excel二进制/XML格式  
**典型数据：** 含格式与公式的表格数据  
**应用场景：** 实验记录，数据录入，报告  
**Python库：**  
- `pandas`：`pd.read_excel('file.xlsx')`  
- `openpyxl`：完整Excel文件操作  
- `xlrd`：读取.xls（旧版）  
**EDA分析要点：**  
- 工作表枚举与名称  
- 单工作表数据分析  
- 公式求值  
- 合并单元格处理  
- 隐藏行列  
- 数据验证规则  
- 命名区域  
- 纯格式单元格检测  

### .json - JavaScript对象表示法
**描述：** 层次化文本数据格式  
**典型数据：** 嵌套数据结构，元数据  
**应用场景：** API响应，配置，结果存储  
**Python库：**  
- `json`：内置模块  
- `pandas`：`pd.read_json()`  
- `ujson`：高速JSON解析  
**EDA分析要点：**  
- 模式推断  
- 嵌套深度  
- 键值分布  
- 数组长度  
- 数据类型一致性  
- 缺失键检测  
- 重复项检测  
- 规模与复杂度指标  

### .xml - 可扩展标记语言
**描述：** 层次化标记格式  
**典型数据：** 含元数据的结构化数据  
**应用场景：** 标准化数据交换，API  
**Python库：**  
- `lxml`：`lxml.etree.parse()`  
- `xml.etree.ElementTree`：内置XML解析  
- `xmltodict`：XML转字典  
**EDA分析要点：**  
- 模式/DTD验证  
- 元素层级与深度  
- 命名空间处理  
- 属性与元素内容  
- CDATA区块  
- 文本内容提取  
- 兄弟节点与子节点计数  

### .yaml / .yml - YAML
**描述：** 人类可读数据序列化  
**典型数据：** 配置，元数据，参数  
**应用场景：** 实验配置，流程管道  
**Python库：**  
- `yaml`：`yaml.safe_load()`或`yaml.load()`  
- `ruamel.yaml`：支持YAML 1.2  
**EDA分析要点：**  
- 配置结构  
- 数据类型处理  
- 列表与字典深度  
- 锚点与别名使用  
- 多文档文件  
- 注释保留  
- 模式验证  

### .toml - TOML配置
**描述：** 配置文件格式  
**典型数据：** 设置项，参数  
**应用场景：** Python包配置，参数设置  
**Python库：**  
- `tomli` / `tomllib`：TOML读取（Python 3.11+内置tomllib）  
- `toml`：读写支持  
**EDA分析要点：**  
- 区块结构  
- 键值对  
- 数据类型推断  
- 嵌套表验证  
- 必填与选填字段  

### .ini - INI配置
**描述：** 简易配置格式  
**典型数据：** 应用设置  
**应用场景：** 旧版配置，简单设置  
**Python库：**  
- `configparser`：内置INI解析器  
**EDA分析要点：**  
- 区块枚举  
- 键值提取  
- 类型转换  
- 注释处理  
- 大小写敏感性  

## 二进制与压缩数据

### .hdf5 / .h5 - 层次化数据格式5
**描述：** 大型科学数据集容器  
**典型数据：** 多维数组，元数据，组  
**应用场景：** 大规模数据集，多模态数据，并行I/O  
**Python库：**  
- `h5py`：`h5py.File('file.h5', 'r')`  
- `pytables`：高级HDF5接口  
- `pandas`：通过HDFStore存储  
**EDA分析要点：**  
- 组与数据集层级  
- 数据集形状与数据类型  
- 属性与元数据  
- 压缩与分块策略  
- 内存高效采样  
- 数据集关联性  
- 文件大小与效率  
- 访问模式优化  

### .zarr - 分块数组存储
**描述：** 云优化分块数组  
**典型数据：** 大型N维数组  
**应用场景：** 云存储，并行计算，流处理  
**Python库：**  
- `zarr`：`zarr.open('file.zarr')`  
- `xarray`：支持Zarr后端  
**EDA分析要点：**  
- 数组元数据与维度  
- 分块大小优化  
- 压缩编解码器与比率  
- 同步器与存储类型  
- 多尺度层级  
- 并行访问性能  
- 属性元数据  

### .gz / .gzip - Gzip压缩
**描述：** 压缩数据文件  
**典型数据：** 任意压缩文本或二进制  
**应用场景：** 存储/传输压缩  
**Python库：**  
- `gzip`：内置gzip模块  
- `pandas`：读取函数自动处理gzip  
**EDA分析要点：**  
- 压缩比率  
- 原始文件类型检测  
- 解压验证  
- 头部信息  
- 多成员归档  

### .bz2 - Bzip2压缩
**描述：** Bzip2压缩格式  
**典型数据：** 高压缩率文件  
**应用场景：** 优于gzip的压缩率  
**Python库：**  
- `bz2`：内置bz2模块  
- pandas自动处理  
**EDA分析要点：**  
- 压缩效率  
- 解压时间  
- 内容验证  

### .zip - ZIP归档
**描述：** 多文件归档  
**典型数据：** 文件集合  
**应用场景：** 文件分发，归档  
**Python库：**  
- `zipfile`：内置ZIP支持  
- `pandas`：可读取压缩CSV  
**EDA分析要点：**  
- 归档成员列表  
- 单文件压缩方法  
- 总大小与压缩大小  
- 目录结构  
- 文件类型分布  
- 解压验证  

### .tar / .tar.gz - TAR归档
**描述：** Unix磁带归档  
**典型数据：** 多文件与目录  
**应用场景：** 软件分发，备份  
**Python库：**  
- `tarfile`：内置TAR支持  
**EDA分析要点：**  
- 成员文件列表  
- 压缩类型（如.tar.gz, .tar.bz2）  
- 目录结构  
- 权限保留  
- 解压测试  

## 时间序列与波形数据

### .wav - 波形音频
**描述：** 音频波形数据  
**典型数据：** 声学信号，录音  
**应用场景：** 声学分析，超声波，信号处理  
**Python库：**  
- `scipy.io.wavfile`：`scipy.io.wavfile.read()`  
- `wave`：内置模块  
- `soundfile`：增强音频I/O  
**EDA分析要点：**  
- 采样率与时长  
- 位深度与声道  
- 振幅分布  
- 频谱分析（FFT）  
- 信噪比  
- 削波检测  
- 频率成分  

### .mat - MATLAB数据
**描述：** MATLAB工作区变量  
**典型数据：** 数组，结构体，元胞  
**应用场景：** MATLAB-Python互操作  
**Python库：**  
- `scipy.io`：`scipy.io.loadmat()`  
- `h5py`：处理MATLAB v7.3文件（基于HDF5）  
- `mat73`：纯Python处理v7.3  
**EDA分析要点：**  
- 变量名与类型  
- 数组维度  
- 结构体字段探查  
- 元胞数组处理  
- 稀疏矩阵检测  
- MATLAB版本兼容性  
- 元数据提取  

### .edf - 欧洲数据格式
**描述：** 时间序列数据（尤用于医疗）  
**典型数据：** EEG，生理信号  
**应用场景：** 医疗信号存储  
**Python库：**  
- `pyedflib`：EDF/EDF+读写  
- `mne`：神经生理数据（支持EDF）  
**EDA分析要点：**  
- 信号数量与名称  
- 采样频率  
- 信号范围与单位  
- 记录时长  
- 标注事件  
- 数据质量（饱和，噪声）  
- 患者/研究信息  

### .csv (时间序列)
**描述：** 含时间戳列的CSV  
**典型数据：** 时间索引测量值  
**应用场景：** 传感器数据，监测，实验  
**Python库：**  
- `pandas`：`pd.read_csv()`配合`parse_dates`  
**EDA分析要点：**  
- 时间范围与分辨率  
- 采样规律性  
- 缺失时间点  
- 趋势与季节性  
- 平稳性检验  
- 自相关性  
- 异常检测  

## 地理空间与环境数据

### .shp - 形状文件
**描述：** 地理空间矢量数据  
**典型数据：** 地理要素（点，线，面）  
**应用场景：** GIS分析，空间数据  
**Python库：**  
- `geopandas`：`gpd.read_file('file.shp')`  
- `fiona`：底层形状文件访问  
- `pyshp`：纯Python读取器  
**EDA分析要点：**  
- 几何类型与数量  
- 坐标参考系  
- 边界框  
- 属性表分析  
- 几何有效性  
- 空间分布  
- 多部件要素  
- 关联文件（.shx, .dbf, .prj）  

### .geojson - GeoJSON
**描述：** 地理数据JSON格式  
**典型数据：** 含几何与属性的要素  
**应用场景：** 网络地图，空间分析  
**Python库：**  
- `geopandas`：原生支持  
- `json`：解析为JSON后处理  
**EDA分析要点：**  
- 要素数量与类型  
- CRS规范  
- 边界框计算  
- 属性模式  
- 几何复杂度  
- 嵌套结构  

### .tif / .tiff (地理空间)
**描述：** 含空间参考的GeoTIFF  
**典型数据：** 卫星影像，DEM，栅格  
**应用场景：** 遥感，地形分析  
**Python库：**  
- `rasterio`：`rasterio.open('file.tif')`  
- `gdal`：地理空间数据抽象库  
- `xarray`配合`rioxarray`：N维地理空间数组  
**EDA分析要点：**  
- 栅格尺寸与分辨率  
- 波段数量与描述  
- 坐标参考系  
- 地理变换参数  
- NoData值处理  
- 像素值分布  
- 直方图分析  
- 概览图与金字塔  

### .nc / .netcdf - 网络通用数据格式
**描述：** 自描述型数组数据  
**典型数据：** 气候，大气，海洋数据  
**应用场景：** 科学数据集，模型输出  
**Python库：**  
- `netCDF4`：`netCDF4.Dataset('file.nc')`  
- `xarray`：`xr.open_dataset('file.nc')`  
**EDA分析要点：**  
- 变量枚举  
- 维度分析  
- 时间序列属性  
- 空间覆盖  
- 属性元数据（CF规范）  
- 坐标系  
- 分块与压缩  
- 数据质量标志  

### .grib / .grib2 - 网格二进制
**描述：** 气象数据格式  
**典型数据：** 天气预报，气候数据  
**应用场景：** 数值天气预报  
**Python库：**  
- `pygrib`：GRIB文件读取  
- `xarray`配合`cfgrib`：GRIB转xarray  
**EDA分析要点：**  
- 消息清单  
- 参数与层级类型  
- 空间网格规范  
- 时间覆盖  
- 集合成员  
- 预报与分析  
- 数据打包与精度  

### .hdf4 - HDF4格式
**描述：** 旧版HDF格式  
**典型数据：** NASA地球科学数据  
**应用场景：** 卫星数据（MODIS等）  
**Python库：**  
- `pyhdf`：HDF4访问  
- `gdal`：支持读取  
**EDA分析要点：**  
- 科学数据集列表  
- Vdata与属性  
- 维度标度  
- 元数据提取  
- 质量标志  
- 转HDF5或NetCDF  

## 专业科学格式

### .fits - 灵活图像传输系统
**描述：** 天文数据格式  
**典型数据：** 望远镜图像，表格，光谱  
**应用场景：** 天文观测  
**Python库：**  
- `astropy.io.fits`：`fits.open('file.fits')`  
- `fitsio`：替代库  
**EDA分析要点：**  
- HDU（头数据单元）结构  
- 图像尺寸与WCS  
- 头关键字分析  
- 表格列描述  
- 数据类型与缩放  
- FITS规范符合性  
- 校验和验证  

### .asdf - 高级科学数据格式
**描述：** 新一代天文数据格式  
**典型数据：** 复杂层次化科学数据  
**应用场景：** 詹姆斯·韦伯太空望远镜数据  
**Python库：**  
- `asdf`：`asdf.open('file.asdf')
