# Stable Baselines3 算法参考指南

本文详细介绍了 Stable Baselines3 中所有强化学习算法的特性，帮助用户针对特定任务选择合适的算法。

## 算法对比表

| 算法 | 类型 | 动作空间 | 采样效率 | 训练速度 | 适用场景 |
|-----------|------|--------------|-------------------|----------------|----------|
| **PPO** | 同策略 | 全部 | 中等 | 快 | 通用场景，稳定性高 |
| **A2C** | 同策略 | 全部 | 低 | 极快 | 快速原型开发，多进程处理 |
| **SAC** | 异策略 | 连续 | 高 | 中等 | 连续控制，采样高效 |
| **TD3** | 异策略 | 连续 | 高 | 中等 | 连续控制，确定性策略 |
| **DDPG** | 异策略 | 连续 | 高 | 中等 | 连续控制（建议改用 TD3） |
| **DQN** | 异策略 | 离散 | 中等 | 中等 | 离散动作，Atari 游戏 |
| **HER** | 异策略 | 全部 | 极高 | 中等 | 目标导向型任务 |
| **RecurrentPPO** | 同策略 | 全部 | 中等 | 慢 | 部分可观测环境 (POMDP) |

## 详细算法特性

### PPO (近端策略优化)

**概述：** 通用型同策略算法，在多种任务中表现优异。

**优势：**
- 训练稳定可靠
- 支持所有动作空间类型（离散、连续、多维离散、多维二元）
- 采样效率与训练速度平衡良好
- 在向量化环境中支持多进程并行
- 超参数易于调节

**劣势：**
- 采样效率低于异策略方法
- 需要大量环境交互

**最佳适用场景：**
- 通用强化学习任务
- 稳定性要求高的场景
- 环境模拟成本低的场景
- 连续或离散动作任务

**超参数指南：**
- `n_steps`：连续任务 2048-4096，Atari 任务 128-256
- `learning_rate`：默认推荐 3e-4
- `n_epochs`：连续任务 10，Atari 任务 4
- `batch_size`：64
- `gamma`：0.99（长序列任务建议 0.995-0.999）

### A2C (优势演员-评论家)

**概述：** A3C 的同步变体，比 PPO 简单但稳定性较低。

**优势：**
- 训练速度极快（比 PPO 更简单）
- 支持所有动作空间类型
- 适合快速原型开发
- 内存效率高

**劣势：**
- 稳定性低于 PPO
- 需要精细调节超参数
- 采样效率较低

**最佳适用场景：**
- 快速实验验证
- 训练速度优先的场景
- 简单环境任务

**超参数指南：**
- `n_steps`：根据任务在 5-256 间选择
- `learning_rate`：7e-4
- `gamma`：0.99

### SAC (柔性演员-评论家)

**概述：** 带熵正则化的异策略算法，在连续控制领域达到顶尖水平。

**优势：**
- 卓越的采样效率
- 训练过程非常稳定
- 自动熵调节机制
- 通过随机策略实现良好探索
- 机器人控制领域领先

**劣势：**
- 仅支持连续动作空间（Box）
- 实际训练时间高于同策略方法
- 超参数更复杂

**最佳适用场景：**
- 连续控制（机器人、物理仿真）
- 采样效率优先的场景
- 环境模拟成本高的场景
- 需要良好探索能力的任务

**超参数指南：**
- `learning_rate`：3e-4
- `buffer_size`：多数任务推荐 1M
- `learning_starts`：10000
- `batch_size`：256
- `tau`：0.005（目标网络更新率）
- `train_freq`：设为 1 且 `gradient_steps=-1` 可获得最佳性能

### TD3 (双延迟深度确定性策略梯度)

**概述：** DDPG 的改进版，采用双 Q 学习和延迟策略更新。

**优势：**
- 高采样效率
- 确定性策略（适合部署）
- 比 DDPG 更稳定
- 擅长连续控制任务

**劣势：**
- 仅支持连续动作空间（Box）
- 探索能力弱于 SAC
- 需要精细调节超参数

**最佳适用场景：**
- 连续控制任务
- 偏好确定性策略的场景
- 采样效率优先的学习任务

**超参数指南：**
- `learning_rate`：1e-3
- `buffer_size`：1M
- `learning_starts`：10000
- `batch_size`：100
- `policy_delay`：2（每 2 次评论家更新后更新策略）

### DDPG (深度确定性策略梯度)

**概述：** 早期的异策略连续控制算法。

**优势：**
- 支持连续动作空间
- 异策略学习机制

**劣势：**
- 稳定性低于 TD3 或 SAC
- 对超参数敏感
- 通常被 TD3 超越

**最佳适用场景：**
- 旧版兼容场景
- **建议：** 新项目请改用 TD3

### DQN (深度 Q 网络)

**概述：** 经典的异策略算法，适用于离散动作空间。

**优势：**
- 离散动作任务中采样效率高
- 经验回放机制可复用历史数据
- 在 Atari 游戏中验证成功

**劣势：**
- 仅支持离散动作空间
- 未经调优可能不稳定
- 存在高估偏差

**最佳适用场景：**
- 离散动作任务
- Atari 游戏及类似环境
- 采样效率优先的场景

**超参数指南：**
- `learning_rate`：1e-4
- `buffer_size`：根据任务在 100K-1M 间选择
- `learning_starts`：Atari 任务建议 50000
- `batch_size`：32
- `exploration_fraction`：0.1
- `exploration_final_eps`：0.05

**变体：**
- **QR-DQN**：分布强化学习版本，提升价值估计精度
- **Maskable DQN**：支持动作屏蔽的环境

### HER (事后经验回放)

**概述：** 非独立算法，是针对目标导向型任务设计的回放缓冲策略。

**优势：**
- 显著改善稀疏奖励场景的学习效果
- 通过目标重标记从失败中学习
- 兼容所有异策略算法（SAC、TD3、DQN）

**劣势：**
- 仅适用于目标导向型环境
- 需特定观测结构（包含"observation"、"achieved_goal"、"desired_goal"的字典）

**最佳适用场景：**
- 目标导向型任务（机器人操作、导航）
- 稀疏奖励环境
- 目标明确但奖励二元化的任务

**用法示例：**
```python
from stable_baselines3 import SAC, HerReplayBuffer

model = SAC(
    "MultiInputPolicy",
    env,
    replay_buffer_class=HerReplayBuffer,
    replay_buffer_kwargs=dict(
        n_sampled_goal=4,
        goal_selection_strategy="future",  # 可选 "episode" 或 "final"
    ),
)
```

### RecurrentPPO

**概述：** 带 LSTM 策略的 PPO，用于处理部分可观测性。

**优势：**
- 处理部分可观测环境 (POMDP)
- 可学习时序依赖关系
- 适合需要记忆能力的任务

**劣势：**
- 训练速度慢于标准 PPO
- 超参数调节更复杂
- 需要序列化数据

**最佳适用场景：**
- 部分可观测环境
- 需记忆能力的任务（如无完整地图的导航）
- 时间序列问题

## 算法选择指南

### 决策树

1. **动作空间类型？**
   - **连续 (Box)** → 考虑 PPO、SAC 或 TD3
   - **离散** → 考虑 PPO、A2C 或 DQN
   - **多维离散/多维二元** → 使用 PPO 或 A2C

2. **采样效率是否关键？**
   - **是（环境模拟成本高）** → 使用异策略：SAC、TD3、DQN 或 HER
   - **否（环境模拟成本低）** → 使用同策略：PPO、A2C

3. **是否需要快速训练？**
   - **是** → 使用带向量化环境的 PPO 或 A2C
   - **否** → 所有算法均可

4. **是否目标导向型稀疏奖励任务？**
   - **是** → 使用 SAC/TD3 + HER
   - **否** → 继续选择标准算法

5. **环境是否部分可观测？**
   - **是** → 使用 RecurrentPPO
   - **否** → 使用标准算法

### 快速推荐

- **入门/通用任务：** PPO
- **连续控制/机器人：** SAC
- **离散动作/Atari：** DQN 或 PPO
- **目标导向/稀疏奖励：** SAC + HER
- **快速原型开发：** A2C
- **采样效率优先：** SAC、TD3 或 DQN
- **部分可观测环境：** RecurrentPPO

## 训练配置技巧

### 同策略算法 (PPO, A2C)

```python
# 使用向量化环境加速训练
env = make_vec_env(env_id, n_envs=8, vec_env_cls=SubprocVecEnv)

model = PPO(
    "MlpPolicy",
    env,
    n_steps=2048,  # 每次更新前每个环境收集的步数
    batch_size=64,
    n_epochs=10,
    learning_rate=3e-4,
    gamma=0.99,
)
```

### 异策略算法 (SAC, TD3, DQN)

```python
# 减少并行环境数量，但设置 gradient_steps=-1 提升效率
env = make_vec_env(env_id, n_envs=4)

model = SAC(
    "MlpPolicy",
    env,
    buffer_size=1_000_000,
    learning_starts=10000,
    batch_size=256,
    train_freq=1,
    gradient_steps=-1,  # 每环境步执行梯度更新（4个环境则为4次）
    learning_rate=3e-4,
)
```

## 常见陷阱

1. **在连续动作空间使用 DQN** - DQN 仅适用于离散动作
2. **未在 PPO/A2C 中使用向量化环境** - 浪费加速潜力
3. **并行环境数量不足** - 同策略方法需要大量样本
4. **回放缓冲区过大** - 可能导致内存问题
5. **忽略学习率调节** - 对训练稳定性至关重要
6. **未进行奖励缩放** - 标准化奖励可提升学习效果
7. **策略类型选择错误** - 图像任务用 "CnnPolicy"，字典观测用 "MultiInputPolicy"

## 性能基准测试

常见基准测试的预期性能（平均奖励）参考：

### 连续控制 (MuJoCo)
- **HalfCheetah-v3**：PPO ~1800, SAC ~12000, TD3 ~9500
- **Hopper-v3**：PPO ~2500, SAC ~3600, TD3 ~3600
- **Walker2d-v3**：PPO ~3000, SAC ~5500, TD3 ~5000

### 离散控制 (Atari)
- **Breakout**：PPO ~400, DQN ~300
- **Pong**：PPO ~20, DQN ~20
- **Space Invaders**：PPO ~1000, DQN ~800

*注：实际性能因超参数和训练时长存在显著差异*
