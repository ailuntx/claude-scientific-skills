# RDKit 常用 SMARTS 模式

本文档收集了 RDKit 中用于子结构搜索的常用 SMARTS 模式。

## 功能基团

### 醇类

```python
# 伯醇
'[CH2][OH1]'

# 仲醇
'[CH1]([OH1])[CH3,CH2]'

# 叔醇
'[C]([OH1])([C])([C])[C]'

# 任意醇
'[OH1][C]'

# 苯酚
'c[OH1]'
```

### 醛类和酮类

```python
# 醛
'[CH1](=O)'

# 酮
'[C](=O)[C]'

# 任意羰基
'[C](=O)'
```

### 羧酸及其衍生物

```python
# 羧酸
'C(=O)[OH1]'
'[CX3](=O)[OX2H1]'  # 更精确

# 酯
'C(=O)O[C]'
'[CX3](=O)[OX2][C]'  # 更精确

# 酰胺
'C(=O)N'
'[CX3](=O)[NX3]'  # 更精确

# 酰氯
'C(=O)Cl'

# 酸酐
'C(=O)OC(=O)'
```

### 胺类

```python
# 伯胺
'[NH2][C]'

# 仲胺
'[NH1]([C])[C]'

# 叔胺
'[N]([C])([C])[C]'

# 芳香胺（苯胺）
'c[NH2]'

# 任意胺
'[NX3]'
```

### 醚类

```python
# 脂肪醚
'[C][O][C]'

# 芳香醚
'c[O][C,c]'
```

### 卤化物

```python

'[C][F,Cl,Br,I]'

# 芳基卤
'c[F,Cl,Br,I]'

# 特定卤化物
'[C]F'  # 氟化物
'[C]Cl'  # 氯化物
'[C]Br'  # 溴化物
'[C]I'  # 碘化物
```

### 腈类和硝基

```python

'C#N'

# 硝基
'[N+](=O)[O-]'

# 芳香硝基
'c[N+](=O)[O-]'
```

### 硫醇和硫醚

```python
# 硫醇
'[C][SH1]'

# 硫醚
'[C][S][C]'

# 二硫化物
'[C][S][S][C]'

# 亚砜

# 砜
```

## 使用示例

```python
from rdkit import Chem

# 创建SMARTS查询
pattern = Chem.MolFromSmarts('[CH2][OH1]')  # 伯醇

# 分子搜索
mol = Chem.MolFromSmiles('CCO')
matches = mol.GetSubstructMatches(pattern)

# 多模式查询
patterns = {
    'alcohol': '[OH1][C]',
    'amine': '[NH2,NH1][C]',
    'carboxylic_acid': 'C(=O)[OH1]'
}

# 功能基团检测
for name, smarts in patterns.items():
    query = Chem.MolFromSmarts(smarts)
    if mol.HasSubstructMatch(query):
        print(f"Found {name}")
```

## SMARTS编写技巧

1. **必要时精确指定**：使用原子属性[CX3]而非单纯[C]
2. **使用括号增强可读性**：[C]与C（芳香碳）不同
3. **考虑芳香性**：小写字母(c,n,o)表示芳香原子
4. **检查环归属**：[R]表示在环内，[!R]表示不在环内
5. **使用递归SMARTS**：$(...)处理复杂模式
6. **测试模式**：始终在已知分子上验证SMARTS
7. **从简单开始**：逐步构建复杂模式

## 常用SMARTS语法

- `[C]` - 脂肪碳
- `[c]` - 芳香碳
- `[CX4]` - 四连接碳（sp3）
- `[CX3]` - 三连接碳（sp2）
- `[CX2]` - 二连接碳（sp）
- `[CH3]` - 甲基
- `[R]` - 在环内
- `[r6]` - 在六元环内
- `[r{5-7}]` - 在五/六/七元环内
- `[D2]` - 度数为2（两个邻接原子）
- `[+]` - 正电荷
- `[-]` - 负电荷
- `[!C]` - 非碳原子
- `[#6]` - 原子序数为6的元素（碳）
- `~` - 任意键类型
- `-` - 单键
- `=` - 双键
- `#` - 三键
- `:` - 芳香键
- `@` - 顺时针手性
- `@@` - 逆时针手性
