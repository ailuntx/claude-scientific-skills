# 无细胞蛋白质表达优化

**网址：** https://cloud.ginkgo.bio/protocols/cell-free-protein-expression-optimization  
**状态：** Ginkgo认证  
**价格：** $199/样本（默认：1个蛋白质×3个重复=3个样本，共597美元）  
**交付周期：** 6-11天  

## 概述  

采用实验设计（DoE）方法，在专有的重构大肠杆菌转录-翻译系统中表达蛋白质靶标。每个构建体在多达24种反应条件下进行评估，包括靶标特异性添加剂（如分子伴侣、二硫键增强剂和辅因子）。专为难以表达的蛋白质设计，包括膜蛋白以及需要二硫键或辅因子的靶标。  

## 输入  

- **DNA序列**（`.fasta`格式）  

## 输出  

- **比较产量：** 所有测试变量（裂解液、温度、添加剂）的滴度数据图谱  
- **纯度分析：** 目标蛋白与背景杂质的对比，寻找最高质量产量  
- **最佳条件：** 叠加电泳图精确定位特定序列的最优配方  

## 自动化工作流程  

### 阶段1 - 试剂准备  

1. 从4°C取出板  
2. 室温解冻  
3. PBS回填  

### 阶段2 - CFPS反应设置与孵育  

1. 从4°C取出板  
2. 分配裂解液  
3. 质控板读数  
4. 孵育（振荡或静置，依条件而定）  

### 阶段3 - 定量准备与读数  

1. 分配PBS  
2. 拆封板  
3. LabChip定量分析  
4. 密封板  
5. 4°C储存  

## 实验参数  

- 有效载荷与试剂  
- Bravo Stamp  
- HiG离心机  
- 孵育与储存  

## 优化变量  

实验设计矩阵可为每个蛋白质设置多达24种条件，变量包括：  

- **裂解液成分**（不同大肠杆菌提取物配方）  
- **温度**（孵育温度曲线）  
- **添加剂：**  
  - 分子伴侣（针对折叠困难的靶标）  
  - 二硫键增强剂（针对需要二硫键桥的靶标）  
  - 辅因子（金属离子、辅酶、辅基）  
  - 其他靶标特异性补充剂
