# 研究查询技能

本技能通过OpenRouter使用Perplexity的Sonar Pro搜索模型提供实时研究信息查询服务。

## 设置步骤

1. **获取OpenRouter API密钥：**
   - 访问 [openrouter.ai](https://openrouter.ai)
   - 创建账户并生成API密钥
   - 为账户充值额度

2. **配置环境变量：**
   ```bash
   export OPENROUTER_API_KEY="your_api_key_here"
   ```

3. **测试配置：**
   ```bash
   python scripts/research_lookup.py --model-info
   ```

## 使用指南

### 命令行用法

```bash
# 单次研究查询
python scripts/research_lookup.py "2024年CRISPR基因编辑最新进展"

# 批量查询（带延迟）
python scripts/research_lookup.py --batch "CRISPR应用" "基因治疗临床试验" "伦理考量"

# Claude代码集成（自动调用）
python lookup.py "您的研究查询内容"
```

### Claude代码集成

当您执行以下操作时，研究查询工具会自动启用：

1. **提出研究问题：** "调研量子计算最新进展"
2. **请求文献综述：** "查找关于气候变化影响的当前研究"
3. **需要文献引用：** "关于transformer注意力机制的最新论文有哪些？"
4. **获取技术信息：** "流式细胞术标准操作流程"

## 核心功能

- **学术导向：** 优先检索同行评审论文和权威来源
- **时效信息：** 聚焦近期出版物（2020-2024年）
- **完整引用：** 提供含DOI的完整文献信息
- **多格式支持：** 适配各类查询需求
- **深度搜索：** 始终采用高搜索上下文进行深入全面研究
- **质量优先：** 自动优选顶级会议的高被引论文
- **成本效益：** 单次查询成本约$0.01-0.05

## 论文质量优先级

本技能**始终优先选择高影响力论文**而非冷门出版物，排序依据：

### 引用量分级

| 论文年限 | 引用阈值 | 分类等级 |
|-----------|-------------------|----------------|
| 0-3年 | 20+ 引用 | 值得关注 |
| 0-3年 | 100+ 引用 | 高影响力 |
| 3-7年 | 100+ 引用 | 重要成果 |
| 3-7年 | 500+ 引用 | 里程碑 |
| 7年以上 | 500+ 引用 | 开创性 |
| 7年以上 | 1000+ 引用 | 奠基性 |

### 期刊质量分级

优先选择高等级期刊论文：

- **一级（最高优先级）：** Nature, Science, Cell, NEJM, Lancet, JAMA, PNAS, Nature Medicine, Nature Biotechnology
- **二级（高优先级）：** 高影响因子期刊(IF>10)，顶级会议（ML/AI领域的NeurIPS, ICML, ICLR）
- **三级（优质）：** 专业权威期刊(IF 5-10)
- **四级（谨慎使用）：** 其他同行评审来源

### 作者声誉

优先选择：
- 高h指数的资深研究者
- 知名机构的成熟研究团队
- 在顶级期刊多次发表论文的作者
- 获专业认可的研究者（获奖经历/编委职务）

### 相关性优先级

1. 直接解决研究问题的论文
2. 提供适用方法/数据的论文
3. 仅限顶级期刊或高被引的间接相关论文

## 响应格式

每项研究结果包含：
- **摘要：** 关键发现概述
- **核心研究：** 3-5篇最相关近期论文
- **引用信息：** 完整文献数据
- **使用统计：** 用于成本追踪的token用量
- **时间戳：** 研究执行时间

## 科研写作集成

本技能通过以下方式提升科研写作：
1. **文献综述：** 为引言部分提供最新研究
2. **方法验证：** 对照现行标准验证实验流程
3. **结果背景：** 与近期同类研究对比发现
4. **讨论支持：** 为论点提供最新证据
5. **文献管理：** 规范格式的参考文献

## 故障排除

**"未找到API密钥"**
- 确认已设置`OPENROUTER_API_KEY`环境变量
- 检查OpenRouter账户余额

**"模型不可用"**
- 验证API密钥是否具有Perplexity模型权限
- 查看OpenRouter服务状态页

**"超出速率限制"**
- 使用`--delay`参数添加请求间隔
- 检查账户限额设置

**"无相关结果"**
- 尝试更具体或更宽泛的查询
- 添加时间范围（如"2023-2024"）
- 使用学术关键词和技术术语

## 成本管理

- 通过OpenRouter仪表盘监控使用情况
- 典型成本：$0.01-0.05/次查询
- 支持批量查询处理
- 优化查询精度可降低token消耗

本技能专为学术研究设计，通过提供高质量、可溯源的引用信息，有效支持科研写作与研究活动。
