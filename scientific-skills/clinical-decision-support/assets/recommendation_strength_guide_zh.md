# 推荐强度指南

## 临床推荐的GRADE框架

### 推荐构成要素

每项临床推荐应包含：

1. **人群**：干预措施适用于哪些人群？
2. **干预**：具体的治疗/行动是什么？
3. **对照**：与何种替代方案比较？
4. **结局**：预期结果是什么？
5. **强度**：推荐强度如何？
6. **证据质量**：对证据的置信度如何？

### 推荐强度（1级 vs 2级）

#### 强推荐（1级）

**适用情形**：
- 获益明显大于风险（或反之）
- 高质量或中等质量证据
- 价值观与偏好：预期变异性小
- 资源影响：成本效益高或成本考量次要

**措辞**："我们推荐..." 或 "临床医生应..."

**含义**：
- 大多数患者应接受推荐干预
- 遵循推荐可成为质量指标
- 政策制定者可将其作为绩效衡量标准

**示例**：

```
强烈推荐（1级）：

"我们推荐奥希替尼80mg每日一次作为携带EGFR外显子19缺失或L858R突变的晚期NSCLC成人患者的一线治疗（强推荐，高质量证据 - GRADE 1A）。"

依据：
- 显著PFS获益：18.9 vs 10.2个月（HR 0.46, p<0.001）
- OS获益：38.6 vs 31.8个月（HR 0.80, p=0.046）  
- 耐受性更佳：3-4级不良事件发生率更低
- 证据：高质量（大型RCT，低偏倚风险）
- 获益明确大于风险
```

```
强烈反对（1级）：

"我们反对在新诊断胶质母细胞瘤一线治疗中使用贝伐珠单抗改善总生存期（强烈反对，高质量证据 - GRADE 1A）。"

依据：
- 无OS获益：HR 0.88 (0.76-1.02), p=0.10 (AVAglio试验)
- 毒性：≥3级不良事件增加（66% vs 52%）
- 证据：高质量（两项大型3期RCT）
- 风险大于生存获益缺失
```

#### 条件性/弱推荐（2级）

**适用情形**：
- 获益与风险接近平衡
- 低质量或极低质量证据
- 价值观与偏好：存在显著变异性
- 资源影响：成本高昂或可及性有限

**措辞**："我们建议..." 或 "临床医生可考虑..."

**含义**：
- 不同患者适用不同选择
- 共同决策至关重要
- 政策制定需充分讨论和利益相关方参与

**示例**：

```
条件性推荐（2级）：

"对于一线铂类-培美曲塞化疗后未进展的晚期非鳞状NSCLC患者，我们建议考虑培美曲塞维持治疗（条件性推荐，中等质量证据 - GRADE 2B）。"

依据：
- 有限PFS获益：4.0 vs 2.0个月（HR 0.62）
- 无OS获益：13.9 vs 11.0个月（HR 0.79, p=0.23）
- 毒性：持续化疗负担
- 生活质量：症状控制与治疗副作用的权衡
- 患者价值观：部分重视治疗间歇期，部分重视疾病控制
- 共同决策至关重要
```

```
条件性推荐 - 两种方案均可接受（2级）：

"根据患者偏好和临床因素，我们建议PD-L1≥50% NSCLC患者一线治疗可选择帕博利珠单抗单药或帕博利珠单抗联合铂类双药化疗（条件性推荐，高质量证据 - GRADE 2A）。"

依据：
- 两种方案均为NCCN 1类优选
- 单药：毒性更低，口服vs静脉，生活质量更佳
- 联合：更高ORR（48% vs 39%），PFS数值更长
- OS：策略间相似
- 患者价值观：差异显著（耐受性vs缓解率优先级）
```

### 证据质量（⊕⊕⊕⊕ 至 ⊕○○○）

#### 高质量（⊕⊕⊕⊕）

- 进一步研究极不可能改变效应估计值的置信度
- 设计良好的RCT结果一致
- 无严重局限性
- 直接证据（目标人群、干预措施、结局指标）
- 精确估计（窄置信区间）

**示例**：奥希替尼治疗EGFR+ NSCLC的FLAURA试验——大型RCT、结果一致、低偏倚风险、直接结局指标

#### 中等质量（⊕⊕⊕○）

- 进一步研究可能影响置信度并改变估计值
- 存在某些局限性的RCT或观察性研究的极强证据
- 存在不一致性、间接性、不精确性或发表偏倚

**示例**：存在某些局限性的单项RCT，或存在中度异质性的多项RCT

#### 低质量（⊕⊕○○）

- 进一步研究极可能显著影响效应估计值的置信度
- 观察性研究或存在严重局限性的RCT
- 存在严重的一致性、直接性、精确性或偏倚问题

**示例**：实施良好的队列研究，或存在高失访率和分配隐藏不明的RCT

#### 极低质量（⊕○○○）

- 效应估计值极不确定
- 病例系列、专家意见、机制推理
- 存在非常严重的局限性

**示例**：回顾性病例系列，未经系统评价的专家共识

## 强度与证据质量的组合

### 全部九种可能组合

| 证据质量 | 强烈支持 (↑↑) | 弱支持 (↑) | 强烈反对 (↓↓) | 弱反对 (↓) |
|----------|---------------|-------------|----------------|--------------|
| **高质量 (⊕⊕⊕⊕)** | 1A级 | 2A级 | 1A级（反对） | 2A级（反对） |
| **中等质量 (⊕⊕⊕○)** | 1B级 | 2B级 | 1B级（反对） | 2B级（反对） |
| **低质量 (⊕⊕○○)** | 1C级* | 2C级 | 1C级（反对）* | 2C级（反对） |
| **极低质量 (⊕○○○)** | 1D级* | 2D级 | 1D级（反对）* | 2D级（反对） |

*罕见：强推荐通常至少需要中等质量证据

### 特殊组合（出现情形）

**强推荐伴低质量证据（1C级）**

罕见，但可能出现在：
- 观察性数据效应量极大（RR >5 或 <0.2）
- 证据质量低但获益-风险平衡明确
- 示例：房颤抗凝治疗（RCT前，强观察性数据）

**弱推荐伴高质量证据（2A级）**

出现在：
- 获益与风险接近平衡
- 患者价值观高度可变
- 示例：低风险人群阿司匹林一级预防（获益微小，出血风险存在，患者价值观各异）

## 措辞模板

### 强推荐

**支持 (↑↑)**：
- "我们推荐对[人群]采用[干预措施]"
- "临床医生应[行动]"
- "推荐使用[干预措施]"

**反对 (↓↓)**：
- "我们反对对[人群]采用[干预措施]"
- "临床医生不应[行动]"
- "不推荐使用[干预措施]"

### 条件性/弱推荐

**支持 (↑)**：
- "我们建议对[人群]采用[干预措施]"
- "临床医生可考虑[行动]"
- "[干预措施]可考虑用于特定患者"

**反对 (↓)**：
- "我们建议不对[人群]使用[干预措施]"
- "临床医生可避免[行动]"
- "通常不推荐使用[干预措施]"

**均可接受**：
- "我们建议根据患者偏好选择[方案A]或[方案B]"
- "两种方法均合理"

## 可视化文档的颜色编码

**强推荐（绿色背景）**：
- RGB(0, 153, 76) 或 #009954
- 清晰视觉优先级
- 用于1A、1B级

**条件性推荐（黄色背景）**：
- RGB(255, 193, 7) 或 #FFC107
- 需讨论提示
- 用于2A、2B、2C级

**研究性方案（蓝色背景）**：
- RGB(33, 150, 243) 或 #2196F3
- 临床试验考量
- 标准治疗证据不足

**不推荐（红色边框/背景）**：
- RGB(220, 20, 60) 或 #DC143C
- 强烈反对推荐
- 存在伤害或无获益证据

## 常见场景

### 场景1：强证据，明确获益-风险平衡

**示例**：帕博利珠单抗治疗PD-L1≥50% NSCLC

- 证据：大型3期RCT（KEYNOTE-024），n=305，设计良好
- 结果：PFS HR 0.50 (0.37-0.68)，OS HR 0.60 (0.41-0.89)
- 毒性：较化疗更低3-5级不良事件（27% vs 53%）
- 患者价值观：多数优先考虑疗效和耐受性

**推荐**：强烈支持（1A级）

### 场景2：中等证据，平衡性权衡

**示例**：已切除黑色素瘤的辅助免疫治疗

- 证据：RCT显示无复发生存获益，OS数据未成熟
- 结果：复发风险降低但存在持续毒性
- 毒性：需类固醇治疗的免疫相关不良事件（部分严重）
- 成本：12个月治疗年费用高昂
- 患者价值观：多变（部分优先预防复发，部分规避毒性）

**推荐**：条件性支持（2B级）

### 场景3：低证据，但后果严重

**示例**：人工心脏瓣膜抗凝治疗

- 证据：无RCT（不符合伦理），观察性数据和机制推理
- 后果：未抗凝时血栓栓塞风险极高
- 获益-风险：尽管证据质量低但关系明确

**推荐**：强烈支持（1C级）

### 场景4：高质量证据，但患者偏好各异

**示例**：乳房切除术后重建

- 证据：结局和满意度的高质量数据
- 权衡：美容获益与额外手术、恢复时间的取舍
- 价值观：高度个性化决策，偏好差异大

**推荐**：条件性（2A级）- 讨论选项，患者决定

## 质量核查清单

最终确定推荐前需验证：

- [ ] 推荐声明清晰且可操作
- [ ] 明确标注强度（强/条件性）
- [ ] 证据质量分级（高/中/低/极低）
- [ ] 提供GRADE标注（1A,1B,2A,2B,2C）
- [ ] 引用具体研究结果的证据
- [ ] 量化获益（效应量及CI）
- [ ] 量化风险（不良事件发生率）
- [ ] 解释获益/风险平衡
- [ ] 考虑患者价值观（条件性推荐时）
- [ ] 提及替代方案
- [ ] 记录指南一致性
- [ ] 说明特殊人群（老年、肾/肝功能不全）
- [ ] 明确监测要求
