# 生物标志物分类与解读指南

## 概述

生物标志物是可测量的生物状态或状况指标。在临床决策支持中，生物标志物指导诊断、预后判断、治疗方案选择及疗效监测。本指南涵盖基因组学、蛋白质组学和分子生物标志物，重点关注临床可操作性。

## 生物标志物类别

### 预后生物标志物

**定义**：预测临床结局（生存率、复发率），与接受的治疗无关

**疾病示例**

**癌症**
- **Ki-67指数**：高增殖指数（>20%）预示乳腺癌不良预后
- **TP53突变**：在多种癌症中预示不良预后
- **肿瘤分期/分级**：TNM分期，组织学分级
- **LDH升高**：预示黑色素瘤、淋巴瘤不良预后
- **AFP升高**：预示肝细胞癌不良预后

**心血管疾病**
- **NT-proBNP/BNP**：升高预示心力衰竭死亡率
- **肌钙蛋白**：预测急性冠脉综合征不良事件
- **CRP**：炎症标志物，预测心血管事件

**感染性疾病**
- **病原体DNA/RNA的PCR检测**：SARS-CoV-2、HIV、HCV病毒载量
- **抗体滴度**：IgM（急性期）、IgG（既往暴露/免疫）
- **抗原检测**：快速筛查（链球菌、流感、COVID）

**应用**：风险分层、治疗强度选择、临床试验入组

### 预测性生物标志物

**定义**：识别可能从特定治疗中获益（或不获益）的患者

**正向预测生物标志物（治疗获益）**

**肿瘤学 - 靶向治疗**
- **EGFR外显子19缺失/L858R → EGFR TKI**：缓解率60-70%，无进展生存期10-14个月
- **ALK重排 → ALK抑制剂**：客观缓解率70-90%，无进展生存期25-34个月  
- **HER2扩增 → 曲妥珠单抗**：仅HER2阳性患者获益（IHC 3+或FISH+）
- **BRAF V600E → BRAF抑制剂**：客观缓解率50%，无进展生存期6-7个月（黑色素瘤）
- **PD-L1 ≥50% → 帕博利珠单抗**：客观缓解率45%，无进展生存期10个月 vs 6个月（化疗）

**肿瘤学 - 免疫治疗**
- **MSI-H/dMMR → 抗PD-1**：跨瘤种客观缓解率40-60%
- **TMB高 → 免疫治疗**：研究阶段，存在获益信号
- **PD-L1表达 → 抗PD-1/PD-L1**：高表达与更好疗效相关

**血液学**
- **BCR-ABL → 伊马替尼（CML）**：完全细胞遗传学缓解率80%
- **CD20+ → 利妥昔单抗（淋巴瘤）**：仅CD20表达细胞获益
- **CD33+ → 吉妥珠单抗奥唑米星（AML）**：CD33阳性亚组获益

**负向预测生物标志物（耐药/无获益）**
- **KRAS突变 → 抗EGFR单抗（CRC）**：无获益，禁用
- **EGFR T790M → 第一/二代TKI**：耐药机制，改用奥希替尼
- **需RAS/RAF野生型 → BRAF抑制剂（黑色素瘤）**：矛盾性MAPK通路激活

### 诊断性生物标志物

**定义**：检测或确认疾病存在

**感染性疾病**
- **病原体DNA/RNA的PCR检测**：SARS-CoV-2、HIV、HCV病毒载量
- **抗体滴度**：IgM（急性期）、IgG（既往暴露/免疫）
- **抗原检测**：快速筛查（链球菌、流感、COVID）

**自身免疫性疾病**
- **抗核抗体（ANA）**：系统性红斑狼疮、结缔组织病筛查
- **抗CCP抗体**：类风湿关节炎特异性标志
- **抗双链DNA抗体**：狼疮，与疾病活动度相关
- **ANCA**：血管炎（c-ANCA诊断肉芽肿性多血管炎，p-ANCA诊断显微镜下多血管炎）

**癌症**
- **PSA**：前列腺癌筛查/监测
- **CA 19-9**：胰腺癌、胆道梗阻
- **CEA**：结直肠癌监测
- **AFP**：肝细胞癌、生殖细胞肿瘤

### 药效学生物标志物

**定义**：评估治疗反应或作用机制

**示例**
- **糖化血红蛋白（HbA1c）**：糖尿病血糖控制（目标值通常<7%）
- **低密度脂蛋白胆固醇（LDL）**：他汀疗效（高危人群目标值<70 mg/dL）
- **血压**：抗高血压疗效（目标值<130/80 mmHg）
- **病毒载量抑制**：抗逆转录病毒疗效（目标值<20拷贝/mL）
- **国际标准化比值（INR）**：华法林抗凝监测（多数适应症目标值2-3）

## 基因组学生物标志物

### 突变分析

**驱动突变（致癌性）**
- **激活突变**：通路持续激活（BRAF V600E、EGFR L858R）
- **失活突变**：抑癌基因缺失（TP53、PTEN）
- **热点突变**：高频位点（KRAS G12/G13、PIK3CA H1047R）
- **变异等位基因频率（VAF）**：克隆性（VAF≈50%为克隆性，<10%为亚克隆）

**耐药突变**
- **EGFR T790M**：对第一/二代TKI耐药（40-60%病例）
- **ALK G1202R、I1171N**：对早期ALK抑制剂耐药
- **ESR1突变**：对芳香化酶抑制剂耐药（乳腺癌）
- **RAS突变**：抗EGFR治疗获得性耐药（结直肠癌）

**突变检测方法**
- **组织NGS**：全面基因组分析（300-500基因）
- **液体活检**：ctDNA分析，无创，可连续监测
- **PCR检测**：靶向热点检测，FDA批准的伴随诊断
- **等位基因特异性PCR**：对已知突变高灵敏度（cobas EGFR检测）

### 拷贝数变异（CNV）

**扩增**
- **HER2（ERBB2）**：乳腺癌、胃癌 → 曲妥珠单抗、帕妥珠单抗
  - 检测：IHC（0、1+、2+、3+）→ 若2+需FISH（HER2/CEP17比值≥2.0）
- **MET扩增**：NSCLC耐药机制 → 克唑替尼、卡马替尼
  - 临界值：基因拷贝数≥5，GCN/CEP7比值≥2.0
- **EGFR扩增**：胶质母细胞瘤、部分NSCLC
- **FGFR2扩增**：胃癌 → 研究性FGFR抑制剂

**缺失**
- **PTEN缺失**：常见于多种癌症，预示PI3K通路激活
- **RB1缺失**：小细胞转化，预后不良
- **CDKN2A/B缺失**：细胞周期失调
- **纯合缺失**：双等位基因完全缺失（更具临床意义）

**检测方法**
- **荧光原位杂交（FISH）**：HER2、ALK重排检测
- **NGS拷贝数分析**：测序深度分析
- **SNP芯片**：全基因组CNV检测
- **微滴式数字PCR（ddPCR）**：定量拷贝数测量

### 基因融合与重排

**致癌性融合**
- **ALK融合**（NSCLC）：EML4-ALK最常见（60%），20+种伴侣基因
  - 检测：IHC（D5F3抗体）、FISH（分离探针）、NGS/RNA测序
- **ROS1融合**（NSCLC、胶质母细胞瘤）：CD74-ROS1、SLC34A2-ROS1等
- **RET融合**（NSCLC、甲状腺癌）：KIF5B-RET、CCDC6-RET
- **NTRK融合**（多瘤种，罕见）：ETV6-NTRK3等
  - 泛瘤种：拉罗替尼、恩曲替尼获批
- **BCR-ABL**（CML、ALL）：t(9;22)，费城染色体

**融合伴侣考量**
- 伴侣基因影响药物敏感性（EML4-ALK变体3更敏感）
- 5'端与3'端融合影响检测方法
- 内含子断点各异（RNA测序比DNA检测更全面）

**检测方法**
- **FISH分离探针**：ALK、ROS1、RET
- **IHC**：ALK蛋白过表达（初筛）、ROS1
- **RT-PCR**：靶向融合检测
- **RNA测序**：全面融合检测，可识别新型伴侣基因

### 肿瘤突变负荷（TMB）

**定义**：每兆碱基DNA的体细胞突变数量

**分类**
- **TMB高**：≥10突变/Mb（部分标准≥20突变/Mb）
- **TMB中**：6-9突变/Mb
- **TMB低**：<6突变/Mb

**临床应用**
- **免疫治疗预测**：TMB越高→新抗原越多→免疫应答越强
- **FDA批准**：帕博利珠单抗用于TMB-H（≥10突变/Mb）实体瘤（2020年）
- **局限性**：非所有瘤种均适用，检测方法存在差异

**典型高TMB瘤种**
- 黑色素瘤（中位数10-15突变/Mb）
- 非小细胞肺癌（尤其吸烟相关型，8-12突变/Mb）
- 尿路上皮癌（8-10突变/Mb）
- 微卫星不稳定肿瘤（30-50突变/Mb）

### 微卫星不稳定性（MSI）与错配修复（MMR）

**分类**
- **MSI-H（高度不稳定）**：5个位点中≥2个不稳定或≥30%标志物异常
- **MSI-L（低度不稳定）**：5个位点中<2个不稳定
- **微卫星稳定（MSS）**：无不稳定现象

**错配修复状态**
- **dMMR（缺陷型）**：IHC显示MLH1、MSH2、MSH6或PMS2缺失
- **pMMR（完整型）**：所有四种MMR蛋白表达正常

**临床意义**
- **MSI-H/dMMR肿瘤**：占实体瘤3-5%，结直肠癌15%
- **免疫治疗敏感性**：抗PD-1治疗客观缓解率30-60%
  - 帕博利珠单抗获FDA批准用于MSI-H/dMMR实体瘤（2017年）
  - 纳武利尤单抗±伊匹木单抗获批
- **化疗耐药性**：MSI-H结直肠癌无法从5-FU辅助治疗获益
- **林奇综合征**：若MSI-H+年轻发病+家族史，需行胚系MMR突变检测

**检测流程**
```
结直肠癌（所有新确诊患者）：
1. MMR蛋白IHC检测（MLH1、MSH2、MSH6、PMS2）
   ├─ 全部完整 → pMMR（MSS）→ 按指征行标准化疗
   │
   └─ 任一缺失 → dMMR（可能MSI-H）
      └─ MLH1启动子甲基化补充检测
         ├─ 甲基化 → 散发性MSI-H，可选免疫治疗
         └─ 未甲基化 → 林奇综合征胚系检测
```

## 表达生物标志物

### 免疫组织化学（IHC）

**PD-L1表达（免疫检查点）**
- **检测方法**：22C3（FDA批准）、28-8、SP263、SP142（评分标准存在差异）
- **评分**：
  - 肿瘤比例评分（TPS）= 膜染色阳性肿瘤细胞百分比
    - TPS <1%：低/阴性
    - TPS 1-49%：中等
    - TPS ≥50%：高表达
  - 综合阳性评分（CPS）=（PD-L1+肿瘤细胞+免疫细胞）/总肿瘤细胞×100
    - 用于部分适应症（如头颈鳞癌中CPS≥10适用帕博利珠单抗）

**激素受体（乳腺癌）**
- **ER/PR阳性**：IHC核染色≥1%（ASCO/CAP指南）
  - Allred评分0-8（比例+强度）- 传统方法
  - H评分0-300（各强度百分比）- 定量方法
- **临床临界值**：
  - ER≥1%：需内分泌治疗
  - ER 1-10%："低阳性"，获益可能较低
  - ER阳性伴PR缺失：可能内分泌耐药

**HER2检测（乳腺癌/胃癌）**
```
IHC初筛：
├─ 0或1+：HER2阴性（无需补充检测）
│
├─ 2+：临界值 → 补充FISH检测
│  ├─ FISH阳性（HER2/CEP17比值≥2.0或HER2拷贝数≥6/细胞）→ HER2阳性
│  └─ FISH阴性 → HER2阴性
│
└─ 3+：HER2阳性（无需FISH）
   └─ >10%肿瘤细胞呈现均匀强阳性完整膜染色

HER2阳性：需曲妥珠单抗为基础的治疗
HER2低表达（IHC 1+或2+/FISH-）：符合曲妥珠单抗德鲁替康用药条件（2022年）
```

### RNA表达分析

**基因表达谱（乳腺癌）**

**Oncotype DX（21基因检测）**
- **复发评分（RS）**：0-100分
  - RS<26：低危 → 仅需内分泌治疗（多数患者）
  - RS 26-100：高危 → 化疗+内分泌治疗
- **适用人群**：ER+/HER2-，淋巴结阴性或1-3枚阳性
- **证据**：TAILORx试验（N=10,273）证实RS<26可豁免化疗

**MammaPrint（70基因检测）**
- **结果**：高危 vs 低危（二元分类）
- **适用人群**：早期乳腺癌，ER+/HER2-
- **证据**：MINDACT试验证实低危可豁免化疗

**Prosigna（PAM50）**
- **结果**：复发风险（ROR）评分+内在亚型
- **亚型**：管腔A型、管腔B型、HER2富集型、基底样型
- **应用**：绝经后ER+患者，淋巴结阴性或1-3枚阳性

**RNA测序融合检测**
- **优势**：可识别新型融合伴侣，量化表达水平
- **应用**：NTRK融合（罕见，多伴侣基因）、RET融合
- **局限**：需新鲜/冰冻组织或高质量FFPE RNA

## 分子亚型

### 胶质母细胞瘤（GBM）分子分型

**Verhaak 2010分型（4亚型）**

**前神经亚型**
- **特征**：PDGFRA扩增、IDH1突变（继发性GBM）、TP53突变
- **年龄**：通常较年轻
- **预后**：较好（中位总生存期15-18个月）
- **治疗**：贝伐珠单抗获益可能低于其他亚型

**神经亚型**
- **特征**：神经元标志物（NEFL、GABRA1、SYT1、SLC12A5）
- **争议**：可能含正常脑组织污染
- **预后**：中等
- **治疗**：标准替莫唑胺方案

**经典型**
- **特征**：EGFR扩增（97%）、7号染色体增益、10号染色体缺失
- **关联**：无TP53、PDGFRA、NF1突变
- **预后**：中等
- **治疗**：可能受益于EGFR抑制剂（研究阶段）

**间充质亚型**
- **特征**：NF1突变/缺失、间充质标志物高表达（CHI3L1/YKL-40）
- **免疫特征**：巨噬细胞/小胶质细胞浸润更高
- **亚组**：间充质-免疫活化型（高免疫特征）
- **预后**：较差（中位总生存期12-13个月）
- **治疗**：抗血管生成治疗反应可能更佳，免疫治疗研究阶段

**临床应用**
```
GBM分子分型报告：

患者队列：间充质-免疫活化亚型（n=15）

分子特征：
- NF1变异：73%（11/15）
- YKL-40高表达：100%（15/15）
- 免疫基因特征：升高（中位z值+2.3）
- CD163+巨噬细胞：高密度（中位180/mm²）

治疗意义：
- 标准方案：替莫唑胺为基础（Stupp方案）
- 考虑：复发疾病使用贝伐珠单抗（可能增效）
- 临床试验：免疫检查点

- 预后：中位总生存期（OS）12-14个月（较前神经亚型更差）

建议：
若符合条件则加入联合免疫治疗试验，否则采用标准治疗
并在进展时尽早考虑贝伐珠单抗。

### 乳腺癌内在亚型

**基于PAM50的分类**

**管腔A型**
- **特征**：ER阳性，HER2阴性，低增殖（Ki-67 <20%）
- **基因特征**：高ER相关基因表达，低增殖基因表达
- **预后**：最佳预后，低复发风险
- **治疗**：通常单用内分泌治疗即可
- **化疗**：除非存在高风险特征，否则极少需要

**管腔B型**
- **特征**：ER阳性，HER2阴性或阳性，高增殖（Ki-67 ≥20%）
- **亚型**：管腔B型（HER2阴性）与管腔B型（HER2阳性）
- **预后**：中等预后
- **治疗**：化疗+内分泌治疗；若HER2阳性则加用曲妥珠单抗

**HER2富集型**
- **特征**：HER2阳性，ER阴性，PR阴性
- **基因特征**：高HER2及增殖基因表达，低ER基因表达
- **预后**：未经治疗预后差，HER2靶向治疗预后良好
- **治疗**：化疗+曲妥珠单抗+帕妥珠单抗

**基底样型**
- **特征**：ER阴性，PR阴性，HER2阴性（三阴性），高增殖
- **基因特征**：基底细胞角蛋白（CK5/6, CK17），EGFR
- **重叠性**：与三阴性乳腺癌80%一致，但不完全相同
- **预后**：侵袭性强，早期复发风险高
- **治疗**：化疗（铂类、蒽环类）；若BRCA突变则用PARP抑制剂
- **免疫治疗**：PD-L1阳性患者可能受益于帕博利珠单抗+化疗

### 结直肠癌共识分子亚型（CMS）

**CMS1（14%）：微卫星不稳定免疫型**
- **特征**：微卫星高度不稳定，BRAF突变，强免疫激活
- **预后**：尽管存在免疫浸润，复发后生存率差
- **治疗**：免疫治疗高效，5-FU化疗无效

**CMS2（37%）：经典型**
- **特征**：上皮型，显著WNT和MYC激活
- **预后**：生存率较好
- **治疗**：受益于辅助化疗

**CMS3（13%）：代谢型**
- **特征**：代谢失调，KRAS突变
- **预后**：中等生存率
- **治疗**：可能受益于靶向代谢疗法（研究阶段）

**CMS4（23%）：间质型**
- **特征**：间质浸润，TGF-β激活，血管生成
- **预后**：最差生存率，常晚期确诊
- **治疗**：可能受益于抗血管生成治疗（贝伐珠单抗）

## 伴随诊断

### FDA批准的生物标志物-药物组合

**必需检测（标签适应症）**
```

```
## 临床可操作性框架

### OncoKB证据等级（纪念斯隆凯特琳癌症中心）

**1级：FDA批准**
- 特定瘤种中FDA批准的生物标志物-药物组合
- 示例：EGFR L858R → 奥希替尼治疗NSCLC

**2级：标准超说明书治疗**
- 专业指南推荐的特定瘤种生物标志物-药物组合（非FDA批准适应症）
- 示例：BRAF V600E → 达拉非尼+曲美替尼治疗CRC（NCCN推荐）

**3级：临床证据**
- 支持生物标志物-药物关联的临床试验证据
- 3A：强有力临床证据
- 3B：其他瘤种标准治疗或研究性治疗

**4级：生物学证据**
- 仅临床前证据（细胞系、小鼠模型）
- 4级：支持关联的生物学证据

**R1-R2级：耐药**
- R1：标准治疗相关耐药
- R2：研究性或临床前耐药证据

### CIViC（癌症变异临床解读）

**证据等级**
- **A级**：临床实践验证或监管关联验证
- **B级**：临床试验或其他原始患者数据支持
- **C级**：含分子分析的病例研究
- **D级**：临床前证据（细胞培养、动物模型）
- **E级**：推断性关联（文献综述、专家意见）

**临床意义分级**
- **I级**：具强临床意义的变异（专业指南中的预测性、诊断性、预后性）
- **II级**：具潜在临床意义的变异（临床试验或病例研究证据）
- **III级**：临床意义不确定的变异
- **IV级**：良性或可能良性变异

- **应用**：无创、动态监测、组织样本不可用时

- **基因**：648基因（DNA）+全转录组（RNA）
```

```
## 生物标志物截断值与阈值

### 临床截断值确立方法

**数据驱动法**
- **中位数分割**：简单但随意，可能非最优
- **三分位/四分位**：分3-4组
- **ROC曲线分析**：最大化敏感性与特异性
- **最大选择秩统计**：寻找最优预后截断点
- **必需验证**：独立队列确认

**生物学依据法**
- **检测限**：检测方法定量下限
- **机制导向**：通路激活阈值
- **药效学**：靶点结合阈值
- **正常范围**：与健康人群对比

**临床定义法**
- **指南推荐**：专业学会制定
- **监管批准**：FDA指定的伴随诊断阈值
- **试验定义**：关键临床试验所用截断值

**PD-L1示例**
- **截断值**：不同试验采用1%、5%、10%、50% TPS
- **情境依赖**：因药物、疾病、治疗线数而异
- **≥50%**：帕博利珠单抗单药（KEYNOTE-024）
- **≥1%**：阿替利珠单抗联合方案，覆盖更广人群

### 连续变量与分类变量分析

**连续分析优势**
- 保留信息（避免二分类损失）
- 维持统计效能
- 可评估剂量-反应关系
- 按单位增量或标准差计算HR

**分类分析优势**
- 临床可解释性（高/低分组）
- 便于治疗决策（二元判断：是否使用靶向药）
- 符合监管审批（生物标志物阳性=适用）

**最佳实践**：同时报告连续与分类分析
- 含连续生物标志物的Cox模型
- 按临床相关截断值分层分析
- 亚组分析验证一致性

## 胚系与体细胞检测

### 胚系（遗传性）突变

**胚系检测指征**
- **癌症易感综合征**：BRCA1/2、林奇综合征（MLH1/MSH2）、李-佛美尼综合征（TP53）
- **家族史**：多位亲属患病、年轻发病
- **肿瘤特征**：年轻患者MSI-H、<60岁三阴性乳腺癌
- **治疗意义**：BRCA突变（胚系/体细胞）适用PARP抑制剂

**常见遗传性癌症综合征**
- **BRCA1/2**：乳腺癌、卵巢癌、胰腺癌、前列腺癌
  - 检测：所有卵巢癌、<60岁TNBC、男性乳腺癌
  - 治疗：PARP抑制剂（奥拉帕利、他拉唑帕利）
  - 预防：预防性乳腺/卵巢切除术
- **林奇综合征（MLH1/MSH2/MSH6/PMS2）**：结直肠癌、子宫内膜癌、卵巢癌、胃癌
  - 检测：MSI-H/dMMR肿瘤、Amsterdam II标准家族
  - 监测：20-25岁起每1-2年结肠镜检
- **李-佛美尼综合征（TP53）**：年轻多发癌种
- **PTEN（考登综合征）**：乳腺癌、甲状腺癌、子宫内膜癌

**遗传咨询**
- 检测前咨询：对患者及家族的影响
- 检测后咨询：管理、监测、家族检测
- 知情同意：遗传歧视顾虑（GINA保护法案）

### 体细胞（仅肿瘤）检测

**肿瘤组织检测**
- 仅检测癌细胞突变（非遗传性）
- 多数癌症驱动突变为体细胞性（如肺癌KRAS、EGFR）
- 不影响家族成员
- 指导治疗选择

**胚系与体细胞区分**
- **等位基因频率**：胚系~50%（杂合）或~100%（纯合）；体细胞频率不定
- **配对正常样本**：肿瘤-正常配对测序可明确
- **数据库**：胚系变异数据库（gnomAD、ClinVar）
- **胚系复检**：疑似致病性胚系变异时触发检测
```
