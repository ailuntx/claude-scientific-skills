# 治疗推荐指南

## 概述

循证治疗推荐为临床医生提供系统性治疗决策指导。本指南涵盖药物和医疗环境中临床推荐的制定、分级与呈现方法。

## 证据分级体系

### GRADE（推荐分级评估、制定与评价）

**证据质量等级**

**高质量 (⊕⊕⊕⊕)**
- 进一步研究极不可能改变对效应估计值的置信度
- 标准：设计良好的随机对照试验（RCT）且结果一致，无严重局限性
- 示例：多个大型RCT显示相似的治疗效果

**中等质量 (⊕⊕⊕○)**
- 进一步研究可能对置信度产生重要影响
- 标准：存在局限性的RCT或观察性研究的极强证据
- 示例：单个RCT或多个存在不一致性的RCT

**低质量 (⊕⊕○○)**
- 进一步研究极可能对置信度产生重要影响
- 标准：观察性研究或存在严重局限性的RCT
- 示例：存在混杂因素的病例对照研究、队列研究

**极低质量 (⊕○○○)**
- 效应估计值高度不确定
- 标准：病例系列报告、专家意见或存在极严重局限性
- 示例：机制推理、非系统性临床观察

**推荐强度**

**强推荐 (1级)**
- 获益明确大于风险与负担（或反之）
- 措辞："我们推荐..."
- 含义：绝大多数患者应接受推荐方案
- 符号：↑↑（强力支持）或↓↓（强力反对）

**条件性/弱推荐 (2级)**
- 存在权衡取舍；获益与风险接近平衡
- 措辞："我们建议..."
- 含义：不同患者选择不同；需共同决策
- 符号：↑（弱支持）或↓（弱反对）

**GRADE标注示例**
- **1A**：强推荐，高质量证据
- **1B**：强推荐，中等质量证据
- **2A**：弱推荐，高质量证据
- **2B**：弱推荐，中等质量证据
- **2C**：弱推荐，低质量或极低质量证据

### 牛津循证医学中心（CEBM）分级

**1级：系统评价/荟萃分析**
- 1a：RCT的系统评价
- 1b：置信区间狭窄的单个RCT
- 1c："全或无"研究（治疗前患者全部死亡，治疗后部分存活）

**2级：队列研究**
- 2a：队列研究的系统评价
- 2b：单个队列研究（含低质量RCT）
- 2c：结局研究、生态学研究

**3级：病例对照研究**
- 3a：病例对照研究的系统评价
- 3b：单个病例对照研究

**4级：病例系列报告**
- 病例系列报告、低质量队列或病例对照研究

**5级：专家意见**
- 基于机制的推理、未经严格评价的专家意见

**推荐等级**
- **A级**：一致的1级研究
- **B级**：一致的2级或3级研究，或1级研究的推论
- **C级**：4级研究或2/3级研究的推论
- **D级**：5级证据或不一致/不确定的研究

## 治疗顺序与治疗线数

### 一线治疗

**选择标准**
- **标准治疗**：基于III期试验的指南推荐方案
- **患者因素**：体能状态、合并症、器官功能
- **疾病因素**：分期、分子谱、侵袭性
- **治疗目标**：治愈（辅助/新辅助）、延长缓解期、症状控制

**一线方案文档**
```
一线治疗方案：

方案1：方案A（NCCN 1类，ESMO I-A）
- 证据：III期RCT（n=1000），中位无进展生存期12个月 vs 8个月（HR 0.6, p<0.001）
- 适用人群：PD-L1≥50%，EGFR/ALK阴性
- 毒性特征：免疫相关不良事件（15% 3-4级）
- 推荐强度：1A（强推荐，高质量证据）

方案2：方案B（NCCN 1类，ESMO I-A）
- 证据：III期RCT（n=800），中位无进展生存期10个月 vs 8个月（HR 0.7, p=0.003）
- 适用人群：全人群，无需生物标志物筛选
- 毒性特征：血液学毒性（25% 3-4级）
- 推荐强度：1A（强推荐，高质量证据）
```

### 二线及后续治疗

**二线选择**
- **前期反应**：对一线治疗的缓解持续时间
- **进展模式**：寡进展 vs 广泛进展
- **残留毒性**：一线治疗毒性的恢复情况
- **生物标志物演变**：获得性耐药机制
- **临床试验可及性**：研发中的新型药物

**治疗史文档**
```
既往治疗：
1. 一线：帕博利珠单抗（12周期）
   - 最佳反应：部分缓解（肿瘤负荷减少45%）
   - 无进展生存期：14个月
   - 停药原因：疾病进展
   - 残留毒性：1级甲状腺功能减退（服用左甲状腺素）

2. 二线：多西他赛+雷莫芦单抗（6周期）
   - 最佳反应：疾病稳定
   - 无进展生存期：5个月
   - 停药原因：疾病进展
   - 残留毒性：2级周围神经病变

当前考虑：三线方案
- 临床试验 vs 铂类化疗
```

### 维持治疗

**适应症**
- 诱导治疗缓解后的巩固治疗
- 避免持续细胞毒治疗情况下的疾病进展预防
- 过渡至根治性治疗（如移植）

**证据要求**
- 随机试验证实的无进展生存获益
- 可耐受的长期毒性特征
- 生活质量维持或改善

## 生物标志物指导的治疗选择

### 伴随诊断

**FDA批准的生物标志物-药物组合**

**必需检测（治疗特异性）**
- **ALK重排 → 阿来替尼、布加替尼、劳拉替尼**（非小细胞肺癌）
- **EGFR外显子19缺失/L858R → 奥希替尼**（非小细胞肺癌）
- **BRAF V600E → 达拉非尼+曲美替尼**（黑色素瘤、非小细胞肺癌、结直肠癌）
- **HER2扩增/3+ → 曲妥珠单抗、帕妥珠单抗**（乳腺癌、胃癌）
- **PD-L1≥50% → 帕博利珠单抗单药**（非小细胞肺癌一线）

**补充诊断（参考性非必需）**
- **PD-L1 1-49%**：优先选择联合免疫治疗
- **TMB高**：可能预测免疫治疗获益（研究阶段）
- **MSI-H/dMMR**：帕博利珠单抗获批用于所有瘤种

### 生物标志物检测流程

**非小细胞肺癌标志物组合**
```
诊断时自动检测：
✓ EGFR突变（外显子18,19,20,21）
✓ ALK重排（免疫组化或FISH）
✓ ROS1重排（FISH或NGS）
✓ BRAF V600E突变
✓ PD-L1免疫组化（22C3或SP263）
✓ 考虑：全面NGS组合检测

奥希替尼进展后若EGFR阳性：
✓ 液体活检检测T790M（如使用过第一/二代TKI）
✓ 组织活检检测耐药机制
✓ MET扩增、HER2扩增、小细胞肺癌转化
```

**乳腺癌标志物流程**
```
初诊时：
✓ ER/PR免疫组化
✓ HER2免疫组化和FISH（如2+）
✓ Ki-67增殖指数

若转移性ER+/HER2-：
✓ ESR1突变（AI治疗进展后液体活检）
✓ PIK3CA突变（阿培利司适用性）
✓ BRCA1/2胚系检测（PARP抑制剂适用性）
✓ PD-L1检测（如考虑免疫联合治疗）
```

### 可干预变异

**I级：FDA批准的靶向治疗**
- 前瞻性试验的强有力证据
- 指南推荐方案
- 示例：EGFR外显子19缺失、HER2扩增、ALK融合

**II级：临床试验或超说明书使用**
- 新兴证据，优先选择临床试验
- 示例：NTRK融合（拉罗替尼）、RET融合（塞普替尼）

**III级：生物学合理性**
- 仅临床前证据
- 强烈建议加入临床试验
- 示例：新型激酶融合、罕见耐药突变

## 联合治疗方案

### 联合治疗原理

**作用机制**
- **非重叠毒性**：最大化各药物剂量强度
- **协同作用**：超越累加效应的增效作用
- **互补机制**：同时靶向多通路
- **预防耐药**：降低耐药克隆选择压力

**联合设计原则**
- **序贯**：诱导治疗后巩固（不同方案）
- **同步**：同时给药实现协同
- **交替**：轮换方案最小化耐药
- **间歇**：脉冲给药 vs 持续暴露

### 药物相互作用评估

**药代动力学相互作用**
- **CYP450诱导/抑制**：核查药物间相互作用
- **转运体相互作用**：P-gp、BCRP、OATP底物/抑制剂
- **蛋白结合**：高蛋白结合药物（华法林需谨慎）
- **肾/肝清除**：避免多重肾清除药物

**药效学相互作用**
- **毒性叠加**：避免不良事件重叠（如QTc延长）
- **拮抗作用**：确保机制互补而非对立
- **剂量调整**：预定义联合用药减量方案

### 联合方案文档
```
联合方案：药物A + 药物B

原理：
- III期RCT证实无进展生存获益（16 vs 11个月，HR 0.62, p<0.001）
- 互补机制：药物A（VEGF抑制剂）+ 药物B（免疫检查点抑制剂）
- 非重叠毒性特征

剂量：
- 药物A：10 mg/kg 静脉注射 每3周
- 药物B：1200 mg 静脉注射 每3周
- 持续至疾病进展或不可耐受毒性

关键毒性：
- 高血压（药物A）：30% 3-4级，需降压药管理
- 免疫相关不良事件（药物B）：15% 3-4级，需皮质类固醇管理
- 未观察到显著药代动力学相互作用

监测：
- 血压：首月每日监测，之后每周
- 甲状腺功能：每6周
- 肝功能：每周期前
- 影像学：每6周（RECIST v1.1标准）
```

**血液学毒性**

## 特殊人群

### 老年患者（≥65-70岁）

**考量因素**
- **器官功能减退**：根据肾/肝功能调整剂量
- **多重用药**：药物相互作用风险
- **衰弱状态**：老年综合评估（G8、VES-13、CARG评分）
- **治疗目标**：生活质量 vs 生存期，功能独立性

**调整方案**
- 剂量减少：衰弱患者减量20-25%
- 延长间隔：每4周替代每3周方案
- 低强度方案：单药 vs 联合治疗
- 支持治疗：加强监测，预防性G-CSF

### 肾功能不全

**根据eGFR调整剂量**
```
eGFR (mL/min/1.73m²)  类别      措施
≥90                   正常      标准剂量
60-89                 轻度      标准剂量（多数药物）
30-59                 中度      肾清除药物减量25-50%
15-29                 重度      减量50-75%，避免肾毒性药物
<15（透析）           终末期    避免多数药物，个案决策
```

**需调整的肾清除药物**
- 卡铂（Calvert公式：AUC × [GFR + 25]）
- 甲氨蝶呤（肌酐清除率<60时减量50-75%）
- 卡培他滨（肌酐清除率30-50时减量25-50%）

### 肝功能不全

**根据胆红素与AST/ALT调整剂量**
```
类别          胆红素         AST/ALT      措施
正常         ≤正常上限       ≤正常上限    标准剂量
轻度（Child A）1-1.5×正常上限 任意        肝代谢药物减量25%
中度（Child B）1.5-3×正常上限 任意        减量50%，考虑替代方案
重度（Child C）>3×正常上限    任意        避免多数药物，个案决策
```

**需调整肝代谢的药物**
- 多西他赛（胆红素升高时减量25-50%）
- 伊立替康（胆红素达1.5-3倍正常上限时减量50%）
- 酪氨酸激酶抑制剂（多数经CYP3A4代谢，减量50%）

### 妊娠与生育力

**避孕要求**
- 治疗期间及结束后6-12个月需采取有效避孕措施
- 对强致畸性药物建议采用双重避孕法
- 男性患者：若伴侣有生育能力需避孕

**生育力保存**
- 卵母细胞/胚胎冷冻（女性，在性腺毒性治疗前）
- 精子冷冻（男性，在烷化剂/铂类治疗前）
- GnRH激动剂（卵巢抑制，疗效存争议）
- 治疗前转诊生殖内分泌科

**妊娠期管理**
- 避免孕早期化疗（器官形成期）
- 孕中晚期可选安全药物（个案评估）
- 多学科团队：肿瘤科、母胎医学、新生儿科

## 临床试验考量

### 临床试验推荐时机

**理想场景**
- 无标准疗法可用（罕见病/难治性疾病）
- 存在等效标准方案（患者倾向新药）
- 标准治疗失败（二线及以上）
- 高风险疾病（辅助治疗试验改善预后）

**试验筛选标准**
- **阶段**：Ⅰ期（剂量探索/安全性）、Ⅱ期（有效性信号）、Ⅲ期（比较疗效）
- **入组**：符合纳入/排除标准
- **机制**：新机制与成熟机制、生物学依据
- **申办方**：学术机构vs药企、试验设计质量
- **可行性**：试验中心距离、随访频率、自费成本

### 共同决策

**患者告知要点**
- 未经治疗的自然病程
- 标准治疗的循证依据/获益/风险
- 可用临床试验选项
- 治疗目标一致性
- 患者价值观与偏好

**决策辅助工具**
- 获益可视化图表（图标阵列）
- 需治数（NNT）计算
- 生活质量权衡分析
- 决策冲突量表

## 质量指标

### 治疗推荐质量要素

- 所有推荐均标注循证等级
- 存在等效证据时提供多选项
- 明确描述毒性特征
- 制定监测计划
- 包含剂量调整指南
- 特殊人群考量（老年/肝肾损伤）
- 适时提及临床试验选项
- 记录共同决策过程
- 治疗强度与照护目标匹配
