# 临床决策算法指南

## 概述

临床决策算法为诊断、治疗方案选择及患者管理提供系统性、分步骤指导。本指南涵盖使用决策树和流程图进行算法开发、验证及可视化呈现的方法。

## 算法设计原则

### 核心要素

**决策节点**
- **问题/标准**：清晰可量化的临床参数
- **二元与多元**：是/否（简单）对比多选项（复杂）
- **客观性**：实验室数值、影像学发现 vs 主观性：临床判断

**行动节点**
- **治疗**：含剂量说明的特定干预
- **检查**：附加诊断程序
- **转诊**：专科会诊或升级护理级别
- **观察**：设定随访的观察等待

**终末节点**
- **结局**：最终决策点
- **随访**：复评安排
- **退出标准**：算法终止条件

### 设计准则

**清晰性**
- 无歧义决策点
- 互斥路径分支
- 避免循环（除非设计复评周期）
- 明确入口与出口

**临床有效性**
- 循证决策标准
- 已验证的生物标志物截断值
- 符合指南的推荐意见
- 证据不足时采用专家共识

**可用性**
- 单路径最多7个决策点（认知负荷）
- 视觉层级（高发路径突出）
- 优选单页可打印格式
- 按紧急/安全等级色彩编码

**完整性**
- 覆盖所有可能场景
- 边缘病例默认路径
- 异常表现的安全网机制
- 明确升级标准

## 临床决策树

### 诊断算法

**胸痛评估算法**

```
入口：胸痛患者

├─ STEMI标准？(相邻2导联ST段抬高≥1mm)
│  ├─ 是 → 激活导管室，阿司匹林325mg，肝素，氯吡格雷600mg
│  │        转诊行直接PCI（目标门球时间<90分钟）
│  └─ 否 → 继续评估

├─ 高风险特征？(血流动力学不稳/心律失常/肌钙蛋白升高)
│  ├─ 是 → 收治CCU，连续肌钙蛋白检测，心内科会诊
│  │        若NSTEMI考虑早期血管造影
│  └─ 否 → 计算TIMI或HEART评分

├─ TIMI评分0-1或HEART评分0-3？(低风险)
│  ├─ 是 → 观察6-12小时，连续肌钙蛋白检测，阴性者行负荷试验
│  │        全阴性则出院，72小时内心内科随访
│  └─ 否 → TIMI 2-4或HEART 4-6(中风险)

├─ TIMI评分2-4或HEART评分4-6？(中风险)
│  ├─ 是 → 收治遥测病房，连续肌钙蛋白检测，负荷影像或CT血管造影
│  │        药物管理：阿司匹林、他汀、β受体阻滞剂
│  └─ 否 → TIMI≥5或HEART≥7(高风险) → 按NSTEMI处理

决策终点：记录30天事件率的风险分层路径
```

**肺栓塞诊断算法（Wells评分）**

```
入口：疑似PE

步骤1：计算Wells评分
  临床特征赋分：
  - DVT临床症状：3分
  - PE可能性高于其他诊断：3分  
  - 心率>100：1.5分
  - 过去4周制动/手术：1.5分
  - 既往PE/DVT：1.5分
  - 咯血：1分
  - 恶性肿瘤：1分

步骤2：风险分层
  ├─ Wells评分≤4 (PE可能性低)
  │  └─ D-二聚体检测
  │     ├─ D-二聚体阴性(<500 ng/mL) → 排除PE，考虑其他诊断
  │     └─ D-二聚体阳性(≥500 ng/mL) → CTPA
  │
  └─ Wells评分>4 (PE可能性高)
     └─ CTPA (跳过D-二聚体)

步骤3：CTPA结果
  ├─ PE阳性 → 分层评估严重度
  │  ├─ 大面积PE(低血压/休克) → 溶栓 vs 取栓术
  │  ├─ 次大面积PE(RV劳损/肌钙蛋白+) → 收治ICU，考虑溶栓
  │  └─ 低风险PE → 抗凝治疗，考虑门诊管理
  │
  └─ PE阴性 → 排除PE，排查其他病因

步骤4：治疗决策(确诊PE)
  ├─ 抗凝绝对禁忌？
  │  ├─ 是 → 置入下腔静脉滤器，治疗基础疾病
  │  └─ 否 → 抗凝治疗
  │
  ├─ 癌症相关血栓？
  │  ├─ 是 → 优选LMWH(艾多沙班替代)
  │  └─ 否 → 优选DOAC(阿哌沙班/利伐沙班/艾多沙班)
  │
  └─ 疗程：至少3个月，无诱因或复发者延长
```

### 治疗方案选择算法

**NSCLC一线治疗算法**

```
入口：晚期/转移性NSCLC，PS良好(ECOG 0-2)

步骤1：生物标志物检测完成？
  ├─ 否 → 快速检测：EGFR/ALK/ROS1/BRAF/PD-L1，考虑NGS
  │       等待结果期间暂停系统治疗(快速进展除外)
  └─ 是 → 进入步骤2

步骤2：存在可干预基因变异？
  ├─ EGFR外显子19缺失/L858R → 奥希替尼80mg每日
  │  └─ 备选：厄洛替尼/吉非替尼/阿法替尼(次选)
  │
  ├─ ALK重排 → 阿来替尼600mg每日两次
  │  └─ 备选：布加替尼/劳拉替尼/克唑替尼(次选)
  │
  ├─ ROS1重排 → 克唑替尼250mg每日两次或恩曲替尼
  │
  ├─ BRAF V600E → 达拉非尼+曲美替尼
  │
  ├─ MET外显子14跳跃 → 卡马替尼或特泊替尼
  │
  ├─ RET重排 → 塞普替尼或普拉替尼
  │
  ├─ NTRK融合 → 拉罗替尼或恩曲替尼
  │
  ├─ KRAS G12C → 索托拉西或阿达格拉西(无其他选择时)
  │
  └─ 无可干预变异 → 进入步骤3

步骤3：PD-L1检测结果？
  ├─ PD-L1≥50% (TPS)
  │  ├─ 方案1：帕博利珠单抗200mg每3周(单药，NCCN 1类)
  │  ├─ 方案2：帕博利珠单抗+铂类双药化疗
  │  └─ 方案3：阿替利珠单抗+贝伐珠单抗+卡铂+紫杉醇
  │
  ├─ PD-L1 1-49% (TPS)
  │  ├─ 优选：帕博利珠单抗+铂类双药化疗
  │  └─ 备选：铂类双药化疗单用
  │
  └─ PD-L1<1% (TPS)
     ├─ 优选：帕博利珠单抗+铂类双药化疗
     └─ 备选：铂类双药化疗±贝伐珠单抗

步骤4：铂类双药选择(如适用)
  ├─ 鳞状组织学
  │  └─ 卡铂AUC6+紫杉醇200mg/m²每3周(4周期)
  │      或卡铂AUC5+白蛋白紫杉醇100mg/m² D1,8,15每4周
  │
  └─ 非鳞状组织学  
     └─ 卡铂AUC6+培美曲塞500mg/m²每3周(4周期)
         应答者继续培美曲塞维持治疗
         符合条件者(无咯血/脑转移)加贝伐珠单抗15mg/kg

步骤5：监测与疗效评估
  - 前12周每6周影像复查，之后每9周
  - 持续至进展或不可耐受毒性
  - 进展后进入二线治疗算法
```

**心力衰竭管理算法（AHA/ACC指南）**

```
入口：确诊心力衰竭

步骤1：确定心衰类型
  ├─ HFrEF (EF≤40%)
  │  └─ 启动指南导向药物治疗(GDMT)
  │
  ├─ HFpEF (EF≥50%)
  │  └─ 治疗合并症，利尿剂缓解淤血，考虑SGLT2i
  │
  └─ HFmrEF (EF 41-49%)
     └─ 考虑HFrEF GDMT，证据有限

步骤2：HFrEF的GDMT(除非禁忌)

四联疗法(1类推荐)：

1. ACEI/ARB/ARNI
   ├─ 优选：沙库巴曲缬沙坦49/51mg每日两次 → 滴定至97/103mg每日两次
   │  └─ 适用于ACEI初治或<10mg依那普利当量者
   ├─ 备选：ACEI(依那普利/赖诺普利/雷米普利)至目标剂量
   └─ 备选：ARB(氯沙坦/缬沙坦)用于ACEI不耐受者

2. β受体阻滞剂(低起始，慢滴定)
   ├─ 比索洛尔1.25mg每日 → 目标10mg每日
   ├─ 琥珀酸美托洛尔12.5mg每日 → 目标200mg每日
   └─ 卡维地洛3.125mg每日两次 → 目标25mg每日两次(>85kg者50mg每日两次)

3. 盐皮质激素受体拮抗剂(MRA)
   ├─ 螺内酯12.5-25mg每日 → 目标50mg每日
   └─ 依普利酮25mg每日 → 目标50mg每日
   └─ 禁忌：血钾>5.0，肌酐清除率<30 mL/min

4. SGLT2抑制剂(无论糖尿病状态)
   ├─ 达格列净10mg每日
   └─ 恩格列净10mg每日

步骤3：基于表型的附加治疗

├─ 窦性心律+β阻滞剂后心率≥70？
│  └─ 是：加伊伐布雷定5mg每日两次 → 目标7.5mg每日两次
│
├─ 非裔美国人+NYHA III-IV级？
│  └─ 是：加肼屈嗪37.5mg每日三次+硝酸异山梨酯20mg每日三次
│          (目标：肼屈嗪75mg每日三次+ISDN 40mg每日三次)
│
├─ 房颤？
│  ├─ 室率控制(静息<80次/分，活动<110次/分)
│  └─ 抗凝(优选DOAC，瓣膜病用华法林)
│
└─ 铁缺乏(铁蛋白<100或<300且TSAT<20%)？
   └─ 是：静脉补铁(羧基麦芽糖铁)

步骤4：器械治疗评估

├─ EF≤35%，NYHA II-III级，LBBB且QRS≥150ms，窦性心律？
│  └─ 是：心脏再同步化治疗(CRT-D)
│
├─ EF≤35%，NYHA II-III级，GDMT≥3月？
│  └─ 是：ICD一级预防
│          (预期生存>1年且功能状态良好)
│
└─ EF≤35%，GDMT后NYHA IV级或晚期心衰？
   └─ 转诊晚期心衰专科
      ├─ LVAD评估
      ├─ 心脏移植评估
      └─ 姑息治疗会诊

步骤5：监测与滴定

滴定期间每周至双周随访：
- 血压(目标SBP≥90 mmHg)
- 心率(目标50-60次/分)
- 血钾(目标4.0-5.0 mEq/L，>5.5时暂停MRA)
- 肌酐(预期升高10-20%，<30%且稳定可接受)
- 症状与淤血状态(每日体重，NYHA分级)

GDMT稳定期：
- 每3-6月随访
- GDMT优化后3-6月心超，之后每年
- NT-proBNP或BNP趋势监测(生物标志物导向治疗研究阶段)
```

## 风险分层工具

### 心血管风险评分

**TIMI风险评分（NSTEMI/不稳定型心绞痛）**

```
评分计算(0-7分)：
☐ 年龄≥65岁(1分)
☐ ≥3个心脏风险因素(高血压/高脂血症/糖尿病/吸烟/家族史)(1分)
☐ 已知CAD(狭窄≥50%)(1分)
☐ 过去7天使用ASA(1分)
☐ 严重心绞痛(24小时内≥2次发作)(1分)
☐ ST段偏移≥0.5mm(1分)
☐ 心脏标志物升高(1分)

风险分层：
├─ 评分0-1：14天内死亡/心梗/紧急血运重建风险5%(低)
│  └─ 管理：观察、负荷试验、门诊随访
│
├─ 评分2：风险8%(中低)
│  └─ 管理：收住院、药物治疗、负荷影像
│
├─ 评分3-4：风险13-20%(中高)
│  └─ 管理：收住院、强化药物治疗、早期侵入策略
│
└─ 评分5-7：风险26-41%(高)
   └─ 管理：强化治疗，24小时内紧急血管造影
```

**CHA2DS2-VASc评分（房颤卒中风险）**

```
评分计算：
☐ 心力衰竭(1分)
☐ 高血压(1分)
☐ 年龄≥75岁(2分)
☐ 糖尿病(1分)
☐ 既往卒中/TIA/血栓栓塞(2分)
☐ 血管疾病(心梗/PAD/主动脉斑块)(1分)
☐ 年龄65-74岁(1分)
☐ 女性(1分)

最高分：9分

治疗算法：
├─ 评分0(男)或1(女)：年卒中风险0-1.3%
│  └─ 无需抗凝或阿司匹林(IIb类)
│
├─ 评分1(男)：年卒中风险1.3%
│  └─ 考虑抗凝(IIa类)
│      因素：患者意愿、出血风险、合并症
│
└─ 评分≥2(男)或≥3(女)：年卒中风险≥2.2%
   └─ 推荐抗凝(I类)
      ├─ 优选：DOAC(阿哌沙班/利伐沙班/艾多沙班/达比加群)
      └─ 备选：华法林(INR 2-3)用于DOAC禁忌者

出血风险评估(HAS-BLED)：
H - 高血压(SBP>160)
A - 肾功能/肝功能异常(各1分)
S - 卒中史
B - 出血史或倾向
L - INR不稳定(华法林治疗时)
E - 高龄(>65岁)
D - 药物(抗血小板/NSAIDs)或酒精(各1分)

HAS-BLED≥3：高出血风险 → 修正可变因素，优选DOAC而非华法林
```

## TikZ流程图最佳实践

### 视觉设计原则

**节点样式**
```latex
% 决策节点（菱形）
\tikzstyle{decision} = [diamond, draw, fill=yellow!20, text width=4.5em, text centered, inner sep=0pt]

% 处理节点（矩形）
\tikzstyle{process} = [rectangle, draw, fill=blue!20, text width=5em, text centered, rounded corners, minimum height=3em]

% 终止节点（圆角矩形）
\tikzstyle{terminal} = [rectangle, draw, fill=green!20, text width=5em, text centered, rounded corners=1em, minimum height=3em]

% 输入/输出（平行四边形）
\tikzstyle{io} = [trapezium, draw, fill=purple!20, text width=5em, text centered, minimum height=3em]
```

**紧急程度颜色编码**
- **红色**：危及生命，需立即处理
- **橙色**：紧急，数小时内处理
- **黄色**：次紧急，24-48小时内处理
- **绿色**：常规，病情稳定
- **蓝色**：信息性，仅需监测

**路径强调**
- 主要路径用粗箭头
- 罕见场景用虚线箭头
- 箭头粗细反映路径频率
- 关键决策点加高亮框

## 算法验证

### 开发流程

**步骤1：文献回顾与证据整合**
- 指南系统回顾（NCCN, ASCO, ESMO, AHA/ACC）
- 临床试验荟萃分析
- 专家共识声明
- 本地实践模式与资源可用性

**步骤2：算法草案制定**
- 多学科团队参与（医师、护士、药师）
- 定义决策节点与标准
- 明确处理措施与结局
- 识别不确定领域

**步骤3：试点测试**
- 历史病例回溯应用（n=20-50）
- 识别算法未覆盖场景
- 优化决策标准
- 终端用户可用性测试

**步骤4：前瞻性验证**
- 临床实践实施并收集数据
- 追踪依从率（目标>80%）
- 对比历史对照监测结局
- 用户满意度调查

**步骤5：持续质量改进**
- 季度算法性能审查
- 根据新证据更新
- 分析偏差及未依从原因
- 版本控制与变更记录

### 性能指标

**过程指标**
- 算法依从率（遵循算法的病例比例）
- 决策时间（从就诊到治疗启动中位时间）
- 完成率（到达终止节点的病例比例）

**结局指标**
- 治疗适当性（与指南一致性）
- 临床结局（死亡率、发病率、再入院率）
- 资源利用（住院时长、非必要检查）
- 安全性（不良事件、差错率）

**用户体验指标**
- 易用性（李克特量表评估）
- 使用耗时（导航算法中位时间）
- 感知效用（报告算法有帮助的用户比例）
- 使用障碍（质性反馈）

## 实施策略

### 临床工作流整合

**电子病历集成**
- 关键决策点临床决策支持（CDS）提醒
- 算法路径关联医嘱套餐
- 电子病历数据自动生成风险评分
- 符合算法结构的文档模板

**床旁工具**
- 快速参考口袋卡
- 交互式算法移动应用
- 临床区域挂图
- 完整算法二维码链接

**教育培训**
- 算法原理专题授课
- 案例实践练习
- 情景模拟训练
- 依从性审核反馈

### 障碍应对

**常见障碍**
- 算法复杂性（决策点过多）
- 认知不足（传播不到位）
- 建议分歧（被视为"烹饪书式医疗"）
- 优先级冲突（时间压力、多患者处理）
- 资源限制（推荐检查/治疗不可及）

**缓解策略**
- 简化算法（优选≤7个决策点/路径）
- 建立推广网络（本地意见领袖倡导）
- 本地化定制（保留临床判断灵活性）
- 结果测量报告（证明价值）
- 资源保障（确保算法推荐方案可用）

## 算法维护与更新

### 版本控制

**变更日志示例**
```
算法：NSCLC一线治疗
版本：3.2
生效日期：2024年1月1日
上一版本：3.1（2023年7月1日生效）

3.2版变更：
1. 新增KRAS G12C突变路径（sotorasib, adagrasib）
   - 证据：2021/2022年5月FDA批准
   - 指南：NCCN v4.2023

2. PD-L1≥50%推荐更新：将帕博利珠单抗单药列为优选方案1
   - 证据：KEYNOTE-024五年随访数据
   - 指南：NCCN 1类优选

3. 克唑替尼从优选ALK抑制剂降级为替代方案
   - 证据：ALEX、CROWN试验显示艾乐替尼/劳拉替尼更优
   - 指南：NCCN/ESMO将艾乐替尼列为1类一线方案

审核：胸部肿瘤委员会
批准：[姓名]博士，医疗总监
下次审核日期：2024年7月1日
```

### 更新触发机制

**强制更新（3个月内）**
- FDA批准算法适应症新药
- 指南变更（NCCN/ASCO/ESMO 1类推荐）
- 安全警示或推荐药物黑框警告
- 改变标准治疗的重要临床试验结果

**常规更新（年度）**
- 次要证据更新
- 基于本地性能数据优化
- 格式或可用性改进
- 新增遇到的临床场景

**紧急更新（1周内）**
- 药物短缺需替代路径
- 药物召回或安全撤市
- 疫情/大流行需修改方案
