# 临床决策支持文档

## 描述

为制药公司、临床研究人员和医学决策者生成专业的临床决策支持（CDS）文档。该技能专注于分析性、基于证据的文档，为治疗策略和药物开发提供信息：

1. **患者队列分析** - 基于生物标志物分层的群体分析，附统计结局比较
2. **治疗建议报告** - 基于循证医学的临床指南，包含GRADE分级和决策算法

所有文档均生成为可直接用于出版的LaTeX/PDF文件，专为药物研究、监管申报和临床指南开发优化。

**注意：** 对于床旁个体患者的治疗方案，请改用 `treatment-plans` 技能。本技能侧重于药物/研究环境中的群体水平分析和证据综合。

**写作风格：** 针对面向医学期刊的待出版文档，请参考 **venue-templates** 技能中的 `medical_journal_styles.md`，获取关于结构化摘要、证据语言以及CONSORT/STROBE合规性的指导。

## 能力

### 文档类型

**患者队列分析**
- 基于生物标志物的患者分层（分子亚型、基因表达、免疫组化）
- 分子亚型分类（例如，GBM间充质-免疫活化型 vs 前神经元型，乳腺癌亚型）
- 附带统计分析的结局指标（OS、PFS、ORR、DOR、DCR）
- 亚组间统计比较（风险比、p值、95% CI）
- 使用Kaplan-Meier曲线和对数秩检验进行生存分析
- 疗效表和瀑布图
- 比较有效性分析
- 药物队列报告（试验亚组、真实世界证据）

**治疗建议报告**
- 针对特定疾病状态的循证治疗指南
- 推荐的强度分级（GRADE系统：1A、1B、2A、2B、2C）
- 证据质量评估（高、中、低、极低）
- 使用TikZ图的治疗算法流程图
- 基于生物标志物的治疗线序贯
- 包含临床和分子标准的决策路径
- 药物策略文件
- 为医学学会制定临床指南

### 临床特性

- **生物标志物整合**：基因组改变（突变、拷贝数变异、融合）、基因表达特征、IHC标志物、PD-L1评分
- **统计分析**：风险比、p值、置信区间、生存曲线、Cox回归、对数秩检验
- **证据分级**：GRADE系统（1A/1B/2A/2B/2C）、牛津CEBM分级、证据质量评估
- **临床术语**：SNOMED-CT、LOINC、规范医学命名、试验命名
- **法规合规性**：HIPAA去标识化、保密性页眉、ICH-GCP一致性
- **专业格式**：紧凑的0.5英寸页边距、颜色编码的建议、可直接出版、适用于监管申报

## 制药与研究应用场景

本技能专为制药和临床研究应用设计：

**药物开发**
- **II/III期试验分析**：基于生物标志物分层的疗效和安全性分析
- **亚组分析**：显示各患者亚组治疗效应的森林图
- **伴随诊断开发**：将生物标志物与药物反应联系起来
- **监管申报**：附带证据总结的IND/NDA文档

**医学事务**
- **KOL教育材料**：面向思想领袖的循证治疗算法
- **医学策略文档**：竞争格局与定位策略
- **顾问委员会材料**：队列分析和治疗建议框架
- **发表规划**：为同行评审期刊准备的稿件式分析

**临床指南**
- **指南制定**：使用GRADE方法进行证据综合，供专业学会使用
- **共识建议**：多利益相关方治疗算法制定
- **实践标准**：基于生物标志物的治疗选择标准
- **质量指标**：基于证据的绩效指标

**真实世界证据**
- **RWE队列研究**：基于EMR数据的患者队列回顾性分析
- **比较有效性**：真实世界中头对头治疗比较
- **结局研究**：临床实践中的长期生存和安全性
- **卫生经济学**：按生物标志物亚组进行的成本-效果分析

## 何时使用

当您需要以下内容时使用此技能：

- **分析患者队列**，按生物标志物、分子亚型或临床特征分层
- **生成治疗建议报告**，附带用于临床指南或药物策略的证据分级
- **比较患者亚组间的结局**，进行统计分析（生存、缓解率、风险比）
- **制作药物研究文档**，用于药物开发、临床试验或监管申报
- **制定临床实践指南**，包含GRADE证据分级和决策算法
- **在群体层面（而非个体患者）记录生物标志物指导的治疗选择**
- **综合来自多个试验或真实世界数据源的证据**
- **创建带有流程图的临床决策算法**，用于治疗序贯

**请勿将此技能用于：**
- 个体患者治疗方案（使用 `treatment-plans` 技能）
- 床旁临床护理文档（使用 `treatment-plans` 技能）
- 简单的患者特异性治疗方案（使用 `treatment-plans` 技能）

## 文档结构

**关键要求：所有临床决策支持文档必须在第1页以完整的执行摘要开始，该摘要占满整个第一页，然后才是任何目录或详细章节。**

### 第一页执行摘要结构

每个CDS文档的第一页应仅包含执行摘要，并包含以下组成部分：

**必需元素（全部在第1页）：**
1. **文档标题和类型**
   - 主标题（例如，“生物标志物分层队列分析”或“循证治疗建议”）
   - 副标题，注明疾病状态和重点
   
2. **报告信息框**（使用彩色 tcolorbox）
   - 文档类型和目的
   - 分析/报告日期
   - 疾病状态和患者人群
   - 作者/机构（如适用）
   - 分析框架或方法
   
3. **主要发现框**（3-5个使用 tcolorbox 的彩色框）
   - **主要结果**（蓝色框）：主要疗效/结局发现
   - **生物标志物洞察**（绿色框）：关键分子亚型发现
   - **临床意义**（黄色/橙色框）：可操作的治疗意义
   - **统计摘要**（灰色框）：风险比、p值、关键统计量
   - **安全性亮点**（红色框，如适用）：关键不良事件或警告

**视觉要求：**
- 使用 `\thispagestyle{empty}` 移除第1页的页码
- 所有内容必须适合第1页（在 `\newpage` 之前）
- 使用不同颜色的彩色 tcolorbox 环境以实现视觉层次
- 框应便于快速浏览，突出最关键信息
- 使用项目符号，而非叙述性段落
- 在目录或详细章节之前以 `\newpage` 结束第1页

**示例第一页 LaTeX 结构：**
```latex
\maketitle
\thispagestyle{empty}

% 报告信息框
\begin{tcolorbox}[colback=blue!5!white, colframe=blue!75!black, title=报告信息]
\textbf{文档类型：} 患者队列分析\\
\textbf{疾病状态：} HER2阳性转移性乳腺癌\\
\textbf{分析日期：} \today\\
\textbf{人群：} 60名患者，按HR状态进行生物标志物分层
\end{tcolorbox}

\vspace{0.3cm}

% 主要发现 #1：主要结果
\begin{tcolorbox}[colback=blue!5!white, colframe=blue!75!black, title=主要疗效结果]
\begin{itemize}
    \item 总ORR：72\% (95\% CI: 59-83\%)
    \item 中位PFS：18.5个月 (95\% CI: 14.2-22.8)
    \item 中位OS：35.2个月 (95\% CI: 28.1-未达到)
\end{itemize}
\end{tcolorbox}

\vspace{0.3cm}

% 主要发现 #2：生物标志物洞察
\begin{tcolorbox}[colback=green!5!white, colframe=green!75!black, title=生物标志物分层结果]
\begin{itemize}
    \item HR+/HER2+：ORR 68%，中位PFS 16.2个月
    \item HR-/HER2+：ORR 78%，中位PFS 22.1个月
    \item HR状态与结局显著相关 (p=0.041)
\end{itemize}
\end{tcolorbox}

\vspace{0.3cm}

% 主要发现 #3：临床意义
\begin{tcolorbox}[colback=orange!5!white, colframe=orange!75!black, title=临床建议]
\begin{itemize}
    \item 无论HR状态如何，均观察到强大疗效（1A级）
    \item HR-/HER2+ 患者数值上显示出更好的结局
    \item 推荐对所有HER2+ MBC患者进行治疗
\end{itemize}
\end{tcolorbox}

\newpage
\tableofcontents  % 目录在第2页
\newpage  % 详细内容从第3页开始
```

### 患者队列分析（详细章节 - 第3页起）
- **队列特征**：人口学资料、基线特征、患者选择标准
- **生物标志物分层**：分子亚型、基因组改变、IHC图谱
- **治疗暴露**：接受的疗法、剂量、按亚组的治疗持续时间
- **结局分析**：缓解率（ORR、DCR）、生存数据（OS、PFS）、DOR
- **统计方法**：Kaplan-Meier生存曲线、风险比、对数秩检验、Cox回归
- **亚组比较**：按生物标志物分层的疗效、森林图、统计显著性
- **安全性概况**：按亚组的不良事件、剂量调整、停药
- **临床建议**：基于生物标志物特征的治疗意义
- **图形**：瀑布图、泳道图、生存曲线、森林图
- **表格**：人口学表、生物标志物频率、按亚组的结局

### 治疗建议报告（详细章节 - 第3页起）

**治疗建议的第一页执行摘要应包括：**
1. **报告信息框**：疾病状态、指南版本/日期、目标人群
2. **关键建议框**（绿色）：按治疗线列出的前3-5条GRADE分级建议
3. **生物标志物决策标准框**（蓝色）：影响治疗选择的关键分子标志物
4. **证据总结框**（灰色）：支持建议的主要试验（如KEYNOTE-189、FLAURA）
5. **关键监测框**（橙色/红色）：基本安全监测要求

**详细章节（第3页起）：**
- **临床背景**：疾病状态、流行病学、当前治疗格局
- **目标人群**：患者特征、生物标志物标准、分期
- **证据综述**：系统性文献综合、指南总结、试验数据
- **治疗方案**：可用疗法及其作用机制
- **证据分级**：每条建议的GRADE评估（1A、1B、2A、2B、2C）
- **按治疗线的建议**：一线、二线、后续治疗
- **生物标志物指导的选择**：基于分子图谱的决策标准
- **治疗算法**：显示决策路径的TikZ流程图
- **监测方案**：安全性评估、疗效监测、剂量调整
- **特殊人群**：老年人、肾功能/肝功能损害、合并症
- **参考文献**：完整参考文献列表，包含试验名称和引用

## 输出格式

**强制性第一页要求：**
- **第1页**：完整页面的执行摘要，包含3-5个彩色 tcolorbox 元素
- **第2页**：目录（可选）
- **第3页起**：包含方法、结果、图形、表格的详细章节

**文档规格：**
- **主要格式**：LaTeX/PDF，页边距0.5英寸，紧凑且数据密集
- **长度**：通常5-15页（1页执行摘要 + 4-14页详细内容）
- **风格**：可直接出版、制药级、适用于监管申报
- **第一页**：始终为完整的执行摘要，占满整个第1页（参见文档结构部分）

**视觉元素：**
- **颜色**：
  - 第1页框：蓝色=数据/信息，绿色=生物标志物/建议，黄色/橙色=临床意义，红色=警告
  - 建议框（绿色=强烈建议，黄色=有条件，蓝色=需要研究）
  - 生物标志物分层（颜色编码的分子亚型）
  - 统计显著性（颜色编码的p值、风险比）
- **表格**：
  - 人口学及基线特征表
  - 按亚组的生物标志物频率表
  - 结局表（按分子亚型的ORR、PFS、OS、DOR）
  - 按队列的不良事件表
  - 附带GRADE评级的证据总结表
- **图形**：
  - Kaplan-Meier生存曲线，附带对数秩p值及风险表
  - 显示每个患者最佳缓解的瀑布图
  - 带有置信区间的亚组分析森林图
  - TikZ决策算法流程图
  - 显示个体患者时间线的泳道图
- **统计量**：风险比及95% CI、p值、中位生存时间、里程碑生存率
- **合规性**：依据HIPAA安全港进行去标识化、专有数据的保密声明

## 与治疗计划技能的关键区别

**临床决策支持（本技能）：**
- **受众**：制药公司、临床研究人员、指南委员会、医学事务
- **范围**：群体水平分析、证据综合、指南制定
- **重点**：生物标志物分层、统计比较、证据分级
- **输出**：多页分析文档（通常5-15页），包含大量图形和表格
- **用例**：药物开发、监管申报、临床实践指南、医学策略
- **示例**：“按激素受体状态分析60名HER2+乳腺癌患者的生存结局”

**治疗计划技能：**
- **受众**：临床医生、患者、护理团队
- **范围**：个体患者护理规划
- **重点**：SMART目标、患者特异性干预、监测计划
- **输出**：简洁的1-4页可操作护理计划
- **用例**：床旁临床护理、EMR文档、以患者为中心的规划
- **示例**：“为一名新诊断2型糖尿病的55岁患者制定治疗计划”

**何时使用各自：**
- 使用 **clinical-decision-support** 进行：队列分析、生物标志物分层研究、治疗指南制定、药物策略文档
- 使用 **treatment-plans** 进行：个体患者护理计划、特定患者的治疗方案、床旁临床文档

## 使用示例

### 患者队列分析

**示例1：NSCLC生物标志物分层**
```
> 分析一个45名NSCLC患者的队列，按PD-L1表达（<1%、1-49%、≥50%）分层，接受帕博利珠单抗治疗。
> 包括结局：ORR、中位PFS、中位OS，比较PD-L1 ≥50%与<50%的风险比。生成Kaplan-Meier曲线和瀑布图。
```

**示例2：GBM分子亚型分析**
```
> 为30名GBM患者生成队列分析，分为Cluster 1（间充质-免疫活化型）和Cluster 2（前神经元型）分子亚型。
> 比较结局，包括中位OS、6个月PFS率以及对TMZ+贝伐珠单抗的缓解。包括生物标志物特征表和统计比较。
```

**示例3：乳腺癌HER2队列**
```
> 分析60名HER2阳性转移性乳腺癌患者，接受德曲妥珠单抗治疗，按既往曲妥珠单抗暴露（是/否）分层。
> 包括ORR、DOR、中位PFS，附带按激素受体状态、脑转移和既往治疗线数进行亚组分析的森林图。
```

### 治疗建议报告

**示例1：HER2+转移性乳腺癌指南**
```
> 创建HER2阳性转移性乳腺癌的循证治疗建议，包括基于生物标志物的治疗选择。
> 使用GRADE系统对一线（曲妥珠单抗+帕妥珠单抗+紫杉类）、二线（德曲妥珠单抗）和三线选项进行分级。
> 包括基于脑转移、激素受体状态和既往治疗的决策算法流程图。
```

**示例2：晚期NSCLC治疗算法**
```
> 根据PD-L1表达、EGFR突变、ALK重排和体能状态，生成晚期NSCLC的治疗建议报告。
```

## 关键特性

### 生物标志物分类
- 基因组：突变、CNV、基因融合
- 表达：RNA-seq、IHC评分
- 分子亚型：疾病特异性分类
- 临床可操作性：治疗选择指导

### 结局指标
- 生存：OS（总生存期）、PFS（无进展生存期）
- 缓解：ORR（客观缓解率）、DOR（缓解持续时间）、DCR（疾病控制率）
- 质量：ECOG体能状态、症状负担
- 安全性：不良事件、剂量调整

### 统计方法
- 生存分析：Kaplan-Meier曲线、对数秩检验
- 组间比较：t检验、卡方检验、Fisher精确检验
- 效应量：风险比、比值比及95% CI
- 显著性：p值、多重检验校正

### 证据分级

**GRADE系统**
- **1A**：强烈建议，高质量证据
- **1B**：强烈建议，中等质量证据
- **2A**：弱建议，高质量证据
- **2B**：弱建议，中等质量证据
- **2C**：弱建议，低质量证据

**建议强度**
- **强烈**：获益明确超过风险
- **有条件**：存在权衡，患者价值重要
- **研究**：证据不足，需要临床试验

## 最佳实践

### 队列分析

1. **患者选择透明度**：清晰记录纳入/排除标准、患者流程及排除原因
2. **生物标志物清晰性**：注明检测方法、平台（如FoundationOne、Caris）、临界点和验证状态
3. **统计严谨性**：
   - 报告风险比时附带95%置信区间，而不仅仅是p值
   - 在生存分析中包括中位随访时间
   - 说明所使用的统计检验（对数秩、Cox回归、Fisher精确）
   - 适当时考虑多重比较
4. **结局定义**：使用标准标准：
   - 缓解：RECIST 1.1，免疫治疗使用iRECIST
   - 不良事件：CTCAE 5.0版
   - 体能状态：ECOG或Karnofsky
5. **生存数据呈现**：
   - 中位OS/PFS及95% CI
   - 里程碑生存率（6个月、12个月、24个月）
   - Kaplan-Meier曲线下方的风险表
   - 明确标示删失
6. **亚组分析**：预先指定亚组；明确标记为探索性 vs 预先计划的分析
7. **数据完整性**：报告缺失数据及其处理方式

### 治疗建议报告

1. **证据分级透明度**：
   - 一致使用GRADE系统（1A、1B、2A、2B、2C）
   - 记录每个分级的理由
   - 清楚说明证据质量（高、中、低、极低）
2. **全面证据综述**：
   - 以III期随机试验作为主要证据
   - 对于新兴疗法补充II期数据
   - 注明真实世界证据和荟萃分析
   - 引用试验名称（如KEYNOTE-189、CheckMate-227）
3. **生物标志物指导的建议**：
   - 将特定生物标志物与治疗建议关联
   - 注明检测方法和经过验证的检测
   - 包含伴随诊断的FDA/EMA批准状态
4. **临床可操作性**：每条建议应有明确的实施指导
5. **决策算法清晰性**：TikZ流程图应明确，具有清晰的“是/否”决策点
6. **特殊人群**：涉及老年人、肾功能/肝功能损害、妊娠、药物相互作用
7. **监测指导**：指定安全性实验室、影像学及频率
8. **更新频率**：为建议标明日期，并计划定期更新

### 通用最佳实践

1. **第一页执行摘要（强制性）**：
   - 始终在第1页创建完整的执行摘要，占满整个第一页
   - 使用3-5个彩色 tcolorbox 元素突出主要发现
   - 第1页上不要有目录或详细章节
   - 使用 `\thispagestyle{empty}` 并以 `\newpage` 结束
   - 这是最重要的页面——应在60秒内快速浏览完毕
2. **去标识化**：在生成文档前移除所有18个HIPAA标识符（安全港方法）
3. **法规合规性**：包含专有制药数据的保密声明
4. **可出版格式**：使用0.5英寸页边距、专业字体、颜色编码部分
5. **可重复性**：记录所有统计方法以允许重复
6. **利益冲突**：适用时披露制药资助或关系
7. **视觉层次**：一致使用彩色框（蓝色=数据，绿色=生物标志物，黄色/橙色=建议，红色=警告）
