# 科学稿件中常见的方法学与统计学问题

本文档按类别整理了同行评审中频繁出现的问题。可作为参考资料，用于识别潜在问题并提供建设性反馈。

## 统计学问题

### 1. P值滥用与误读

**常见问题：**
- P值操纵（选择性报告显著结果）
- 未校正的多重检验（导致族错误率膨胀）
- 将不显著结果解释为无效应证据
- 仅关注p值而忽略效应量
- 在任意阈值二分连续p值（p=0.049 vs p=0.051）
- 混淆统计显著性与生物学/临床显著性

**识别方法：**
- 大量p值恰好低于0.05的可疑现象
- 执行多次检验但未提及校正
- 出现"未发现差异"等基于不显著结果的表述
- 未报告效应量或置信区间
- 暗示p值代表效应强度的表述

**改进建议：**
- 报告置信区间伴随的效应量
- 采用适当的多重检验校正（Bonferroni、FDR、Holm-Bonferroni）
- 谨慎解释不显著结果（缺乏证据 ≠ 无证据）
- 预先注册分析方案避免p值操纵
- 对"无差异"主张考虑等效性检验

### 2. 统计检验方法不当

**常见问题：**
- 违反前提假设时使用参数检验（非正态数据、方差不齐）
- 对配对数据使用非配对检验
- 多组比较使用t检验而非ANOVA及事后检验
- 将有序数据视为连续变量
- 忽略重复测量数据结构
- 适用回归分析时使用相关性检验

**识别方法：**
- 未提及假设检验
- 小样本量下使用参数检验
- 多重t检验替代ANOVA
- 李克特量表使用t检验分析
- 时间序列数据未考虑重复测量

**改进建议：**
- 明确检验假设前提（正态性检验、Q-Q图）
- 适时采用非参数替代方法
- ANOVA后应用适当的多重比较校正
- 重复测量数据使用混合效应模型
- 有序结果变量考虑有序回归

### 3. 样本量与统计功效问题

**常见问题：**
- 无样本量依据或功效计算
- 低功效研究声称"无效应"
- 进行事后功效计算（无参考价值）
- 未预先设定终止规则
- 组间样本量不均衡且无合理解释

**识别方法：**
- 小样本量（常规设计n<30/组）
- 方法部分未提及功效分析
- 出现事后功效相关表述
- 置信区间过宽提示精度不足
- 大p值小样本量下声称"无效应"

**改进建议：**
- 基于预期效应量进行先验功效分析
- 报告实际功效或精度（置信区间宽度）
- 承认研究功效不足的情况
- 结合效应量与置信区间解释结果
- 预先注册样本量与终止规则

### 4. 缺失数据处理问题

**常见问题：**
- 无合理依据的完整案例分析（整列删除）
- 未报告缺失程度或模式
- 未经验证假设数据完全随机缺失（MCAR）
- 采用不恰当的填补方法
- 未执行敏感性分析

**识别方法：**
- 不同分析间样本量差异未作说明
- 未讨论缺失数据问题
- 受试者"被排除于分析"
- 使用简单均值填补
- 未比较完整数据与填补数据的敏感性分析

**改进建议：**
- 报告缺失程度与模式
- 检验MCAR假设（Little检验）
- 采用适当填补方法（多重填补、最大似然法）
- 执行敏感性分析
- 临床试验考虑意向治疗分析

### 5. 循环分析与双重使用数据

**常见问题：**
- 相同数据用于筛选与推断
- 基于对比结果定义ROI，又在同一ROI检验该对比
- 筛选离群值后检验组间差异
- 事后亚组分析伪装成预设分析
- HARKing（结果已知后提出假设）

**识别方法：**
- 基于结果选择ROI或特征
- 意外出现的亚组分析
- 事后分析未明确标注为探索性
- 无独立数据验证
- 引言完美预测研究结果

**改进建议：**
- 使用独立数据集进行筛选与检验
- 预先注册分析与假设
- 明确区分验证性与探索性分析
- 采用交叉验证或保留数据集
- 校正选择偏倚

### 6. 伪重复问题

**常见问题：**
- 技术重复视为生物学重复
- 同个体多次测量视为独立数据
- 聚类数据未考虑聚类效应
- 空间或时间数据存在非独立性

**识别方法：**
- n定义为测量次数而非生物学单元
- 同动物多个细胞计为独立样本
- 未说明重复测量设计
- 未提及随机效应或聚类

**改进建议：**
- 将n定义为生物学重复单元（动物、患者、独立样本）
- 嵌套或聚类数据使用混合效应模型
- 明确说明重复测量设计
- 分析前平均技术重复数据
- 同时报告技术与生物学重复

## 实验设计问题

### 7. 缺乏适当对照组

**常见问题：**
- 缺少阴性对照
- 缺少阳性验证对照
- 药物研究无载体对照
- 纵向研究无时间匹配对照
- 无批次对照

**识别方法：**
- 方法部分仅列出实验组
- 图表中未提及对照组
- 基线或参照条件不明确
- 无对照的跨批次比较

**改进建议：**
- 设置阴性对照评估特异性
- 设置阳性对照验证方法
- 使用与实验处理匹配的载体对照
- 手术干预设置假手术对照
- 跨批次比较设置批次对照

### 8. 混杂变量问题

**常见问题：**
- 组间存在干预外的系统性差异
- 批次效应未控制或校正
- 序贯实验存在顺序效应
- 未控制昼夜节律影响
- 未设盲导致操作者效应

**识别方法：**
- 组间存在多重特征差异
- 不同组样本分批次处理
- 未随机化样本处理顺序
- 未提及设盲操作
- 组间基线特征存在差异

**改进建议：**
- 将实验单元随机分配至条件
- 对已知混杂因素进行区组设计
- 随机化样本处理顺序
- 采用设盲减少偏倚
- 必要时进行批次校正
- 报告并校正基线差异

### 9. 重复不足问题

**常见问题：**
- 单次实验无重复验证
- 技术重复误作生物学重复
- 以"领域惯例"为由使用小样本量
- 关键发现无独立验证
- 选择性展示代表性案例

**识别方法：**
- 方法声明"实验仅进行一次"
- n=3且无合理解释
- 标注"展示代表性图像"
- 核心结论基于单次实验
- 无独立数据集验证

**改进建议：**
- 进行独立生物学重复（通常≥3次）
- 在独立队列验证关键发现
- 报告全部重复而非仅代表性案例
- 通过功效分析证明样本量合理性
- 展示个体数据点而非仅汇总统计

## 可重复性问题

### 10. 方法细节不足

**常见问题：**
- 方法描述不足以支持重复实验
- 关键试剂未明确（供应商、货号）
- 未报告软件版本与参数
- 抗体未经验证
- 细胞系未经验证

**识别方法：**
- 模糊描述（如"采用标准方案"）
- 无试剂来源信息
- 仅提软件名称未注版本
- 无抗体验证信息
- 细胞系未经验证

**改进建议：**
- 提供详细方案或引用具体文献
- 包含试剂供应商、货号、批号
- 报告软件版本及所有参数
- 提供抗体验证（Western blot、特异性测试）
- 报告细胞系验证方法（STR分型）
- 公开实验方案（protocols.io、补充材料）

### 11. 数据与代码可及性

**常见问题：**
- 无数据可用性声明
- "数据应要求提供"（常无法兑现）
- 未提供计算分析代码
- 未公开定制软件
- 缺乏清晰文档

**识别方法：**
- 缺少数据可用性声明
- 无数据库收录号
- 计算方法无代码支持
- 定制流程无法获取
- 无README或说明文档

**改进建议：**
- 原始数据存入专业数据库（GEO、SRA、Dryad、Zenodo）
- 通过GitHub等平台共享分析代码
- 提供清晰文档与README文件
- 包含requirements.txt或环境文件
- 公开定制软件及安装说明
- 使用DOI永久标识数据

### 12. 方法验证缺失

**常见问题：**
- 新方法未与金标准比较
- 未验证检测特异性、灵敏度、线性
- 无加标对照
- 未测试交叉反应性
- 未确定检测限

**识别方法：**
- 新检测方法未经验证
- 未与现有方法比较
- 未展示阴阳性对照
- 无证据支持特异性声明
- 无标准曲线或对照

**改进建议：**
- 对照成熟方法验证新方案
- 证明特异性（基因敲除/敲低对照）
- 展示线性与动态范围
- 包含阴阳性对照
- 报告检测限与定量限
- 展示跨重复与操作者的可重复性

## 结果解读问题

### 13. 结论过度延伸

**常见问题：**
- 相关性数据使用因果性表述
- 无机制证据提出机制性结论
- 超出数据范围外推（物种、条件、人群）
- 未充分文献检索即声称"首次发现"
- 有限样本过度泛化

**识别方法：**
- 观察性数据得出"X导致Y"
- 未经直接验证提出机制
- 小鼠数据未加说明推及人类
- 新颖性声明存在漏引
- 狭窄样本得出广泛结论

**改进建议：**
- 使用准确表述（"相关"而非"导致"）
- 区分相关性与因果性
- 承认模型系统的局限性
- 提供充分文献背景
- 明确结论的普适性范围
- 将机制解释为假说而非定论

### 14. 选择性报告与数据筛选

**常见问题：**
- 仅报告显著结果
- 展示可能非典型的"代表性"图像
- 无合理依据排除离群值
- 未报告阴性或矛盾结果
- 切换不同统计方法

**识别方法：**
- 所有报告结果均显著
- "代表3次实验"但无量化的图像
- 结果提及数据排除但方法未说明
- 补充数据与主要结论矛盾
- 多种分析方法仅报告一种

**改进建议：**
- 报告所有预设分析（无论结果如何）
- 量化并展示重复实验变异性
- 预先设定离群值排除标准
- 包含阴性结果
- 预先注册分析方案
- 报告所有比较的效应量与置信区间

### 15. 忽略替代解释

**常见问题：**
- 未考虑替代解释即提出倾向性结论
- 未讨论即否定矛盾证据
- 未考虑脱靶效应
- 未承认混杂变量
- 局限性描述简略或缺失

**识别方法：**
- 单一解释呈现为事实
- 未引用或讨论既往矛盾发现
- 未考虑替代机制
- 无局限性讨论
- 无对照即假设特异性

**改进建议：**
- 讨论替代性解释
- 回应文献中的矛盾发现
- 包含适当特异性对照
- 充分承认并讨论局限性
- 考虑并检验替代假说

## 图表与数据呈现问题

### 16. 数据可视化不当

**常见问题：**
- 连续数据使用柱状图（掩盖分布）
- 无误差线或未定义误差线
- 截断y轴夸大差异
- 双y轴导致误导性比较
- 有效数字过多
- 非色觉友好配色

**识别方法：**
- 数据点稀少的柱状图
- 误差线含义不明（SD？SEM？CI？）
- 比率/百分比数据y轴未从零开始
- 左右y轴比例尺不同
- 数值精度过度（p=0.04562）
- 红绿色系方案

**改进建议：**
- 散点图/箱线图/小提琴图展示个体数据点
- 明确定义误差线（SD、SEM、95%CI）
- y轴从零开始或明确标注截断
- 避免双y轴，改用分面图
- 报告恰当有效数字
- 采用色觉友好调色板（viridis、colorbrewer）
- 图注中标注样本量

### 17. 图像处理问题

**常见问题：**
- 过度调整对比度/亮度
- 拼接胶图或图像未标注
- 图像或面板重复使用
- Western blot背景不均
- 选择性裁剪
- 过度处理的显微图像

**识别方法：**
- 可疑图案或不连续性
- 无背景的高对比度图像
- 不同面板相似特征
- 暗示拼接的直线痕迹
- 背景不一致
- 细节丢失提示过度处理

**改进建议：**
- 全图像统一调整参数
- 拼接胶图标注分界线
- 补充材料展示完整未裁剪图像
- 应要求提供原始图像
- 遵循期刊图像完整性政策
- 使用专业图像分析工具

## 研究设计问题

### 18. 假设与结局指标定义不清

**常见问题：**
- 未陈述明确假设
- 未指定主要结局指标
- 多重结局未校正
- 数据收集后变更结局指标
- 探索性研究伪装成假设驱动

**识别方法：**
- 引言未提出可检验假设
- 多重结局指标层级不明
- 结果与方法的结局指标不符
- 探索性研究表述为验证性
- 多重检验未校正

**改进建议：**
- 陈述清晰可检验的假设
- 预先确定主要与次要结局
- 尽可能预先注册研究
- 对多重结局进行适当校正
- 明确区分探索性与验证性分析
- 报告所有预设结局指标

### 19. 基线不均衡与选择偏倚

**常见问题：**
- 组间基线特征差异
- 选择标准应用不一致
- 健康志愿者偏倚
- 幸存者偏倚
- 观察性研究中的适应症偏倚

**识别方法：**
- 表1显示显著基线差异
- 组间纳入标准不同
- 应答率<50%且未分析
- 仅分析完成者数据
- 非随机化的自选分组

**改进建议：**
- 表1报告基线特征
- 采用随机化确保均衡性
- 分析中校正基线差异
- 报告应答率并比较应答/非应答者
- 观察性数据考虑倾向评分匹配
- 采用意向治疗分析

### 20. 时间与批次效应

**常见问题：**
- 按条件分批处理样本
- 未考虑时间趋势
- 仪器随时间漂移
- 不同组别由不同操作者处理
- 组间试剂批次变更

**识别方法：**
- 所有处理组样本同日处理
- 对照组来自不同时段
- 未提及批次或时间效应
- 组别对应不同技术员
- 长周期研究未分析时间因素

**改进建议：**
- 跨批次/时间随机化样本
- 将批次作为协变量纳入分析
- 执行批次校正（ComBat、limma）
- 各批次包含质控样本
- 报告并检验时间趋势
- 平衡操作者分配

## 报告规范问题

### 21. 统计报告不完整

**常见问题：**
- 未报告检验统计量
- 缺失自由度
- 精确p值被不等式替代（p<0.05）
- 无置信区间
- 无效应量
- 未报告组别样本量

**识别方法：**
- 仅提供p值无检验统计量
- p值报告为p<0.
