# 科学批判性评估与同行评审

## 概述

同行评审是评估科学手稿的系统化流程。评估方法学、统计学、设计、可重复性、伦理和报告标准。本技能适用于跨学科手稿和基金评审，提供建设性、严谨的评估。

## 适用场景

本技能适用于：
- 期刊科学手稿同行评审
- 基金申请和研究方案评估
- 方法学和实验设计严谨性评估
- 统计分析和报告标准审查
- 可重复性和数据可用性评估
- 报告指南合规性检查（CONSORT, STROBE, PRISMA）
- 提供科学写作的建设性反馈

## 同行评审工作流

通过以下阶段系统化开展同行评审，根据手稿类型和学科调整深度与重点。

### 阶段1：初步评估

从高层次评估开始，确定手稿范围、创新性和整体质量。

**核心问题：**
- 核心研究问题或假设是什么？
- 主要发现和结论是什么？
- 研究是否科学可靠且有意义？
- 是否适合目标发表平台？
- 是否存在阻碍发表的重大缺陷？

**输出：** 2-3句话摘要，概括手稿核心内容和初步印象。

### 阶段2：逐章节详细评审

全面评估每个章节，记录具体问题和优势。

#### 摘要与标题
- **准确性：** 摘要是否准确反映研究内容和结论？
- **清晰度：** 标题是否具体、准确且信息丰富？
- **完整性：** 关键发现和方法是否恰当概括？
- **可读性：** 摘要是否易于广大科研人员理解？

#### 引言
- **背景：** 背景信息是否充分且前沿？
- **合理性：** 研究问题是否明确论证？
- **创新性：** 是否清晰阐述原创性和意义？
- **文献：** 是否恰当引用相关前期研究？
- **目标：** 研究目的/假设是否明确陈述？

#### 方法
- **可重复性：** 他人能否根据描述复现研究？
- **严谨性：** 方法是否适合解决研究问题？
- **细节：** 方案、试剂、设备和参数是否充分描述？
- **伦理：** 伦理审批、知情同意和数据处理是否规范记录？
- **统计：** 统计方法是否恰当、清晰描述并论证？
- **验证：** 对照、重复和验证方法是否充分？

**关键验证要素：**
- 样本量和功效计算
- 随机化和盲法流程
- 纳入/排除标准
- 数据收集方案
- 计算方法和软件版本
- 统计检验与多重比较校正

#### 结果
- **呈现：** 结果是否逻辑清晰？
- **图表：** 可视化是否恰当、清晰且标注规范？
- **统计：** 统计结果是否规范报告（效应量、置信区间、p值）？
- **客观性：** 结果是否避免过度解读？
- **完整性：** 是否包含所有相关结果（含阴性结果）？
- **可重复性：** 是否提供原始数据或汇总统计？

**常见问题识别：**
- 结果选择性报告
- 不当统计检验
- 缺失误差线或变异度量
- 过拟合或循环分析
- 批次效应或混杂变量
- 缺失对照或验证实验

#### 讨论
- **解读：** 结论是否有数据支持？
- **局限性：** 是否承认并讨论研究局限？
- **背景：** 发现是否在现有文献中准确定位？
- **推测：** 是否明确区分推测与数据支持结论？
- **意义：** 是否清晰阐述影响和重要性？
- **未来方向：** 是否讨论后续步骤或未解问题？

**危险信号：**
- 结论夸大
- 忽视矛盾证据
- 相关性数据推导因果主张
- 局限讨论不足
- 无机制证据的机制主张

#### 参考文献
- **完整性：** 是否引用关键相关文献？
- **时效性：** 是否包含近期重要研究？
- **平衡性：** 是否恰当引用对立观点？
- **准确性：** 引用是否准确恰当？
- **自引：** 是否存在过度或不恰当自引？

### 阶段3：方法与统计严谨性

评估研究的技术质量和严谨性，特别关注常见陷阱。

**统计评估：**
- 是否满足统计假设（正态性、独立性、方差齐性）？
- 是否同时报告效应量和p值？
- 多重检验校正是否恰当应用？
- 是否提供置信区间？
- 样本量是否通过功效分析论证？
- 参数/非参数检验选择是否恰当？
- 缺失数据处理是否规范？
- 探索性与验证性分析是否区分？

**实验设计：**
- 对照是否恰当充分？
- 重复是否充足（生物学和技术重复）？
- 是否识别并控制潜在混杂因素？
- 随机化是否规范实施？
- 盲法程序是否充分？
- 实验设计是否最优解决研究问题？

**计算/生物信息学：**
- 计算方法是否清晰描述并论证？
- 软件版本和参数是否记录？
- 是否提供可重复性代码？
- 算法和模型是否恰当验证？
- 计算方法假设是否满足？
- 批次校正是否恰当应用？

### 阶段4：可重复性与透明度

评估研究是否符合现代可重复性和开放科学标准。

**数据可用性：**
- 原始数据是否存入合适仓库？
- 是否提供公共数据库编号？
- 数据共享限制是否合理（如患者隐私）？
- 数据格式是否标准且可访问？

**代码与材料：**
- 分析代码是否可用（GitHub, Zenodo等）？
- 特殊材料是否可获取或描述充分？
- 方案是否详细描述？

**报告标准：**
- 是否遵循学科特定报告指南（CONSORT, PRISMA, ARRIVE, MIAME, MINSEQE等）？
- 常见指南见`references/reporting_standards.md`
- 是否涵盖相应清单所有要素？

### 阶段5：图表与数据呈现

评估数据可视化的质量、清晰度和完整性。

**质量检查：**
- 图表是否高分辨率且标注清晰？
- 坐标轴是否带单位规范标注？
- 误差线是否定义（SD, SEM, CI）？
- 统计显著性标识是否说明？
- 配色方案是否恰当且可访问（色盲友好）？
- 图像是否含比例尺？
- 数据可视化是否适配数据类型？

**完整性检查：**
- 是否存在图像处理痕迹（复制、拼接）？
- Western blot和凝胶是否规范呈现？
- 代表性图像是否真实代表？
- 是否展示所有条件（无选择性呈现）？

**清晰度：**
- 图表能否通过图注独立理解？
- 每张图表信息是否即时清晰？
- 是否存在冗余图表或面板？
- 数据是否更适合表格呈现？

### 阶段6：伦理考量

验证研究是否符合伦理标准和指南。

**人类受试者：**
- 是否记录IRB/伦理审批？
- 是否描述知情同意？
- 弱势群体是否恰当保护？
- 患者隐私是否充分保护？
- 是否披露潜在利益冲突？

**动物研究：**
- 是否记录IACUC或等效审批？
- 操作是否人道且论证充分？
- 是否考虑3R原则（替代、减少、优化）？
- 安乐死方法是否恰当？

**科研诚信：**
- 是否存在数据捏造/篡改嫌疑？
- 作者身份是否合理？
- 是否披露竞争利益？
- 是否说明资金来源？
- 是否存在抄袭或重复发表嫌疑？

### 阶段7：写作质量与清晰度

评估手稿的清晰度、组织结构和可读性。

**结构与组织：**
- 手稿是否逻辑清晰？
- 章节是否连贯衔接？
- 观点过渡是否明确？
- 叙述是否引人入胜？

**写作质量：**
- 语言是否清晰、精确、简洁？
- 术语和缩写是否最小化并定义？
- 语法拼写是否正确？
- 句子是否过度复杂？
- 被动语态是否滥用？

**可读性：**
- 非专业人士能否理解主要发现？
- 技术术语是否解释？
- 广泛受众能否理解研究意义？

## 同行评审报告结构化

按优先级组织反馈，提供可操作指导。

### 总结陈述

简明总体评估（1-2段）：
- 研究概要
- 总体建议（接收/小修/大修/拒稿）
- 关键优势（2-3要点）
- 关键不足（2-3要点）
- 重要性和可靠性的底线评估

### 主要意见

列出严重影响手稿有效性、可解释性或重要性的关键问题。按序号排列。

**主要意见通常包括：**
- 根本性方法缺陷
- 不当统计分析
- 无支持或夸大结论
- 缺失关键对照或实验
- 严重可重复性问题
- 重大文献覆盖缺口
- 伦理问题

**每条主要意见需：**
1. 明确陈述问题
2. 解释问题原因
3. 建议具体解决方案或补充实验
4. 说明是否必须解决才能发表

### 次要意见

列出改善清晰度、完整性或呈现的次要问题。按序号排列。

**次要意见通常包括：**
- 图表标注不清
- 方法细节缺失
- 排版或语法错误
- 数据呈现优化建议
- 次要统计报告问题
- 可加强结论的补充分析
- 澄清请求

**每条次要意见需：**
1. 定位具体位置（章节/段落/图表）
2. 清晰陈述问题
3. 建议解决方案

### 逐行具体意见（可选）

需要详细反馈时，提供章节或逐行意见：
- 标注具体页码/行号或章节
- 指出事实错误、模糊陈述或缺失引用
- 建议具体编辑以提升清晰度

### 作者答疑

列出需澄清的具体问题：
- 不明确的方法细节
- 看似矛盾的结果
- 评估所需的缺失信息
- 补充数据或分析请求

## 语气与态度

全程保持建设性、专业性和协作性。

**最佳实践：**
- **建设性：** 将批评转化为改进机会
- **具体化：** 提供实例和可操作建议
- **平衡性：** 肯定优势并指出不足
- **尊重性：** 认可作者付出
- **客观性：** 聚焦科学而非科学家
- **全面性：** 不遗漏问题但合理排序
- **清晰性：** 避免模糊批评

**避免：**
- 人身攻击或贬低语言
- 讽刺或居高临下
- 无具体案例的模糊批评
- 超出范围的实验要求
- 要求符合个人偏好而非最佳实践
- 双盲评审中泄露身份

## 不同手稿类型的特殊考量

### 原创研究论文
- 强调严谨性、可重复性和创新性
- 评估意义和影响
- 验证结论是否数据驱动
- 检查完整方法和恰当对照

### 综述与荟萃分析
- 评估文献覆盖全面性
- 评估检索策略和纳入/排除标准
- 验证系统方法和无偏倚
- 检查批判性分析而非单纯总结
- 荟萃分析需评估统计方法和异质性

### 方法学论文
- 强调验证及与现有方法比较
- 评估可重复性和方案/代码可用性
- 评估对现有方法的改进
- 检查实施细节充分性

### 简报/通讯
- 根据简洁性调整预期
- 确保核心发现仍严谨重要
- 验证格式适配研究内容

### 预印本
- 需知未经正式同行评审
- 可能不如期刊投稿完善
- 仍应坚持科学有效性标准
- 考虑提供建设性反馈助作者改进

### 演示文稿与幻灯片

**⚠️ 关键：评审演示文稿时，切勿直接读取PDF。务必先转换为图像。**

评审科学演示文稿（PowerPoint, Beamer, 幻灯片）时：

#### 强制图像化评审流程

**切勿直接读取PDF**——会导致缓冲区溢出且无法显示视觉格式问题。

**必需流程：**
1. 使用Python转换PDF为图像：
   ```bash
   python skills/scientific-slides/scripts/pdf_to_images.py presentation.pdf review/slide --dpi 150
   # 生成: review/slide-001.jpg, review/slide-002.jpg 等
   ```
2. 按序检查每张幻灯片图像
3. 记录具体幻灯片编号问题
4. 提供视觉格式和内容反馈

**开始评审时打印：**
```
[HH:MM:SS] 同行评审：检测到演示文稿 - 正在转换为图像
[HH:MM:SS] PDF评审：永不直接读取PDF - 采用图像化检查
```

#### 演示文稿专属评估标准

**视觉设计与可读性：**
- [ ] 文字足够大（正文最小18pt，建议24pt+）
- [ ] 文字背景高对比度（最低4.5:1，建议7:1）
- [ ] 配色专业且色盲友好
- [ ] 全幻灯片视觉风格统一
- [ ] 留白充足（不拥挤）
- [ ] 字体清晰专业

**布局与格式（逐图检查）：**
- [ ] 无文字溢出或边缘截断
- [ ] 无元素重叠（文字覆盖图像、形状重叠）
- [ ] 标题位置统一
- [ ] 内容对齐规范
- [ ] 项目符号和文字无截断
- [ ] 图表适配幻灯片边界
- [ ] 标注和标签清晰可读

**内容质量：**
- [ ] 每页幻灯片一个核心观点（不超载）
- [ ] 文字精简（每页最多3-6个项目）
- [ ] 项目符号简洁（每项5-7词）
- [ ] 图表简化清晰（非论文直接复制）
- [ ] 数据可视化标签大而清晰
- [ ] 引用规范存在
- [ ] 结果/数据页占主导（40-50%内容）

**结构与流程：**
- [ ] 清晰叙事线（引言→方法→结果→讨论）
- [ ] 幻灯片间逻辑递进
- [ ] 幻灯片数量适配演讲时长（约1页/分钟）
- [ ] 标题页含作者、单位、日期
- [ ] 引言引用相关文献（3-5篇）
- [ ] 讨论引用对比文献（3-5篇）
- [ ] 结论页总结核心发现
- [ ]

- 文字过多（大段文字，非要点形式）
- 图示简化不当（坐标轴标签过小）
- 布局拥挤，留白不足
- 缺失关键结构要素（无结论页）
- 配色不当（未考虑色盲友好）
- 结果内容过少（幻灯片占比<30%）

**次要问题（改进建议）：**
- 可增加更多视觉图表
- 部分幻灯片文字稍显密集
- 存在轻微对齐不一致
- 可增加留白空间
- 补充引用可增强论点可信度
- 配色方案可更现代化

#### 演示文稿评审报告格式

**总结陈述：**
- 演示文稿整体质量印象
- 对目标受众及时长的适配性
- 核心优势（视觉设计、内容、清晰度）
- 主要缺陷（格式问题、内容缺失）
- 建议（可直接演示、需小修、需大改）

**版式与格式问题（按幻灯片编号）：**
```
Slide 3: 文字溢出 - 第4个要点超出右边界
Slide 7: 元素重叠 - 图表与说明文字重叠
Slide 12: 字号问题 - 坐标轴标签过小难以远距离识别
Slide 18: 对齐问题 - 标题未居中
```

**内容与结构反馈：**
- 背景介绍与文献引用的充分性
- 研究问题与目标的清晰度
- 方法摘要的质量
- 结果呈现的有效性
- 结论与启示的力度

**设计与可访问性：**
- 整体视觉吸引力与专业度
- 色彩对比度与可读性
- 色盲友好性
- 幻灯片间的一致性

**时长与范围：**
- 幻灯片数量是否符合预期时长
- 内容详略是否适配演讲类型
- 各章节的平衡性
