# DiffDock置信度评分与局限性

本文档详细指导如何解读DiffDock置信度评分并理解该工具的局限性。

## 置信度评分解读

DiffDock为每个预测的结合构象生成置信度评分，该评分反映模型对预测结果的确定程度。

### 评分范围

| 评分区间      | 置信等级       | 解读说明                     |
|---------------|----------------|------------------------------|
| **> 0**       | 高置信度       | 强预测结果，可能为准确结合构象 |
| **-1.5 至 0** | 中等置信度     | 合理预测，建议验证           |
| **< -1.5**    | 低置信度       | 不确定性预测，需谨慎验证     |

### 置信度评分重要说明

1. **非结合亲和力**：置信度评分反映预测确定性，而非结合亲和力强度
   - 高置信度 = 模型对结构预测有把握
   - 不表示强/弱结合亲和力

2. **上下文依赖性**：置信度评分需根据体系复杂度调整：
   - **降低预期**的情况：
     - 大分子配体（>500 Da）
     - 多链蛋白质复合物
     - 未结合蛋白质构象（可能需构象变化）
     - 训练数据中未充分表征的新蛋白家族

   - **提高预期**的情况：
     - 类药小分子（150-500 Da）
     - 单链蛋白质或明确结合位点
     - 与训练数据相似的蛋白质（PDBBind, BindingMOAD）

3. **多重预测**：DiffDock为每个复合物生成多个样本（默认：10个）
   - 审阅置信度排名靠前的预测
   - 考虑聚类相似构象
   - 多个样本的高置信度共识可增强预测可靠性

## DiffDock预测能力范围

### ✅ DiffDock可预测
- **结合构象**：配体在蛋白质结合位点的3D空间取向
- **置信度评分**：模型对预测的确定程度
- **多重构象**：多种可能的结合模式

### ❌ DiffDock不可预测
- **结合亲和力**：蛋白质-配体相互作用强度（ΔG, Kd, Ki）
- **结合动力学**：结合/解离速率、停留时间
- **ADMET性质**：吸收、分布、代谢、排泄、毒性
- **选择性**：对不同靶标的相对结合能力

## 适用范围与局限性

### 适用对象
- **小分子对接**：典型有机化合物（100-1000 Da）
- **蛋白质靶标**：单链或多链蛋白质
- **小肽段**：短肽配体（< ~20个残基）
- **小核酸**：短链寡核苷酸

### 不适用对象
- **大生物分子**：完整蛋白质-蛋白质相互作用
  - 请改用DiffDock-PP、AlphaFold-Multimer或RoseTTAFold2NA
- **大肽段/蛋白质**：>20个残基的配体
- **共价对接**：不可逆共价键形成
- **金属蛋白特性**：可能无法准确处理金属配位
- **膜蛋白**：未专门针对膜嵌入蛋白训练

### 训练数据考量

DiffDock训练数据来源：
- **PDBBind**：多样化蛋白质-配体复合物
- **BindingMOAD**：多结构域蛋白质结构

**影响**：
- 对类似训练数据的蛋白质/配体表现最佳
- 以下情况可能表现欠佳：
  - 新型蛋白家族
  - 非常规配体化学型
  - 训练数据中未充分表征的变构位点

## 验证与辅助工具

### 推荐工作流程

1. **DiffDock生成构象**
   - 使用置信度评分进行初步排序
   - 考虑多个高置信度预测

2. **可视化检查**
   - 在分子查看器中检查蛋白质-配体相互作用
   - 验证合理性：
     - 氢键
     - 疏水相互作用
     - 空间互补性
     - 静电相互作用

3. **评分与优化**（选择一项或多项）：
   - **GNINA**：基于深度学习的评分函数
   - **分子力学**：能量最小化与优化
   - **MM/GBSA或MM/PBSA**：结合自由能估算
   - **自由能计算**：采用FEP或TI进行精确亲和力预测

4. **实验验证**
   - 生化检测（IC50, Kd测量）
   - 结构验证（X射线晶体学、冷冻电镜）

### 结合亲和力评估工具

DiffDock应与以下工具联用进行亲和力预测：

- **GNINA**：快速精确的评分函数
  - Github: github.com/gnina/gnina

- **AutoDock Vina**：经典对接与评分
  - 网站: vina.scripps.edu

- **自由能计算**：
  - OpenMM + OpenFE
  - GROMACS + ABFE/RBFE方案

- **MM/GBSA工具**：
  - MMPBSA.py (AmberTools)
  - gmx_MMPBSA

## 性能优化

### 最佳实践

1. **蛋白质预处理**：
   - 移除结合位点外的水分子
   - 尽可能补全缺失残基
   - 考虑生理pH下的质子化状态

2. **配体输入**：
   - 使用结构文件时提供合理3D构象
   - 采用规范SMILES确保结果一致性
   - 必要时用RDKit进行预处理

3. **计算资源**：
   - 强烈推荐GPU（加速10-100倍）
   - 首次运行需预计算查找表（耗时数分钟）
   - 批量处理比单次预测更高效

4. **参数调整**：
   - 复杂案例增加`samples_per_complex`（20-40）
   - 调整温度参数平衡多样性/准确性
   - 重复预测时使用预计算ESM嵌入

## 常见问题与排查

### 低置信度评分
- **大分子/柔性配体**：考虑分片段处理或改用其他方法
- **多重结合位点**：可能预测多个位置且置信度分散
- **蛋白质柔性**：考虑采用蛋白质构象集合

### 非现实预测
- **空间冲突**：可能需优化蛋白质结构
- **表面结合**：检查真实结合位点是否被阻断
- **异常构象**：考虑增加样本探索更多构象

### 运行缓慢
- **使用GPU**：保证合理运行时间的关键
- **预计算嵌入**：相同蛋白质复用ESM嵌入
- **批量处理**：比顺序单次预测更高效
- **减少样本量**：快速筛选时降低`samples_per_complex`
