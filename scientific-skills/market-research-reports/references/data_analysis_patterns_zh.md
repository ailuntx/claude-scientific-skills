用于开展严谨市场分析的模板与框架。

## 市场规模测算框架

### TAM/SAM/SOM 分析

**总体可触达市场（TAM）** 代表实现100%市场份额时的总营收机会。

#### 自上而下法
```
TAM = 行业总营收（来自市场研究报告）

示例：
- 全球人工智能软件市场（2024年）：1840亿美元
- 来源：Gartner、IDC或类似机构
```

#### 自下而上法
```
TAM = 潜在客户数量 × 单客户平均营收

示例：
- 全球企业数量：4亿家
- 目标客群（大型企业）：50,000家
- 解决方案年均支出：50万美元
- TAM = 50,000 × $500,000 = 250亿美元
```

**可服务可触达市场（SAM）** 代表产品/服务能力可覆盖的TAM部分。

```
SAM = TAM × 适用细分市场百分比

示例：
- TAM：250亿美元
- 地域限制（仅北美）：40%
- 产品适配性（仅限企业级）：60%
- SAM = $25B × 40% × 60% = 60亿美元
```

**可获取服务市场（SOM）** 代表实际可获取的市场份额。

```
SOM = SAM × 可实现市场份额百分比

示例：
- SAM：60亿美元
- 保守市场份额（5%）：3亿美元
- 基准市场份额（10%）：6亿美元
- 乐观市场份额（15%）：9亿美元
```

### 增长率计算

#### 复合年增长率（CAGR）
```
CAGR = (期末值 / 期初值)^(1/n) - 1

其中 n = 年数

示例：
- 2020年市场规模：100亿美元
- 2024年市场规模：180亿美元
- n = 4年
- CAGR = (18/10)^(1/4) - 1 = 15.8%
```

#### 同比增长率
```
同比增长率 = (当年值 - 上年值) / 上年值 × 100

示例：
- 2023年：150亿美元
- 2024年：180亿美元
- 同比增长率 = (18-15)/15 × 100 = 20%
```

## 财务分析模式  

### 收入预测模型  

```  
第N年收入 = 第N-1年收入 × (1 + 增长率)  

或自下而上：  
收入 = 客户数 × 单客户收入 × 留存率  
        + 新客户数 × 单客户收入 × (1 - 流失率)  
```

| 指标 | 公式 | 目标值 |  
|--------|---------|--------|  
| 毛利率 | (收入 - 销售成本) / 收入 | X% |
