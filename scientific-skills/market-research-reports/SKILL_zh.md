# 市场研究报告

## 概述

市场研究报告是分析行业、市场及竞争格局的战略性文件，为商业决策、投资策略和战略规划提供依据。本技能可生成**50页以上的专业级报告**，包含丰富可视化内容，模拟麦肯锡、BCG、贝恩、高德纳、弗雷斯特等顶级咨询公司的交付成果。

**核心特性：**
- **全面篇幅**：报告设计为50+页，无token限制
- **可视化丰富**：初始生成5-6个关键图表（撰写过程中按需追加）
- **数据驱动分析**：深度整合research-lookup获取市场数据
- **多框架分析**：波特五力/PESTLE/SWOT/BCG矩阵/TAM-SAM-SOM
- **专业排版**：咨询公司级字体/色彩/版式设计
- **可执行建议**：聚焦战略实施路线图

**输出格式：** 采用专业样式LaTeX编译为PDF，使用`market_research.sty`样式包确保统一专业排版。

## 使用场景

本技能适用于：
- 为投资决策制作市场深度分析
- 制定战略规划所需的行业报告
- 分析竞争格局与市场动态
- 执行市场规模测算（TAM/SAM/SOM）
- 评估市场进入机会
- 准备并购尽职调查材料
- 创建行业定位思想领导内容
- 制定市场进入战略文档
- 分析政策法规对市场影响
- 构建新产品上市商业论证

## 工作流程

### 阶段1：研究与数据采集

**步骤1：界定范围**
- 明确市场定义
- 设定地理边界
- 确定时间跨度
- 识别核心研究问题

**步骤2：深度研究**

使用`research-lookup`采集市场数据：

```bash
# 市场规模与增长数据
python skills/research-lookup/scripts/research_lookup.py \
  "[行业]当前市场规模及预测增长率？含TAM/SAM/SOM预估及复合年增长率预测"

# 竞争格局
python skills/research-lookup/scripts/research_lookup.py \
  "[市场]Top10竞争者？其市场份额与竞争定位？"

# 行业趋势
python skills/research-lookup/scripts/research_lookup.py \
  "2024-2030年[市场]主要趋势与增长驱动？"

# 政策环境
python skills/research-lookup/scripts/research_lookup.py \
  "影响[市场]的核心法规与政策变动？"
```

**步骤3：数据整理**
- 创建`sources/`研究笔记目录
- 按章节整理数据
- 识别数据缺口
- 按需补充研究

### 阶段2：分析与框架应用

**步骤4：应用分析框架**

对每个框架执行结构化分析：
- **市场规模**：TAM→SAM→SOM（明确假设）
- **波特五力**：逐项评估高/中/低（附依据）
- **PESTLE**：各维度趋势与影响分析
- **SWOT**：内部优势劣势/外部机会威胁
- **竞争定位**：定义坐标轴/标定竞争者

**步骤5：提炼洞察**
- 整合发现形成关键洞察
- 识别战略启示
- 制定建议方案
- 机会优先级排序

### 阶段4：报告撰写

**步骤7：初始化项目结构**

创建标准项目结构：

```
writing_outputs/YYYYMMDD_HHMMSS_market_report_[主题]/
├── progress.md
├── drafts/
```

**步骤8：使用模板撰写报告**

以`market_report_template.tex`为起点撰写报告。遵循结构指南编写每个章节，确保：

- **全面覆盖**：处理所有子章节
- **数据驱动内容**：论点需有研究支撑
- **可视化整合**：引用所有生成图表
- **专业语气**：咨询风格写作
- **无字数限制**：完整撰写，勿缩写

**撰写指南：**
- 尽可能使用主动语态
- 以洞察为先导，数据为支撑
- 建议事项采用编号列表
- 所有统计数据注明来源
- 章节间过渡自然流畅

## 质量标准

### 页数目标

| 章节 | 最低页数 | 目标页数 |
|---------|---------------|--------------|
| 前辅文 | 4 | 5 |
| 市场概览 | 4 | 5 |

| 投资主题 | 2 | 4 |
| 后辅文 | 4 | 5 |
| **总计** | **43** | **66** |

### 可视化质量要求

- **分辨率**：所有图像最低300 DPI
- **格式**：栅格图用PNG，矢量图用PDF
- **无障碍设计**：色盲友好配色
- **一致性**：全文档统一配色方案
- **标注**：所有坐标轴/图例/数据点带标签
- **来源标注**：图注中注明数据来源

### 数据质量要求

- **时效性**：数据不超过2年（优先当年）
- **溯源**：所有统计数据标注具体来源
- **验证**：尽可能交叉验证多源数据
- **假设说明**：所有预测需声明基础假设
- **局限性**：注明数据局限与缺口

### 撰写质量要求

- **客观性**：平衡分析，承认不确定性
- **清晰度**：避免术语，定义技术词汇
- **精确性**：使用具体数值替代模糊描述
- **结构**：标题清晰，逻辑流畅，过渡自然
- **可操作性**：建议具体且可实施

## LaTeX格式规范

### 使用样式包

`market_research.sty`提供专业排版格式。在文档中引入：

```latex
\documentclass[11pt,letterpaper]{report}
\usepackage{market_research}
```

### 高亮框环境

使用彩色框突出关键内容：

```latex
% 核心洞察框（蓝色）
\begin{keyinsightbox}[关键发现]
预计到2030年市场年复合增长率将达15.3%。
\end{keyinsightbox}

% 市场数据框（绿色）
\begin{marketdatabox}[市场快照]
\begin{itemize}
    \item 当前规模(2024)：452亿美元
    \item 预测规模(2030)：987亿美元
    \item 年复合增长率：15.3%
\end{itemize}
\end{marketdatabox}

% 风险框（橙色/警告）
\begin{riskbox}[重大风险]
监管变化可能影响40%的市场参与者。
\end{riskbox}

% 建议框（紫色）
\begin{recommendationbox}[战略建议]
优先布局亚太区域市场。
\end{recommendationbox}

% 标注框（灰色）
\begin{calloutbox}[定义]
TAM（总可触达市场）代表整体营收机会。
\end{calloutbox}
```

## 故障排除

### 常见问题

**问题**：报告不足50页
- **解决方案**：扩展附录数据表，增加企业档案详情，补充区域细分分析

**问题**：图表渲染失败
- **解决方案**：检查LaTeX文件路径，确认图像位于figures/目录，验证文件扩展名

**问题**：参考文献缺失
- **解决方案**：首次xelatex编译后运行bibtex，检查.bib文件语法

**问题**：表格/图像溢出
- **解决方案**：使用`\resizebox`或`adjustbox`宏包，降低图像宽度百分比

**问题**：生成图像质量差
- **解决方案**：使用`--doc-type report`参数，通过`--iterations 5`增加迭代次数
