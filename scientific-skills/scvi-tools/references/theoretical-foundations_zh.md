# scvi-tools的理论基础

本文档阐述了scvi-tools背后的数学与统计学原理。

## 核心概念

### 变分推断

**定义**
变分推断是一种近似复杂概率分布的技术。在单细胞分析中，我们期望理解后验分布p(z|x)——即给定观测数据x时隐变量z的概率。

**应用价值**
- 复杂模型的精确推断在计算上不可行
- 可扩展到海量数据集（数百万细胞）
- 提供不确定性量化
- 支持基于贝叶斯框架的细胞状态推理

**实现原理**
1. 定义带可学习参数的简化近似分布q(z|x)
2. 最小化q(z|x)与真实后验p(z|x)之间的KL散度
3. 等价于最大化证据下界（ELBO）

**ELBO目标函数**：
```
ELBO = E_q[log p(x|z)] - KL(q(z|x) || p(z))
       ↑                    ↑
  重构项                  正则化项
```

- **重构项**：模型应生成与观测数据相似的输出
- **正则化项**：隐表示应与先验分布匹配

### 变分自编码器（VAEs）

**架构**：
```
x (观测数据)
    ↓
[编码器神经网络]
    ↓
z (隐表示)
    ↓
[解码器神经网络]
    ↓
x̂ (重构数据)
```

**编码器**：将细胞数据(x)映射到隐空间(z)
- 学习近似后验分布q(z|x)
- 由带可学习权重的神经网络参数化
- 输出隐分布的均值和方差

**解码器**：将隐空间(z)映射回基因空间
- 学习似然函数p(x|z)
- 从隐表示生成基因表达数据
- 建模计数分布（负二项分布、零膨胀负二项分布）

**重参数化技巧**：
- 允许通过随机采样进行反向传播
- 采样公式：z = μ + σ ⊙ ε，其中ε ~ N(0,1)
- 支持基于梯度下降的端到端训练

### 摊销推断

**核心思想**：所有细胞共享编码器参数

**传统推断**：为每个细胞学习独立隐变量
- 参数量：n_cells × n_latent
- 无法扩展到大型数据集

**摊销推断**：为所有细胞学习单一编码器
- 参数量与细胞数量无关
- 支持新细胞的快速推断
- 跨数据集迁移学习模式

**优势**：
- 可扩展至百万级细胞
- 查询数据快速推断
- 利用细胞间共享结构
- 实现少样本学习

## 统计建模

### 计数数据分布

单细胞数据为整数值计数，需采用适当分布建模

#### 负二项分布（NB）
```
x ~ NB(μ, θ)
```
- **μ (均值)**：期望表达水平
- **θ (离散度)**：控制方差
- **方差公式**：Var(x) = μ + μ²/θ

**适用场景**：无零膨胀的基因表达数据
- 比泊松分布更灵活（允许过离散）
- 建模技术和生物变异

#### 零膨胀负二项分布（ZINB）
```
x ~ π·δ₀ + (1-π)·NB(μ, θ)
```
- **π (零缺失率)**：技术性零值概率
- **δ₀**：零值点质量
- **NB(μ, θ)**：非零缺失时的表达分布

**适用场景**：稀疏scRNA-seq数据
- 区分技术性零缺失与生物性零值
- 更适配高稀疏数据（如10x数据）

#### 泊松分布
```
x ~ Poisson(μ)
```
- 最简计数分布
- 均值等于方差：Var(x) = μ

**适用场景**：较少使用；ATAC-seq片段计数
- 比NB限制性更强
- 计算速度更快

### 批次校正框架

**问题**：技术变异干扰生物信号
- 不同测序批次、实验方案、实验室
- 需消除技术效应同时保留生物信息

**scvi-tools方案**：
1. 将批次编码为类别变量s
2. 在生成模型中引入s
3. 隐空间z保持批次不变性
4. 解码器基于s处理批次特异性效应

**数学表达**：
```
编码器：q(z|x, s)  - 批次感知编码
隐空间：z          - 批次校正表示
解码器：p(x|z, s)  - 批次特异性解码
```

**关键洞见**：批次信息流经解码器而非隐空间
- z捕获生物变异
- s解释技术变异
- 生物效应与批次效应可分离

### 深度生成建模

**生成模型**：学习数据分布p(x)

**生成过程**：
1. 采样隐变量：z ~ p(z) = N(0, I)
2. 生成表达数据：x ~ p(x|z)
3. 联合分布：p(x, z) = p(x|z)p(z)

**优势**：
- 生成合成细胞
- 填补缺失值
- 量化不确定性
- 执行反事实预测

**推断网络**：逆转生成过程
- 给定x推断z
- q(z|x)近似真实后验p(z|x)

## 模型架构细节

### scVI架构

**输入**：基因表达计数x ∈ ℕ^G（G个基因）

**编码器**：
```
h = ReLU(W₁·x + b₁)
μ_z = W₂·h + b₂
log σ²_z = W₃·h + b₃
z ~ N(μ_z, σ²_z)
```

**隐空间**：z ∈ ℝ^d（通常d=10-30）

**解码器**：
```
h = ReLU(W₄·z + b₄)
μ = softmax(W₅·h + b₅) · 文库大小
θ = exp(W₆·h + b₆)
π = sigmoid(W₇·h + b₇)  # ZINB专用
x ~ ZINB(μ, θ, π)
```

**损失函数（ELBO）**：
```
L = E_q[log p(x|z)] - KL(q(z|x) || N(0,I))
```

### 协变量处理

**类别协变量**（批次、供体等）：
- 独热编码：s ∈ {0,1}^K
- 与隐变量拼接：[z, s]
- 或使用条件层

**连续协变量**（文库大小、线粒体基因占比）：
- 标准化为零均值单位方差
- 引入编码器和/或解码器

**协变量注入策略**：
- **拼接法**：[z, s]输入解码器
- **深度注入**：s在多层添加
- **条件批归一化**：批次特异性归一化

## 高级理论概念

### 迁移学习（scArches）

**原理**：将预训练模型作为新数据初始化

**流程**：
1. 在大规模数据集训练参考模型
2. 冻结编码器参数
3. 在查询数据上微调解码器
4. 或以更低学习率微调全部参数

**有效性基础**：
- 编码器学习通用细胞表示
- 解码器适配查询数据特性
- 避免灾难性遗忘

**应用场景**：
- 查询-参考数据映射
- 稀有细胞类型的少样本学习
- 新数据集快速分析

### 多分辨率建模（MrVI）

**核心思想**：分离共享变异与样本特异性变异

**隐空间分解**：
```
z = z_共享 + z_样本
```
- **z_共享**：跨样本共有
- **z_样本**：样本特异性效应

**层级结构**：
```
样本层：ρ_s ~ N(0, I)
细胞层：z_i ~ N(ρ_{s(i)}, σ²)
```

**优势**：
- 解耦生物变异来源
- 支持不同分辨率样本比较
- 识别样本特异性细胞状态

### 反事实预测

**目标**：预测不同条件下的结果

**示例**："若该细胞来自不同批次，其表达将如何变化？"

**方法**：
1. 编码细胞至隐空间：z = 编码器(x, s_原始)
2. 新条件解码：x_新 = 解码器(z, s_新)
3. x_新即为反事实预测

**应用场景**：
- 批次效应评估
- 治疗响应预测
- 计算机扰动研究

### 后验预测分布

**定义**：给定观测数据的新数据分布

```
p(x_新 | x_观测) = ∫ p(x_新|z) q(z|x_观测) dz
```

**估计方法**：从q(z|x)采样z，通过p(x_新|z)生成x_新

**用途**：
- 不确定性量化
- 鲁棒预测
- 异常值检测

## 差异表达分析框架

### 贝叶斯方法

**传统方法**：比较点估计值
- Wilcoxon检验、t检验等
- 忽略不确定性
- 需伪计数处理

**scvi-tools方案**：比较分布
- 从后验采样：μ_A ~ p(μ|x_A), μ_B ~ p(μ|x_B)
- 计算对数倍数变化：LFC = log(μ_B) - log(μ_A)
- LFC的后验分布量化不确定性

### 贝叶斯因子

**定义**：后验概率比与先验概率比的比值

```
BF = P(H₁|数据) / P(H₀|数据)
     ─────────────────────────
     P(H₁) / P(H₀)
```

**判读标准**：
- BF > 3：支持H₁的中等证据
- BF > 10：强证据
- BF > 100：决定性证据

**在scvi-tools中**：用于按差异表达证据强度排序基因

### 错误发现比例（FDP）

**目标**：控制期望错误发现率

**流程**：
1. 计算每个基因的差异表达后验概率
2. 按证据强度（贝叶斯因子）排序基因
3. 选择满足E[FDP] ≤ α的top k基因

**相对p值的优势**：
- 完全贝叶斯框架
- 与后验推断自然契合
- 无需人为设定阈值

## 实现细节

### 优化策略

**优化器**：Adam（自适应学习率）
- 默认学习率lr = 0.001
- 动量参数：β₁=0.9, β₂=0.999

**训练循环**：
1. 采样细胞小批量
2. 计算ELBO损失
3. 反向传播梯度
4. Adam更新参数
5. 重复直至收敛

**收敛标准**：
- 验证集ELBO趋于稳定
- 早停防止过拟合
- 典型训练200-500轮

### 正则化技术

**KL退火**：逐步增加KL项权重
- 防止后验塌陷
- 初始为0，训练轮次中渐增至1

**随机失活**：训练中随机丢弃神经元
- 默认失活率：0.1
- 防止过拟合
- 提升泛化能力

**权重衰减**：权重L2正则化
- 抑制权重过大
- 提升稳定性

### 可扩展性

**小批量训练**：
- 单次迭代处理子集细胞
- 批量大小：64-256细胞
- 支持百万级细胞规模

**随机优化**：
- 基于小批量估计ELBO
- 无偏梯度估计
- 收敛至最优解

**GPU加速**：
- 神经网络天然可并行
- 数量级速度提升
- 处理大规模数据的关键

## 与其他方法的关联

### 对比PCA
- **PCA**：线性、确定性
- **scVI**：非线性、概率性
- **优势**：scVI捕获复杂结构，原生处理计数数据

### 对比t-SNE/UMAP
- **t-SNE/UMAP**：面向可视化
- **scVI**：完整生成模型
- **优势**：scVI支持下游任务（差异表达、填补）

### 对比Seurat整合
- **Seurat**：基于锚点的对齐
- **scVI**：概率建模
- **优势**：scVI提供不确定性量化，支持多批次处理

### 对比Harmony
- **Harmony**：PCA+批次校正
- **scVI**：基于VAE
- **优势**：scVI原生处理计数数据，灵活性更强

## 数学符号说明

**常用符号**：
- x：观测基因表达（计数）
- z：隐表示
- θ：模型参数
- q(z|x)：近似后验（编码器）
- p(x|z)：似然函数（解码器）
- p(z)：隐变量先验
- μ, σ²：均值与方差
- π：零缺失概率（ZINB）
- θ（NB中）：离散度参数
- s：批次/协变量指示符
