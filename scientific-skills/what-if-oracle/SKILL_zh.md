# 假设预言机 —— 可能性空间探索器

通过严谨的多分支情景分析探索不确定未来的结构化系统。预言机不提供单一预测，而是绘制完整的**可能性空间**——每个分支时间线都有其内在逻辑、概率和后果的树状图谱。

基于"假设陈述"范式：推测性问题（"如果X发生？"）并非空想，而是**基础计算操作**——人类在投入资源前模拟未来的思维机制。

已发表研究：[假设陈述 (DOI: 10.5281/zenodo.18736841)](https://doi.org/10.5281/zenodo.18736841) | [IDNA整合v2 (DOI: 10.5281/zenodo.18807387)](https://doi.org/10.5281/zenodo.18807387)

## 核心原则：0·若·1

所有情景分析包含三要素：

- **0** —— 未显化状态（尚未发生的潜在可能）
- **1** —— 显化状态（当前现实）
- **若** —— 条件纽带（促使0转化为1的决策、事件或变化）

分析质量取决于"若"的精确度。模糊的"如果出问题怎么办？"产生模糊结论；精确的"如果主要供应商Q3涨价30%？"则生成可行动情报。

## 预言机操作指南

### 阶段1 —— 问题界定

提炼用户的假设性问题：

**要素拆解：**
- **变量：** 具体变化项？（每次分析单变量）
- **幅度：** 变化程度？（尽可能量化）
- **时间：** 变化周期？
- **背景：** 变化前的现状？

**模糊问题精炼示例：**
- "如果AI统治世界？" → "若未来3年[具体行业]40%知识型工作被AI自动化？"
- "如果我们失败？" → "若月收入连续6个月低于5000美元？"

精炼后需用户确认再继续。

### 阶段2 —— 绘制可能性空间

按框架生成**4-6个情景分支**：

| 分支             | 定义                                                                 | 作用                                               |
| ---------------- | -------------------------------------------------------------------- | -------------------------------------------------- |
| **Ω最佳情况**    | 一切顺利。关键假设成立，出现有利转机                                 | 界定上限——最大收益？                               |
| **α可能情况**    | 基于当前证据的最可能路径，无重大意外                                 | 锚定现实预期                                       |
| **Δ最坏情况**    | 关键假设失效，同时出现两处问题                                       | 界定下限——最大风险？                               |
| **Ψ黑天鹅**      | 出现未被追踪的意外变量                                               | 应对不可预见的压力测试                             |
| **Φ逆向思维**    | 共识观点的对立面成立                                                 | 打破群体思维，揭示隐藏假设                         |
| **∞二阶效应**    | 首轮影响引发无人预见的连锁反应                                       | 描绘涟漪效应                                       |

### 阶段3 —— 分支分析

每个情景分支需提供：

║  时间：[可能发生时段]                        ║

╠══════════════════════════════════════════════╣
║  情景推演：                                  ║
║  [2-3句话逐步描述该情景发展路径]             ║
║                                              ║

### 阶段4 —— 综合分析

全部分支分析后提供：

**概率分布：**

```
Ω最佳情况 ····· [██████░░░░] 15%
α可能情况 ··· [████████░░] 45%
Δ最坏情况 ···· [██████░░░░] 20%
Ψ黑天鹅 ····· [███░░░░░░░]  8%
Φ逆向思维 ···· [████░░░░░░]  7%
∞二阶效应 ·· [███░░░░░░░]  5%
```

**稳健行动：** 哪些措施在多个分支中均有益？这些是无悔决策——无论何种未来都应执行。

**风险对冲：** 哪些预案能防范最坏分支又不牺牲收益？

**决策触发器：** 哪些可观测信号预示主导分支变化？定义警戒阈值。

**1%关键洞察：** 绝大多数分析者会忽略的核心要素？非显性模式、隐藏假设或被忽视的变量。

## 黄金比例权重

存在证据时采用黄金比例分配：

- **主未来（最可能）：** 61.8%注意力/资源
- **次未来：** 38.2%注意力/资源

该比例避免单一路径过度投入或应急方案过度分散。自然界分支系统（树木/血管/河流）均遵循此比例，战略规划亦可效仿。

## 工作模式

### 快速预言（2-3分钟）

仅分析最佳/可能/最坏三分支，提供精简推演，适用于快速决策。

### 深度预言（5-10分钟）

完整六分支分析，含影响链/触发器/综合评估，适用于高风险决策。

### 情景链

将预言机输出作为新分析输入："若Δ分支发生，其内部存在哪些可能性？"适用于复杂战略的递归推演。

### 逆向预言

从目标结果反推："实现X需哪些条件？达成目标的最可能路径？"适用于目标设定与战略设计。

### 竞争预言

多视角分析同一假设："若推出此产品，我方/对手方/市场的可能性空间分别如何？"

## 非适用场景

- 非预测工具——而是可能性地图。预言机不预知未来，助你备战多元未来。
- 非水晶球——概率基于现有证据估算，非确定性结论。
- 非行动替代——无后续决策与执行，再完美的情景分析也毫无价值。
