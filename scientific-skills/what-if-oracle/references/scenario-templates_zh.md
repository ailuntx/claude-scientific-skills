# 假设推演指南 — 场景模板集

领域特定情景分析的配置参考指南。

## 初创企业/商业决策

**待测试变量：**

- 市场进入时机
- 定价策略
- 合作条款
- 招聘决策
- 融资轮次

**分支侧重：** 基准情形 + 逆向假设 + 二阶效应  
**核心矛盾：** 速度与周全性——初创企业无法承受无限期分析

**模板提示：**

> "若我们在[时间框架]内执行[具体行动]会怎样？现状：[营收/团队规模/资金储备]。关键约束：[限制因素]。"

## 技术架构

**待测试变量：**

- 技术栈选择
- 自研与采购
- 扩展方案
- 安全模型
- 迁移路径

**分支侧重：** 最坏情形 + 黑天鹅事件 + 二阶效应  
**核心矛盾：** 工程优雅性与交付速度

**模板提示：**

> "若为[系统]选择[技术/方案]会怎样？当前架构：[简述]。团队能力：[相关技能]。时间节点：[截止期限]。"

## 投资/财务

**待测试变量：**

- 市场环境
- 估值情景
- 退出时机
- 资金配置
- 收入模式变更

**分支侧重：** 全六维度分析——资金决策需完整推演  
**核心矛盾：** 风险承受力与机会成本

**模板提示：**

> "若发生[市场条件/金融事件]会怎样？风险敞口：[金额/百分比]。当前状况：[财务状态]。时间跨度：[投资周期]。"

## 职业/个人

**待测试变量：**

- 职位变动
- 技能发展路径
- 迁移定居
- 关系决策
- 健康变化

**分支侧重：** 基准情形 + 最佳情形 + 逆向假设  
**核心矛盾：** 安全性与成长性——舒适区与突破区

**模板提示：**

> "若我[个人决策]会怎样？现状简述：[...]。核心价值：[1-3项]。深层顾虑：[坦诚回答]。"

## 地缘政治/宏观环境

**待测试变量：**

- 政策变更
- 监管转向
- 市场颠覆
- 技术突破
- 社会运动

**分支侧重：** 黑天鹅事件 + 二阶效应 + 逆向假设  
**核心矛盾：** 局部影响与系统性效应

**模板提示：**

> "若发生[地缘政治事件]会怎样？受影响程度：[对个人/组织的冲击]。时间跨度：[相关周期]。"

## 危机应对

**待测试变量：**

- 事态升级
- 沟通策略
- 资源调配
- 恢复周期
- 声誉影响

**分支侧重：** 最坏情形（详析） + 基准情形 + 二阶效应  
**核心矛盾：** 紧急处置与根因解决

**模板提示：**

> "当前面临[危机/事件]。直接影响：[受损环节]。涉众范围：[受影响方]。可用资源：[可调度力量]。若[具体升级情景]发生会怎样？"

## 递归推演模板

适用于多层次复杂分析：

```
第一轮："若X发生？"
  → 确定最可能分支（α）

第二轮："在α发生前提下，若Y发生？"
  → 确定最可能子分支

第三轮："在α+Y发生前提下，若Z发生？"
  → 推演深层连锁反应

每轮分析收窄可能性空间并深化认知。
建议最大深度：3轮。
```

## 概率校准指南

分配分支概率时参照：

| 置信等级   | 概率区间 | 证据要求                     |
| ---------- | -------- | ---------------------------- |
| **极高**   | >80%     | 强历史先例 + 当前数据吻合    |
| **高**     | 60-80%   | 多重信号印证，部分历史支撑   |
| **中**     | 30-60%   | 混合信号，双向可能性         |
| **低**     | 10-30%   | 需特定条件链成立方可实现     |
| **极低**   | <10%     | 黑天鹅领域——可能但概率渺茫   |

**铁律：** 单次分析中所有分支概率总和应趋近100%。若非如此，则存在遗漏分支。
