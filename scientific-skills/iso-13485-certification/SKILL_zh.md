# ISO 13485认证文档助手

## 概述

本技能协助医疗器械制造商准备符合ISO 13485:2016认证的完整文档体系。提供创建、评审和差距分析质量管理体系（QMS）所需文档的工具、模板、参考和指导。

**本技能提供：**
- 现有文档差距分析
- 所有强制文件模板
- 全面要求指南
- 分步文档创建指导
- 缺失文档识别
- 合规检查清单

**适用场景：**
- 启动ISO 13485认证流程
- 执行ISO 13485差距分析
- 创建或更新QMS文档
- 准备认证审核
- 从FDA QSR过渡至QMSR
- 与欧盟MDR要求协调

## 核心工作流

### 1. 评估现状（差距分析）

**适用场景：** 用户已有文档需识别差距

**流程：**

1. **收集现有文档：**
   - 要求用户提供当前QMS文档目录
   - 支持任意格式（.txt, .md, .doc, .docx, .pdf）
   - 包含所有程序文件、手册、作业指导书、表单

2. **执行差距分析脚本：**
   ```bash
   python scripts/gap_analyzer.py --docs-dir <path_to_docs> --output gap-report.json
   ```

3. **分析结果：**
   - 识别31项必要程序的现存情况
   - 定位缺失关键文档（质量手册、MDF等）
   - 计算合规百分比
   - 确定文档补全优先级

4. **向用户呈现结果：**
   - 总结现有文档
   - 清晰列出缺失项
   - 提供优先级行动计划
   - 预估所需工作量

**输出：** 含优先级行动项的全面差距分析报告

### 2. 理解要求（参考咨询）

**适用场景：** 用户需解读特定ISO 13485要求

**可用参考：**
- `references/iso-13485-requirements.md` - 逐条款解析
- `references/mandatory-documents.md` - 31项必要程序说明
- `references/gap-analysis-checklist.md` - 详细合规检查清单
- `references/quality-manual-guide.md` - 质量手册编制指南

**使用方式：**

1. **条款咨询：**
   - 阅读`iso-13485-requirements.md`相关章节
   - 用通俗语言解释要求
   - 提供实践案例

2. **文档要求咨询：**
   - 查阅`mandatory-documents.md`
   - 说明必须记录的内容
   - 澄清文档适用性与可排除性

3. **实施指导：**
   - 使用`quality-manual-guide.md`处理政策级文档
   - 提供分步创建流程
   - 展示优劣实施案例

**关键参考章节：**

- **条款4：** QMS要求、文档管理、风险管理、软件验证
- **条款5：** 管理职责、质量方针、目标、管理评审
- **条款6：** 资源、能力、培训、基础设施
- **条款7：** 产品实现、设计、采购、生产、可追溯性
- **条款8：** 测量、审核、CAPA、投诉、数据分析

### 3. 创建文档（模板化生成）

**适用场景：** 用户需创建特定QMS文档

**可用模板：**
- 质量手册：`assets/templates/quality-manual-template.md`
- CAPA程序：`assets/templates/procedures/CAPA-procedure-template.md`
- 文件控制：`assets/templates/procedures/document-control-procedure-template.md`

**文档创建流程：**

1. **确定创建需求：**
   - 基于差距分析或用户请求
   - 优先关键文档（质量手册、CAPA、投诉处理、审核）

2. **选择对应模板：**
   - 质量手册使用QM模板
   - 程序文件参考SOP模板
   - 根据组织需求调整结构

3. **定制模板信息：**
   - 替换所有占位符：[公司名称]、[日期]、[姓名]等
   - 根据实际业务调整范围
   - 按适用性增删章节
   - 确保与组织流程一致

4. **关键定制区域：**
   - 公司信息与地址
   - 产品类型与分类
   - 适用法规要求
   - 组织架构与职责
   - 实际流程与程序
   - 文件编号规则
   - 排除项及理由

5. **验证完整性：**
   - 所有必要章节完整
   - 占位符全部替换
   - 交叉引用正确
   - 审批部分完备

**文档创建优先级顺序：**

**阶段1 - 基础（关键）：**
1. 质量手册
2. 质量方针与目标
3. 文件控制程序
4. 记录控制程序

**阶段2 - 核心流程（高优先级）：**
5. 纠正与预防措施（CAPA）
6. 投诉处理
7. 内部审核
8. 管理评审
9. 风险管理

**阶段3 - 产品实现（高优先级）：**
10. 设计与开发（如适用）
11. 采购
12. 生产与服务提供
13. 不合格品控制

**阶段4 - 支持流程（中优先级）：**
14. 培训与能力
15. 计量设备校准/控制
16. 过程验证
17. 产品标识与可追溯性

**阶段5 - 附加要求（中优先级）：**
18. 反馈与上市后监督
19. 法规报告
20. 客户沟通
21. 数据分析

**阶段6 - 专项（如适用）：**
22. 安装（如适用）
23. 维护（如适用）
24. 灭菌（如适用）
25. 污染控制（如适用）

### 4. 开发特定文档

#### 创建质量手册

**流程：**

1. **阅读完整指南：**
   - 通读`references/quality-manual-guide.md`
   - 理解结构与必要内容
   - 研究示例文档

2. **收集组织信息：**
   - 公司法定名称与地址
   - 产品类型与分类
   - 组织架构
   - 适用法规
   - 业务范围
   - 需排除的条款

3. **使用模板：**
   - 基于`assets/templates/quality-manual-template.md`
   - 严格遵循ISO 13485要求的结构
   - 替换所有占位符

4. **完成必要章节：**
   - **章节0：** 文件控制与审批
   - **章节1：** 引言与公司概述
   - **章节2：** 范围与排除项（关键 - 必须说明排除理由）
   - **章节3：** 质量方针（需最高管理者签署）
   - **章节4-8：** 政策层面对应ISO 13485各条款
   - **附录：** 程序清单、组织图、过程图、术语定义

5. **核心要求：**
   - 必须引用全部31项程序（附录A）
   - 必须描述过程交互（附录C - 创建过程图）
   - 必须定义文档结构（章节4.2）
   - 必须说明所有排除理由（章节2.4）

6. **验证清单：**
   - [ ] 符合ISO 13485条款4.2.2的全部要求
   - [ ] 质量方针经最高管理者签署
   - [ ] 所有排除项说明理由
   - [ ] 附录A列出全部程序
   - [ ] 包含过程图
   - [ ] 包含组织架构图

#### 创建程序文件（SOP）

**通用方法：**

1. **理解要求：**
   - 阅读`references/iso-13485-requirements.md`相关条款
   - 明确需记录的内容
   - 确定组织内的执行人、时间、地点

2. **采用模板结构：**
   - 参照CAPA或文件控制模板
   - 标准章节：目的、范围、定义、职责、程序、记录、引用
   - 保持程序清晰可执行

3. **明确职责：**
   - 定义具体岗位（非人名）
   - 说明各岗位职责
   - 覆盖全部必要活动

4. **记录"做什么"而非过度描述"如何做"：**
   - 程序应定义必须执行的事项
   - 详细操作指南放入作业指导书（第三级文件）
   - 平衡指导性与灵活性

5. **包含必要元素：**
   - ISO 13485条款规定的所有要素
   - 必须保存的记录
   - 每项活动的责任人
   - 相关文件引用

**示例：创建CAPA程序**

1. 从参考文件阅读ISO 13485条款8.5.2和8.5.3
2. 使用`assets/templates/procedures/CAPA-procedure-template.md`
3. 定制内容：
   - 组织内部的CAPA优先级标准
   - 采用的根因分析方法
   - 审批权限与职责
   - 基于运营的时间框架
   - 与投诉处理、审核等流程的衔接
4. 添加附件表单：
   - CAPA申请单
   - 根因分析工作表
   - 行动计划模板
   - 有效性验证清单

#### 创建医疗器械文档（MDF）

**MDF定义：**
- 每类/系列医疗器械的专属文档集
- 替代独立的DHF/DMR/DHR（符合FDA QMSR协调要求）
- 包含设备所有相关文档

**ISO 13485条款4.2.3要求内容：**

1. 概述与预期用途
2. 标签及使用说明规范
3. 产品规范
4. 生产规范
5. 采购、生产、维护程序
6. 测量与监控程序
7. 安装要求（如适用）
8. 风险管理文档
9. 验证与确认信息
10. 设计与开发文档（如适用）

**流程：**

1. 识别每类/系列医疗器械
2. 创建MDF结构（文件夹或活页夹）
3. 收集或创建各项必要内容
4. 确保文档间可追溯性
5. 作为动态文档维护（随变更更新）

### 5. 执行全面差距分析

**适用场景：** 用户需评估所有要求的符合性

**流程：**

1. **使用综合检查清单：**
   - 打开`references/gap-analysis-checklist.md`
   - 逐条款评估
   - 标记每项状态：合规/部分合规/不合规/不适用

2. **逐条款处理：**
   - 阅读要求描述
   - 识别现存证据
   - 记录差距或缺陷
   - 明确整改措施
   - 分配责任人与完成时限

3. **按条款汇总：**
   - 计算每条款合规率
   - 识别最高风险项
   - 确定行动优先级

4. **制定行动计划：**
   - 列出所有差距项
   - 优先级排序：严重>高>中>低
   - 分配责任人与完成时间
   - 预估所需资源

5. **输出：**
   - 完整的差距分析清单
   - 含合规率的总结报告
   - 优先级行动计划
   - 时间线与里程碑

## 常见场景

### 场景1：从零开始

**用户请求：** "我们是医疗器械初创公司，需要实施ISO 13485，如何起步？"

**应对方案：**

1. **说明实施路径：**
   - ISO 13485要求完整QMS文档体系
   - 通常需6-12个月完成实施
   - 可采用分阶段推进

2. **建立基础：**
   - 质量方针与目标
   - 质量手册
   - 组织架构与职责

3. **遵循优先级顺序：**
   - 采用前文阶段1-6优先级列表
   - 按逻辑顺序创建文档
   - 基于已有文档逐步扩展

4. **关键里程碑：**
   - 第1-2月：基础文档（质量手册、方针）
   - 第3-4月：核心流程（CAPA、投诉、审核）
   - 第5-6月：产品实现流程
   - 第7-8月：支持流程
   - 第9-10月：内部审核与优化
   - 第11-12月：管理评审与认证审核

### 场景2：现有QMS差距分析

**用户请求：** "我们已有部分程序，但不确定ISO 13485还缺什么"

**应对方案：**

1. **执行自动差距分析：**
   - 获取文档目录
   - 运行`scripts/gap_analyzer.py`
   - 分析自动检测结果

2. **执行深度评估：**
   - 使用综合检查清单深度分析
   - 超越自动化检测范围
   - 评估现存文档质量（非仅检查存在性）

3. **提供优先级差距清单：**
   - 缺失的必要程序
   - 不完整的程序
   - 现存文档质量问题
   - 缺失的记录或表单

4. **制定整改计划：**
   - 高优先级：安全相关、法规强制要求
   - 中优先级：核心QMS流程
   - 低优先级：改进机会

### 场景3：创建特定文档

**用户请求：** "请协助创建CAPA程序"

**应对方案：**

1. **解读要求：**
   - 从参考文件阅读ISO 13485条款8.5.2和8.5.3
   - 说明CAPA程序必备要素
   - 提供优质CAPA流程案例

2. **应用模板：**
   - 基于CAPA程序模板
   - 解释各章节作用
   - 说明需定制内容

3. **收集用户信息：**
   - 组织内CAPA启动机制
   - 责任方划分
   - 适用的优先级标准
   - 将采用的根因分析方法
   - 合理的时间框架

4. **定制程序文件：**
   - 替换所有占位符
   - 适应用户流程
   - 确保内容完整

5. **补充支持材料：**
   - CAPA申请单
   - 根因分析工作表
   - 行动计划模板
   - 有效性验证清单

### 场景4：适应法规更新

**用户请求：** "我们需要更新QMS以符合FDA QMSR协调要求"

**应对方案：**

1. **解读变更：**
   - FDA 21 CFR Part 820与ISO 13485协调
   - 现称QMSR（2026年2月2日生效）
   - 关键变更：医疗器械文档替代DHF/DMR/DHR

2. **评审当前文档：**
   - 识别引用QSR的文件
   - 检查独立的DHF/DMR/DHR结构
   - 排查ISO 13485合规差距

3. **更新策略：**
   - 将QSR引用更新为QMSR
   - 将DHF/DMR/DHR整合为医疗器械文档
   - 补充缺失的ISO 13485要求
   - 过渡期保持向后兼容

4. **制定过渡计划：**
   - 更新质量手册
   - 修订MDF程序
   - 重组器械历史文档
   - 开展人员变更培训

### 场景5：准备认证审核

**用户请求：** "文档已就绪，如何准备认证审核？"

**应对方案：**

1. **执行准备度评估：**
   - 使用综合差距分析清单
   - 检查所有文档完整性
   - 验证必要记录的存在性
   - 确认实施一致性

2. **预审清单：**
   - [ ] 31项程序文件齐备且获批
   - [ ] 质量手册包含全部必要内容
   - [ ] 所有产品的医疗器械文档完整
   - [ ] 内部审核完成且问题关闭
   - [ ] 管理评审完成
   - [ ] 人员完成QMS程序培训
   - [ ] 记录保存符合留存要求
   - [ ] CAPA系统有效运行且

- 交叉引用相关文档  
   - 保持编号方案一致  
   - 同步更新所有相关文档  

3. **为受众而写：**  
   - 清晰简洁的语言  
   - 避免专业术语  
   - 定义技术名词  
   - 必要时提供示例  

4. **确保流程可用性：**  
   - 采用行动导向的语言  
   - 逻辑流程  
   - 明确责任归属  
   - 合理的时间框架  

### 排除条款  

**可排除的情形：**  
- 设计与开发（仅作为合同制造商时）  
- 安装（若产品无需安装）  
- 维修服务（若不提供）  
- 灭菌（若为非无菌产品）  

**理由要求：**  
- 必须写入质量手册  
- 必须说明排除原因  
- 若流程已执行则不可排除  
- 不得影响提供安全有效器械的能力  

**良好理由示例：**  
> "条款7.3'设计与开发'被排除。ABC公司作为合同制造商，完全按照客户提供的设计规范生产医疗器械。所有设计活动均由客户执行，ABC公司不承担设计输入、输出、验证、确认或设计变更的责任。"  

**不良理由示例：**  
> "我们不负责设计"（过于简略，未说明原因或证明无影响）

   - 用自身语言表述  
   - 描述实际
