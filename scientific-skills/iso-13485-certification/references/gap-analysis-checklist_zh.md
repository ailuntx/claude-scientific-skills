# ISO 13485:2016 差距分析检查表

本综合检查表帮助识别当前质量管理体系与ISO 13485:2016要求之间的差距。

## 如何使用本检查表

**状态指示符：**
- ✅ **符合：** 要求已完全实施并形成文件
- ⚠️ **部分符合：** 要求部分实施，需改进
- ❌ **不符合：** 要求未实施或未形成文件
- N/A **不适用：** 要求不适用（需提供理由）

**每项操作步骤：**
1. 评估当前状态
2. 识别现有文件
3. 记录差距或缺陷
4. 确定行动优先级
5. 分配责任人和目标日期
