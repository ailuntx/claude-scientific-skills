## 1. 目的

本程序规定质量管理体系内文件控制的要求，以确保：
- 文件在使用前获得批准
- 文件在必要时经过评审、更新和重新批准
- 变更和当前修订状态得到标识
- 相关版本文件在使用点可获取
- 文件保持清晰可辨且易于识别
- 外部文件得到识别和控制
- 防止作废文件被意外使用
- 保留的作废文件得到适当标识

本程序确保符合 ISO 13485:2016 条款 4.2.4 的要求。

---

## 2. 范围

本程序适用于质量管理体系内所有受控文件，包括但不限于：
- 质量手册
- 标准操作规程（SOP）
- 作业指导书（WI）
- 表格和模板
- 医疗器械档案
- 设计与开发文件
- 风险管理文件
- 验证与确认方案及报告
- 规范（产品、过程、测试方法、材料）
- 图纸和示意图
- 标签和使用说明
- 外部文件（标准、法规、客户规范）

本程序**不**适用于：
- 记录（按 SOP-[编号]《记录控制》管理）
- 临时文件（非质量管理体系组成部分的邮件、会议记录）
- 营销和销售材料（除非影响产品质量或法规符合性）

## 3. 定义

| 术语 | 定义 |
|------|------------|
| **受控文件** | 需按本程序进行评审、批准、分发控制和变更管理的文件 |
| **主文件** | 由文件控制部门维护的官方受控副本，所有分发副本均源于此 |
| **文件所有者** | 负责文件内容、准确性和维护的个人或部门 |
| **文件控制协调员** | 负责管理文件控制系统的人员 |
| **修订** | 经批准发布的受控文件变更 |
| **作废文件** | 已被新修订版本替代或不再适用的文件 |
| **外部文件** | 源自组织外部的文件（标准、法规、客户规范等） |
| **已替代** | 为参考目的保留的作废文件上使用的水印标识 |

## 4. 职责

### 4.1 文件控制协调员
- 管理文件控制系统
- 分配文件编号
- 维护主文件库
- 确保文件发布前获得适当批准
- 分发受控文件
- 维护分发清单
- 回收并销毁/归档作废文件
- 维护文件控制记录
- 对人员进行文件控制程序培训

### 4.2 文件所有者
- 在其负责领域创建和维护文件
- 确保文件准确性和完整性
- 必要时发起文件变更
- 参与文件评审和批准
- 识别文件作废状态
- 确保其领域人员使用现行文件

### 4.3 质量经理
- 批准所有质量管理体系文件（SOP、质量手册）
- 评审文件变更对质量管理体系的影响
- 确保文件控制系统有效性
- 审核文件控制合规性

### 4.4 部门经理
- 批准部门专用作业指导书
- 确保其区域可获取现行文件
- 确保人员接受文件变更培训
- 清除使用区域的作废文件

### 4.5 全体人员
- 仅使用现行批准文件
- 报告文件问题（错误、字迹不清、文件缺失）
- 不使用作废或未批准文件
- 保持文件完好状态

## 5. 程序

### 5.1 文件类型与层级

质量管理体系文件按四级层级组织：

**层级 1：质量手册（QM）**
- 政策级文件
- 描述整体质量管理体系
- 引用所有层级 2 程序
- 由 CEO 和质量经理批准

**层级 2：标准操作规程（SOP）**
- 定义需执行内容、执行人员及时间
- 跨职能流程
- 包含 ISO 13485 要求的全部 31 项文件化程序
- 由质量经理批准

**层级 3：作业指导书（WI）**
- 定义具体任务执行方法
- 分步骤说明
- 部门或流程专用
- 由部门经理和质量经理批准

**层级 4：表格和模板**
- 数据收集标准化格式
- 支持 SOP 和 WI
- 由文件所有者和质量经理批准

**其他受控文件：**
- 医疗器械档案（MDF）
- 设计历史文件（DHF）
- 验证文件
- 规范
- 图纸
- 标签和使用说明

### 5.2 文件编号系统

所有受控文件分配唯一识别编号：

**质量手册：**
- 格式：QM-[###]
- 示例：QM-001

**标准操作规程：**
- 格式：SOP-[ISO条款]-[###]
- 示例：SOP-4.2.4-001（对应条款 4.2.4 文件控制）
- 示例：SOP-8.5-001（CAPA 程序）

**作业指导书：**
- 格式：WI-[部门代码]-[###]
- 示例：WI-MFG-001（生产部门作业指导书）
- 部门代码：MFG（生产）、QC（质量控制）、ENG（工程）等

**表格：**
- 格式：FORM-[SOP/WI编号]-[字母]
- 示例：FORM-SOP-8.5-001-A（CAPA 申请表格）

**医疗器械档案：**
- 格式：MDF-[产品代码]-[###]
- 示例：MDF-ABC-001

**其他文件：**
- 格式按文件类型确定
- 由文件控制协调员分配

**修订标识：**
- 首次发布：修订号 00
- 首次修订：修订号 01
- 后续修订：02、03、04 等
- 格式：[文件编号] Rev [##]

### 5.3 文件创建

**5.3.1 启动文件创建**

1. 文件所有者识别新文件需求
2. 文件所有者通知文件控制协调员
3. 文件控制协调员：
   - 分配文件编号
   - 提供文件模板（如适用）
   - 在主清单中登记为"编制中"

**5.3.2 文件格式要求**

所有受控文件必须包含：

**页眉（每页）：**
- 文件编号
- 文件标题
- 修订号
- 生效日期
- 页码（第 X 页，共 Y 页）

**文件控制部分：**
- 批准签名表
- 修订历史表

**内容要求：**
- 清晰简洁的语言
- 使用现在时态和主动语态
- 术语一致
- 编号的章节和小节
- 引用相关文件
- 产生的记录（如适用）

**5.3.3 文件起草**

1. 文件所有者起草文件内容
2. 文件所有者在每页标注"草案"
3. 草案可进行非正式评审和意见征集
4. 准备正式评审时，文件所有者提交给文件控制协调员

### 5.4 文件评审与批准

**5.4.1 评审流程**

1. 文件控制协调员：
   - 验证文件编号正确性
   - 验证格式符合性
   - 检查必要章节
   - 安排评审路径

2. 评审人员包括：
   - 技术评审员（主题专家）
   - 质量评审员（确保质量管理体系符合性）
   - 其他相关方（如适用）

3. 评审员：
   - 评审技术准确性
   - 评审清晰度和完整性
   - 评审要求符合性
   - 向文件所有者提供意见

4. 文件所有者：
   - 处理所有意见
   - 按需修订文件
   - 重新提交批准

**5.4.2 批准流程**

批准权限基于文件类型：

| 文件类型 | 批准权限 |
|---------------|-------------------|
| 质量手册 | CEO 和质量经理 |
| 标准操作规程 | 质量经理 |
| 作业指导书 | 部门经理和质量经理 |
| 表格 | 文件所有者和质量经理 |
| 规范 | 工程经理和质量经理 |
| 医疗器械档案 | [按法规要求] |

**批准步骤：**

1. 文件控制协调员将文件送交批准人
2. 批准人评审并在批准栏签名/注明日期
3. 必须获得全部所需批准后文件方可生效
4. 文件控制协调员：
   - 移除"草案"水印
   - 添加生效日期（通常为批准后 [X] 天）
   - 确定最终格式
   - 纳入受控文件系统
   - 更新主文件清单

**5.4.3 培训要求**

文件生效前：
- 识别受影响人员
- 按需开展培训
- 培训记录按 SOP-[编号] 保存

### 5.5 文件分发与访问

**5.5.1 主文件**

- 文件控制协调员维护主副本
- 主文件存储于：[电子系统或物理位置]
- 主文件明确标识为"主副本"
- 主文件是所有分发副本的参考源

**5.5.2 受控副本**

**电子分发（主要方式）：**
- 文件存储于[文件管理系统]
- 通过用户权限控制访问
- 多数用户仅限只读访问
- 始终显示当前修订版
- 作废修订版自动移除访问权限
- 用户可为即时使用打印（非受控副本）

**物理分发（必要时）：**
- 为特定位置/用途发放受控副本
- 每份副本加盖"受控副本 - [副本编号]"印章
- 维护分发清单，包含：
  - 副本编号
  - 文件编号及修订号
  - 持有人姓名和位置
  - 发放日期
- 持有人负责保持副本完好
- 文件修订时，文件控制部门回收旧版并发放新版

**5.5.3 非受控副本**

- 为临时即时使用打印
- 加盖或标注"非受控副本"
- 用户每次使用前需验证当前修订版
- 应在使用后或 [X] 天内销毁

**5.5.4 使用点可获取性**

- 工作执行处可获取现行文件
- 工作站提供电子访问
- 无电子访问区域提供受控物理副本
- 文件需防止损坏、丢失或变质

### 5.6 文件变更

**5.6.1 启动变更**

变更可由以下情况触发：
- 文件所有者识别需求
- CAPA 要求程序变更
- 内部审核发现
- 管理评审措施
- 法规或标准更新
- 流程改进

**5.6.2 变更请求流程**

1. 请求人：
   - 填写文件变更申请表（附件 A）
   - 描述变更需求及理由
   - 提交文件所有者

2. 文件所有者：
   - 评审变更请求
   - 判断变更是否适当
   - 批准或拒绝请求
   - 若批准，启动文件修订

**5.6.3 实施变更**

1. 文件所有者：
   - 向文件控制部门申请当前主文件
   - 创建含变更的修订版
   - 增加修订号
   - 更新修订历史表
   - 标识文件中的变更（变更标记、高亮或摘要）
   - 标注为"修订草案"

2. 变更由以下人员评审批准：
   - 与原文件相同的批准权限
   - 除非原批准人指定不同批准权限
   - 评审员可访问前一修订版进行比对

3. 批准：
   - 按章节 5.4.2 批准新修订版
   - 新修订版生效日旧版即作废

**5.6.4 变更标识**

变更通过以下方式标识：
- 修订历史表（描述变更性质）
- 文件中的变更标记或高亮（可选但建议）
- 重大修订的变更摘要页（可选）

**5.6.5 紧急变更**

对安全或法规符合性有影响的紧急变更：
- 加速评审和批准流程
- 可采用临时方法（如手写变更加批准）
- 尽快完成正式文件修订
- 若因不符合项引发变更，按 CAPA 流程记录

### 5.7 作废文件控制

**5.7.1 文件作废条件**

文件在以下情况作废：
- 新修订版批准生效
- 文件不再适用于运营
- 产品停产
- 流程变更

**5.7.2 清除使用**

1. 文件控制协调员：
   - 新修订版生效日将替代版本标记为作废
   - 从电子文件系统移除或限制访问并标注"作废"
   - 从分发位置回收物理受控副本
   - 更新分发清单

2. 部门经理：
   - 清除工作区域的作废副本
   - 退回文件控制部门或销毁
   - 确保人员知晓新修订版

**5.7.3 作废文件保留**

作废文件可因以下目的保留：
- 参考用途
- 产品调查
- 法规或法律要求
- 历史记录

**若保留：**
- 清晰标注"作废 - 仅供参考"或"已替代"
- 与现行文件分开存储
- 限制并控制访问权限
- 按适用保存要求保留

**保存位置：**
- 带"作废"水印的电子存档
- 独立物理存档区

**5.7.4 防止意外使用**

防止意外使用的措施：
- 物理副本加盖红色"作废"印章
- 电子副本添加"作废"水印
- 从工作区域移除
- 独立存档区存储
- 培训文件控制系统及现行版本验证方法

### 5.8 外部文件控制

**5.8.1 外部文件类型**

外部文件包括：
- ISO 标准
- IEC 标准
- FDA 法规和指南文件
- 欧盟法规（MDR, IVDR）
- 其他法规要求
- 客户规范
- 供应商认证
- 校准证书
- 参考资料

**5.8.2 识别与控制**

1. 文件所有者或请求人：
   - 识别所需外部文件
   - 向文件控制协调员提供副本

2. 文件控制协调员：
   - 分配外部文件编号：EXT-[类别]-[###]
   - 登记外部文件台账，包含：
     - 文件标题和编号
     - 来源/发布方
     - 日期/版本
     - 组织内存放位置
     - 负责监控更新的责任人
   - 存入外部文件库

**5.8.3 时效性审查**

- 文件所有者负责监控外部文件更新
- 频率：[每年或收到更新通知时]
- 检查发布方网站更新
- 可订阅更新通知服务
- 发现更新时：
  - 获取新版本
  - 提交文件控制部门
  - 评估对质量管理体系文件的影响
  - 按需更新质量管理体系文件（必要时通过 CAPA）
  - 按章节 5.7 作废前一版本

**5.8.4 客户提供文件**

- 客户规范和图纸按外部文件控制
-

| 文件批准记录 | [X年或设备生命周期] | 文件控制系统 | 文件控制协调员 |
| 文件修订历史 | [X年或设备生命周期] | 文件控制系统 | 文件控制协调员 |
| 文件变更申请 | [X年] | [位置] | 文件控制协调员 |
| 分发清单 | 当前版本+[X]年 | [位置] | 文件控制协调员 |
| 作废文件存档 | [按保留计划] | [位置] | 文件控制协调员 |
| 外部文件登记册 | 当前版本+[X]年 | [位置] | 文件控制协调员 |
