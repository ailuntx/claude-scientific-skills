## 研究发现

### 关键观察

1. **预计小幅降温趋势**：模型预测平均异常值较 2024 年低 0.07°C，表明在 2023-2024 年破纪录高温后可能出现稳定趋势。

2. **季节性规律延续**：预测显示典型的季节性波动，冬末（2-3月）异常值较高，秋末（11-12月）较低。

3. **不确定性扩大**：90%置信区间从 1 月的 ±0.04°C 扩大到 12 月的 ±0.08°C，反映预测随时间推移的典型不确定性增长。

4. **峰值温度**：预计 2025 年 3 月将出现最高异常值 1.30°C，可能接近 2023 年 9 月创下的 1.47°C 纪录。

### 局限性

- TimesFM 为零样本预测模型，未引入物理气候模型约束
- 36 个月训练窗口可能无法捕捉数十年尺度的气候趋势
- 未显式建模厄尔尼诺/拉尼娜（El Niño/La Niña）周期

### 建议

- 将此预测作为物理气候模型的基准参照
- 随新观测数据每季度更新预测
- 考虑结合 TimesFM 与其他方法的集成预测方案

## 技术说明

### API 差异

TimesFM PyTorch API 与 GitHub README 文档存在差异：

**文档描述（GitHub README）：**
```python
model = timesfm.TimesFm(
    context_len=512,
    horizon_len=128,
    backend="gpu",
)
model.load_from_google_repo("google/timesfm-2.5-200m-pytorch")
```

**实际可用 API：**
```python
hparams = timesfm.TimesFmHparams(horizon_len=12)
checkpoint = timesfm.TimesFmCheckpoint(
    huggingface_repo_id="google/timesfm-1.0-200m-pytorch"
)
model = timesfm.TimesFm(hparams=hparams, checkpoint=checkpoint)
```

### TimesFM 2.5 PyTorch 问题

`google/timesfm-2.5-200m-pytorch` 检查点下载为 `model.safetensors`，但 TimesFM 加载器预期 `torch_model.ckpt`，导致模型加载时出现 `FileNotFoundError`。使用 TimesFM 1.0 PyTorch 可解决此问题。
