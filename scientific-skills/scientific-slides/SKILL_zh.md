# 科学幻灯片

## 概述

科学演讲是沟通研究成果、分享发现以及与学术和专业受众互动的重要媒介。本技能为创建有效的科学演讲提供全面指导，涵盖从结构和内容开发到视觉设计和交付准备的各个方面。

**关键重点**：会议、研讨会、答辩和专业演讲的口头报告。

**关键设计理念**：科学演讲应具有视觉吸引力并基于研究。坚决避免枯燥、文字堆砌的幻灯片。优秀的科学演讲结合了：
- **引人注目的视觉元素**：高质量的图表、图片、示意图（不只是项目符号）
- **研究背景**：通过研究查询获得的适当引用，建立可信度
- **最少的文字**：项目符号作为提示，您口头提供解释
- **专业设计**：现代配色方案、强烈的视觉层次、充足的留白
- **故事驱动**：清晰的叙事弧线，而不是数据倾泻

**记住**：枯燥的演讲 = 被遗忘的科学。让幻灯片视觉上令人难忘，同时通过适当的引用保持科学严谨性。

## 何时使用本技能

以下情况应使用本技能：
- 准备会议报告（5-20分钟）
- 开发学术研讨会（45-60分钟）
- 创建论文或学位论文答辩演讲
- 设计资助申请演讲
- 准备期刊俱乐部报告
- 在机构或公司进行研究报告
- 科学主题的教学或辅导演讲

## 使用 Nano Banana Pro 生成幻灯片

**本技能使用 Nano Banana Pro AI 自动生成精美幻灯片。**

根据输出格式，有两种工作流程：

### 默认工作流程：PDF 幻灯片（推荐）

使用 Nano Banana Pro 将每张幻灯片生成为完整图像，然后合并为 PDF。这会产生最具视觉冲击力的结果。

**工作原理：**
1. **规划演示文稿**：为每张幻灯片创建详细计划（标题、关键点、视觉元素）
2. **生成幻灯片**：为每张幻灯片调用 Nano Banana Pro 创建完整的幻灯片图像
3. **合并为 PDF**：将幻灯片图像组装成单个 PDF 演示文稿

**步骤 1：规划每张幻灯片**

在生成之前，为您的演示文稿创建详细计划：

```markdown
# 演示文稿计划：机器学习导论

## 幻灯片 1：标题幻灯片
- 标题："机器学习：从理论到实践"
- 副标题："AI 大会 2025"
- 演讲者：Jane Smith 博士，XYZ 大学
- 视觉元素：现代抽象神经网络背景

## 幻灯片 2：引言
- 标题："为什么机器学习很重要"
- 关键点：行业采用、突破性应用、未来潜力
- 视觉元素：显示不同机器学习应用的图标（医疗保健、金融、机器人）

## 幻灯片 3：核心概念
- 标题："三种学习类型"
- 内容：监督学习、无监督学习、强化学习
- 视觉元素：三部分示意图，每种类型附有示例

...（为所有幻灯片继续）
```

**步骤 2：生成每张幻灯片**

使用 `generate_slide_image.py` 脚本创建每张幻灯片。

**关键：格式一致性协议**

为确保演示文稿中所有幻灯片的格式统一：

1. **在演示文稿开始时定义格式目标**，并将其包含在每个提示中：
   - 配色方案（例如"深蓝色背景、白色文字、金色点缀"）
   - 字体样式（例如"粗体无衬线标题、干净正文"）
   - 视觉风格（例如"极简、专业、企业美学"）
   - 布局方法（例如"充足留白、左对齐内容"）

2. **生成后续幻灯片时，始终附加上一张幻灯片**，使用 `--attach`：
   - 这允许 Nano Banana Pro 查看并匹配现有样式
   - 在演示文稿中创建视觉连续性
   - 确保颜色、字体和设计语言一致

3. **默认作者为"K-Dense"**，除非另有指定

4. **在提示中直接包含引用**，用于引用研究的幻灯片：
   - 在提示文本中添加引用，使其出现在生成的幻灯片上
   - 使用格式："包含引用：(作者等, 年份)" 或 "显示参考文献：作者等, 年份"
   - 对于多个引用，在提示中全部列出
   - 引用应以小字出现在幻灯片底部或相关内容附近

5. **为结果幻灯片附加现有图表/数据**（对数据驱动的演示文稿至关重要）：
   - 在创建关于结果的幻灯片时，始终检查以下位置是否存在现有图表：
     - 工作目录（例如 `figures/`、`results/`、`plots/`、`images/`）
     - 用户提供的输入文件或目录
     - 与演示文稿相关的任何数据可视化、图表或图形
   - 使用 `--attach` 包含这些图表，使 Nano Banana Pro 能够整合它们：
     - 为结果幻灯片附加实际数据图/图表
     - 为方法学幻灯片附加相关示意图
     - 为标题幻灯片附加徽标或机构图片
   - 当附加数据图表时，在提示中描述您想要的内容：
     - "创建一张展示所附结果图表的幻灯片，突出关键发现"
     - "围绕此附加图表构建幻灯片，添加标题和解释数据的项目符号"
     - "将附加的图形整合到带有解释的结果幻灯片中"
   - **在生成结果幻灯片之前**：列出工作目录中的文件以找到相关图表
   - 可以附加多个图表：`--attach fig1.png --attach fig2.png`

**包含格式一致性、引用和图表附件的示例：**

```bash
# 标题幻灯片（第一张幻灯片 - 设定样式）
python scripts/generate_slide_image.py "演示文稿标题幻灯片：'机器学习：从理论到实践'。副标题：'AI 大会 2025'。演讲者：K-Dense。格式目标：深蓝色背景 (#1a237e)、白色文字、金色点缀 (#ffc107)、极简设计、无衬线字体、充足边距、无装饰元素。" -o slides/01_title.png

# 带有引用的内容幻灯片（附加上一张幻灯片以确保一致性）
python scripts/generate_slide_image.py "演示文稿幻灯片，标题为'为什么机器学习很重要'。三个关键点及简单图标：1) 行业采用，2) 突破性应用，3) 未来潜力。引用：在底部以小字包含：(LeCun 等, 2015; Goodfellow 等, 2016)。格式目标：匹配附加幻灯片的样式 - 深蓝色背景、白色文字、金色点缀、极简专业设计、无视觉杂乱。" -o slides/02_intro.png --attach slides/01_title.png

# 带有多个引用的背景幻灯片
python scripts/generate_slide_image.py "演示文稿幻灯片，标题为'深度学习革命'。关键里程碑：ImageNet 突破 (2012)、Transformer 架构 (2017)、GPT 模型 (2018-至今)。引用：在底部显示参考文献：(Krizhevsky 等, 2012; Vaswani 等, 2017; Brown 等, 2020)。格式目标：精确匹配附加幻灯片的样式 - 相同颜色、字体、极简设计。" -o slides/03_background.png --attach slides/02_intro.png

# 结果幻灯片 - 附加工作目录中的实际数据图
# 首先，检查存在哪些图表：ls figures/ 或 ls results/
python scripts/generate_slide_image.py "演示文稿幻灯片，标题为'模型性能结果'。创建一张呈现所附准确率图表的幻灯片。要突出的关键发现：1) 达到 95% 准确率，2) 比基线高出 12%，3) 在测试集上表现一致。引用：在底部包含：(我们的结果, 2025)。格式目标：精确匹配附加幻灯片的样式。" -o slides/04_results.png --attach slides/03_background.png --attach figures/accuracy_chart.png

# 结果幻灯片 - 多图比较
python scripts/generate_slide_image.py "演示文稿幻灯片，标题为'前后对比'。使用两个附加图表构建并排比较幻灯片。左侧：基线结果，右侧：我们的改进结果。添加简短标签说明改进。格式目标：精确匹配附加幻灯片的样式。" -o slides/05_comparison.png --attach slides/04_results.png --attach figures/baseline.png --attach figures/improved.png

# 方法学幻灯片 - 附加现有示意图
python scripts/generate_slide_image.py "演示文稿幻灯片，标题为'系统架构'。呈现附加的架构图，并附简短解释性项目符号：1) 输入处理，2) 模型推理，3) 输出生成。格式目标：精确匹配附加幻灯片的样式。" -o slides/06_architecture.png --attach slides/05_comparison.png --attach diagrams/system_architecture.png
```

**重要提示：在创建结果幻灯片之前，始终：**
1. 列出工作目录中的文件：`ls -la figures/` 或 `ls -la results/`
2. 检查用户提供的目录中是否有相关图表
3. 附加应出现在幻灯片上的所有相关图表
4. 描述 Nano Banana Pro 应如何整合附加图表

**提示模板：**

在每个提示中包含以下元素（根据需要自定义）：
```
[幻灯片内容描述]
引用：在底部包含：(作者1 等, 年份; 作者2 等, 年份)
格式目标：[背景颜色], [文字颜色], [重点色], 极简专业设计, 无装饰元素, 与附加幻灯片样式一致。
```

## 核心能力

### 1. 演讲结构与组织

构建具有清晰叙事流程并为不同场景量身定制的演示文稿。详细指导请参考 `references/presentation_structure.md`。

**通用故事弧线**：
1. **钩子**：吸引注意力（30-60 秒）
2. **背景**：确立重要性（占演讲 5-10%）
3. **问题/空白**：指出未知领域（占演讲 5-10%）
4. **方法**：解释解决方案（占演讲 15-25%）
5. **结果**：呈现关键发现（占演讲 40-50%）
6. **意义**：讨论含义（占演讲 15-20%）
7. **结尾**：令人难忘的结论（1-2 分钟）

**特定演讲结构**：
- **会议报告（15 分钟）**：聚焦 1-2 个关键发现，方法简要
- **学术研讨会（45 分钟）**：全面覆盖，详细方法，多项研究
- **论文答辩（60 分钟）**：完整论文概述，涵盖所有研究
- **资助申请演讲（15 分钟）**：强调重要性、可行性和影响
- **期刊俱乐部（30 分钟）**：对已发表作品的批判性分析

### 2. 幻灯片设计原则

创建专业、易读且易于理解的幻灯片，增强理解。完整设计指南请参考 `references/slide_design_principles.md`。

**反模式：避免枯燥、文字堆砌的演示**

❌ **导致演示枯燥且易被遗忘的因素：**
- 文字墙（每张幻灯片超过 6 个项目符号）
- 小字体（正文 <24pt）
- 仅白底黑字（无视觉趣味）
- 无图像或图形（仅项目符号）
- 通用模板未经定制
- 密集、类段落式的项目符号
- 缺少研究背景（无引用）
- 所有幻灯片看起来一样（重复）

✅ **使演示引人入胜且令人难忘的因素：**
- **高质量视觉元素**占主导（图表、照片、示意图、图标）
- **大而清晰的文字**作为点缀（而非主要内容）
- **现代、有目的的配色方案**（非默认主题）
- **充足留白**（幻灯片呼吸感）
- **研究支持背景**（通过研究查询获取适当引用）
- **多样化的幻灯片布局**（不全是项目符号列表）
- **故事驱动流程，配有视觉锚点**
- **专业、精致外观**

**核心设计原则**：

**视觉优先方法**（关键）：
- 从视觉元素（图表、图像、示意图）开始，文字作为支持
- 每张幻灯片应有**强烈视觉元素**（图表、图片、照片、示意图）
- 文字解释或补充视觉元素，而非替代它们
- 思考："我如何展示这个，而不仅仅是讲述？"
- 目标：60-70% 视觉内容，30-40% 文字

**简洁且具有冲击力**：
- 每张幻灯片一个主要想法
- **最少的**文字（3-4 个项目符号，每个 4-6 个单词为佳）
- 充足留白（40-50% 幻灯片面积）
- 清晰的视觉焦点
- 大胆、自信的设计选择

**排版以增强参与度**：
- 无衬线字体（Arial, Calibri, Helvetica）
- **大号**字体：正文 24-28pt（而非最小 18pt）
- 幻灯片标题 36-44pt（加粗）
- 高对比度（最低 4.5:1，优选 7:1）
- 使用字号创建层次，而非仅靠粗细

**色彩以增强冲击力**：
- **现代**调色板（非默认蓝/灰）
- 考虑主题：生物技术？鲜艳色彩。物理？深邃深色。健康？暖色调。
- 有限调色板（总共 3-5 种颜色）
- 高对比组合
- 色盲友好（避免红绿组合）
- 有目的地使用颜色（而非装饰）

**布局以增加视觉趣味**：
- 变化布局（不全是项目符号列表）
- 使用两栏布局（文字 + 图表）
- 全屏图表用于关键结果
- 不对称构图（比居中更有趣）
- 三分法用于焦点
- 一致但不重复

### 3. 幻灯片数据可视化

针对演讲场景调整科学图表。详细指导请参考 `references/data_visualization_slides.md`。

**与期刊图表的关键差异**：
- 简化，而非复制
- 更大字体（最小 18-24pt）
- 更少的图版（拆分为多张幻灯片）
- 直接标注（而非图例）
- 通过颜色和大小强调重点
- 对于复杂数据，逐步披露

**可视化最佳实践**：
- **条形图**：比较离散类别
- **折线图**：趋势和轨迹
- **散点图**：关系和相关性
- **热力图**：矩阵数据和模式
- **网络图**：关系和连接

**需避免的常见错误**：
- 小字体（<18pt）
- 一张幻灯片上图版太多
- 复杂图例
- 对比度不足
- 布局杂乱

### 4. 演讲类型特定指导

不同的演讲场景需要不同的方法。每种类型的全面指导请参考 `references/talk_types_guide.md`。

**会议报告**（10-20 分钟）：
- 结构：简短的引言 → 最简方法 → 关键结果 → 快速结论
- 重点：仅 1-2 个主要发现
- 风格：引人入胜、快节奏、令人难忘
- 目标：引起兴趣、建立联系、获得邀请

**学术研讨会**（45-60 分钟）：
- 结构：全面覆盖，详细方法
- 重点：多个发现、深入分析
- 风格：学术、互动、以讨论为导向
- 目标：展示专业知识、获得反馈、开展合作

**论文答辩**（45-60 分钟）：
- 结构：完整论文概述，涵盖所有研究
- 重点：展示掌握程度和独立思考
- 风格：正式、全面、准备接受质询
- 目标：通过考试、辩护研究决策

**资助申请演讲**（10-20 分钟）：
- 结构：问题 → 重要性 → 方法 → 可行性 → 影响
- 重点：创新性、初步数据、团队资质
- 风格：有说服力，聚焦结果和影响
- 目标：获得资助、展示可行性

**期刊俱乐部**（20-45 分钟）：
- 结构：背景 → 方法 → 结果 → 批判性分析
- 重点：理解和评论已发表作品
- 风格：教育性、批判性、促进讨论
- 目标：学习、评论、讨论意义

### 6. 视觉审查与迭代

通过视觉检查实现迭代改进。完整工作流程请参考 `references/visual_review_workflow.md`。

**视觉验证工作流程**：

**步骤 1：生成 PDF**（如果尚不是 PDF）
- PowerPoint：导出为 PDF
- Beamer：编译 LaTeX 源文件

**步骤 2：转换为图像**
```bash
# 使用 pdf_to_images 脚本
python scripts/pdf_to_images.py presentation.pdf review/slide --dpi 150

# 或使用 pptx 技能的缩略图工具
python scientific-skills/pptx/scripts/thumbnail.py presentation.pptx review/thumb
```

**步骤 3：系统检查**

检查每张幻灯片：
- **文字溢出**：文字被边缘裁剪
- **元素重叠**：文字与图像或其他文字重叠
- **字体大小**：文字过小（<18pt）
- **对比度**：文字与背景对比度不足
- **布局问题**：未对齐、间距不当
- **视觉质量**：图像像素化、渲染不佳

**步骤 4：记录问题**

创建问题日志：
```
幻灯片编号 | 问题类型 | 描述 | 优先级
--------|----------|------|--------
3       | 文字溢出 | 项目符号 4 超出框 | 高
7       | 重叠 | 图形与说明文字重叠 | 高
12      | 字体大小 | 轴标签过小 | 中
```

**步骤 5：应用修复**

对源文件进行更正：
- PowerPoint：编辑文本框、调整元素大小
- Beamer：调整 LaTeX 代码，重新编译

**步骤 6：重新验证**

重复步骤 1-5，直到没有关键问题。

**停止标准**：
- 无文字溢出
- 无不恰当重叠
- 所有文字可读（等效 ≥18pt）
- 对比度充足（≥4.5:1）
- 外观专业

确保演示文稿符合分配时间。全面时间指导请参考 `assets/timing_guidelines.md`。

- 15 分钟演讲：练习 3-5 次
- 45 分钟演讲：练习 3-4 次

- 3-4 分钟：完成引言
- 7-8 分钟：结果进行到一半

- 时间不够：跳过备选幻灯片（提前准备）
- 时间充裕：扩展示例，稍微放慢

## 演示文稿开发工作流程

### 阶段 1：规划（创建幻灯片之前）

**定义背景**：
1. 演讲类型？（会议、研讨会、答辩等）
2. 时长？（分钟）
3. 受众是谁？（专家、普通、混合）
4. 场地如何？（房间大小、音视频设备、线上/线下）
5. 之后会发生什么？（问答、讨论、社交）

**研究及文献综述**（使用 research-lookup 技能）：
1. **搜索背景文献**：找到 5-10 篇确立背景的关键论文
2. **识别知识空白**：使用 research-lookup 找出未知领域
3. **定位比较研究**：找到方法或结果相似的论文
4. **收集支持性引用**：收集支持您解释的论文
5. **构建参考文献列表**：创建 .bib 文件或幻灯片引用列表
6. **记录要引用的关键发现**：记录要参考的具体结果

**制定内容大纲**：
1. 确定 1-3 个核心信息
2. 选择要展示的关键发现
3. 选择必要的图表（15 分钟演讲通常 3-6 个）
4. 规划带有适当引用的叙事弧线
5. 按部分分配时间

**15 分钟演讲的示例大纲**：
```
1. 标题（30 秒）
2. 钩子：引人入胜的问题（60 秒）[引用 via research-lookup 的 1-2 篇论文]
3. 背景（90 秒）[引用 3-4 篇确立背景的关键论文]
4. 研究问题（45 秒）[引用显示空白的论文]
5. 方法概述（2 分钟）
6-8. 主要结果 1（3 分钟，3 张幻灯片）
9-10. 主要结果 2（2 分钟，2 张幻灯片）
11-12. 结果 3 或验证（2 分钟，2 张幻灯片）
13-14. 讨论与意义（2 分钟）[与 2-3 篇先前研究比较]
15. 结论（45 秒）
16. 致谢（15 秒）

注意：在创建幻灯片之前，使用 research-lookup 查找背景（幻灯片 2-4）和讨论（幻灯片 13-14）的论文。
```

### 阶段 2：设计与创建

**选择实施方法**：

**选项 A：PowerPoint（通过 PPTX 技能）**
1. 阅读 `assets/powerpoint_design_guide.md`
2. 阅读 `scientific-skills/pptx/SKILL.md`
3. 选择方法（程序化或基于模板）
4. 创建具有一致设计的主幻灯片
5. 按照大纲构建演示文稿

**选项 B：LaTeX Beamer**
1. 阅读 `references/beamer_guide.md`
2. 从 `assets/` 中选择合适模板
3. 自定义主题和颜色
4. 在 LaTeX 中编写内容
5. 编译为 PDF

**设计考虑**（使其视觉上吸引人）：
- **选择现代调色板**：匹配主题（生物技术=鲜艳、物理=简洁、健康=温暖）
  - 使用 pptx 技能的调色板示例（青色和珊瑚色、大胆红色、深紫和翠绿色等）
  - 不要只使用默认蓝/灰主题
  - 3-5 种颜色，高对比度
- **选择清晰字体**：无衬线、大号（正文 24pt+）
- **规划视觉元素**：每张幻灯片使用哪些图像、示意图、图标？
- **创建多样布局**：混合全图、两栏、文字叠加（不全是项目符号）
- **设计分节分隔页**：使用引人注目的图形进行视觉分隔
- **规划动画/构建**：控制复杂幻灯片的信息流
- **添加视觉趣味**：背景图像、色块、形状、图标

### 阶段 3：内容开发

**填充幻灯片**（视觉优先策略）：
1. **从视觉元素开始**：为每个关键点规划图表、图像、示意图
2. **广泛使用 research-lookup**：找到 8-15 篇论文以便适当引用
3. **先创建视觉骨架**：添加所有图表、图形、图像、示意图
4. **添加最少的文字作为支持**：项目符号补充视觉元素，而非替代它们
5. **设计分节分隔页**：使用图像或图形进行视觉分隔（不只有文字）
6. **润色标题/结束页**：使其视觉上引人注目，包含联系方式
7. **添加过渡/构建**：控制信息流

**视觉内容要求**（使幻灯片引人入胜）：
- **图像**：使用高质量照片、插图、概念图形
- **图标**：概念的可视化表示（非装饰）
- **示意图**：流程图、原理图、过程图
- **图表**：简化版研究图表，标注**大号**（18-24pt）
- **图形**：干净的数据可视化，信息明确
- **图形**：视觉隐喻、概念插图
- **色块**：使用彩色形状在视觉上组织内容
- 目标：每张幻灯片**至少 1-2 个强烈视觉元素**

**科学内容**（基于研究）：
- **引用**：广泛使用 research-lookup 找到相关论文
  - 引言：引用 3-5 篇确立背景和空白的论文
  - 背景：视觉展示关键先前工作（不单是引用）
  - 讨论：引用 3-5 篇论文与您的结果进行比较
  - 使用作者-年份格式（Smith 等, 2023）以便阅读
  - 引用建立可信度和科学严谨性
- **图表**：从论文中简化，标注**大号**（最小 18-24pt）
- **方程**：大号、清晰、解释每一项（谨慎使用）
- **表格**：最少化，突出关键比较（非数据倾倒）
- **代码/算法**：使用语法高亮，保持简短

**文字指南**（少即是多）：
- 项目符号，**绝不使用段落**
- 每张幻灯片 3-4 个项目符号（只有必要时最多 6 个）
- 每个项目符号 4-6 个单词（比 6×6 规则更短）
- 关键术语加粗
- 文字起**辅助作用**，视觉元素是主角
- 使用构建来控制节奏

### 阶段 4：视觉验证

**生成图像**：
```bash
# 将 PDF 转换为图像
python scripts/pdf_to_images.py presentation.pdf review/slides

# 或创建缩略图网格
python scientific-skills/pptx/scripts/thumbnail.py presentation.pptx review/grid
```

**系统审查**：
1. 查看每张幻灯片图像
2. 对照问题清单检查
3. 记录问题及幻灯片编号
4. 测试远距离可读性（以 50% 大小查看）

**需要修复的常见问题**：
- 文字超出边界
- 图表与文字重叠
- 字体过小
- 对比度差
- 未对齐

**迭代**：
1. 在源文件中修复已识别问题
2. 重新生成 PDF/演示文稿
3. 再次转换为图像
4. 重新检查
5. 重复直到干净

### 阶段 5：练习与完善

**练习计划**：
- 第 1 次：草稿（会超时）
- 第 2 次：平滑过渡
- 第 3 次：精确计时
- 第 4 次：最终打磨
- 第 5 次+：保持状态（前一天、当天早晨）

**练习内容**：
- 带计时器完整演讲
- 难懂的讲解
- 各部分之间的过渡
- 开场和结尾（直到完美）
- 预期问题

**基于练习的完善**：
- 如果超时，减少幻灯片
- 如果解释不清，扩展说明

## 应避免的常见陷阱

### 内容错误

**枯燥、令人乏味的演示**（需极力避免）：
- 问题：文字密集且无视觉趣味、缺少研究背景的幻灯片
- 迹象：全是项目符号、无图像、默认模板、无引用
- 解决方案：
  - 使用 research-lookup 找到 8-15 篇论文以获得可信背景
  - 为**每张**幻灯片添加高质量视觉元素（图表、照片、示意图、图标）
  - 选择反映主题的现代调色板
  - 变化幻灯片布局（不全是项目符号列表）
  - 用视觉元素讲故事，少用文字

**内容过多**：
- 问题：试图包含论文中的所有内容
- 解决方案：短演讲聚焦 1-2 个关键发现，视觉展示

**文字过多**：
- 问题：幻灯片上完整的段落、密集的项目符号、逐字阅读
- 解决方案：3-4 个项目符号，每个 4-6 个单词，让视觉元素传达信息

**缺少研究背景**：
- 问题：无引用、声明无支持、定位不清
- 解决方案：使用 research-lookup 找到论文，引言引用 3-5 篇，讨论引用 3-5 篇

**叙事不佳**：
- 问题：主题间跳跃、无清晰故事、无流程
- 解决方案：遵循故事弧线、使用视觉过渡、保持主线

**匆匆展示结果**：
- 问题：方法简短、结果简短、讨论冗长
- 解决方案：将 40-50% 的时间用于结果，视觉展示数据

### 设计错误

**通用、默认外观**：
- 问题：使用默认 PowerPoint/Beamer 主题未定制，看起来过时
- 解决方案：选择现代调色板、自定义字体/布局、添加视觉个性

**文字密集、视觉匮乏**：
- 问题：全是项目符号的幻灯片、无图像或图形、看起来无聊
- 解决方案：为**每张**幻灯片添加图表、照片、示意图、图标，使其视觉有趣

**小字体**：
- 问题：正文 <18pt，后排无法阅读，看起来不专业
- 解决方案：正文 24-28pt（不仅是 18pt 最小值），标题 36-44pt

**对比度低**：
- 问题：浅色背景上浅色文字，可见性差，难以阅读
- 解决方案：高对比度（优选 7:1，不仅是 4.5:1 最小值），使用对比度检查器测试

**杂乱幻灯片**：
- 问题：元素过多、无留白、令人窒息
- 解决方案：每张幻灯片一个想法、40-50% 留白、充足间距

**格式不一致**：
- 问题：幻灯片间字体、颜色、布局不同，显得业余
- 解决方案：使用主幻灯片、维护设计系统、保持专业一致性

**缺少视觉层次**：
- 问题：所有内容大小和颜色相同、无强调、焦点不清
- 解决方案：大小差异（标题大、正文中等）、颜色用于强调、清晰焦点

### 时间错误

**不练习**：
- 问题：演示时第一次完整过一遍
- 解决方案：最少练习 3 次并计时

**无时间检查点**：
- 问题：直到太晚才发现时间不够
- 解决方案：设置 3-4 个检查点，全程监控

**超时**：
- 问题：非常不专业、挤占问答时间
- 解决方案：练习到精确时间、准备 B 计划（可跳过的幻灯片）

**跳过结论**：
- 问题：时间不够，匆忙跳过或省略结尾
- 解决方案：永远不要跳过结论，改为裁剪先前内容

## 快速入门指南

### 针对 15 分钟会议报告（PDF 工作流程 - 推荐）

1. **研究与规划**（45 分钟）：
   - **使用 research-lookup** 找到 8-12 篇相关论文以获取引用
   - 构建参考文献列表（背景、比较研究）
   - 制定内容大纲（引言 → 方法 → 2-3 个关键结果 → 结论）
   - **为每张幻灯片创建详细计划**（标题、关键点、视觉元素）
   - 目标 15-18 张幻灯片

2. **使用 Nano Banana Pro 生成幻灯片**（1-2 小时）：
   
   **重要提示：使用一致格式、附加先前幻灯片并包含引用！**
   
   ```bash
   # 标题幻灯片（设定样式 - 默认作者：K-Dense）
   python scripts/generate_slide_image.py "标题幻灯片：'您的研究标题'。会议名称，K-Dense。格式目标：[您的配色方案]，极简专业设计，无装饰元素，干净且企业风。" -o slides/01_title.png
   
   # 带有引用的引言幻灯片（附加上一张以确保一致性）
   python scripts/generate_slide_image.py "幻灯片标题为'为什么这很重要'。三个关键点及简单图标。引用：在底部包含：(Smith 等, 2023; Jones 等, 2024)。格式目标：精确匹配附加幻灯片的样式。" -o slides/02_intro.png --attach slides/01_title.png
   
   # 为每张幻灯片继续（始终附加上一张，相关时包含引用）
   python scripts/generate_slide_image.py "幻灯片标题为'方法'。关键方法学要点。引用：(基于 Chen 等, 2022)。格式目标：精确匹配附加幻灯片的样式。" -o slides/03_methods.png --attach slides/02_intro.png
   
   # 合并为 PDF
   python scripts/slides_to_pdf.py slides/*.png -o presentation.pdf
   ```

3. **审查与迭代**（30 分钟）：
   - 打开 PDF 并审查每张幻灯片
   - 对需要改进的幻灯片重新生成
   - 重新合并为 PDF

4. **练习**（2-3 小时）：
   - 练习 3-5 次并计时
   - 目标 13-14 分钟（留出缓冲）
   - 录制自己，观看回放
   - **准备回答问题**（使用 research-lookup 预测）

5. **最终定稿**（30 分钟）：
   - 如需，生成备选/附录幻灯片
   - 保存多个副本
   - 在演示电脑上测试

总时间：约 5-6 小时可获得高质量的 AI 生成演示文稿

### 备选方案：PowerPoint 工作流程

如果您需要可编辑的幻灯片（例如用于公司模板）：

1. **如上规划幻灯片**
2. 使用 `--visual-only` 标志生成视觉元素：
   ```bash
   python scripts/generate_slide_image.py "示意图描述" -o figures/fig1.png --visual-only
   ```
3. 使用 PPTX 技能结合生成的图像构建 PPTX
4. 使用 PPTX 工作流程单独添加文字

参见 `scientific-skills/pptx/SKILL.md` 获取完整的 PowerPoint 工作流程。

## 总结：关键原则

1. **视觉优先设计**：每张幻灯片需要强烈视觉元素（图表、图像、示意图）——避免纯文字幻灯片
2. **基于研究**：使用 research-lookup 找到 8-15 篇论文，引言引用 3-5 篇，讨论引用 3-5 篇
3. **现代美学**：选择与主题匹配的当代调色板，而非默认主题
4. **最少文字**：3-4 个项目符号，每个 4-6 个单词（24-28pt 字体），让视觉元素讲述故事
5. **结构**：遵循故事弧线，将 40-50% 的时间用于结果
6. **高对比度**：优选 7:1，以获得专业外观
7. **多样布局**：混合全图、两栏、视觉叠加（不全是项目符号）
8. **计时**：练习 3-5 次，约每分钟一张幻灯片，永不跳过结论
9. **验证**：通过视觉审查工作流程捕捉溢出和重叠
10. **留白**：40-50% 的幻灯片空白，以提供视觉呼吸空间

**记住**：
- **枯燥 = 被遗忘**：枯燥、文字密集的幻灯片无法传达您的科学成果
- **视觉 + 研究 = 影响力**：将引人注目的视觉元素与基于研究的背景相结合
- **您本人是演示的主角，幻灯片是视觉支持**：它们应增强而非取代您的演讲
