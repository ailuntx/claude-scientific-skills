## 药物发现与药物化学

### 示例 1：发现用于肺癌的新型 EGFR 抑制剂

**目标**：识别与现有药物相比具有更好性能的新型 EGFR 小分子抑制剂。

**使用技能**：
- `database-lookup` - 查询 ChEMBL, PubChem, COSMIC, AlphaFold DB
- `paper-lookup` - 在 PubMed 上搜索文献
- `rdkit` - 分析分子性质
- `datamol` - 生成类似物
- `medchem` - 药物化学筛选器
- `molfeat` - 分子特征化
- `diffdock` - 分子对接
- `deepchem` - 性质预测
- `torchdrug` - 用于分子的图神经网络
- `scientific-visualization` - 创建图表
- `clinical-reports` - 生成 PDF 报告

**工作流程**：

```bash
# 尽可能使用可用的“技能”。保持输出有条理。

步骤 1：从 ChEMBL 查询已知的高效 EGFR 抑制剂
- 搜索靶向 EGFR (CHEMBL203) 的化合物
- 筛选：IC50 < 50 nM, pChEMBL 值 > 7
- 提取 SMILES 字符串和活性数据
- 导出到 DataFrame 进行分析

步骤 2：分析结构-活性关系
- 将化合物加载到 RDKit 中
- 计算分子描述符（MW、LogP、TPSA、HBD、HBA）
- 生成 Morgan 指纹（半径=2，2048 位）
- 执行层次聚类以识别骨架
- 可视化带有活性注释的顶级骨架

步骤 3：从 COSMIC 识别耐药突变
- 查询 COSMIC 中肺癌的 EGFR 突变
- 关注看门人突变（T790M、C797S）
- 提取突变频率和临床意义
- 与 PubMed 中的文献进行交叉参考

步骤 4：从 AlphaFold 检索 EGFR 结构
- 下载 EGFR 激酶域的 AlphaFold 预测结构
- 或者，使用 PDB 中的实验结构（如果可用）
- 准备对接结构（添加氢，优化）

步骤 5：使用 datamol 生成新型类似物
- 从 ChEMBL 分析中选择前 5 个骨架
- 使用骨架修饰为每个骨架生成 100 个类似物
- 应用 Lipinski 五规则筛选
- 确保合成可及性（SA score < 4）
- 检查 PAINS 和不需要的子结构

步骤 6：使用 DeepChem 预测性质
- 在 ChEMBL EGFR 数据上训练图卷积模型
- 预测生成的类似物的 pIC50
- 预测 ADMET 性质（溶解度、渗透性、hERG）
- 根据预测效力和类药性对候选物进行排名

步骤 7：使用 DiffDock 进行虚拟筛选
- 对前 50 个候选物进行分子对接
- 对接到野生型 EGFR 和 T790M 突变体
- 计算结合能和相互作用模式
- 识别与两种形式均有利结合的化合物

步骤 8：在 PubChem 中搜索商业可用性
- 按 InChI 键查询 PubChem 中前 10 个候选物
- 检查供应商信息和采购选项
- 如果没有精确匹配，则识别近似类似物

步骤 9：使用 PubMed 进行文献验证
- 搜索顶级骨架的任何现有技术
- 查询：“[骨架名称] AND EGFR AND 抑制剂”
- 总结相关发现和潜在问题

步骤 10：创建综合报告
- 生成顶级化合物的 2D 结构可视化
- 创建散点图：MW 与 LogP，TPSA 与效力
- 为前 3 个化合物生成结合构象图
- 生成比较已批准药物（吉非替尼、厄洛替尼）性质的表格
- 撰写包含方法、结果和建议的科学摘要
- 导出为带有适当引用的 PDF

预期输出：
- 10-20 个新型 EGFR 抑制剂候选物的排名列表
- 预测活性和 ADMET 性质
- 对接构象和结合分析
- 包含出版质量图表的综合科学报告
```

### 示例 2：罕见病药物再利用

**目标**：识别可用于治疗罕见代谢疾病的 FDA 批准药物。

**使用技能**：
- `database-lookup` - 查询 DrugBank, Open Targets, STRING, KEGG, Reactome, ClinicalTrials.gov, FDA
- `paper-lookup` - 搜索 OpenAlex, bioRxiv, PubMed
- `networkx` - 网络分析
- `bioservices` - 生物数据库查询
- `literature-review` - 系统综述

**工作流程**：

```bash
步骤 1：定义疾病通路
- 查询 KEGG 和 Reactome 以获取疾病相关通路
- 识别涉及的关键蛋白质和酶
- 绘制上游和下游通路组分

步骤 2：查找蛋白质-蛋白质相互作用
- 查询 STRING 数据库以获取相互作用伙伴
- 围绕关键疾病蛋白质构建蛋白质相互作用网络
- 使用 NetworkX 识别中心蛋白质和瓶颈
- 计算中心性指标（介数、接近度）

步骤 3：查询 Open Targets 以获取可靶向靶点
- 搜索与疾病表型相关的靶点
- 按临床前例和可成药性筛选
- 优先选择现有已批准药物的靶点

步骤 4：搜索 DrugBank 以获取靶向已识别蛋白质的药物
- 查询已批准药物及其靶点
- 按与疾病相关的作用机制筛选
- 检索药物性质和安全性信息

步骤 5：查询 FDA 数据库以获取安全性概况
- 检查 FDA 不良事件数据库（FAERS）
- 审查药品说明书和黑框警告
- 评估罕见病人群的风险-收益

步骤 6：搜索 ClinicalTrials.gov 以获取之前的再利用尝试
- 查询疾病名称 + 药物名称
- 检查失败的试验（以及失败原因）
- 识别可能存在竞争的正在进行的试验

步骤 7：执行通路富集分析
- 将药物靶点映射到疾病通路
- 使用 Reactome 计算富集分数
- 识别影响多个通路节点的药物

步骤 8：进行系统文献综述
- 在 PubMed 上搜索药物名称 + 疾病关联
- 包括 bioRxiv 以获取近期未发表的发现
- 记录任何病例报告或超说明书用药
- 使用 literature-review 技能生成综合综述

步骤 9：优先排序候选物
- 按以下因素排名：通路相关性、安全性概况、现有证据
- 考虑因素：口服可用性、血脑屏障渗透
- 评估商业可行性和专利状态

步骤 10：生成再利用报告
- 创建药物-靶点-通路关系的网络可视化
- 生成前 5 个候选物的比较表
- 为每个候选物撰写详细理由
- 包括作用机制图
- 提供临床前验证建议
- 格式化为带有引用的专业 PDF

预期输出：
- 5-10 个药物再利用候选物的排名列表
- 药物-靶点-疾病关系的网络分析
- 安全性和有效性证据总结
- 包含后续步骤的药物再利用策略报告
```

## 癌症基因组学与精准医疗

### 示例 3：临床变异解读流程

**目标**：分析患者肿瘤测序数据以识别可操作突变并提出治疗建议。

**使用技能**：
- `database-lookup` - 查询 Ensembl, ClinVar, COSMIC, NCBI Gene, UniProt, ClinPGx, DrugBank, ClinicalTrials.gov, Open Targets
- `paper-lookup` - 在 PubMed 上搜索文献证据
- `pysam` - 解析 VCF 文件
- `gget` - 统一的基因/蛋白质数据检索
- `clinical-reports` - 生成临床报告 PDF

**工作流程**：

```bash
步骤 1：解析和过滤 VCF 文件
- 使用 pysam 读取肿瘤 VCF
- 筛选高质量变异（QUAL > 30, DP > 20）
- 提取变异位置、等位基因和 VAF（变异等位基因频率）
- 分离 SNV、插入缺失和结构变异

步骤 2：使用 Ensembl 注释变异
- 查询 Ensembl VEP API 以获取功能性后果
- 分类变异：错义、无义、移码、剪接位点
- 提取转录本信息和蛋白质变化
- 识别每个基因的规范转录本

步骤 3：查询 ClinVar 以获取已知致病变异
- 按基因组坐标搜索 ClinVar
- 提取临床意义分类
- 注意冲突的解释和审查状态
- 优先选择标记为“致病性”或“可能致病性”的变异

步骤 4：查询 COSMIC 以获取体细胞癌症突变
- 在 COSMIC 中搜索每个变异
- 提取不同癌症类型的突变频率
- 识别热点突变（高复发率）
- 注意耐药突变

步骤 5：从 NCBI Gene 检索基因信息
- 获取详细的基因描述
- 提取相关表型和疾病
- 识别癌基因与肿瘤抑制基因分类
- 注意基因功能和生物学通路

步骤 6：使用 UniProt 评估蛋白质水平影响
- 查询 UniProt 以获取蛋白质结构域信息
- 将变异映射到功能结构域（激酶域、结合位点）
- 检查变异是否影响活性位点或蛋白质稳定性
- 检索翻译后修饰位点

步骤 7：搜索 DrugBank 以获取可靶向的改变
- 查询靶向突变基因的药物
- 筛选 FDA 批准的和研究性药物
- 提取作用机制和适应症
- 优先选择具有已批准靶向疗法的变异

步骤 8：查询 Open Targets 以获取靶点-疾病关联
- 验证治疗假设
- 评估靶点可及性分数
- 审查每个基因-疾病对的临床前例

步骤 9：搜索 ClinicalTrials.gov 以获取匹配试验
- 构建查询：癌症类型 + 基因名称 + 变异
- 筛选：招募中状态、II/III 期试验
- 提取试验入选标准
- 注意地理位置和联系信息

步骤 10：文献搜索以获取临床证据
- PubMed 查询：“[基因] AND [变异] AND [癌症类型]”
- 重点关注：病例报告、临床结果、耐药机制
- 提取相关预后或预测信息

步骤 11：按可操作性对变异进行分类
第 1 级：FDA 批准的该变异疗法
第 2 级：该变异有临床试验
第 3 级：在不同癌症中批准的该变异疗法
第 4 级：有生物学证据但无批准疗法

步骤 12：生成临床基因组学报告
- 关键发现的执行摘要
- 具有证据水平的可操作变异表
- 具有支持证据的治疗建议
- 具有入选信息的临床试验选项
- 基于突变谱的预后意义
- 指南参考（NCCN、ESMO、AMP/ASCO/CAP）
- 使用 clinical-reports 技能生成专业 PDF

预期输出：
- 带有临床意义的注释变异列表
- 可操作突变的分级列表
- 带有证据水平的治疗建议
- 匹配的临床试验
- 综合临床基因组学报告（PDF）
```

### 示例 4：基于基因表达的癌症亚型分类

**目标**：使用 RNA-seq 数据对乳腺癌亚型进行分类，并识别亚型特异性治疗脆弱性。

**使用技能**：
- `database-lookup` - 查询 NCBI Gene, Reactome, Open Targets
- `paper-lookup` - 在 PubMed 上搜索文献验证
- `pydeseq2` - 差异表达
- `scanpy` - 聚类和可视化
- `scikit-learn` - 机器学习分类
- `gget` - 基因数据检索
- `matplotlib` - 可视化
- `seaborn` - 热图
- `plotly` - 交互式可视化
- `scikit-survival` - 生存分析

**工作流程**：

```bash
步骤 1：加载和预处理 RNA-seq 数据
- 加载计数矩阵（基因 × 样本）
- 过滤低表达基因（平均计数 < 10）
- 使用 DESeq2 大小因子进行归一化
- 应用方差稳定转换（VST）

步骤 2：使用 PAM50 基因对样本进行分类
- 查询 NCBI Gene 以获取 PAM50 分类器基因列表
- 提取 PAM50 基因的表达值
- 在带标签的训练数据上训练随机森林分类器
- 预测亚型：Luminal A、Luminal B、HER2+、Basal、Normal-like
- 使用已发表的标记物（ESR1、PGR、ERBB2、MKI67）进行验证

步骤 3：对每个亚型执行差异表达
- 使用 PyDESeq2 将每个亚型与所有其他亚型进行比较
- 应用多重检验校正（FDR < 0.05）
- 按 log2 倍数变化过滤（|LFC| > 1.5）
- 识别亚型特异性特征基因

步骤 4：注释差异表达基因
- 查询 NCBI Gene 以获取详细注释
- 分类为癌基因、肿瘤抑制基因或其他
- 提取生物过程和分子功能术语

步骤 5：通路富集分析
- 将基因列表提交给 Reactome API
- 识别每个亚型富集的通路（p < 0.01）
- 重点关注可靶向通路（激酶信号传导、代谢）
- 比较不同亚型之间的通路概况

步骤 6：使用 Open Targets 识别治疗靶点
- 查询 Open Targets 中每个上调基因
- 按可成药性评分 > 5 筛选
- 优先选择具有临床前例的靶点
- 提取相关药物和开发阶段

步骤 7：创建全面的可视化
- 生成按亚型着色的所有样本的 UMAP 投影
- 创建 PAM50 基因在不同亚型中的热图
- 为每个亚型比较生成火山图
- 生成通路富集点图
- 创建药物靶点-通路网络图

步骤 8：文献验证
- 在 PubMed 上搜索每个预测的治疗靶点
- 查询：“[基因] AND [亚型] AND 乳腺癌 AND 治疗”
- 总结临床证据和正在进行的试验
- 注意任何报告的耐药机制

步骤 9：生成亚型特异性建议
对于每个亚型：
- 列出前 5 个差异表达基因
- 识别富集的生物学通路
- 根据脆弱性推荐治疗策略
- 引用文献中的支持证据

步骤 10：创建综合报告
- 带有置信度分数的分类结果
- 每个亚型的差异表达表格
- 通路富集摘要
- 治疗靶点建议
- 出版质量图表
- 导出为带有引用的 PDF

预期输出：
- 样本分类为分子亚型
- 亚型特异性基因特征
- 通路富集概况
- 每个亚型优先的治疗靶点
- 包含可视化和建议的科学报告
```

## 单细胞转录组学

### 示例 5：肿瘤微环境的单细胞图谱

**目标**：表征肿瘤微环境中的免疫细胞群，并识别免疫治疗生物标志物。

**使用技能**：
- `database-lookup` - 查询 NCBI Gene 以获取细胞类型标记物
- `scanpy` - 单细胞分析
- `scvi-tools` - 批次校正和整合
- `cellxgene-census` - 参考数据
- `gget` - 基因数据检索
- `anndata` - 数据结构
- `arboreto` - 基因调控网络
- `pytorch-lightning` - 深度学习
- `matplotlib` - 可视化
- `plotly` - 交互式可视化
- `statistical-analysis` - 假设检验
- `geniml` - 基因组机器学习嵌入

**工作流程**：

```bash
步骤 1：加载和 QC 10X Genomics 数据
- 使用 Scanpy 读取 10X h5 文件
- 计算 QC 指标：n_genes、n_counts、pct_mitochondrial
- 识别线粒体基因（MT- 前缀）
- 筛选细胞：200 < n_genes < 5000，pct_mt < 20%
- 筛选基因：至少在 10 个细胞中表达
- 记录筛选标准和细胞保留率

步骤 2：归一化并识别高变基因
- 将每个细胞归一化为 10,000 个计数
- 对数据进行对数转换（log1p）
- 将原始计数存储在 adata.raw 中
- 识别 3,000 个高变基因
- 回归技术变异（n_counts、pct_mt）
- 缩放到单位方差，裁剪到 10 个标准差

步骤 3：使用 scVI 与参考图谱整合
- 从 Cellxgene Census 下载参考肿瘤微环境数据
- 在组合数据集上训练 scVI 模型以进行批次校正
- 使用 scVI 潜在表示进行下游分析
- 生成批次校正后的表达矩阵

步骤 4：降维和聚类
- 计算邻域图（n_neighbors=15，n_pcs=50）
- 计算 UMAP 嵌入以进行可视化
- 以多个分辨率（0.3、0.5、0.8）执行 Leiden 聚类
- 根据剪影分数选择最佳分辨率

步骤 5：识别细胞类型标记物
- 对每个簇运行差异表达（Wilcoxon 检验）
- 计算标记物分数（log 倍数变化、p 值、表达百分比）
- 查询 NCBI Gene 以获取规范免疫细胞标记物：
  * T 细胞：CD3D、CD3E、CD4、CD8A
  * B 细胞：CD19、MS4A1 (CD20)、CD79A
  * 髓系细胞：CD14、CD68、CD163
  * NK 细胞：NKG7、GNLY、NCAM1
  * 树突状细胞：CD1C、CLEC9A、LILRA4

步骤 6：注释细胞类型
```

## 化学安全性与毒理学

### 示例 7：预测毒理学评估

**目标**：在合成前评估候选药物的潜在毒性和安全风险。

**使用技能**：
- `database-lookup` - 查询 ChEMBL, PubChem, DrugBank, FDA, HMDB

- `medchem` - 毒性基团检测
- `deepchem` - 毒性预测
- `pytdc` - 治疗数据共享
- `scikit-learn` - 分类模型
- `shap` - 模型可解释性
- `clinical-reports` - 安全性评估报告

**工作流程**：

```bash
步骤 1：计算分子描述符
- 使用 RDKit 加载候选分子
- 计算理化性质：
  * MW、LogP、TPSA、可旋转键、氢键供体/受体
  * 芳香环、sp3 杂化分数、形式电荷
- 计算结构警报：
  * PAINS 模式
  * 有毒官能团（硝基芳香族化合物、环氧化物等）
  * 遗传毒性警报（Ames 诱变性）

步骤 2：筛选已知毒性基团
- 使用 SMARTS 模式搜索结构警报：
  * 迈克尔受体
  * 醛/酮反应性
  * 醌和醌样结构
  * 硫脲和异氰酸酯
- 标记具有高风险子结构的分子

步骤 3：查询 ChEMBL 以获取具有毒性数据的类似化合物
- 执行相似性搜索（Tanimoto > 0.7）
- 提取毒性测定结果：
  * 细胞毒性（IC50 值）
  * 肝毒性标记物
  * 心脏毒性（hERG 抑制）
  * 遗传毒性（Ames 试验结果）
- 分析结构-毒性关系

步骤 4：搜索 PubChem BioAssays 以获取毒性筛选数据
- 查询相关测定：
  * Tox21 组（细胞活力、应激反应、遗传毒性）
  * 肝毒性测定
  * hERG 通道抑制
- 提取类似化合物的活性数据
- 计算关注测定的命中率

步骤 5：使用 DeepChem 训练毒性预测模型
- 从 DeepChem 加载 Tox21 数据集
- 训练图卷积模型以预测：
  * 核受体信号传导
  * 应激反应通路
  * 遗传毒性终点
- 使用交叉验证验证模型
- 预测候选分子的毒性

步骤 6：预测 hERG 心脏毒性风险
- 在 ChEMBL 的 hERG 抑制数据上训练 DeepChem 模型
- 预测 hERG 通道的 IC50
- 标记预测 IC50 < 10 μM 的化合物
- 识别与 hERG 风险相关的结构特征

步骤 7：预测肝毒性风险
- 在 DILI（药物性肝损伤）数据集上训练模型

- 预测肝毒性风险等级（低/中/高）
- 使用 SHAP 值解释预测

步骤 8：预测代谢稳定性和代谢物
- 使用 RDKit SMARTS 模式识别代谢位点
- 预测 CYP450 相互作用
- 查询 HMDB 以获取潜在代谢物结构
- 评估代谢物是否含有毒性子结构
- 预测代谢稳定性（半衰期）

步骤 9：检查 FDA 不良事件数据库
- 查询 FAERS 中与候选物相似的已批准药物
- 提取常见不良事件
- 识别靶器官毒性
- 计算严重事件的报告优势比

步骤 10：毒性机制的文献综述
- PubMed 搜索：“[骨架] AND (毒性 OR 肝毒性 OR 心脏毒性)”
- 识别类似化合物的机制研究
- 注意任何不良事件的病例报告
- 审查临床前和临床安全性数据

步骤 11：评估 ADME 风险
- 预测溶解度、渗透性、血浆蛋白结合
- 识别潜在的药物-药物相互作用风险
- 评估血脑屏障渗透（对于 CNS 或非 CNS 药物）
- 评估代谢稳定性

步骤 12：生成安全性评估报告
- 每个候选物的安全性概况执行摘要
- 红旗：结构警报、预测毒性
- 黄旗：需要测试的中度关注
- 绿灯：可接受的预测安全性概况
- 所有候选物的比较表
- 风险缓解建议：
  * 结构修饰以降低毒性
  * 优先进行的体外测定
  * 临床前研究设计建议
- 综合 PDF 报告，包含：
  * 毒性基团分析
  * 带有置信度的预测模型结果
  * SHAP 解释图
  * 文献证据
  * 风险评估矩阵

预期输出：
- 所有候选物的毒性预测
- 结构警报分析
- hERG、肝毒性和遗传毒性风险评分
- 代谢物预测
- 带有安全性排名的优先列表
- 综合毒理学评估报告
```

## 代谢组学与系统生物学

### 示例 9：代谢疾病的多组学整合

**目标**：整合转录组学、蛋白质组学和代谢组学，以识别代谢疾病中失调的通路。

**使用技能**：
- `database-lookup` - 查询 HMDB, Metabolomics Workbench, KEGG, Reactome, STRING
- `pydeseq2` - RNA-seq 分析
- `pyopenms` - 质谱
- `matchms` - 质谱匹配
- `cobrapy` - 基于约束的代谢建模
- `statsmodels` - 多组学关联
- `networkx` - 网络分析
- `pymc` - 贝叶斯建模
- `plotly` - 交互式网络可视化

**工作流程**：

```bash
步骤 1：处理 RNA-seq 数据
- 加载基因计数矩阵
- 使用 PyDESeq2 运行差异表达
- 比较疾病与对照（调整 p < 0.05，|LFC| > 1）
- 提取基因符号和倍数变化
- 映射到 KEGG 基因 ID

步骤 2：处理蛋白质组学数据
- 使用 PyOpenMS 加载 LC-MS/MS 结果
- 执行肽段识别和定量
- 归一化蛋白质丰度
- 运行统计检验（t 检验或 limma）
- 提取显著蛋白质（p < 0.05，|FC| > 1.5）

步骤 3：处理代谢组学数据
- 使用 PyOpenMS 加载非靶向代谢组学数据（mzML 格式）
- 执行峰值检测和对齐
- 通过精确质量将特征与 HMDB 数据库匹配
- 用 MS/MS 碎片注释代谢物
- 提取推定的鉴定结果（2/3 级）
- 执行统计分析（FDR < 0.05，|FC| > 2）

步骤 4：搜索 Metabolomics Workbench 以获取公共数据
- 查询相同疾病或组织类型
- 下载相关研究
- 重新处理以与自身数据保持一致
- 用作验证队列
```

```bash
- QC 后保留约 500,000 个 SNP

步骤 2：评估群体结构
- 计算遗传关系矩阵
- 使用 scikit-learn 执行 PCA（使用前 10 个主成分）
- 可视化群体结构（PC1 vs PC2）
- 识别不同的亚群或混合
- 注意：将在 GWAS 中将 PC 用作协变量

步骤 3：加载和处理表型数据
- 耐旱性评分（1-10 级，在胁迫下测量）
- 谷物产量（公斤/公顷）
- 开花天数
- 株高
- 质量控制：
  * 移除异常值（偏离平均值 > 3 SD）
  * 如果需要，进行转换（对数或基于排名的倾斜性状）
  * 调整环境协变量（田地、年份）

步骤 4：计算亲缘关系矩阵
- 计算遗传相关性矩阵
- 考虑群体结构和相关性
- 将在混合线性模型中用于控制混杂因素

步骤 5：运行全基因组关联研究
- 对于每个表型，测试与每个 SNP 的关联
- 在 statsmodels 中使用混合线性模型（MLM）：
  * 固定效应：SNP 基因型、PC（前 10 个）
  * 随机效应：亲缘关系矩阵
  * Bonferroni 阈值：p < 5e-8（全基因组显著性）
- 多重检验校正：Bonferroni 或 FDR
- 计算基因组膨胀因子（λ）以检查膨胀

步骤 6：识别显著关联
- 提取通过显著性阈值的 SNP
- 确定主导 SNP（每个位点中最显著的）
- 定义位点：围绕主导 SNP 延伸 ±500 kb
- 通过条件分析识别独立关联

步骤 7：注释显著位点
- 使用 Ensembl Plants API 将 SNP 映射到基因
- 识别基因内 vs 基因间 SNP
- 对于基因内 SNP：
  * 确定后果（错义、无义、内含子、UTR）
  * 提取基因名称和描述
- 查询 NCBI Gene 以获取基因功能
- 优先选择在胁迫响应或发育中已知作用的基因

步骤 8：搜索 GWAS Catalog 以获取先前的报告
- 在 GWAS Catalog 中查询相同或相关物种中的类似性状
- 检查已知位点的复制
- 识别新型与已知关联

步骤 9：功能富集分析
- 提取显著位点内的所有基因
- 执行 GO 富集分析
- 检验 KEGG 通路中的富集
- 重点关注与以下相关的通路：
  * 干旱胁迫响应（ABA 信号、渗透调节）
  * 光合作用和碳固定
  * 根系发育

步骤 10：估计 SNP 遗传力和遗传结构
- 计算显著 SNP 解释的方差
- 估计基于 SNP 的遗传力（解释的方差比例）
- 评估遗传结构：少数大效应 vs 多数小效应位点

步骤 11：构建基因组预测模型
- 使用 scikit-learn 训练基因组选择模型：
  * 岭回归（等效于 GBLUP）
  * 弹性网络
  * 随机森林
- 使用所有 SNP（不只是显著的 SNP）
- 交叉验证以预测育种值
- 评估预测准确性

步骤 12：生成 GWAS 报告
- 每个性状的曼哈顿图
- QQ 图以评估检验校准
- 显著位点的区域关联图
- 叠加在位点上的基因模型
- 带有注释的显著 SNP 表
- 功能富集结果
- 基因组预测准确性
- 生物学解释：
  * 耐旱性候选基因
  * 潜在分子机制
  * 对育种计划的影响
- 建议：
  * 用于标记辅助选择的 SNP
  * 用于功能验证的基因
  * 用于生成作图群体的杂交组合
- 导出包含所有结果的出版质量 PDF

预期输出：
- 显著的 SNP-性状关联
- 注释的候选基因
- 功能富集分析
- 基因组预测模型
- 综合 GWAS 报告
- 育种计划建议
```

## 神经科学与脑成像

### 示例 14：fMRI 数据的脑连接分析

**目标**：分析静息态 fMRI 数据，以识别疾病中改变的脑连接模式。

**使用技能**：
- `neurokit2` - 神经生理信号处理
- `neuropixels-analysis` - 神经数据分析
- `scikit-learn` - 分类和聚类
- `networkx` - 图论分析
- `statsmodels` - 统计检验
- `statistical-analysis` - 假设检验
- `torch-geometric` - 图神经网络
- `pymc` - 贝叶斯建模
- `matplotlib` - 脑可视化
- `seaborn` - 连接矩阵
- `plotly` - 交互式脑网络

**工作流程**：

```bash
步骤 1：加载和预处理 fMRI 数据
# 注意：对于 fMRI 特定的预处理，请使用 nilearn 或类似工具
- 加载 4D fMRI 图像（BOLD 信号）
- 预处理：
  * 运动校正（重新对齐）
  * 切片时间校正
  * 空间归一化到 MNI 空间
  * 平滑（6mm FWHM 高斯核）
  * 时间滤波（0.01-0.1 Hz 带通）
  * 干扰回归（运动、CSF、白质）

步骤 2：定义大脑区域（分区）
- 应用大脑图谱（例如，AAL、Schaefer 200 区域图谱）
- 提取每个区域的平均时间序列
- 结果：每个受试者 200 个时间序列（每个大脑区域一个）

步骤 3：使用 NeuroKit2 进行信号清理
- 去噪时间序列
- 移除生理伪影
- 如果需要，应用额外的带通滤波
- 识别和处理异常时间点

步骤 4：计算功能连接
- 计算所有区域之间的成对 Pearson 关联
- 结果：每个受试者 200×200 连接矩阵
- 对相关性进行 Fisher z 变换以进行组统计
- 阈值弱连接（|r| < 0.2）

步骤 5：使用 NetworkX 进行图论分析
- 将连接矩阵转换为图
- 计算全局网络指标：
  * 聚类系数（局部连接性）
  * 路径长度（整合）
  * 小世界性（分离和整合的平衡）
  * 模块化（社区结构）
- 计算节点级别指标：
  * 度中心性
  * 介数中心性
  * 特征向量中心性
  * 参与系数（模块间连接性）

步骤 6：组间统计比较
- 比较患者与健康对照
- 使用 statsmodels 进行组间比较：
  * 连接边缘的配对或非配对 t 检验
  * 对所有边缘进行多重比较的 FDR 校正
  * 识别连接显著不同的边缘
- 比较全局和节点级别的网络指标
- 计算效应量（Cohen's d）

步骤 7：识别改变的子网络
- 阈值统计图（FDR < 0.05）
- 识别改变连接的簇
- 映射到功能性脑网络：
  * 默认模式网络 (DMN)
  * 显著性网络 (SN)
  * 中央执行网络 (CEN)
  * 感觉运动网络
- 在大脑表面可视化改变的连接

步骤 8：机器学习分类
- 训练分类器以区分患者与对照
- 使用 scikit-learn 随机森林或 SVM
- 特征：连接值或网络指标
- 交叉验证（10 折）
- 计算准确率、敏感性、特异性、AUC
- 识别最具区分性的特征（连接边缘）

步骤 9：使用 Torch Geometric 进行图神经网络分析
- 构建图神经网络（GCN 或 GAT）
- 输入：连接矩阵作为邻接矩阵
- 训练以预测诊断
- 提取学习到的表示
- 可视化潜在空间（UMAP）
- 解释哪些大脑区域最重要

步骤 10：使用 PyMC 进行贝叶斯网络建模
- 构建大脑网络的有向图模型
- 估计有效连接（方向性影响）
- 整合关于解剖连接的先验知识
- 执行后验推断
- 识别疾病中的关键驱动区域

步骤 11：临床关联分析
- 将网络指标与临床评分相关联：
  * 症状严重程度
  * 认知表现
  * 治疗响应
- 使用 Spearman 或 Pearson 关联
- 识别脑-行为关系

步骤 12：生成综合神经影像报告
- 脑连接矩阵（患者与对照）
- 大脑表面上的统计比较图
- 网络指标比较条形图
- 图可视化（圆形或力导向布局）
- 机器学习 ROC 曲线
- 脑-行为关联图
- 临床解释：
  * 哪些网络被破坏？
  * 与症状的关系
  * 潜在的生物标志物效用
- 建议：
  * 用于治疗靶向的大脑区域（TMS、DBS）
  * 作为治疗响应预测因子的网络指标
- 导出包含大脑可视化的出版就绪 PDF

预期输出：
- 所有受试者的功能连接矩阵
- 改变连接的统计图
- 图论指标
- 机器学习分类模型
- 脑-行为关联
- 综合神经影像报告
```

## 环境微生物学

### 示例 15：环境样本的宏基因组分析

**目标**：表征环境 DNA 样本中的微生物群落组成和功能潜力。

**使用技能**：
- `database-lookup` - 查询 ENA, GEO, UniProt, KEGG
- `biopython` - 序列处理
- `pysam` - BAM 文件处理
- `etetoolkit` - 系统发育树
- `scikit-bio` - 微生物生态学
- `networkx` - 共现网络
- `statsmodels` - 多样性统计
- `statistical-analysis` - 假设检验
- `matplotlib` - 可视化
- `plotly` - 交互式图表

**工作流程**：

```bash
步骤 1：加载和 QC 宏基因组读段
- 使用 BioPython 加载 FASTQ 文件
- 使用 FastQC 等效工具进行质量控制：
  * 移除接头和低质量碱基（Q < 20）
  * 过滤短读段（< 50 bp）
  * 移除宿主污染（如果适用）
- 如果比较样本，则子采样到均匀深度

步骤 2：分类学分类
- 使用 Kraken2 类似方法或查询 ENA 数据库
- 将读段分类到分类谱系
- 生成丰度表：
  * 行：分类群（物种或 OTU）
  * 列：样本
  * 值：读段计数或相对丰度
- 汇总到不同级别：门、纲、目、科、属、种

步骤 3：使用 scikit-bio 计算多样性指标
- Alpha 多样性（样本内）：
  * 丰富度（物种数量）
  * Shannon 熵
  * Simpson 多样性
  * Chao1 估计丰富度
- Beta 多样性（样本间）：
  * Bray-Curtis 相异性
  * 加权/非加权 UniFrac 距离
  * Jaccard 距离
- 稀疏曲线以评估采样完整性

步骤 4：群落统计比较
- 比较组间多样性（例如，污染与原始）
- 使用 statsmodels 进行：
  * Mann-Whitney 或 Kruskal-Wallis 检验（alpha 多样性）
  * PERMANOVA 用于 beta 多样性（adonis 检验）
  * LEfSe 用于差异丰度检验
- 识别在每种条件下富集或耗竭的分类群

步骤 5：使用 ETE Toolkit 构建系统发育树
- 提取 16S rRNA 序列（或标记基因）
- 对齐序列（MUSCLE/MAFFT 等效工具）
- 构建系统发育树（邻接或最大似然）
- 按样本或环境着色可视化树
- 用外群扎根树

步骤 6：共现网络分析
- 计算分类群之间的成对关联
- 使用 Spearman 关联识别共现模式
- 过滤显著关联（p < 0.01，|r| > 0.6）
- 使用 NetworkX 构建共现网络
- 识别模块（共现分类群的群落）
- 计算网络拓扑指标
- 可视化网络（节点 = 分类群，边 = 关联）

步骤 7：功能注释
- 从读段组装 contig（如果执行组装）
- 使用 Prodigal 类似工具预测基因
- 使用 UniProt 和 KEGG 注释基因
- 将蛋白质映射到 KEGG 通路
- 生成功能谱：
  * 代谢通路的丰度
  * 关键酶（硝化、反硝化、甲烷生成）
  * 抗生素抗性基因
  * 毒力因子

步骤 8：功能多样性分析
- 比较样本之间的功能谱
- 计算通路丰富度和均匀度
- 使用统计检验识别富集通路
- 将分类学与功能关联：
  * 哪些分类群有助于哪些功能？
  * 使用鸟枪法数据将功能分配给分类群

步骤 9：搜索 ENA 以获取相关环境样本
- 查询 ENA 以获取来自类似环境的宏基因组研究
- 下载并与自身样本进行比较
- 将样本置于全球微生物组多样性背景中
- 识别独特与普遍分类群

步骤 10：环境参数关联
- 将群落组成与元数据相关联：
  * 温度、pH、盐度
  * 营养物浓度（N、P）
  * 污染物水平（重金属、碳氢化合物）
- 使用 Mantel 检验关联距离矩阵
- 识别群落结构的环境驱动因素

步骤 11：生物标志物发现
- 识别与环境条件相关的分类群或通路
- 使用随机森林查找预测特征
- 验证生物标志物：
  * 敏感性和特异性
  * 跨样本交叉验证
- 提出分类群作为环境健康生物指示物

步骤 12：生成环境微生物组报告
- 分类组成条形图（按门/纲堆叠）
- Alpha 和 beta 多样性图（箱线图、PCoA）
- 带有环境背景的系统发育树
- 共现网络可视化
- 功能通路热图
- 环境关联图
- 统计比较表
- 生物学解释：
  * 主要分类群及其生态作用
  * 群落的功能潜力
  * 影响微生物组的环境因素
  * 用于监测的生物标志物分类群
- 建议：
  * 用于环境监测的生物标志物
  * 用于恢复的功能群
  * 进一步的采样或测序策略
- 导出综合 PDF 报告

预期输出：
- 所有样本的分类谱
- 多样性指标和统计比较
- 系统发育树
- 共现网络
- 功能注释和通路分析
- 综合微生物组报告
```

## 传染病研究

### 示例 16：抗菌素耐药性监测和预测

**目标**：跟踪抗菌素耐药性趋势并从基因组数据预测耐药表型。

**使用技能**：
- `database-lookup` - 查询 ENA, UniProt, NCBI Gene
- `biopython` - 序列分析
- `pysam` - 基因组组装分析
- `etetoolkit` - 系统发育分析
- `scikit-learn` - 耐药性预测
- `networkx` - 传播网络
- `statsmodels` - 趋势分析
- `statistical-analysis` - 假设检验
- `matplotlib` - 流行病学图
- `plotly` - 交互式仪表板
- `clinical-reports` - 监测报告

**工作流程**：

```bash
步骤 1：收集细菌基因组序列
- 来自医院监测项目的分离株
- 使用 BioPython 加载 FASTA 组装
- 基本 QC：
  * 评估组装质量（N50、完整性）
  * 估计基因组大小和覆盖度
  * 移除受污染的组装

步骤 2：物种鉴定和 MLST 分型
- 执行计算机 MLST（多位点序列分型）
- 提取管家基因序列
- 分配序列类型（ST）
- 将分离株分类为克隆复合体
- 识别高风险克隆（例如，ST131 大肠杆菌，ST258 肺炎克雷伯菌）

步骤 3：抗菌素耐药性 (AMR) 基因检测
- 查询 NCBI Gene 和 UniProt 以获取 AMR 基因数据库
- 筛选组装体中的耐药基因：
  * β-内酰胺酶（blaTEM、blaCTX-M、blaKPC、blaNDM）
  * 氨基糖苷类耐药性（aac、aph、ant）
  * 氟喹诺酮类耐药性（gyrA、parC 突变）
  * 粘菌素耐药性（mcr-1 到 mcr-10）
  * 外排泵
- 计算基因存在/缺失矩阵

步骤 4：耐药机制注释
- 将检测到的基因映射到耐药类别：
  * 酶修饰（例如，β-内酰胺酶）
  * 靶点修饰（例如，核糖体甲基化）
  * 靶点突变（例如，氟喹诺酮类耐药性）
  * 外排泵
- 查询 UniProt 以获取详细的机制描述
- 将基因与受影响的抗生素类别关联

步骤 5：使用 ETE Toolkit 构建系统发育树
- 提取核心基因组 SNP
- 连接 SNP 比对
- 构建最大似然树
- 用外群或中点扎根树
- 用以下信息注释树：
  * 耐药谱
  * 序列类型
  * 收集日期和地点

步骤 6：基因型-表型关联
- 将基因组数据与表型敏感性测试匹配
- 对于每种抗生素，关联：
  * 耐药基因的存在与 MIC 值
  * 靶点突变与耐药表型
- 计算遗传标记的敏感性/特异性
- 识别不一致病例（假阳性/假阴性）

步骤 7：机器学习耐药性预测
- 使用 scikit-learn 训练分类模型：
  * 特征：耐药基因的存在/缺失 + 突变
  * 目标：耐药表型（敏感/中介/耐药）
  * 模型：逻辑回归、随机森林、梯度提升
- 为每种抗生素训练单独的模型
- 交叉验证（分层 5 折）
- 计算准确率、精确度、召回率、F1 分数
- 特征重要性：哪些基因最具预测性？

步骤 8：时间趋势分析
- 追踪耐药率随时间的变化
- 使用 statsmodels 进行：
  * Mann-Kendall 趋势检验
  * Joinpoint 回归（识别变化点）
  * 预测未来耐药率（ARIMA）
- 分析每个抗生素类别的趋势
- 识别新兴耐药机制

步骤 9：传播网络推断
- 识别密切相关的分离株（< 10 个 SNP 差异）
- 使用 NetworkX 构建传播网络：
  * 节点：分离株
  * 边：推定传播链接
- 整合时间和空间数据
- 识别疫情集群
```

### 示例 17：癌症多组学数据的整合分析

**目标**：整合基因组学、转录组学、蛋白质组学和临床数据，以识别癌症亚型和治疗策略。

```bash
- 在 UMAP 空间中可视化聚类

- Log-rank 检验显著性

  * 协变量：亚型、分期、年龄、治疗

- 识别预后亚型

步骤 11：预测治疗响应
```

**目标**：分析粒子探测器实验数据，以识别信号事件并测量物理常数。

```bash

  * 量能器中的能量沉积
  * 径迹探测器中的粒子轨迹

步骤 3：事件重建

- 计算事件权重以进行修正

步骤 5：背景估计

  * 宇宙射线
  * 束流相关背景

  * 物理背景（非信号过程）
- 使用蒙特卡洛模拟背景（如果可用）
- 在控制区域从数据中估计背景

步骤 6：信号提取

- 使用 scipy 进行似然拟合：
  * 信号模型：高斯或 Breit-Wigner
  * 背景模型：多项式或指数
  * 结合最大似然拟合

- 估计系统不确定性

- 使用 ROC 曲线优化选择标准
- 计算信号效率和背景抑制率

步骤 8：用于触发优化的强化学习
- 使用 Stable-Baselines3 优化触发阈值
- 环境：探测器模拟器
- 动作：调整触发阈值
- 奖励：最大化信号效率同时控制速率
- 训练 PPO 或 SAC 智能体
- 在真实数据上验证
```

## 化学工程与过程优化

### 示例 19：化学反应器设计和操作的优化

**目标**：设计和优化连续化学反应器，以在满足安全和经济约束的同时实现最大产量和效率。

**使用技能**：
- `sympy` - 符号方程和反应动力学
- `statistical-analysis` - 数值分析
- `pymoo` - 多目标优化
- `simpy` - 过程仿真
- `pymc` - 贝叶斯参数估计
- `scikit-learn` - 过程建模
- `stable-baselines3` - 实时控制优化
- `matplotlib` - 过程图
- `plotly` - 交互式过程可视化
- `fluidsim` - 流体动力学仿真
- `scientific-writing` - 工程报告
- `pdf` - 技术文档

**工作流程**：

```bash
步骤 1：定义反应系统和动力学
- 化学反应：A + B → C + D
- 使用 Sympy 定义符号速率方程：
  * 阿伦尼乌斯方程：k = A × exp(-Ea/RT)
  * 速率定律：r = k × [A]^α × [B]^β
- 符号定义物料和能量平衡
- 包括平衡常数和热力学
- 考虑副反应和副产品

步骤 2：开发反应器模型
- 选择反应器类型：CSTR、PFR、间歇式或半间歇式
- 编写守恒方程：
  * 质量平衡：dC/dt = (F_in × C_in - F_out × C)/V + r
  * 能量平衡：ρCp × dT/dt = Q - ΔH_rxn × r × V
  * 动量平衡（压降）
- 包括传热关联式
- 模拟混合和传质限制

步骤 3：使用 PyMC 进行参数估计
- 从中试反应器加载实验数据
- 贝叶斯推断估计动力学参数：
  * 指前因子 (A)
  * 活化能 (Ea)
  * 反应级数 (α, β)
- 使用 PyMC 进行 MCMC 采样
- 整合文献中的先验知识
- 计算后验分布和可信区间
- 评估参数不确定性和关联

步骤 4：模型验证
- 使用 scipy.integrate 模拟带有估计参数的反应器
- 将预测与实验数据进行比较
- 计算拟合优度（R²、RMSE）
- 执行敏感性分析：
  * 哪些参数对产量影响最大？
  * 识别关键操作条件
- 如有需要，完善模型

步骤 5：机器学习代理模型
- 使用 scikit-learn 训练快速代理模型
- 从详细模型生成训练数据（1000+ 次运行）
- 特征：T、P、停留时间、进料组成、催化剂负载
- 目标：产量、选择性、转化率
- 模型：高斯过程回归、随机森林
- 验证代理模型准确性（R² > 0.95）
- 用于快速优化

步骤 6：单目标优化
- 使用 scipy.optimize 最大化产量：
  * 决策变量：T、P、进料比、停留时间
  * 目标：最大化 Y = (生成 C 的摩尔数) / (进料 A 的摩尔数)
  * 约束：
    - 温度：300 K ≤ T ≤ 500 K（安全）
    - 压力：1 bar ≤ P ≤ 50 bar（设备限制）
    - 停留时间：1 min ≤ τ ≤ 60 min
    - 转化率：X_A ≥ 90%
- 使用序列二次规划 (SLSQP)
- 识别最佳操作点

步骤 7：使用 PyMOO 进行多目标优化
- 竞争目标：
  1. 最大化产品产量
  2. 最小化能源消耗（加热/冷却）
  3. 最小化运营成本（原材料、公用设施）
  4. 最大化反应器生产率（吞吐量）
- 约束：
  - 安全：温度和压力限制
  - 环境：废物产生限制
  - 经济：最低盈利能力
- 运行 NSGA-II 或 NSGA-III
- 生成最优解的帕累托前沿
- 根据偏好选择操作点

步骤 8：使用 SimPy 进行动态过程仿真
- 模拟完整工厂：
  * 反应器、分离器、换热器
  * 泵、压缩机、阀门
  * 储罐和缓冲罐
- 模拟启动、稳态和停车
- 包括扰动：
  * 进料组成变化
  * 设备故障
  * 需求波动
- 评估动态稳定性
- 计算达到稳态的时间
```
