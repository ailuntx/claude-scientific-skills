# 支持我们所依赖的开源项目

Claude Scientific Skills 建立在巨人的肩膀上。本仓库中的 139 项技能利用了全球开发者社区和研究机构创建维护的数十个卓越开源项目。

**如果您从这些技能中获益，请考虑支持使其成为可能的底层开源项目。**

---

## 如何支持开源

1. **在 GitHub 上点亮星标** - 完全免费，帮助项目获得曝光
2. **通过 GitHub Sponsors、Open Collective 或项目专属捐赠页面直接赞助维护者**
3. **贡献**代码、文档或错误报告
4. 在您的出版物中**引用**项目
5. 向同事**分享**项目
