# 科学技能

## 科学数据库与数据访问

- **数据库查找** - 通过REST API搜索78个公共科学、生物医学、材料科学和经济学数据库，并返回结构化JSON结果。涵盖物理/天文学（NASA、NIST、SDSS、SIMBAD、系外行星档案）、地球/环境（USGS、NOAA、EPA、OpenWeatherMap）、化学/药物（PubChem、ChEMBL、DrugBank、FDA、KEGG、DailyMed、ZINC、BindingDB）、材料科学（Materials Project、COD）、生物学/基因组学（Reactome、BRENDA、UniProt、STRING、Ensembl、NCBI Gene、GEO、GTEx、PDB、AlphaFold、InterPro、ChEBI、BioGRID、基因本体论、QuickGO、NCBI Protein/Taxonomy、dbSNP、SRA、ENA、gnomAD、UCSC Genome、ENCODE、JASPAR、MouseMine、PRIDE、LINCS L1000、人类蛋白质图谱、人类细胞图谱、RummaGEO、代谢组学工作台、EMDB、Addgene）、疾病/临床（COSMIC、Open Targets、ClinPGx、ClinicalTrials.gov、OMIM、ClinVar、GDC/TCGA、cBioPortal、DisGeNET、GWAS Catalog、Monarch、HPO）、监管（FDA、USPTO、SEC EDGAR）、经济学/金融（FRED、BEA、BLS、美联储、世界银行、欧洲央行、美国财政部、Alpha Vantage、Data Commons）和人口统计学（美国人口普查局、欧盟统计局、WHO）。当用户想要查找化合物、药物、蛋白质、基因、通路、酶、基因表达、变异、临床试验、专利、SEC文件、经济指标、晶体结构、天文对象、地震、天气或任何公共数据库API中的数据时，请使用此技能
- **DepMap** - 查询癌症依赖性图谱（DepMap）以获取癌细胞系基因依赖性评分（CRISPR Chronos）、药物敏感性数据和基因效应谱。用于识别癌症特异性脆弱性、合成致死相互作用以及验证肿瘤药物靶点
- **影像数据共享** - 使用idc-index查询并从NCI影像数据共享（Imaging Data Commons）下载公共癌症影像数据。用于访问大规模放射学（CT、MR、PET）和病理学数据集，用于AI训练或研究。无需身份验证。按元数据查询，在浏览器中可视化，检查许可证
- **PrimeKG** - 查询精准医学知识图谱（PrimeKG）以获取多尺度生物学数据，包括基因、药物、疾病、表型等。将20多个生物医学资源整合到一个知识图谱中，用于药物重定位、疾病机制探索和靶点识别
- **美国财政部财政数据** - 美国财政部提供的免费、开放REST API，提供54个数据集和182个数据表，涵盖联邦财政数据。无需API密钥。访问国债（精确到美分的债务回溯至1993年，历史债务回溯至1790年）、每日财政部报表（TGA余额、存款/取款）、月度财政部报表（联邦预算收入和支出）、国债证券拍卖数据（自1979年起的票据、债券、通胀保值债券、浮动利率票据）、国债证券平均利率、财政部报告汇率（每季度170多种货币）、储蓄债券利率、TIPS/CPI数据等。支持过滤、排序、分页以及CSV/XML/JSON输出格式

## 科学集成

### 实验室信息管理系统（LIMS）与研发平台
- **Benchling集成** - 用于与Benchling研发平台集成的工具包，提供对实验室数据管理的编程访问，包括注册实体（DNA序列、蛋白质）、库存系统（样本、容器、位置）、电子实验笔记本（条目、协议）、工作流（任务、自动化）以及使用Python SDK和REST API的数据导出

### 基因组学与生物医学数据云平台
- **DNAnexus集成** - 用于在DNAnexus云平台上进行基因组学和生物医学数据分析的综合工具包。涵盖构建和部署应用/小程序（Python/Bash）、管理数据对象（文件、记录、数据库）、运行分析和工作流、使用dxpy Python SDK、配置应用元数据和依赖项（dxapp.json设置、系统包、Docker、资产）。支持处理FASTQ/BAM/VCF文件、生物信息学流水线、作业执行、工作流编排以及包括项目管理和权限在内的平台操作

### 实验室自动化
- **Opentrons集成** - 用于创建、编辑和调试Opentrons Python Protocol API v2协议的工具包，适用于Flex和OT-2机器人的实验室自动化。实现自动液体处理、移液工作流、硬件模块控制（热循环仪、温度模块、磁力模块、加热振荡器、吸光度板阅读器）、实验室器具管理以及用于生物和化学实验的复杂协议开发
- **Ginkgo Cloud Lab** - 在Ginkgo Bioworks云实验室（cloud.ginkgo.bio）提交和管理协议，这是一个基于Web的界面，用于在可重构自动化推车（RAC）上自主执行实验。支持三种协议：无细胞蛋白质表达验证（39美元/样本，5-10天周转时间）、无细胞蛋白质表达优化（199美元/样本，在24个条件下进行实验设计，6-11天）和荧光像素艺术生成（25美元/板，使用11种荧光大肠杆菌菌株的细菌艺术作品，5-7天）。包括用于自定义协议可行性和定价的EstiMate AI代理

### 电子实验笔记本（ELN）
- **LabArchives集成** - 用于与LabArchives电子实验笔记本（ELN）REST API交互的工具包。提供对笔记本（备份、检索、管理）、条目（创建、评论、附件）、用户身份验证、站点报告和分析以及第三方集成（Protocols.io、GraphPad Prism、SnapGene、Geneious、Jupyter、REDCap）的编程访问。包括用于配置设置、笔记本操作和条目管理的Python脚本。支持多区域API端点（美国、英国、澳大利亚）和OAuth认证
- **开放式笔记本** - 自托管的开源替代方案，替代Google NotebookLM，用于AI驱动的研究和文档分析。将研究材料组织到笔记本中，摄入多种内容来源（PDF、视频、音频、网页、Office文档），生成AI驱动的笔记和摘要，从研究中创建多说话人播客，实现具有上下文感知AI的文档对话，并通过全文和向量搜索跨材料搜索。支持16个以上AI提供商，包括OpenAI、Anthropic、Google、Ollama、Groq和Mistral，通过自托管实现完全的数据隐私

### 工作流平台与云执行
- **LatchBio集成** - 与Latch平台集成，用于构建、部署和执行生物信息学工作流。提供对使用Python装饰器创建无服务器生物信息学流水线、部署Nextflow/Snakemake流水线、管理云数据（LatchFile、LatchDir）和结构化注册表（项目、表、记录）、配置计算资源（CPU、GPU、内存、存储）以及使用预构建的Latch验证工作流（RNA-seq、AlphaFold、DESeq2、单细胞分析、CRISPR编辑）的全面支持。实现自动容器化、UI生成、工作流版本控制以及在可扩展云基础设施上执行，并具有全面的数据管理能力

### 显微镜与生物图像数据
- **OMERO集成** - 用于使用Python与OMERO显微镜数据管理系统交互的工具包。提供对存储在OMERO服务器中的显微镜图像的全面访问，包括数据集和筛选数据检索、像素数据分析、注释和元数据管理、感兴趣区域（ROI）的创建和分析、批处理、OMERO.scripts开发以及用于结构化数据存储的OMERO.tables。对于处理高内涵筛选数据、多维显微镜数据集或协作图像库的研究人员至关重要

### 协议管理与共享
- **Protocols.io集成** - 与protocols.io API集成，用于管理科学协议。实现对协议发现（按关键词、DOI、类别搜索）、协议生命周期管理（创建、更新、发布并分配DOI）、逐步过程文档、使用工作区和讨论的协作开发、文件管理（上传数据、图像、文档）、实验跟踪和文档记录以及数据导出的编程访问。支持OAuth认证、协议PDF生成、材料管理、线程评论、工作区权限和机构协议库。对于协议标准化、可重复性、实验室知识管理和科学协作至关重要

## 科学软件包

### 生物信息学与基因组学
- **AnnData** - 用于处理带注释数据矩阵的Python包，专为单细胞基因组学数据设计。提供对高维数据及其关联注释（观察值/细胞和变量/基因）的高效存储和操作。主要特性包括：基于HDF5的h5ad文件格式，用于高效I/O和压缩；与pandas DataFrame集成处理元数据；支持稀疏矩阵（scipy.sparse）以提高内存效率；分层数据组织（X用于主数据矩阵，obs用于观察注释，var用于变量注释，obsm/varm用于多维注释，obsp/varp用于成对矩阵）；以及与Scanpy、scvi-tools和其他单细胞分析包的无缝集成。支持惰性加载、分块操作以及与其他格式（CSV、HDF5、Zarr）之间的转换。用例：单细胞RNA-seq数据管理、多模态单细胞数据（RNA+ATAC、CITE-seq）、空间转录组学以及任何需要高效存储和操作的高维注释数据
- **Arboreto** - 用于使用集成树方法从单细胞RNA-seq数据高效推断基因调控网络（GRN）的Python包。实现了针对大规模单细胞数据集优化的GRNBoost2（基于梯度提升的网络推断）和GENIE3（基于随机森林的推断）算法。主要特性包括：并行处理以实现可扩展性、支持稀疏矩阵和大规模数据集（数百万个细胞）、与Scanpy/AnnData工作流集成、可定制的超参数以及与网络分析工具兼容的输出格式。提供潜在调控相互作用（转录因子-靶基因对）的排名列表，并附有置信度评分。用例：识别转录因子-靶标关系、从单细胞数据重建基因调控网络、理解细胞类型特异性调控程序以及推断基因表达中的因果关系
- **BioPython** - 用于计算生物学和生物信息学的综合Python库，提供序列操作、数据库访问和生物学数据分析工具。主要特性包括：序列对象（Seq、SeqRecord、SeqIO）用于DNA/RNA/蛋白质序列，带有生物学字母验证；文件格式解析器（FASTA、FASTQ、GenBank、EMBL、Swiss-Prot、PDB、SAM/BAM、VCF、GFF）；NCBI数据库访问（用于PubMed、GenBank、BLAST、分类学的Entrez编程实用程序）；BLAST集成（运行搜索、解析结果）；序列比对（成对和多序列比对，使用Bio.Align）；系统发育学（使用Bio.Phylo进行树的构建和操作）；群体遗传学（Hardy-Weinberg平衡、F统计量）；蛋白质结构分析（PDB解析、结构计算）以及统计分析工具。支持与NumPy、pandas和其他科学Python库的集成。用例：序列分析、数据库查询、系统发育分析、序列比对、文件格式转换以及通用生物信息学工作流
- **BioServices** - 提供对40多种生物学Web服务和数据库的统一编程访问的Python库。支持主要生物信息学资源，包括KEGG（通路和化合物数据）、UniProt（蛋白质序列和注释）、ChEBI（化学实体）、ChEMBL（生物活性分子）、Reactome（通路）、IntAct（蛋白质相互作用）、BioModels（生物模型）等。特点包括不同服务之间的统一API、自动结果缓存、错误处理和重试逻辑、支持REST和SOAP Web服务以及将结果转换为Python对象（字典、列表、BioPython对象）。处理认证、速率限制和API版本控制。用例：从多个生物学数据库自动检索数据、构建生物信息学流水线、数据库集成工作流以及无需手动浏览网页即可编程访问生物学Web资源
- **Cellxgene Census** - 用于查询和分析来自CZ CELLxGENE Discover普查的大规模单细胞RNA-seq数据的Python包。提供对1000多个数据集中5000多万个细胞的访问，并带有标准化注释和元数据。主要特性包括：使用TileDB-SOMA格式进行可扩展查询的高效数据访问；与AnnData和Scanpy集成进行下游分析；细胞元数据过滤和查询；基因表达检索；支持人类和小鼠数据。能够在下载前按细胞类型、组织、疾病或其他元数据进行子集划分，减少数据传输和内存需求。支持本地缓存和批量操作。用例：大规模单细胞分析、细胞类型发现、跨数据集比较、参考数据集构建以及公共单细胞数据的探索性分析
- **deepTools** - 用于探索和可视化下一代测序（NGS）数据的综合Python工具套件，特别适用于ChIP-seq、RNA-seq和ATAC-seq实验。提供命令行工具和Python API，用于处理BAM和bigWig文件。主要特性包括：质量控制指标（plotFingerprint、plotCorrelation）、覆盖度图谱生成（bamCoverage用于创建bigWig文件）、用于热图的矩阵生成（computeMatrix、plotHeatmap、plotProfile）、比较分析（multiBigwigSummary、plotPCA）以及高效处理大文件。支持归一化方法、分箱选项和各种可视化输出。专为高通量分析工作流和出版级图表生成而设计。用例：ChIP-seq峰可视化、RNA-seq覆盖度分析、ATAC-seq信号图谱、比较基因组学和NGS数据探索
- **FlowIO** - 用于读取和操作流式细胞术标准（FCS）文件的Python库，FCS是流式细胞术数据的标准格式。提供对FCS文件（2.0、3.0、3.1版）的高效解析、事件数据（荧光强度、散射参数）访问、元数据提取（关键词、参数、采集设置）以及转换为pandas DataFrame或NumPy数组。特性包括：支持大型FCS文件、处理多个数据段、访问文本段和分析段以及与流式细胞术分析工作流的集成。实现对流式细胞术数据的编程访问，用于下游分析、可视化和机器学习应用。用例：流式细胞术数据分析、高通量筛选、免疫细胞分型以及FCS文件的自动处理
- **gget** - 命令行工具和Python包，用于通过简单统一的界面高效查询基因组数据库。提供对Ensembl（基因信息、序列、直系同源物、变异）、UniProt（蛋白质序列和注释）、NCBI（BLAST搜索、基因信息）、PDB（蛋白质结构）、COSMIC（癌症突变）等数据库的快速访问。特性包括：无需复杂API设置的单命令查询、自动结果格式化、批量查询支持、与pandas DataFrame集成以及支持命令行和Python API使用。针对速度和易用性进行了优化，使没有广泛生物信息学经验的用户也能访问数据库查询。用例：快速基因查找、序列检索、变异注释、蛋白质结构访问以及生物信息学工作流中的快速数据库查询
- **geniml** - 基因组区间机器学习工具包，提供在BED文件上构建ML模型的无监督方法。关键能力包括：Region2Vec（使用分词和神经语言建模对基因组区域和区域集进行word2vec风格的嵌入）、BEDspace（使用StarSpace进行跨模态查询的区域和元数据标签联合嵌入）、scEmbed（将Region2Vec应用于单细胞ATAC-seq数据，生成细胞级嵌入用于与scanpy集成的聚类和注释）、一致峰构建（四种统计方法CC/CCF/ML/HMM，用于从BED集合创建参考宇宙）以及全面实用程序（用于BED缓存的BBClient、用于保留上下文的基因组随机化的BEDshift、嵌入质量评估指标、用于神经搜索后端的Text2BedNN）。属于BEDbase生态系统的一部分。支持Python API和CLI工作流、Hugging Face上的预训练模型以及与用于分词的gtars集成。用例：区域相似性搜索、染色质可及性数据的降维、scATAC-seq聚类和细胞类型注释、元数据感知的基因组查询、用于标准化参考的宇宙构建以及任何需要基因组区域特征向量的ML任务
- **gtars** - 高性能Rust基因组区间分析工具包，提供使用IGD（集成基因组数据库）索引进行重叠检测的专门工具、覆盖度图谱生成（uniwig模块，用于WIG/BigWig格式）、用于机器学习的基因组分词（TreeTokenizer，用于深度学习模型）、参考序列管理（符合refget协议）、单细胞基因组学的片段处理（基于条码的拆分和聚类分析）以及针对参考数据集的片段评分。提供带有NumPy集成的Python绑定、命令行工具（gtars-cli）和Rust库。关键模块包括：tokenizers（将基因组区域转换为ML标记）、overlaprs（高效重叠计算）、uniwig（ATAC-seq/ChIP-seq/RNA-seq覆盖度谱）、refget（符合GA4GH的序列摘要）、bbcache（BEDbase.org集成）、scoring（片段富集指标）和fragsplit（单细胞片段操作）。支持并行处理、内存映射文件、大数据流式处理，并作为geniml基因组ML包的基础。适用于基因组ML预处理、调控元件分析、变异注释、染色质可及性分析以及计算基因组学工作流
- **Polars-Bio** - 在Polars DataFrame上执行高性能基因组区间操作和生物信息学文件I/O。提供对BED/VCF/BAM/GFF区间的重叠、最近、合并、覆盖度、补集和减法操作。具有流式处理和云原生架构，适用于大规模基因组分析，是bioframe的更快替代方案
- **pysam** - 读取、写入和操作基因组数据文件（SAM/BAM/CRAM比对、VCF/BCF变异、FASTA/FASTQ序列），具有堆积分析、覆盖度计算和生物信息学工作流功能
- **PyDESeq2** - R包DESeq2的Python实现，用于批量RNA-seq数据的差异基因表达分析。提供使用负二项广义线性模型确定实验条件之间差异表达的统计方法。主要特性包括：用于文库大小归一化的大小因子估计、离散度估计和收缩、使用Wald检验或似然比检验进行假设检验、多重检验校正（Benjamini-Hochberg FDR）、结果过滤和排序以及与pandas DataFrame的集成。处理复杂实验设计、批次效应和重复。为每个基因生成倍数变化估计、p值和调整后p值。用例：识别条件之间的差异表达基因、RNA-seq实验分析、生物标志物发现以及需要严格统计分析基因表达研究
